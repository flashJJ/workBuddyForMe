# v2.15.0 发行说明

> 可运营：历史可清理、证据可锚定、凭证可轮换、版本可对比。

## 重点

- **技能版本清理与占用视图**：设置页技能版本面板展示「共 N 版 · 占用 X」，非启用版本可逐条删除，删除前二次确认并写入 `skill_version_deleted` 审计。删除按 `name + version` 清理全部状态行，只有当快照目录不再被任何行引用时才从磁盘移除；启用版本与唯一剩余版本硬拒绝（409）。删除后重启不复活。
- **审计区间归档与外部锚点**：审计页新增「导出归档」，按日期区间生成 ZIP（`events.jsonl` + `anchor.json`），区间上限 366 天 / 5 万事件 / 20 MB。锚点同时记录区间尾与全账本尾，可检出归档之后的尾部截断；「验证锚点」上传 JSON 返回通过 / 尾部缺失 / 哈希错位 / 链已断四种业务结果，校验只读，不写 `audit_verified`。
- **Provider 凭证轮换**：设置 → 关于（安全区块）新增「轮换凭证」。Web 主密钥升级为 keyring（`keys/master-keyring.json`，active + fallback），轮换时先解密全部可解密 Provider，再换 key、逐行重封装；坏密文计入 `skipped` 不拖垮轮换，单条失败计入 `failed` 并保留旧密文。`failed===0` 时同步旧 `master.key`，回退旧版本仍可解密。Desktop 走 safeStorage，只重新封装密文，不宣称更换 OS 密钥。轮换成功写 `secrets_rotated` 审计（仅计数，不含密钥）。
- **工作流版本对比**：版本抽屉新增基准 / 目标选择器与「开始对比」，只读展示节点新增 / 删除 / 类型变化 / 配置顶层键变化与边新增 / 删除。节点身份为 id，边身份为 `source→target→handle`，忽略坐标、viewport 与 edge id；类型变化不再重复报配置变化；相同版本显示「没有差异」。对比不改变当前 / 生产版本，不写审计。

## 迁移

- **零迁移**：`LATEST_SCHEMA_VERSION` 保持 42，不新增表 / 列 / 索引。
- 旧库直接可开；Web 主密钥文件格式升级，旧 `master.key` 作为 legacy 读入。
- 旧版本打开 v2.15 库：忽略新审计 kind 与 keyring 文件，不删除技能快照、审计账本与运行历史。
