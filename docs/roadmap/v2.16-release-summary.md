## 2. 技术要点

- **目录收拢**：按「域 > 子能力 > 文件」分区，P0 12 个目录直接文件全部 ≤12。移动批次只做 `git mv` + import 改写，测试断言零改动；根 barrel 改为子域聚合，公开导出面保持兼容。
- **公开入口**：feature 根 `index.ts` 只导出页面级组件；跨域能力走 `@/features/<feature>/<子域>`；`lib/hooks` 拆成 7 个域入口，无根 barrel。首轮 `export *` 导致 `/settings` 513 kB、`/flows/[id]` 541 kB，收紧后回到 472 / 387 kB。
- **页面请求时机**：`PanelVisibilityGate` 用 `IntersectionObserver`（`rootMargin: 200px`）在分组首次进入视口时置可见并 `disconnect`；`useVisibleQuery` 把可见态与 `enabled` 合并。设置页首屏由 29 次 GET / 22 条 distinct 路径降到 9 次 / 7 条（−68.2%），峰值并发 15→4，响应体 45,219 B→5,651 B。
- **聚合端点准入**：首屏已低于目标，剩余 7 条分属供应商、设置、全局语音与系统信息，按契约否决只读聚合端点；现有端点零改动，回退成本为 0。
- **结构门禁**：`check-structure.mjs` 检查目录预算、公开入口、跨域引用（含自身 barrel 反向导入与 `lib/server` 边界）；`check-cycles.mjs` 用 Tarjan 求 SCC，8 个存量环登记，新增即失败。两项都接入 `pnpm check`。
- **循环基线**：扫描 2028 个模块 / 7334 条边；M0 基线 9 个 SCC，M1–M4 收拢后 voice manifest 环消失，当前 8 个，无新增。
- **两个修复**：① 无 `GET /models` 的 OpenAI 兼容厂商（如火山方舟 Agent Plan）不再把 404 当致命错误，改为 `models_unsupported` 提示手动填写 Model ID；已有对话模型时用首字探活验证连接；新增 Ark / Agent Plan 预设。② 桌面端下载改为带 `X-WBFM-Token` 的请求，修复能力包示例、审计 JSONL 与时间线 ZIP 导出的 `UNAUTHORIZED`。

## 3. 数据与迁移

- 旧库直接可开；旧版本可打开 v2.16 库，忽略新增的代码结构变化。

## 6. 已知边界

- 功能行为、UI 文案、API 契约与错误码零变更；本版只改目录位置、引用入口与首屏请求时机。
- 可见区门控只在设置页 4 个分组启用；滚出视口不回收查询，面板 DOM、锚点与交互不变。
- P1 目录（backup / knowledge / tools / emotion / voice / stage / constants / i18n / desktop 主进程 / `lib/server`）与 `core/ingestion` 未分区；≥20 文件目录 24 → 12，未达到 ≤10 的目标，按 P1 非阻塞口径登记偏差（详见验收文档 §3）。
- 循环依赖只做了「无新增 + 逐域登记」，存量 8 个 SCC 未清零。
- 只读聚合端点未启用；设置页剩余请求按页面基础区与全局壳层保留。
