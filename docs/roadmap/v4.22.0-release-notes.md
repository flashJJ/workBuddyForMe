## 一句话

v4.22 把上下文装配拆成「采集 → 装包」两段纯能力，把 Flow 执行器从按序串行改为就绪集合调度：`parallelism=1` 与上一版逐字等价，显式开启并发后扇出分支真正并行，预算共享、幂等与失败隔离都可验收——零迁移。

## 新功能

### Controller Pipeline

- 新增 `packages/core/src/context/pipeline`：Source / Collector / Packer 三个纯函数模块；
- `collectContext` 并发采集所有来源，单来源失败只记 `status='failed'`，不影响其他来源；
- `packContext` 按来源优先级升序拼接、同 `key` 去重、超预算从尾部整段丢弃，仅剩一段仍超限时按 token 截断；
- 任务上下文接入五段式 pipeline，输出与 v4.21 快照逐字一致。

### Flow 并行调度

- 图 JSON 新增可选 `parallelism`（1–4，缺省 1；旧图默认串行）；
- 引擎改为就绪集合调度：前驱全部落定且活性成立才可启动；
- 可并行类型：`llm`、`knowledgeSearch`、`condition`、只读 `tool`、`end`；`human`、写/危险 `tool`、`agent`、`start` 独占运行；
- 并发 > 1 时多个成功 `end` 取拓扑序靠前者作为运行输出；
- `parallelism=1` 保留原串行代码路径，事件序列与 v4.21 完全一致。

### 并行语义

- 全运行共享一个工具轮次预算，超限分支返回 `ok:false` 而非抛错；
- 同一 `${runId}:${nodeId}` 在运行内最多执行一次；
- 失败隔离：失败节点后代级联 `skipped`（理由「上游失败」），无关分支继续，终态 `run_failed` 汇总首个失败。

### 观测

- `run_started` 新增可选 `parallelism`（实际生效值）；
- 节点完成事件补齐 `durationMs`（并行下仍为节点自身耗时）；
- 执行面板只读展示「并发 ×N」，无设置项、无新增页面。

## 改进

- 任务上下文新增来源只需注册，不再修改装配主流程；
- 单来源异常从「整体降级」变为「局部降级」，其他片段照常注入；
- 运行服务集成测试覆盖扇出图的并行执行与落库。

## 兼容性

- 零数据库迁移，备份格式与 `LATEST_SCHEMA_VERSION` 不变；
- 不新增事件类型；旧事件读取方忽略 `parallelism` 即可；
- 重放仍走串行路径，v0.9 重放语义不变；
- 回退代码即可恢复 v4.21 行为。

## 验证

- `pnpm check`：类型、Lint、行数、目录、循环依赖、MSW、框图、资产、surface、E2E 隔离全绿；
- `pnpm verify:local`：eval、perf、unit、integration、web build 全绿；
- 定向单测：collector 并发与容错、packer 排序/去重/裁剪、任务上下文等价、并行调度与失败隔离。

## 已知限制

- 仍不做跨分支数据汇聚（编译器非 end 节点单入边限制不变）；
- 并行分支之间不做完成顺序排序，事件按实际完成顺序发出；
- 治理动作使用观察与解释轨迹落盘只完成评估，未默认启用。
