## 一句话

v4.20 把「快不快」变成可复算的四段指标，给首字等待加上本机预算提示，并让 500 条长会话只挂载看得见的部分——零迁移、零新增运行时依赖。

## 新功能

### 分段指标与本地报告

- 新增冷启动、发送→首字、首段、完成四项指标，统一 `performance.mark` 打点；
- 每次性能运行写 `test-results/perf/report-<ISO>.json` 与 `latest.json`，保留最近 20 份；
- 报告不含正文、令牌与本机绝对路径，写入前复用敏感内容扫描。

### 首字预算提示

- 客户端维护最近 20 轮首字耗时 P50，阈值 = `min(P50×1.5, 10s)`；
- 超过阈值在输入区上方给一条非阻断提示，包含「停止 / 换更小模型 / 缩减上下文」三个入口；
- 每轮最多提示一次，可关闭；不自动切换模型、不自动截断上下文。

### 长会话渲染

- 首屏渲染最近 50 条，向上滚动分批加载；
- 消息数超过 200 条切换窗口化，前后各 10 条 overscan；
- 新增设置开关 `chatVirtualizationEnabled`（默认开），关闭后与 v4.19 行为一致；
- 保持吸底、回到底部、深链定位与高亮、流式追加、编辑重发与复制行为。

### 冷启动与长文本

- 非首屏模块延迟加载，冷启动指标进入本地报告；
- 1024 / 1280 / 1440 三档与长文本复核，无横向溢出与遮挡。

### 并入项

- **语音**：寒暄快路径跳过回合后记忆提取；Edge TTS 改为增量解码，边收边播；
- **回放对比**：CI 新增非阻断 `replay-compare` 任务，结果写 Job Summary，主分支缓存历史；
- **知识新建任务**：知识结果新增动作，跳 `/tasks?draft=` 预填「请基于文档《标题》继续处理：深链」，只预填不提交；
- **备用链**：上限由 3 放宽到 5，单轮切换仍最多 2 次；
- **健康度导出**：设置页健康面板支持导出 Markdown / CSV，不含正文与路径。

## 验证

- `pnpm check` 全绿；
- 单测 839 个文件 / 4689 条用例、集成 11 条、回放脚本 2 个文件通过；
- 定向 E2E：长会话、冷启动、首字提示、知识新建任务、长文本窄窗全部通过；
- 500 条会话滚动 p95 帧间隔 16.7ms（优化前 33.4ms）；
- `pnpm verify:local` 全绿。

## 兼容与迁移

- 零数据库迁移，备份格式不变；
- 仅新增本地 settings 键 `chatVirtualizationEnabled` 与 localStorage 键 `wbfm:perf:first-token-samples`；
- 关闭新开关即回到 v4.19 渲染行为。

## 未包含

- 统一记忆治理、Controller Pipeline、DAG 并行、视觉巡检 L2/L3；
- 首字超时自动降级（只提示）；
- 云端性能上报与多机基线。
