## 2. 技术要点

- **模式只作用于任务运行**：`confirm_each` / `auto_edits` / `smart_approve` / `plan_only` / `full_access` 写入 `task_runs.permission_mode`；聊天与协作仍按策略 `defaultMode`，但策略、审批、审计全量生效。
- **策略即代码**：`settings.agentPolicy` 覆盖工具 / 路径 / 域名 / 命令 / 限额；求值顺序硬拒绝 → 策略 deny → 权限 deny → 模式 → 策略 allow → 持久授权 → 询问，deny 永远优先。
- **审批绑定**：工具、参数哈希、cwd、环境哈希、文件操作数、目标窗口、策略哈希组成 `OperationBinding`；执行前重算，漂移 409 `APPROVAL_BINDING_DRIFT`。
- **审计账本**：`audit_events` 只追加，`hash = sha256(prev_hash + "\n" + canonicalJson(事件))`；校验按 seq 升序，返回首个断链；治理关键事件写入失败 fail-closed。
- **定时 Agent 双端分流**：服务端只标记 `agent_task`，渲染进程只处理提醒 / `follow_up`，避免双端抢标记丢运行；应用退出即停止。
- **隔离网页**：每个运行一个可见 `BrowserWindow` + 非持久 session 分区；协议、私网字面量与域名规则逐次复核，禁下载 / 弹窗 / 新窗口。

## 3. 数据与迁移

- `LATEST_SCHEMA_VERSION = 41`；v041 纯加法：`task_runs` 四列 + `audit_events` 表与三个索引。
- 旧库升级默认 `confirm_each`，审计表为空可直接写；回退旧版本忽略新列 / 新表，不删除审计数据。
- 策略与信任配置仍存 settings JSON；审计独立表，便于哈希链和导出。

## 6. 已知边界

- 定时 Agent 只在应用进程存活时触发，不补跑 / 不重试；窗口全关时审批超时按拒绝。
- 审计账本不自动清理；尾部截断不可检出（需外部锚点）。
- 运行时外部调用限额按 MCP / `fetch_webpage` 粗分；浏览器工具已纳入同一计数。
- 隔离网页仅桌面端，Web 模式降级；重定向未做二次 DNS 私网解析。
- 技能 / 工作流版本化、运行记录下钻仍为 P1。
