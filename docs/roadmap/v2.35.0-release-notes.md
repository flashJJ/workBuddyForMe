# v2.35.0 发行说明

> 主题：**回归修复与朗读——把 v2.25 欠下的修复补齐，并给会话加一个朗读入口**
> 发布：已合入 main · tag `v2.35.0`
> 数据库：零迁移，`LATEST_SCHEMA_VERSION = 51`
> 备份格式：schema v9 不变
> 分支：`feat/v2.35-release-fixes`（已合入）+ `fix/v2.25-citations-and-search-tuning`（补合入）

## 一、核心功能更新

### 1. 会话朗读

- 输入框底部工具条新增喇叭按钮，朗读**最新一条助手回复**，再次点击取消；
- 复用 `/api/voice/tts` 与对话内唯一的播放队列，不新开音频通道，自动朗读与手动朗读互斥；
- 合成前清理 Markdown：去掉标记符号、跳过代码块与表格分隔行，避免把 `**`、`|` 念出来；
- TTS 单次上限 2000 字，长回复按句子切块（每块 ≤1800 字）顺序合成、顺序排队播放；
- 声线跟随当前角色的 `avatarModelId`（与自动朗读同一套 `AVATAR_TTS_VOICES` 绑定），口型联动沿用现有音频电平；
- 合成中显示转圈、播放中变为停止；语音模型未就绪、没有可朗读回复时按钮禁用并给出提示；
- 切换会话或离开页面时中止请求并清空队列，避免串话。

### 2. PTT 识别先入草稿，模型润色后再发送（补合入 v2.25）

- 按住说话结束后，识别文本写入输入框并聚焦，由用户确认后发送；免手 VAD 仍保持自动发送；
- 原文零延迟落草稿，后台调用新增的 `POST /api/voice/polish` 用默认模型润色，返回后仅在原文片段仍存在时替换，不覆盖用户中途编辑；
- 无可用模型或超时则保留原文（`polished: false`），不阻断输入；
- 麦克风在润色进行中显示转圈。

### 3. SearXNG 引擎按网络自动调优（补合入 v2.25）

- 启动托管容器后逐个探测引擎可用性，被墙、超时、验证码统一判为不可用并禁用；
- 设置页搜索面板展示本次探测禁用的引擎与原因，可重新测试连接；
- 配置目录与容器名统一由 `searxng-tuning` 模块管理，减少 IPC 层重复逻辑。

## 二、重要特性优化

- **引用折叠**：默认折叠态由引用条数实时推导，流式回复从 2 条涨到 6 条时自动收起；用户手动展开后不再被后续增长重置。
- **舞台渲染**：`autoUpdate` 改为差量写入，只有动画档位真正变化时才触达第三方 setter。
- **舞台加载**：新增 `loading` 守卫与每次加载自增 token，加载在途时不再重复发起；待机定时器保持单链。
- **代码结构**：会话重命名/删除抽为 `use-conversation-actions`，`chat-page` 回落到 300 行以内；语音润色归入 `packages/core/src/chat/context/voice/` 子域，满足目录文件数预算。

## 三、问题修复列表

1. **全屏舞台拖动一次后动画失速**：`pixi-live2d-display` 的 `autoUpdate` setter 不去重，每赋一次 `true` 就再注册一次 `Ticker.shared` 回调；拖动时每个 `pointermove` 都会重渲染并调用 `update()`，ticker 回调成倍叠加，表现为动作按倍数加速。改为记录 `appliedAutoUpdate` 差量写入。
2. **同一位置重复加载模型**：模型未就绪期间每个 `update()` 都发起一次 `load()`，多个加载共用同一 token 全部通过校验，导致同一角色被重复挂载并叠加多条待机定时器链；新增加载守卫与自增 token 后只保留最后一次。
3. **引用超过 3 条不折叠**：`expanded` 只在挂载时初始化，流式阶段先 0 条挂载、引用后到涨到 6 条时状态不会重新同步；改为 `override ?? !collapsible`，默认态随条数变化。
4. **手动展开被重置**：早期方案在条数变化时强制回到折叠态，覆盖用户操作；改为只有用户点击开关才固定状态。
5. **v2.25 修复从未合入 main**：`fix/v2.25-citations-and-search-tuning` 未发 PR、未打 tag，后续 v2.26–v2.34 全部从 main 切出，导致上述两个修复连续 9 个版本未生效；本次整条分支合入，并在 `docs/development.md` 补充分支纪律。

## 四、兼容性变更说明

- **数据库**：零迁移，`LATEST_SCHEMA_VERSION` 保持 51；备份 schema 保持 9，旧归档无需重打包。
- **接口**：新增 `POST /api/voice/polish`（请求 `{ text }`，返回 `{ text, polished }`）；`/api/voice/tts` 契约不变。
- **输入行为**：按下说话的识别结果不再直接发送，改为写入草稿等待确认；免手模式不受影响。
- **引用展示**：超过 3 条来源默认折叠，可通过「展开全部」查看；该阈值与文案沿用既有 `citations.*` 键。
- **搜索**：SearXNG 托管模式下启动即做引擎探测，可能禁用部分引擎，属预期行为。

## 五、升级注意事项

1. **朗读依赖本地 TTS 模型**：未下载时按钮禁用，请先在设置页完成语音模型下载。
2. **音色随角色变化**：朗读使用当前助手的形象绑定声线；切换形象后同一个按钮的音色会变。
3. **长回复分块合成**：按句分块，块间有极短间隙；取消会中止当前请求并清空未播队列。
4. **PTT 习惯变化**：说完后请确认草稿再发送；如希望说完即发，请使用免手（VAD）模式。
5. **分支纪律（新增规范）**：每个版本必须从已合入上一版本的最新 main 切出；合入前执行 `git branch -a --no-merged main`，结果必须为空。
