# v4.18.0 发行说明

> 主题：**稳、找得到、可评测——故障可恢复、内容可跨域找到、策略可离线复算**
> 发布：tag `v4.18.0`；GitHub Release 由发布流水线构建草稿，核对后转正（2026-11-22）
> 覆盖版本：v4.18（A 稳 + C 找得到 + E 可评测三条线）
> 数据库：无新增迁移，`LATEST_SCHEMA_VERSION` 不变；备份格式不变
> 安装包：由 Release workflow 构建并上传 `WorkBuddyForMe-Setup-4.18.0.exe`

## 一、核心功能更新

### 1. 模型故障可恢复

- 新增统一失败分类：`auth_failed`、`rate_limited`、`timeout`、`stream_interrupted`、`context_overflow`、`provider_5xx`、`unknown`；
- 助手级备用模型 `fallbackModelId`：只对限流、超时、5xx 与首字前断流生效；
- 首字前自动切换，单轮最多 2 次；首字后不自动切换，避免重复输出；
- 每次切换在消息流显示「当前模型不可用，已从 A 切换到 B」，同时写入会话事件（仅模型 id 与原因，不含正文）；
- 错误态提供「重试」「换备用模型」「保留输入」三个动作；
- 401/403 与上下文超限不自动切换，分别引导检查密钥与压缩/换大窗口模型。

### 2. 会话成本有护栏

- 新增会话级 token 预算设置：未设置时不生效，设置后 80% 提示、100% 拦截；
- 预算存于既有设置 JSON，不新增数据库列；
- 100% 拦截返回 `TOKEN_BUDGET_EXCEEDED`（HTTP 422），与七类模型失败码互不混用；
- 预算提醒在对话页可见，超限时保留输入并提供调整入口。

### 3. 五域全局检索

- 新增全局检索入口（`Ctrl + Shift + F`），覆盖会话、任务、流程、会议、知识文档；
- 事件四域复用本机 `/api/search`；知识域只按文档标题/来源/摘要匹配，不读正文、不触发解析；
- 知识库按并发 4、单库最多 5 条查询，单库失败静默跳过，单域失败在界面上可见；
- 结果按域分组，支持域过滤器、空结果引导、`↑↓ / Enter / Ctrl+Enter` 键盘操作；
- 深链直达：会话消息定位、任务详情、流程运行、会议记录、知识库文档；
- 最近搜索仅存本机 localStorage（最多 5 条，可清除），界面明示「本机检索」。

### 4. 快捷键与隐藏用法可发现

- 命令面板固定首组「快捷键与用法」，列出全局检索、会话朗读、`@` 引用、`/` 命令、桌宠开关等用法并直达对应界面；
- 侧栏底部常驻提示「Ctrl+K 命令面板 · Ctrl+/ 快捷键」，可关闭且不再打扰；
- 快捷键真源补齐 `Ctrl + Shift + F`，浮层与实际注册保持一致。

### 5. 离线 A/B 回放与上下文保真

- 新增 `pnpm eval:replay`：同一组 golden 用例分别跑基线/候选两套上下文预算策略；
- 固定五项代理指标：预算占用、截断率、记忆保留、引用保留、约束保留；
- 绝对下限 + 相对退化 + 预算硬上限三重判定，超阈值退出码非 0；
- 报告固定落 `test-results/eval-replay/report.json` 与 `report.md`，不含绝对路径、聊天正文与密钥；
- 首期接入 nightly 非阻断；报告单测（确定性、退化必失败、字段完整、隐私）进入 CI。

## 二、重要优化与修复

- mock 供应商新增 `[eval-fail:模型ID:状态码]` 故障注入与 `[eval-replay]` 上下文探针，E2E 与回放共用，零外网；
- mock eval 探针抽到独立子域（`mock/eval-probes`、`mock/message-utils`），主 mock 文件行数回落到门禁内；
- 全局检索结果映射、知识并发查询、最近搜索均为纯函数并配单测，避免 UI 测试依赖网络桩；
- 命令面板抽离帮助命令模块，单文件行数回到 300 以内；
- 新增 E2E：429 自动切换并在消息流可见；同一关键词跨会话与知识库分组、打开两类深链。

## 三、兼容性变更说明

- **数据库 / 备份**：无迁移、无格式变化；
- **依赖**：零新增运行时依赖；
- **导航**：不新增侧栏入口；检索与命令面板共存，原命令面板检索命令保留；
- **助手配置**：`fallbackModelId` 为新增可选字段，未配置时行为与旧版一致；
- **会话设置**：token 预算为新增可选字段，未设置时不生效；
- **版本号**：根工程、桌面端与运行时版本统一升至 `4.18.0`。

## 四、升级注意事项

1. 本版无数据库迁移，正常覆盖安装即可；
2. 自动切换默认开启，但只有配置了备用模型的助手才会触发；不配置则完全沿用旧行为；
3. 检索只查询本机事件日志与知识文档列表，不发送远端请求；
4. 知识库文档编译状态与检索无关：即使未编译，文档标题/来源仍可被检索到；
5. `eval:replay` 首次运行会创建 `eval-replay-kb` 固定知识库与评测助手，可在知识库/助手列表中手动删除。
