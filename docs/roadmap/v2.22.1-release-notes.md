# v2.22.1 发行说明（安装包热修复）

> 修复：v2.22.0 Windows 安装包启动崩溃
> 发布：2026-11-05 · tag `v2.22.1` · 无功能变更 · 无迁移（`LATEST_SCHEMA_VERSION = 45`）
> 承接版本：[v2.22](../plan/v2.22/README.md)

## 问题

安装 v2.22.0 后应用无法启动，主进程报：

```text
Error: Cannot find module '@nut-tree-fork/nut-js'
Require stack:
- ...\resources\app.asar\dist\index.js
```

线上安装包的 `app.asar` 只包含 `node_modules/zod`，缺少 `@nut-tree-fork/nut-js` 与 `electron-updater`。

## 原因

发布流水线使用 `npx electron-builder`。electron-builder 在 `workspaceRoot/projectDir/appDir` 均找不到 lockfile 时会回退读取进程环境，`npx` 把 `npm_config_user_agent` 标成 npm，于是选择 npm collector；本仓库为 pnpm `node-linker=hoisted` 布局，生产依赖提升在仓库根 `node_modules`，只扫描 `apps/desktop/node_modules` 必然漏收。

## 修复

- 发布流水线改用 `pnpm exec electron-builder`，包管理器探测进入 pnpm collector，正确归集根级生产依赖。
- `verify-artifacts.ps1` 增加 asar 生产依赖完整性校验：逐项核对 `apps/desktop/package.json` 的 `dependencies`，缺少任意一项即阻断发布。

## 升级说明

- 已安装 v2.22.0 且启动失败的用户无法通过应用内更新恢复，请下载 `WorkBuddyForMe-Setup-2.22.1.exe` 覆盖安装。
- 数据目录与数据库不受影响，无需迁移；功能与 v2.22.0 一致。
