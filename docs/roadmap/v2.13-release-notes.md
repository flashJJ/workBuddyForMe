# v2.13.0 发行说明

> 可治理的 Agent：每一次执行都可授权、可约束、可审计。

## 重点

- **五档执行模式与工作目录**：任务启动可选 `confirm_each`（默认）/ `auto_edits` / `smart_approve` / `plan_only` / `full_access`；`full_access` 需二次确认、只对当前运行生效、永不进入无人值守白名单。任务可指定工作目录，文件 / 命令类操作限定在目录内，realpath 校验拒绝符号链接逃逸。
- **策略即代码**：设置新增 `agentPolicy`（工具 allow/deny、路径根、域名、命令、运行限额）。求值顺序固定，**deny 永远优先**；策略保存计算哈希，运行写入快照；设置页提供可视化编辑。
- **审批绑定具体操作**：审批项绑定工具、参数哈希、cwd、环境哈希、文件操作数、目标窗口与策略哈希；执行前重算，任一字段漂移返回 409 `APPROVAL_BINDING_DRIFT` 并审计。
- **执行审计账本**：新增 `audit_events` 追加式账本与哈希链；策略更新、策略拒绝、审批请求 / 通过 / 拒绝 / 超时、绑定漂移、运行生命周期、定时触发、无人值守拒绝、完整性校验均落账本。支持按时间 / 类型 / 运行过滤、游标分页、链完整性校验与 JSONL 导出；**无删除入口**。
- **定时 Agent 任务**：`scheduled_tasks.payload` 支持 `agent_task`（目标、会话、模式、目录、通知）。服务端 10s 常驻调度只接管 Agent 任务，渲染进程继续处理提醒，避免双端抢标记；创建校验无人值守白名单与视觉模型；同一任务不并发、受策略并发上限约束；终态写 WorkSignal。
- **隔离网页会话**：仅桌面端。每次任务运行一个独立临时 session 的可见窗口，不共享主浏览器登录态；新增 `browser_open/read/snapshot/click/type/close` 六个工具；仅 http/https，域名 allow/deny 与私网字面量逐次复核，禁止下载、弹窗、新窗口与外部协议；纯 Web 模式降级提示。
- **运行时限额**：步数、运行时长、写入次数、外部调用次数受策略约束，超限以 `policy_limit` 收敛。

## 迁移

- 迁移 v041 纯加法：`task_runs` 新增 `permission_mode` / `workspace_path` / `policy_snapshot_json` / `origin_scheduled_task_id`；新增 `audit_events` 表与索引。
- 旧库升级后既有运行默认 `confirm_each`；回退旧版本忽略新增列 / 新表，不删除审计数据。审计本版不自动清理。
