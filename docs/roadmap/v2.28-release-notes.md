# v2.28.0 发行说明

> 主题：**记忆可管——统计可视、审计轮转与约束撤销**
> 发布：待发布 · 一次迁移 v048（`LATEST_SCHEMA_VERSION = 48`）
> 完整方案：[v2.28](../plan/v2.28/README.md)

## 新功能

### 记忆统计卡

- **设置页可见**：设置 → 记忆分组顶部新增统计卡，直接消费 `GET /api/memories/stats`，展示总量 / 活跃 / 归档、被取代比例、零召回率、召回总轮次、用户纠正次数。
- **口径只有一份**：前端只做格式化，不重新计算比例；空库显示 0 而不是空白。
- **状态完整**：加载骨架、失败可重试、手动刷新；同一响应补最近 5 条审计，底部显示最近一次轮转时间。
- **保留期入口**：卡片底部直接切换审计保留期，改完即时保存，不跳设置页。

### 审计轮转

- **迁移 v048 纯加法**：新增 `memory_event_rollups(action, actor, count)` 聚合表与 `memory_events.created_at` 索引，无数据回填。
- **单事务轮转**：按 `action + actor` 聚合过期事件 → UPSERT 计数 → 删除原文；返回删除条数与聚合键数，并写一条结构化日志（条数、键数、耗时）供核对。
- **保留期可选**：默认 90 天，支持 30 / 90 / 180 天或永久（0）；配置存现有 `AppSettings.memoryEventRetentionDays`，不新增表。
- **调度可控**：服务启动后异步执行一次 + 每 24 小时一次；单飞锁防重入，定时器不阻止进程退出；失败只告警，不阻塞启动与接口。
- **计数不下降**：`countUserCorrections()` 改为「在线事件 + rollups 聚合」，轮转前后数字一致；用户清空记忆时在同一事务里同步清空 rollups。

### 约束确认与撤销

- **零模型成本写入**：过敏 / 忌口 / 禁止 / 显式「记住」这类实时约束，从回合后移到 `done` 帧之前执行，走 `rememberCandidates({ skipEmbedding: true })`，不调用嵌入、不调用模型。
- **可选契约**：`done` 帧新增可选 `memoryNotices: Array<{ id, content }>`；旧前端忽略即可，不影响完成语义。
- **内联提示**：助手消息末尾显示「已记住：{content} · 撤销」，不弹窗、不打断流式；同会话按记忆 id 去重，一次命中多条时合并展示且最多 2 条。
- **撤销即归档**：撤销复用 `PATCH /api/memories/:id` 置为 `archived`，现有服务层写入 `actor='user'` 的审计；提示变为「已撤销」，下一轮召回不再注入。

### 评测基线报告

- **本地一条命令**：新增 `pnpm memory:eval`（`scripts/eval/memory-report.mjs`），在内存 SQLite 上复用召回管线，跑 `scripts/eval/memory-golden.json` 的 12 条用例。
- **四项指标**：输出 hit@3、零召回率、平均召回耗时与最大召回耗时，写 `docs/eval/memory-report.json`，并与上一版报告计算差值。
- **不改变发布流程**：只写本地文件，不上传、不进 CI 必过项；未配置嵌入模型时走关键词通道，报告标注 `channel=keyword`。
- **当前基线**：hit@3 `0.833`、零召回率 `0.00`、平均召回 `0.49ms`、最大 `1.3ms`（keyword 通道，12 条用例）。

## 修正

- **轮转后纠正数下降**：用户纠正次数原先只数在线事件，过期事件被清理后数字会变少；改为叠加聚合存量，轮转前后一致。
- **提示晚于完成帧**：实时约束原先在回合结束后写入，`done` 帧拿不到新记忆；提前到完成之前，提示才能随本轮消息返回。
- **清空后的残留计数**：清空记忆只删事件、不删聚合会让统计偏高；现在同一事务清空两张表。
- **统计只停留在接口层**：v2.26 已提供 stats 接口但设置页看不到；本版把它接到页面，页面数字与接口完全同源。

## 升级说明

- 一次迁移：启动时执行 v048，纯加法、可重复执行，不修改任何既有列；`LATEST_SCHEMA_VERSION = 48`。
- `done` 新增字段为可选：旧客户端、旧消息、旧备份均可直接读取；无 `memoryNotices` 时不渲染提示。
- 保留期默认 90 天；选择「永久」则不再删除原文，但聚合计数与最近审计仍然保留。
- 轮转的语义是「保留计数 + 最近审计」，不保证逐条永久可回溯；需要逐条追溯时请使用导出的备份。
- 评测报告是本地参考，不替代单测，也不会因为指标波动阻断发布。

## 范围说明

本版已交付：记忆统计卡（含最近审计与保留期配置）、审计轮转（v048 + 聚合读写 + 调度 + 计数一致性）、实时约束提前写入与内联撤销、本地评测基线报告。

本版未交付：线上评测看板与服务端定时评测、记忆图关系边与空闲整理、跨设备同步、召回权重调整；约束撤销不新增独立删除接口，统一走归档语义。
