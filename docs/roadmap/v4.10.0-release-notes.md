# v4.10.0 发行说明

> 主题：**从陪伴到上下文智能——v3.0 以来能力与体验的累计收口**
> 发布：tag `v4.10.0` 已推送 · GitHub Draft Release 已生成（待人工转正）
> 覆盖版本：v3.0 → v4.10（含 v4.6.1 修复；历史版本仍有各自 tag 与发行说明）
> 数据库：v4.6 迁移 `v052`、v4.7 迁移 `v053`，`LATEST_SCHEMA_VERSION = 53`
> 备份格式：schema v9 不变
> 安装包：`WorkBuddyForMe-Setup-4.10.0.exe`（270,002,553 字节，约 257.5 MB）

## 一、核心功能更新

### 1. 陪伴闭环与可插拔（v3.0–v3.1）

- **v3.0 肥鱼计划**：把桌宠从散装触发升级为四层陪伴——受限剧本（Scene / Beat / Cue）、Utility 决策与理由码、`/stage?stage=play` 三席 VRM 小剧场、原创角色与 CC0 曲库；
- 内置雪团、冉卡露丽、菲比三个原创 VRM，118 个 morph 表情目录；4 集 × 6 句小剧场，支持幕间切背景/配乐、上一句/下一句/重播与分享卡 PNG；
- **v3.1 可插拔前置**：能力 effect 从 `switch(kind)` 改为 handler 表，provider 从 `switch(protocol)` 改为 factory 表，动效内容改为 `MotionContent` 快照注入；舞台普通模式也使用内置 VRM，托盘/应用菜单可切换自由舞台与小剧场。

### 2. 平台化与内容生态（v4.0–v4.4）

- **v4.0 平台化一期**：能力包增加 `coreVersion`、依赖环检测与稳定拓扑序；动效契约抽到内部 motion 包；`motion-pack` 可安装；安装/停用生成会话级内容快照；发布产物补 `SHA256SUMS.txt` 与 `build-info.json`，可复算、可回溯；
- **v4.1 质量可回归**：Utility 打分下沉到共享包，离线回放最近 50 条决策，12 组上下文矩阵，设置页只读质量卡；4 小时长跑采样补 p50、长任务与 GPU 资源计数，新增 10 分钟短跑相对基线门禁；
- **v4.2 统一音频导演**：四类音轨 `music / theater-bgm / voice / sfx`，优先级 voice > theater-bgm > music > sfx；语音期间背景乐 duck 到 35%；全局静音单一状态，首次手势统一解锁；音效并发上限 2；
- **v4.3 内容与资产收口**：新增声明式 `scene-pack` 与 `prop-pack`，复用 ZIP/清单/校验和/签名/升级/回滚；`check:assets` 把模型、贴图、morph 与安装包体积变成门禁；音频输出设备可选，工具描述符与 provider 能力只读展示；
- **v4.4 背景与壁纸**：背景统一为 `builtin / image / video` 三种来源与 `main / stage / pet` 三个作用域；桌面端本地图片/视频复制到数据根并受控读取；`wallpaper-pack` 复用能力包管道；桌宠改为 9:16 并加木相框。

### 3. 启动体验与声线归属（v4.5–v4.6.1）

- **v4.5 一眼启动**：640×360 无边框启动窗，只显示 `prepare / server / workspace` 三段真实阶段；首次安装/覆盖升级首启播放 8 秒《潮汐开门》，可跳过、只播一次；同一片源复用为主窗口视频壁纸；启动超过 8 秒/20 秒有等待提示，失败显示原因与日志路径；
- **v4.6 声线有归属**：`resolveAvatarVoice` 统一服务端、设置页与舞台的声线解析；`vrm_avatars.voice_sid` 让导入 VRM 可持久化绑定 103 个音色；语速改为逐句参数，不再触发模型重建；预热失败可重试，短句加进程内 LRU；
- **v4.6.1 下载可信**：Kokoro 模型固定 revision，LFS 大文件补 SHA256；下载链路增加重试、退避、超时、Range 断点续传与流式写盘；错误区分缺失/大小不符/哈希不符。

### 4. 上下文工程（v4.7–v4.9）

- **v4.7 任务模式有上下文、能续跑**：Planner / Executor 注入会话摘要、结构化事实、当前计划、近期对话与相关长期记忆；步骤历史改为首 2 步 + 最近 8 步 + 中段省略；新增 `task_run_checkpoints`，重启后可「继续运行」；复杂任务先出只读计划预览；结果回投补正文、证据与未竟事项；
- **v4.8 对话上下文有策略**：7 类意图路由（规则优先，小模型可选兜底）；`ContextPlan` 按意图分配原文/摘要/记忆/证据配额；压缩事件化（70% 阈值、85% 预判、模型切换、用户显式）；「记住 / 忘掉」成为一等意图；对话顶栏新增上下文面板；
- **v4.9 统一上下文控制器**：七个场景、两个预算预设（上下文块 15%/320–2000、步骤历史 12%/320–1200）；`fitPromptMessages` 给协作、任务与 Flow 统一装包，超窗时头 60% / 尾 40% 截断；协作上下文块取三角色最小窗口；桌面任务启动注入会话上下文；新增 `context_scene_snapshot` 事件。

### 5. 上下文可见（v4.10）

- 协作卡、任务详情、Flow 执行面板新增「上下文预算」区，展示场景、角色、窗口、预算、实际占用与截断状态；
- 场景快照增量补充 `systemTokens` / `inputTokens` / `messageCount`，可区分「角色提示太重」还是「历史/观察太长」；
- 发生截断时给出显式警告与建议：换更大窗口模型、减少历史条数、关闭不必要的知识库，或缩短上游节点输出；
- Flow 快照改为「首节点基线 + 截断追加」，正常运行的节点也有可对照的预算数据；
- 旧事件缺少新字段时仍可解析，面板只显示总量。

## 二、重要特性优化

- **小窗口预算**（v4.8.1）：输出预留改为窗口比例 `clamp(窗口 × 15%, 512, 2048)`，固定块挤占时先裁技能提示与技能工具声明。4096 窗口实测 `historyBudget 0 → 1843`、单轮 `promptTokens 3330 → 497`。
- **小窗口摘要**（v4.8.1）：窗口低于阈值时跳过 JSON 抽取与保真重试，直接走纯文本摘要，避免 7B 模型输出无关 JSON。
- **压缩载荷裁剪**：写入前按契约裁剪摘要、折叠 id、事实、结论、遗留项与保真缺失，避免单条事件超限导致面板整条丢弃。
- **启动交接**：主窗 `show: false` 创建，`ready-to-show` 后启动画面先退场再显示主窗；首启标记只在画面真正显示后写入，安装器不再自动拉起覆盖安装。
- **声音链路**：语速移出 TTS 引擎缓存键；预热成功复用、失败可重试；短句缓存按条数、单条长度与总样本三重限制。
- **协作观测**：交接时间线展示每个角色的 token 用量；上下文快照按角色取最新一条展示。
- **事件装卸**：任务/Flow 的快照按「首次 + 截断」节流，Flow 事件量从每节点一条降为 1 + 截断次数。

## 三、问题修复列表

1. **全屏舞台拖动一次后动画失速**（v2.35 补合入）：`autoUpdate` 差量写入，避免 ticker 回调成倍叠加。
2. **同一位置重复加载模型**：加载守卫 + 自增 token，只保留最后一次加载。
3. **引用超过 3 条不折叠**：默认折叠态随引用条数实时推导，手动展开后不被后续增长重置。
4. **覆盖安装后首启动画丢失**（v4.5.1）：NSIS 改为完成后不自动拉起，首启标记延后到主窗 reveal。
5. **Kokoro 下载误报「校验缺失」**（v4.6.1）：manifest 过期大小修正，状态刷新以磁盘为准。
6. **任务模式从零开始**：Planner / Executor 输入契约只有 goal，已补会话上下文块。
7. **固定 12 步截断丢早期证据**：改为首尾保留 + 中段省略，原文仍可从步骤表回溯。
8. **重启后任务只能取消**：检查点保留可恢复位置，任务中心提供继续运行。
9. **结果回投只有一行状态**：补正文、证据、未竟事项与失败原因。
10. **小窗口历史预算被固定块吃光**：输出预留比例化 + 技能块二次裁剪。
11. **压缩事件超契约导致面板空白**：写入前裁剪，历史脏事件读取时宽松归一。
12. **协作 Planner 小窗口超窗**：上下文块窗口取三角色最小值。
13. **Flow 长文本节点无上限**：装配后统一装包，仅超窗截断。
14. **协作快照帧被前端丢弃**：reducer 保存快照并限制 24 条。
15. **任务面板 `task_start` 被角色行挤掉**：混合场景改按 scene 分行。
16. **温度/TopP 小数无法输入**：`NumberInput` 支持小数步进，`0.7` 不再被钳制成 `2`。
17. **发布门禁修复**：补齐 mock 生成器 `yield`、SSE 事件计数 26、结构基线、runner 类型环、Windows 仓库扫描性能与 Linux 越界测试路径。

## 四、兼容性变更说明

- **数据库**：v4.6 增加 `vrm_avatars.voice_sid`（`v052`，可空列）；v4.7 新增 `task_run_checkpoints`（`v053`，纯加法）；其余版本零迁移。
- **备份**：schema v9 不变；声线绑定、检查点与任务运行字段随现有轨道读写。
- **事件**：新增 `turn_intent`、`context_condensed`、`context_snapshot`、`context_scene_snapshot`；旧读取方忽略未知类型即可。
- **设置**：新增上下文预判压缩开关、意图分类器绑定、复杂任务先确认计划、音频输出设备等设置项，缺省不改变旧行为。
- **输入行为**：助手表单的温度/TopP 现在是小数输入；PTT 识别结果先入草稿，确认后发送（免手 VAD 仍自动发送）。
- **Flow**：正常运行也会写一条首节点快照；不影响节点输出与既有工作流定义。
- **TTS 模型**：首次启动会按新 manifest 校验；大小/哈希不符时才重新下载。

## 五、升级注意事项

1. **先备份**：v3.0 以来累计两次纯加法迁移（`v052`、`v053`）；建议升级前导出一份归档。
2. **语音模型**：Kokoro 固定 revision 并校验 SHA256；旧文件不匹配时会重新下载，弱网环境建议使用镜像并留足时间。
3. **小窗口模型**：4096 窗口下上下文块与步骤历史会自动收敛；若仍频繁截断，优先减少历史条数或关闭不必要的知识库。
4. **续跑语义**：继续运行会新建一次 run 并记录 `resumed_from_run_id`，已完成的步骤由模型按上下文跳过；写操作仍需授权。
5. **计划确认**：复杂任务默认先出只读计划；可在 Agent 治理设置中关闭。
6. **Flow 快照**：每个 run 至少一条基线快照，截断时追加；事件量增加但受节流控制。
7. **Draft Release**：`v4.10.0` 目前是 GitHub Draft，需人工核对安装包、`latest.yml` 与 blockmap 后转正。
