# v2.14.0 发行说明

> 可维护：能升级、能回退、能定位、能对账。

## 重点

- **技能版本化与回退**：技能扫描确认后把目录快照到数据根 `skill-versions/<stateId>/<version>/`，`skill_versions` 记录版本、清单、checksum 与时间；设置页技能行可展开「版本历史」，一键把任意快照原子写回 `skills/<name>`，启用态保持不变。自动保留最近 5 版且永不删除启用版本；单目录超过 50 MB 时跳过快照并提示，不阻断技能加载。
- **工作流生产版本**：`workflows.published_version` 明确「生产版本」。保存草稿只推进 `current_version`，运行 / 端点 / MCP 上下文固定读取生产版本；无生产版本时回退当前版本，兼容历史草稿。版本抽屉展示创建时间、当前与生产徽章，任意历史版本可「设为生产」而不改动编辑器草稿。
- **能力包降级与同版本修复**：目标版本低于当前时必须携带 `confirmDowngrade=true` 与 `expectedVersion`，目标不一致返回 422；启用中的其他包仍声明旧版本时返回 409 `CAPABILITY_DEPENDENTS_ACTIVE` 并列出依赖方，不自动停用。版本相同但内容变化可用 `repair=true` 重装；内容也一致时提示无需修复。升级对话框首次提交只探测方向，降级需勾选风险确认后才能继续。
- **运行记录下钻**：审计事件与审批项的 `runId` 变为链接，一次点击到 `/timeline?scope=task&id=<runId>`；审计页支持 `?runId=` 直达并预填过滤，清空同步移除参数，无关联时显示专用空态。任务列表展开区新增治理摘要（模式、脱敏工作目录、策略哈希、来源定时任务）与最近 10 条关联审计事件。
- **一键诊断包**：设置 → 关于新增「导出诊断包」，本地生成 ZIP 下载，不上传。白名单组装 `manifest.json`、`versions.json`、`audit-verify.json`、`capabilities.json`、`runs-summary.json`、`settings-summary.json`、`errors.log` 与 `README.txt`；不输出 API Key、令牌、密码、对话 / 记忆正文、完整 URL、绝对路径、会话与运行 id。审计链校验超过 10 万条时只校验最近 10 万条并标注 `truncated`；生成预算 30 秒，超时返回 503 `DIAGNOSTICS_TIMEOUT`。

## 迁移

- 迁移 v042 纯加法：新增 `skill_versions` 表、`skills_state.active_version` 列与 `workflows.published_version` 列；`published_version` 按既有 `published_at` 回填。
- 旧库升级后技能首次扫描即建立当前版本快照；无版本的老技能按原方式工作。回退旧版本忽略新增表 / 列，不删除技能快照、审计账本与运行历史。
