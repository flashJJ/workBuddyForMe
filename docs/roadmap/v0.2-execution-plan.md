## 技术设计总览

### 数据流（工具循环）

```text
用户消息
  → 编排器：system + history + tools 声明（仅白名单）
  → provider.chatStream（透传 OpenAI tools 字段）
  → 模型返回 finish_reason=tool_calls（增量分片到达，适配器按 index 拼装）
  → 编排器：SSE tool(start) → Zod 校验参数 → 执行（单工具 15s / 总 60s / 最多 5 轮）
  → tool 结果以 role:'tool' 消息回灌 → 再次请求模型
  → 模型给最终回答（delta 流）→ tool(end) 在此之前发完 → done，tool_trace 落库
```

### 契约变更（全部向后兼容：字段追加、事件追加）

| 层 | 变更 |
|---|---|
| shared 常量 | 新增 `TOOL_NAMES` 枚举：current_time / knowledge_search / fetch_webpage |
| shared SSE | 新增事件 `tool`：`{phase:'start'\|'end', callId, tool, argsSummary?, status?, durationMs?, resultSummary?, error?}` |
| shared 领域 | Assistant 增 `enabledTools: ToolName[]`、`retrieveAlways: boolean`；Message 增 `toolTrace: ToolTraceEntry[]` |
| DB migration v2 | assistants 加 `enabled_tools`（默认 `["current_time"]`）、`retrieve_always`（默认 1）；messages 加 `tool_trace`；老 KB 助手补 knowledge_search 权限 |
| ai ChatMessage | 可空 `content`、可带 `toolCalls`；tool 结果消息 `role:'tool' + toolCallId + name` |
| ai ChatParams | 增 `tools?: ToolDefinition[]`；ChatChunk 增 `toolCalls`（拼装后）与 `finishReason` |
| ChatProvider | 增只读能力位 `supportsTools: boolean`；不支持时编排器不下发 tools |
| chat 请求 | 增 `regenerate?: boolean`（不取新输入，沿用上一条用户消息重跑） |

### 工具安全模型

- 工具默认**全部关闭**，必须助手显式勾选；内置通用助手与 v0.1 行为一致（不开工具）。
- 只做只读工具；`knowledge_search` 只能查助手绑定的那一个知识库。
- `fetch_webpage`：协议白名单 http/https → DNS 解析校验 IP 段 → 手动跟 3 跳重定向（每跳重校）→ 8s 连接 / 200KB / 仅文本类 Content-Type。

## 任务拆解（T1-T15，按依赖排序）

### M1 工具内核（T1-T6）—— 单工具 current_time 全链路

| ID | 任务 | 关键产出/验收 |
|---|---|---|
| T1 | shared 契约扩展 | constants 增 TOOL_NAMES；新建 types/tool.ts（ToolTraceEntry/工具事件载荷）；sse.ts 增 tool 事件；domain + assistant zod schema 增 enabledTools/retrieveAlways（默认 current_time）；单测 |
| T2 | DB migration v2 + 仓储 | v002 迁移（含老数据回填规则）；AssistantRow/MessageRow/mappers/repo 字段贯通；message repo 增 saveToolTrace；既有迁移测试补 v1→v2 用例 |
| T3 | ai 工具协议扩展 | ChatMessage/ChatParams/ChatChunk 类型；payloads 请求体 tools 透传 + chunk tool_calls/finish_reason；chat-stream 按 index 拼装增量；supportsTools 能力位；chat-stream.test 增工具帧用例 |
| T4 | core 工具框架 | tools/{types,tool-executor}.ts：Tool 接口、Zod 校验、一次自纠正约定、15s 超时、错误归一；current-time-tool.ts；工具单测（校验失败/超时/成功） |
| T5 | 编排器工具循环 | chat-orchestrator 重构：5 轮上限、工具事件、tool_trace 收集落库、retrieveAlways 老 RAG 路径保留、abort 语义不变；orchestrator 测试：mock 支持工具的 provider 跑通「调用→回灌→作答」与无工具降级 |
| T6 | Web 工具事件渲染 | use-chat-stream 加 onTool；use-chat-session 维护 toolTrace；新建 tool-trace.tsx 过程卡片（名称/参数/耗时/状态/可展开结果）；message-item 挂载 |

**M1 验收**：mock provider 返回 current_time 工具调用时，SSE 序列为 meta→tool(start)→tool(end)→delta…→done，落库 tool_trace 非空，前端可见过程卡片。

### M2 知识/网页工具（T7-T10）

| ID | 任务 | 关键产出/验收 |
