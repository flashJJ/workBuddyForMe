# v2.20.0 发行说明

> 看得见、分得清：过程图、光线与阶段化会话。

## 重点

- **RunGraph 五域统一**：一条会话下把消息、工具、任务步骤、Flow 节点、协作阶段与代理产物投影到同一张图；会议页有独立的 meeting 图。刷新后图与 `session_events` 一致，历史加载不补演。
- **聊天右侧与时间线图谱**：聊天时可打开右侧过程图；回看时进 `/timeline` 图谱。同一组件复用，支持聚焦当前运行、折叠其他与错误隔离。
- **Light UI**：新节点按锚点发射光线（最多 12 条、1200ms），活跃节点有流动边框；`prefers-reduced-motion` 直接完成，页面隐藏暂停，卸载无残留。
- **实时追加**：复用既有 SSE 事件旁路，图随 `meta/tool/done/error/stop`、协作与会议事件增量更新；终态节点不会被迟到帧回退。
- **阶段计划**：每个会话可保存 1–8 个阶段，阶段带标题、模型、技能、目标与交付要求；超出上限、技能不可用、模型不可用均由服务端返回 422。
- **阶段条与载入任务**：对话顶部切换阶段、编辑阶段、点「载入任务」把目标组装进输入框；不自动发送，非空草稿与运行中都会阻止。
- **会话级模型**：阶段绑定的模型写入当前会话，后续轮次沿用；切回无模型阶段清空覆盖；不改助手绑定。
- **默认阶段复制**：6 张内置角色卡各带 4 个默认阶段；创建会话或应用角色卡时按空缺复制，之后修改不回溯覆盖。
- **备份恢复**：阶段计划、会话模型、助手与角色卡默认阶段随备份恢复；旧归档缺字段按空值降级。

## 隐私与安全

- 图投影、光线与阶段校验全部在本机完成；不新增外部服务或运行时依赖。
- 阶段技能校验读取本地技能目录；不可用技能不会进入提示词。
- 会话模型只影响当前会话，不修改助手与角色卡绑定。
- 备份继续走既有脱敏链路；阶段计划与模型字段为可选，旧归档可恢复。
