## 2. 技术要点

- **厂商可描述**：新增 `packages/ai/src/vendors/` registry，`ProviderPreset` 扩展 discovery / keyScope / modelIdHint；现有预设 id 与设置页表单保持不变。新增厂商只改一个描述文件，不改适配器。
- **发现与三态**：按「`/models` → 厂商专用 → 推荐模型 → 手动」降级；404/405 归一化为 `models_unsupported`；连接测试返回 `verified / reachable_unverified / failed`，保留 `ok` 兼容字段，不伪造成功。
- **搜索可插拔**：`SearchProvider` 抽象 + SearXNG / mock 适配器；`web_search` 只返回标题/链接/摘要，正文交给 `fetch_webpage`；结果映射 Citation，回答可带来源。
- **搜索治理**：endpoint 只允许 http/https，公网要求 https + 私网校验，自建 SearXNG 可显式放行；查询正文不落审计；结果去 HTML、限长、按外部不可信数据处理。
- **能力可装载**：`CapabilityCatalogEntry` + 内置精选目录；安装复用既有 ZIP 校验 / 验签 / 依赖 / 落盘 / 启用链路；`capability_install.alwaysConfirm` 使 `full_access`、策略 allow、持久授权也不能跳过审批。
- **下一轮绑定**：安装后只把只读工具追加进 `assistant.enabledTools`，write/danger/未知工具跳过；下一轮 `buildTools` 生效，不做同轮热替换。
- **零迁移**：设置 JSON、`assistant.enabledTools`、能力包表全部沿用；`LATEST_SCHEMA_VERSION = 42` 不变。

## 3. 数据与迁移

- **零迁移**：`LATEST_SCHEMA_VERSION = 42`，不新增表 / 列 / 索引。

- 不新增运行时依赖；搜索适配器只在服务端运行。

## 6. 已知边界

- 搜索 provider 只实现 SearXNG 与 mock；Tavily / Brave / 博查等 API Key provider 留后续版本。
- `web_search` 未接专用审计事件；查询正文不入审计。
- 能力目录只收内置精选包，不含 MCP 预置；`capability_list` 未实现。
- 能力安装审批框复用通用工具确认，未展示目录来源/签名/effect/新增工具。
- 无浏览器端能力安装审批 e2e；由权限门与工具单测覆盖。
- 桌面冒烟 `computer-input` 为环境相关失败，非本版回归。
- v2.18 起再处理图表/内容包/证据元数据等「可交付」能力。
