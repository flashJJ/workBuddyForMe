## 2. 技术要点

- **产物零迁移**：复用 attachments 表与文件目录，扩展 HTML / SVG / Markdown 的 MIME 与扩展名映射；不新增产物表。
- **安全预览**：`/api/artifacts/:id` 统一返回 CSP、`nosniff` 与下载头；前端带令牌取 Blob，预览走 `<iframe sandbox="">`，不把 URL 直接交给 `<a href>`。
- **模板化图表**：10 类 zod 判别联合输入；服务端模板生成自包含 HTML + 内联 SVG；数据图拒绝空序列、缺值、NaN/Infinity；超 9 节点提示拆图。
- **客户端导出**：从 HTML 提取第一个内联 SVG，补 `xmlns` 与尺寸；PNG 使用 Image + Canvas + `toBlob`，白底 2 倍图，导出前等待字体。
- **内容包协议**：固定 commit 的 34 个 Markdown + 逐文件哈希 + 整包 SHA-256；下载与校验在服务端完成，建库固定 id，导入 34 篇原文 + 1 篇署名页，后台逐篇摄入。
- **证据元数据**：`ToolEvidence` 只挂在 `ToolResult` / `ToolTraceEntry` / SSE `tool end`；模型只看到 `output`，证据只进 UI 与分享导出。
- **全量回归修复**：补齐 `diagram-design` / `life-decision-guide` 技能模板（15 → 17 条）；修复工具执行器未透传 `artifacts` 的旧缺口。

## 6. 已知边界

- 图表仅支持 10 类简化布局；超过 9 节点建议拆图，45 类全量 references 不做。
- 通用 HTML 产物只保证预览/下载，不承诺 PNG；PNG 仅针对图表内联 SVG。
- 内容包首版固定上游 commit，未做“检查更新”；上游内容变化时哈希校验会拒绝导入。
- 产物卡片位于 tool-trace 内，不是独立消息气泡；单轮产物数量限制尚未运行时计数。
- 证据覆盖先做 web/knowledge 工具；其他工具暂无证据字段。
- 桌面冒烟 `computer-input` 为环境相关失败，非本版回归。
