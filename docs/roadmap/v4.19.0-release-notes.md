## 一、核心功能更新

### 1. 备用模型补完：链 + 会话覆盖

- 助手可配置最多 3 个备用模型，顺序即切换顺序；
- 新增会话级覆盖：只作用于当前会话，`null` 表示清除覆盖、回到助手配置；
- 解析优先级固定：会话覆盖 → 助手链 → 旧单值备用 → 无备用；
- 链中不得包含主模型，重复项按首次出现去重；写入拒绝无效模型，读取跳过已删除模型；
- 单轮最多切换 2 次，已尝试模型不重复尝试，首字后不切换的规则不变；
- 第一个备用模型继续写回旧单值键，旧数据与旧客户端可读；
- 会话设置显示当前来源（会话覆盖 / 助手配置 / 未配置）。

### 2. 供应商健康度与失败统计

- 新增只读接口 `GET /api/providers/health?days=1..30`，默认 7 天；
- 按供应商聚合：失败次数（按错误码）、切换次数、最近失败时间；
- 数据源只有本机会话事件 `model_switched` 与 `message_error`，不新增埋点、不记录正文；
- `message_error` 事件新增可选 `modelId`，用于归属供应商；
- 模型或供应商已删除时归入「未知供应商」分组，不丢弃历史事件；
- 设置页供应商列表下方新增只读面板，已配置供应商即使零事件也会展示。

### 3. 回放历史与报告对比

- `pnpm eval:replay` 每次成功报告额外归档到 `test-results/eval-replay/history/`；
- 文件名 `report-<ISO去分隔符>.json`，按文件名时间排序，只保留最近 20 份；
- 新增 `--compare=last`：读取最新一份历史报告（排除本次），输出五项指标的相对变化；
- Markdown 报告新增「与上次对比」小节，控制台同步打印；
- 对比口径为「本次候选 − 上次候选」，不参与阈值判定；
- 历史文件与主报告遵循同一隐私约束：命中绝对路径/令牌时拒绝落盘。

### 4. 知识结果复制引用

- 知识检索结果新增「复制引用」按钮，复制内容为 `文档标题 — /knowledge?kb=<id>`；
- 不复制摘要、正文与本机路径，总长上限 300 字符；
- 复制成功/失败只做弹层内联提示，不关闭弹层、不阻断继续检索；
- 原有「打开知识库」行为不变。

### 5. 桌宠主窗入口与窄窗复核

- 侧栏底部工具区新增桌宠入口，仅桌面端（存在 pet 桥）渲染；
- 点击复用现有桌宠桥接 `open()`，不新增窗口逻辑；
- 1024 / 1280 / 1440 三档复核：无横向滚动、入口完整可见、中心点未被遮挡、点击生效。

### 6. 语音链路与寒暄快路径（实现期追加）

- 流式 TTS：引擎新增可选 `synthesizeStream`，本地 sherpa worker 按块回传 PCM，语音桥收到即下发；
- 本地新增 Matcha 模型：单中文女声，速度约为 Kokoro 的 10 倍，与 Melo/Kokoro 共用下载与预热链路；
- 新增腾讯云在线 TTS：TC3-HMAC-SHA256 签名、PCM 直出、凭据加密落库、失败回退本地；
- 新增微软 Edge 免密钥在线朗读：WSS + 内置令牌，MP3 经 WASM 解码为 24kHz 单声道；
- 朗读来源三选一（本地 / 腾讯云 / 微软在线），设置页只展示当前来源需要的配置；
- 寒暄快路径：高置信短寒暄不再注入工具 schema、不召回长期记忆，`context_snapshot` 增加 `fastChitchat` 字段；
- 任务关键词、URL、图片、长文本、低置信度任一出现即回退完整链路。

## 二、重要优化与修复

- `message_error` 事件补充目标模型 id，切换与失败可在健康面板复算；
- 助手备用模型存储拆分为独立 store，助手服务与会话服务行数回到门禁内；
- 全局检索弹层为知识结果增加独立复制按钮，避免按钮嵌套；
- E2E 支持注入最小 pet 桥验证桌面入口，并断言对话页正常渲染；
- `with-server.mjs` 透传未识别参数，`eval:replay --compare=last` 可直接使用；
- 对话正文与输入区改为 `clamp(48rem, 70vw, 72rem)` 自适应列宽，大屏不再固定 768px 居中；
- 版本号单一真源统一升至 `4.19.0`（根工程、Web、桌面端、运行时）。

## 三、兼容性变更说明

- **数据库 / 备份**：无迁移、无格式变化；
- **设置存储**：新增 `assistant-fallback-chains` 与 `conversation-fallback-models`，旧键继续读写；
- **事件**：`message_error` 新增可选 `modelId`，旧事件仍可解析；
- **依赖**：本版新增 `ws` 与 `mpg123-decoder` 两个运行时依赖（语音链路追加，均为纯 JS/WASM，无原生编译），是本版对「零新增运行时依赖」约束的唯一偏离；
- **导航**：侧栏底部新增桌宠图标入口，仅桌面端可见；不新增页面路由；
- **版本号**：`4.19.0`。

## 四、升级注意事项

1. 本版无数据库迁移，正常覆盖安装即可；
2. 未配置备用链或会话覆盖时，行为与 v4.18 完全一致；
3. 健康度面板只统计最近 7 天本机事件，不读取云端数据；
4. 回放历史只保留 20 份，旧报告会自动清理；对比不改变原有阈值门禁；
5. 在线朗读会把朗读文本发送到对应云服务，设置页已注明；离线用户可继续使用本地模型；
6. `eval:replay` 首次运行仍会创建固定评测知识库与助手，可在界面手动删除。
