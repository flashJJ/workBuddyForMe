# v2.12.0 发行说明

> 可扩展 III：能力包收口——签名可验证、升级可回滚、坏了能自检。

## 重点

- **清单签名可验证**：能力包清单支持 Ed25519 签名（`signature` + `signatureKeyId`），宿主用本地信任库验签；策略三档 `off` / `warn`（默认）/ `require` 在安装、升级、启用三个入口生效。`warn` / `require` 下签名对不上（`invalid` / `malformed`）一律 422，策略只决定「没签名」与「不认识的密钥」是否放行。
- **同 id 原地升级与回滚**：新端点 `POST /api/capabilities/:id/upgrade`；版本必须严格递增、kind 必须一致；暂存写入 → 目录原子换位 → 按六类 effect 适配。启用失败自动恢复旧包、旧版本与旧 effect；二次失败落 `disabled + lastError` 并提示重装旧包，不停在「半升级」。
- **按需健康自检**：`GET /api/capabilities/health` 覆盖目录、清单、checksum、payload 多余文件、依赖三态（缺失/停用/版本不符）、六类 effect 目标与状态、签名共 11 个 issue 码；孤儿目录与超过 24h 的 `.staging` / `.backup` 可在确认后清理。
- **管理与设置收口**：`/capabilities` 行内签名/健康徽章、effect 详情、升级对话框、健康横幅与孤儿清理；`/settings` 新增签名策略与信任公钥管理（label + PEM、≤20 条），中英双语文案。
- **零迁移**：不新增表与列（`LATEST_SCHEMA_VERSION` 仍为 v040）；v2.11 数据库直接打开，回退旧版本不删除数据。
- **工程门禁**：`pnpm check` 通过、8 包单测全绿（2739 例）；生产模式 Web e2e 125/125；桌面冒烟 10/11（`computer-input` 环境相关）；新增签名/升级/健康 e2e 3 例。
