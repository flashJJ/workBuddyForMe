## 亮点

- **Webhook 触发**：每个流程可配置多条 Webhook，创建时生成一次性 Secret；调用方 `POST /api/public/flows/triggers/:triggerId` 即可创建运行。
- **文件监听触发**：指定目录 + 扩展名白名单，新增/修改文件后自动运行；支持递归、防抖与启动重建。
- **统一单飞**：同流程已有 queued/running/waiting_human 运行时不再新建；Webhook 返回 409，文件事件记录跳过。
- **无人值守安全**：事件触发与定时触发一样，写/危险工具默认拒绝；agent 桌面工具域禁单。
- **编辑器入口**：工具栏「触发」对话框支持创建、启停、删除，并展示 Webhook 地址与最近触发状态。
- **运行中心文案补齐**：定时 / Webhook / 文件三种来源都有明确标识。

## 升级说明

- 迁移 v055 纯加法，启动时自动执行；`LATEST_SCHEMA_VERSION = 55`。
- 旧流程不配置触发器时行为与 v4.24 完全一致。
- 新增运行 trigger 值 `webhook` / `file`；按 trigger 过滤运行记录的接口自动支持。

## 安全提示

- Webhook 仅接受 `127.0.0.1` / `localhost` 访问，不提供公网暴露。
- Secret 仅创建时展示一次；丢失后请删除并重建触发器。
- 事件触发会按无人值守执行：涉及写入或高危工具时请改用人工试运行或对话触发。

## 已知限制

- 幂等键为进程内短期去重（10 分钟），应用重启后不保留。
- 事件触发不自动重试，失败只记录状态。
- 非 Windows/macOS 平台的文件监听降级为根目录监听。
