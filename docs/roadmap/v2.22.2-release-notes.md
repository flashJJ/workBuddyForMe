# v2.22.2 发行说明（发布链加固）

> 主题：**把「装完起不来」的同类风险堵在流水线里**
> 发布：2026-11-05 · tag `v2.22.2` · 无功能变更 · 无迁移（`LATEST_SCHEMA_VERSION = 45`）
> 承接版本：[v2.22.1](v2.22.1-release-notes.md)

## 问题

v2.22.0 安装包启动崩溃的直接修复只是把 CI 的 `npx` 换成 `pnpm exec`，根因仍在：

- `apps/desktop` 既没有 lockfile 也没有 `packageManager` 字段，包管理器判定完全依赖调用方环境，任何人用 `npx electron-builder` 都会重现漏收依赖。
- 产物自检只核对 desktop 的顶层 `dependencies`，`@nut-tree-fork/nut-js` 的传递包（`libnut` 平台包等）与 `app.asar.unpacked` 里的原生 `.node` 都在盲区。
- 服务端资源归集靠手工白名单，缺件只 `console.warn`，装出来的包会静默缺失功能（MCP stdio、OCR、语音、向量）。

## 修复

- **包管理器不再靠猜**：`apps/desktop/package.json` 写入 `packageManager: pnpm@11.24.0`，electron-builder 在项目目录即可判定 pnpm，不再回退环境变量。
- **自检覆盖传递依赖**：新增 `apps/desktop/scripts/verify-asar-dependencies.mjs`，从 desktop 的 `dependencies` 递归展开核对 asar，并校验每个 `.node` 是否真的解包到 `app.asar.unpacked`；其他平台的平台包允许缺失。
- **归集缺件硬失败**：MCP stdio server、兜底包白名单、pdfjs worker 任一缺失即 `exit 1`，不再产出缺功能的安装包。
- **启动失败可见**：托管服务 30s 未就绪、密钥链不可用、内置 Node 缺失等 `throw` 统一落盘 `userData/startup-error.log` 并弹错误框，不再是「双击没反应」。
- **升级首启缓存竞态**：`clearStorageData` 改为 `await` 且在清理成功后才写版本标记，失败则下次启动重试。
- **发布门禁**：Release 流水线补跑 `pnpm check`（typecheck / lint / 行数 / 结构 / 环 / ASCII）；自检或后续步骤失败时自动删除草稿 Release（保留 tag），避免坏包被直接转正式。

## 升级说明

- 无数据库迁移，旧库直接可用；备份格式不变。
- 仅桌面端打包链路与启动错误提示变化，Web 模式不受影响。
- v2.19–v2.22.0 的安装包仍不可用，请直接升级/重装到本版本。
