## 2. 技术要点

- **结构解析**：PDF 按文字层坐标识别页、标题/章节、表格与图注；DOCX 复用 HTML 标题/表格，PPTX 取页标题，XLSX 取工作表与表格。解析失败回退旧纯文本，扫描件与多栏保留 warning。
- **结构持久化与分块**：`document_blocks` 按文档整批替换；`document_chunks` 新增 `section_path/block_kind/table_no/table_row_start/table_row_end`。表格原子化，超长表格按数据行切分并重复表头；标题作为章节边界。
- **引用粒度**：`Citation` 增加可选 `sectionPath/tableNo/tableRow/tableCell`，检索→引用→分享导出全链路透传；表格优先于页码/段落。
- **表格问答**：`detectTableIntent` 轻量词面识别，规则重排增加 `tableIntent` 小幅权重；`locateTableCell` 按显式行/列、表头、行首标签与唯一值定位，输出 Excel 地址。
- **跨文档对比**：纯函数生成章节/表格对比模型，表格按表头/标题 Jaccard 匹配；Markdown/HTML 双格式，产物经 attachments 落盘，知识库页可预览/下载。
- **文档查看器**：章节树按前缀合并，点击切换原文块；表格面板展示表头/行号/Excel 列；引用定位自动展开并高亮目标行/单元格；块内容按纯文本渲染。
- **图表理解（可选）**：`POST /api/documents/:id/figure-summary` 渲染图注所在 PDF 页交给已配置的视觉模型；未配置时返回 422 并在查看器内联提示。
- **图检索**：规则抽取同句相邻实体对（动词/连接词为标签），写入 `knowledge_relations`；查询命中实体后 BFS 两跳、边去重、上限 12，关系事实带来源文档/页/段；引用类型 `relation`。
- **表格置信度**：缺表头、数据行不足、错列、稀疏、单列等信号降分；OCR 表格上限 0.55；结构 API 与查看器展示置信度与警告，不阻断检索。
- **评测基线**：Promptfoo 8 个 fixture 用例 + mock provider + CI 步骤；metric 分组覆盖引用可追溯、空结果、对比统计、关系可追溯、表格置信度与降级说明。

## 6. 已知边界

- PDF 表格为启发式重建，复杂版面只保证降级与警告，不承诺准确率；
- OCR 表格置信度上限 0.55，扫描件结构可能不准确；
- 关系抽取为规则实现，不做指代消解、事件抽取或 LLM 关系生成；
- 多跳上限 2 跳 / 12 条边，最多注入 2 条关系事实；
- Promptfoo 使用 mock provider，锁定 CI 口径，不代表真实模型质量；
- 旧文档不自动重解析，需手动触发结构重建；
- 视觉模型为可选能力，未配置时明确提示不支持。
