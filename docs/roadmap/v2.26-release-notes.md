# v2.26.0 发行说明

> 主题：**记得久、说得清——双时态记忆、混合召回与上下文分层压缩**
> 发布准备：2026-11-08 · 目标 tag `v2.26.0` · 迁移 v046 / v047（`LATEST_SCHEMA_VERSION = 47`）
> 完整方案：[v2.26](../plan/v2.26/README.md)

## 新功能

### 记忆写入与冲突

- **双时态事实**：`memories` 增加 `valid_from / valid_to / superseded_by / version`，新旧事实并存，旧版本标记 `superseded` 而不是直接覆盖，可回溯「曾经住北京、现在住上海」。
- **实时硬约束**：回合后任务先跑窄规则，识别过敏、忌口、带时间前缀的禁止与显式「记住」，命中即写入 `constraint`、置顶、高重要性，不调用 LLM。
- **同主体冲突消解**：同一 `subject_key` 的新内容取代旧内容，旧行 `archived + valid_to`，新行版本号 +1，两侧各写一条审计；向量与 FTS 同步新行。
- **作用域**：自动抽取绑定当前助手，手工新建为全局；召回只返回全局或当前助手记忆，历史数据保持全局可见。
- **全链路审计**：新增 `memory_events`，记录 create / merge / update / supersede / archive / restore / delete，管理页可逐条回溯。

### 混合召回

- **向量 + 关键词双通道**：向量与 FTS 各取 20 条候选，按 `0.55 × 语义 + 0.20 × 关键词 + 0.15 × 重要性 + 0.10 × 新鲜度` 融合，低于 0.5 丢弃。
- **无嵌入不再失效**：嵌入模型缺席时语义权重并入关键词（0.75 / 0.15 / 0.10），纯关键词仍可召回。
- **硬约束固定注入**：当前作用域内置顶的 constraint 每轮最多注入 3 条，不受查询相似度与时间衰减影响。
- **可按来源解释**：召回理由标记为 `pinned / hybrid / semantic / keyword`，记忆块文本按 token 预算硬限长，避免挤占上下文。

### 上下文压缩与工作记忆

- **结构化摘要**：摘要器输出 `summary / facts / decisions / open_loops`，事实落入 `conversation_facts`，携带单位、生效时间、来源消息与校验和。
- **数字与日期保真**：从折叠原文抽取数字与日期核对事实与摘要，缺失时保留原文片段或重试一次，降低「把 6 个月记成 6 周」。
- **固定注入顺序与配额**：人设 → 硬约束 → 结构化事实 → 摘要 → 最近原文 → RAG；原文 50% / 摘要 25% / 事实 10% / 记忆 10%，余量留给输出。
- **任务检查点**：计划或 Todo 执行时生成 `task_checkpoints`（目标、计划、待办、最近工具摘要、下一步），跨轮注入并在完成或超时后归档。

### 生命周期与观测

- **分数衰减**：`decay_score = importance × recency × usage`，周任务按 30 / 90 / 180 天分档，只归档不删除；置顶与 constraint 永不衰减。
- **TTL 到期**：临时事件通过 `ttl_at` 到期归档，工作记忆通过 `task_checkpoints.expires_at` 归档；到期清理不受 7 天间隔限制。
- **线上计数**：新增 `GET /api/memories/stats`，返回记忆总量、active / archived / superseded、superseded 比例、零召回率与用户纠正次数。
- **golden 评测**：冲突、陈旧、负样本、作用域隔离四类用例，断言 hit@3、误召回率、冲突解决正确率、陈旧干扰率与无嵌入召回率。

### 工程质量

- **摄入批处理**：超大知识分片按 200 条一批写入，批间让出事件循环；维度冲突在清理前校验，失败时回滚已写批次，避免长任务卡死与半成品数据。

## 修正

- **v046 迁移幂等**：改为按表/列存在性补齐，修复老库重放时 `duplicate column name: scope` 与空库直升时 `no such table: memories` 导致的迁移中断。
- **历史迁移测试**：36 个迁移用例的最新版本断言统一更新到 47，增量迁移用例补齐 46 / 47，全量测试恢复通过。
- **召回理由断言**：对话编排记忆用例由 `semantic` 更新为 `hybrid`，与双通道召回实际行为一致。

## 升级说明

- 启动时自动执行 v046 / v047，存量 `memories` 回填全文索引；旧数据标记为 `global + legacy`，升级后仍全局可见。
- 嵌入模型仍为可选；未配置时写入照常，召回走关键词通道，不阻断对话。
- 实时约束规则保持窄口径，宁漏判不误判；识别结果可在管理页删除或恢复，删除会留下审计。
- 新增 `memory_events` 与 `conversation_facts` 表，备份 / 恢复沿用现有逻辑，无需手工迁移。
- 线上计数目前只提供接口，未接入设置页可视化。
