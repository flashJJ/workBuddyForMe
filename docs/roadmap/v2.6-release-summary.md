# WorkBuddy v2.6 版本总结：会沉淀——结论可执行，记忆有来路

## 1. 主题与价值主张

v2.5 把平台底座换到了 Next 15 与 Electron 44；v2.6 回到用户价值，补两条最容易「做完就散」的链路：

**讨论 → 结论 → 行动项 → 提醒 / Flow；记忆 → 来源会话 → 来源消息 → 召回理由。**

同时完成 Electron 45 的两个破坏性迁移（`safeStorage` 异步化、沙箱 preload 全局移除），并交付三项 P1：截图粘贴引导、跨链路运行报告、桌面性能基线脚本。

## 3. 核心机制

### 3.1 会议结论与行动项

- 只有 `finished` 会议才能生成结论；生成由用户显式触发，同会议并发生成 409。
- 模型输出必须通过 Zod；非法 JSON / 形状错误不落库；长转录 > 24,000 字符先分块压缩。
- 结论支持摘要 / 决策 / 未决问题编辑；重新生成替换 generated 行动项，manual 行动项保留。
- 行动项：负责人、截止时间、`open → done/cancelled → open`；转提醒要求截止时间且助手为会议成员；运行 Flow 只接受已发布 Flow，默认把行动项内容映射到 `actionItem/query/topic/question`。
- 导出 Markdown 含议题、状态、成员、转录、结论与行动项勾选，不包含密钥或内部提示词。

### 3.2 记忆溯源

- 新提取记忆记录来源会话 + 本轮助手消息；摘要记忆只有来源会话；手工/旧记忆显示「来源未知」，不伪造。
- 召回返回 `score`（L2 → 余弦）与 `reason='semantic'`；`recall_count += 1`、`last_accessed_at` 同步刷新。
- 对话 chips 可展开查看类别、内容、相关度高/中/低与来源入口；点击 `/chat?conversation=&message=` 定位并高亮消息。
- 来源会话/消息已删除时给出可读提示；记忆本身保留。

### 3.3 Electron 45 与备份 v7

- `safeStorage` 全链路可 await，旧密文仍可解密；沙箱 preload 不依赖被移除的 Node 全局。
- 备份 schema **7**：events 轨新增 `memories.json`、`meetingConclusions.json`、`meetingActionItems.json`；旧归档缺文件按 0 降级，恢复幂等。
- 记忆恢复保留来源与召回次数；向量不入档（语义召回需重新嵌入，与知识库口径一致）。

### 3.4 P1：截图、运行报告、性能基线

- Composer 视觉模型下可直接粘贴截图；无视觉模型 / 任务模式给出明确提示。
- `/reports` 汇总 task / flow / agent-run 的成功率、中位耗时与失败 Top 5，支持时间窗、链路筛选与 Markdown/CSV 导出；不新增运行表。
- `perf:baseline` 脚本在 pack:dir 产物上采样启动、首窗、首页可交互与空闲内存。
