# v2.22.0 发行说明

> 主题：**收口——分支会话可靠性与发布闭环**

> 完整方案：[v2.22](../plan/v2.22/README.md) · 验收记录：[M4](../plan/v2.22/06-M4-实施记录.md)

## 新功能

- **分支事件随备份走**：conversations 轨新增 `branch-events.json`，恢复后分支车道、子会话节点与回传节点不再依赖重新运行；旧备份缺文件按空处理，单分支最多保留最近 200 条并标记截断。
- **终态回传补齐**：`interrupted` / `cancelled` / `budget_exceeded` 与成功/失败一样写 `branch_status` + `branch_returned`；无运行结果时摘要为空、`needsReview=true`，面板显示「无运行结果」而不是静默消失。
- **一键重试**：终态分支卡提供「重试」，以旧分支的目标与标题新建分支，旧分支保留终态与回传供追溯；并发/深度/预算上限全部复用派生校验。
- **运行超预算熔断**：结算时若会话树已用 + 预留超过上限，`succeeded` 改判 `budget_exceeded`，预留归零并写回传。
- **分支实时帧**：分支面板轮询到变化后向 RunGraph 发布分支帧，打开的图 1 秒内刷新；面板关闭即停止，10 秒快照继续兜底。

## 可靠性修正（v2.21.0 后已修未发布）

- 命令面板派生入口保留当前会话参数；消息右键可派生。
- 启动仅允许 `queued`，启动前复检并发上限；启动被拒绝时面板展示接口原因。
- 子会话继承父会话显式模型；分支详情补全 `childConversation` / `evidence`。
- 回传产物从子会话工具轨迹提取并去重；图子会话节点状态随分支终态收敛。
- 分支重命名入口与图标题同步；归档车道默认折叠。
- 排队分支可取消；运行中删除等待终态；运行中 Token 回落显示预留。
- e2e 覆盖取消、上限、运行回传与归档标记。

## 升级说明

- 无数据库迁移，旧库直接可用；旧备份可直接恢复。
- 备份格式仅 conversations 轨新增可选文件与可选计数字段，`LATEST_SCHEMA_VERSION` 保持 45。
- `waiting` 状态保留枚举但无写入路径，历史数据可正常读取。
