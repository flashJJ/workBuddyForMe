# v2.17.0 发行说明

> 可连通：模型接得上、网页搜得到、能力装得进。

## 重点

- **厂商可描述**：厂商差异从硬编码分支收拢为 `ProviderPreset` 描述与 registry。新增火山方舟 Agent Plan / Coding Plan 预设；不提供 `GET /models` 的厂商不再被当成鉴权失败，改为提示手动填写 Model ID，已配置对话模型时用首字探活验证。连接测试返回三态：已验证 / 可达但无法验证 / 失败。
- **内置联网搜索**：新增 `web_search` 工具与 SearXNG / mock 搜索后端；设置页可配置搜索服务并测试连接，助手可单独勾选联网搜索。搜索只返回标题、链接与摘要，正文由 `fetch_webpage` 按需读取；结果自动映射为引用，回答可附来源。
- **能力目录与安装代理**：Agent 可以按意图搜索能力目录，展示用途、权限、效果与预计新增工具；安装必须经用户审批，安装成功后只读工具在下一轮自动加入当前助手，write/danger 工具仍需手动勾选。未批准不落库，失败按能力包既有 fail-closed 语义回滚。

## 隐私与安全

- 搜索密钥只在本机加密保存；查询会发送到用户配置的搜索服务，设置页有明确提示。
- 搜索 endpoint 默认拒绝私网与 http 公网地址；自建 SearXNG 需显式允许私网。
- 搜索查询正文不写审计；结果去 HTML、限长，按外部不可信内容处理。
- 能力安装即使处于 `full_access`、策略 allow 或已持久授权，也会强制弹出人工审批。

## 迁移

- **零迁移**：`LATEST_SCHEMA_VERSION` 保持 42，不新增表 / 列 / 索引。
- 旧库直接可开；搜索设置与厂商配置写入既有 settings JSON。
- 不新增运行时依赖；搜索适配器仅服务端运行。
