## 2. 技术要点

- **技能版本快照**：`reconcile()` 扫描成功后按 manifest version + 目录 checksum 建档；同版本内容变化覆盖快照，同 checksum 只更新 active；能力包升级重建 `skills_state` 行时按 name + version + checksum 复用既有快照目录，避免重复占盘。
- **原子回退**：快照复制到 staging → 目标目录改名为 backup → staging 换位为正式目录；失败恢复 backup。回退后 `active_version` 对齐并重新扫描，启用态不变。
- **生产版本隔离**：`loadCompiledGraph` 统一读 `getProductionVersion()`（无生产版本回退当前版本），试运行、对话、端点与 MCP 共用同一解析；保存草稿只改 `current_version`，不改 `published_version`。
- **降级协议**：`assertUpgradeDirection` 纯函数判定 upgrade / downgrade / repair；降级必须同时满足 `confirmDowngrade` 与 `expectedVersion === 包内版本`；反向依赖在文件替换前检查，启用中直接 409，禁用中仅回传受影响列表。
- **下钻只读**：审计事件与审批项仅增加导航链接；审计页用 `history.replaceState` 同步 `runId` 参数；任务详情复用 `useTaskAudit` 取最近 10 条，不新增写操作。
- **诊断包白名单**：每个文件独立从数据库 / 服务读取固定字段，不做「先收集再过滤」；manifest 记录条目大小与 sha256；错误日志只保留时间、scope、净化类型与安全错误码。

## 6. 已知边界

- 技能快照保留最近 5 版且永不删除启用版本；单目录超过 50 MB 不建快照，不阻断加载。
- 工作流生产版本不改变编辑器草稿；无生产版本时回退当前版本。
- 能力包降级只保证代码与清单回退，不承诺设置 / effect 数据回滚；反向依赖不自动停用。
- 审计账本不自动清理；尾部截断不可检出（外部锚点仍列 P1）。
- 诊断包不含密钥、对话 / 记忆正文、绝对路径与运行 id；审计校验截断时标注 `truncated`。
- 定时 Agent 仅在应用进程存活时触发；隔离网页仍仅桌面端。
