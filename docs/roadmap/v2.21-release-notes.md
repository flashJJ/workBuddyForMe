## 新功能

- **父子会话**：从顶栏或消息底部派生独立子会话；子会话有自己的消息与上下文，父会话主线不受影响。
- **结构化回传**：分支进入终态生成 evidence（摘要、usage、需核对标记）；父会话先核对再汇总，不自动污染转录。
- **分支管理**：启动、取消、归档/恢复、删除；删除只删关联，子会话与消息保留。
- **四项上限**：并发（3）、深度（2）、每父分支数（6）、会话树 Token（200000）；设置页高级区可调，超限返回 422 与原因码。
- **预算视图**：按会话树展示已用 / 预留 / 上限；启动前先预留，终态结算归零。
- **RunGraph 分支车道**：`branch` / `branch_return` 节点与 `parent_to_branch`、`branch_to_child`、`branch_to_return` 边。

## 可靠性与数据

- 分支事件写入 `session_events`（`scope=branch`），供图投影与复盘。
- 备份 conversations 轨新增 `branches.json`：恢复先会话后分支，父/子会话缺失则跳过计数；旧归档缺文件按空。
- 恢复时 `running/waiting` 分支改写为 `interrupted`，预留归零；进程重启同样收敛，避免幽灵运行。
