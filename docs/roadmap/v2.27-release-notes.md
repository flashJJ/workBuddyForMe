## 新功能

### 引用编号契约

- **统一 `citeIndex`**：引用新增展示编号（从 1、本轮内连续唯一），与提示词资料块 `[1..n]` 一一对应；`ordinal` 收窄为「文档内片段序号」，网页结果固定 0，不再充当展示编号。
- **装配层统一编号**：RAG 资料块按注入顺序编号，工具引用按本轮追加顺序续号，多路合并后整体重排。
- **合并去重**：以 `documentId + ordinal + staticKind + tableNo + tableRow + sourceUrl` 为键，重复引用保留首条并合并更完整的片段，网页同 URL 多次搜索只留一条。
- **旧消息兼容**：`citeIndex` 为派生展示字段，旧消息缺省时前端按列表位置兜底编号，不回填、不迁移。

### 正文角标与来源定位

- **可点击角标**：正文中独立的 `[n]` 与 `【n】` 渲染为角标，点击后滚动并高亮对应来源卡（1.5 秒）；仅对已完成消息解析，流式期间保持原文，避免半截标记闪烁。
- **解析不误伤**：纯函数按行跟踪围栏代码块，跳过行内代码、既有链接、图片与脚注定义，示例代码中的 `[0]` 不被改写。
- **来源分组**：来源按「文档 / 网页」分组，折叠标题显示两类计数；超过 3 条默认折叠，≤3 条保持平铺，无引用不渲染空容器。
- **失效降级**：模型中编造的编号（无对应来源）保留原文并标注「引用不可用」；文档已删除时由查看器给出不可用提示，条目本身不隐藏、不报错。

### 回合运行摘要

- **一条摘要交代全过程**：有工具调用或有引用的已完成回合显示「工具次数（成功 / 失败）· 工具耗时 · 引用条数与来源类型」，展开后显示输入 / 输出 token 与逐工具耗时。
- **口径克制**：只展示工具耗时与 token，不宣称端到端耗时；纯对话回合继续沿用原 token 行，不重复展示。

### 抓取失败降级

- **同 URL 不重复重试**：`fetch_webpage` 对同一地址连续失败 2 次后，本轮后续调用直接跳过，结果标记 `degraded`。
- **只降级可恢复失败**：仅网络、超时、页面过大类失败累计；鉴权失败与被拒仍按原语义返回，不触发降级。
- **收尾提示**：编排器在降级后向收尾轮注入提示，要求基于已获搜索摘要作答并说明未取到全文，每轮新降级地址只提示一次。
- **失败卡收敛**：抓取失败只提供「用浏览器打开」与「检查网络 / 代理」，并显示降级说明，不再引导重复请求同一地址。

### 协作交接泳道时间线

- **一条时间线看清分工**：协作卡在预算条下按服务端 `seq` 展示 Planner → Executor → Reviewer（→ 用户）的交接记录，含角色、相邻交接耗时与结论摘要（子任务标题 / 交付摘要 / 审查意见），便于复盘谁交给了谁、每一步等了多久。
- **复用既有数据**：直接消费 v1.4 的 handoff 帧与终态回放，不新增接口、不新增存储；断线重连按 `round + seq` 去重，不重复展示。
- **轻量呈现**：空交接不渲染；审查裁决以徽标标注，摘要最多两行、悬停查看全文。

## 修正

- **`[0]` 与重复编号**：知识分片从 0 起、网页结果从 1 起导致的底部角标错乱，统一改为 1 起始的 `citeIndex`。
- **来源混淆**：文档与网页混排、无法判断引用来自知识库还是搜索的问题，改为分组展示。
- **缺失来源静默**：正文编号找不到对应来源时不再无声无息，保留原文并显示不可用提示。

## 升级说明

- 零迁移：启动时不执行新的 schema 迁移，旧库、旧备份、旧消息均可直接读取。
- `citeIndex` 只存在于消息 JSON 与内存，属派生展示字段；SSE `citations` 事件仅新增可选字段，旧前端忽略即可。
- 正文角标是增强能力：模型未输出 `[n]` 时来源卡仍完整展示，不影响回答。
