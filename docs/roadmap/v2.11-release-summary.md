## 2. 技术要点

- **统一可逆 effect**：六类 kind 共用 enable/disable/uninstall 分派；workflow 无运行时删行、有运行保留禁用行；剧本/卡片/动作成对清理。
- **事件契约向后兼容**：内置剧本继续 `titleKey`/`lineKey`，能力包剧本强制字面量 `title`/`text`；台词运行时改为判别对象，i18n 只处理 key。
- **能力包剧本不绕过导演**：短语命中后按定义直接 `admit`，勿扰/对话锁/冷却×频率/每日上限/队列全部沿用。
- **外部代理 fail-closed**：默认不注册；运行前审批（拒绝/超时/关闭开关都不 spawn）；子进程 permission 帧独立审批；`.bat/.cmd` 在 `shell:false` 下视为不可用。
- **证据三处留痕**：`subagent_runs` + WorkSignal（`source='subagent'`）+ `session_events`（`subagent_started/finished`）；终态经 `run_completions(kind='subagent')` 幂等回投。
- **发布打包修复**：standalone 曾把 `.next/cache`（约 1.6GB）带进 `resources/server`，归集后裁撤缓存与测试产物，安装包从 1.23GB 回到 192.5MB。
