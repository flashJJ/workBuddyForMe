# WorkBuddy v2.3 版本总结：用起来顺手——控件统一、窄窗响应式与开箱即用内容

## 1. 主题与价值主张

v2.2 把桌宠交互从「扁平反馈」做成了「有形状的反馈」，但主界面的体验欠账还在：下拉框是系统原生的，选项挤在一起；数值输入用的是浏览器自带的小箭头；窗口一拖窄，侧栏吃掉固定宽度、表单文字挤压；知识库是空的，工作流模板躺在种子数据里没人看得见。

v2.3 是**体验补课版**，不改后端能力口径：

**下拉与数值输入全仓统一 → 窄窗自动折叠、表单纵向堆叠 → 首启就有现成知识库与工作流可点 → MCP / 技能有地方加载。**

六条主线：

1. **下拉选择器统一**：把已安装但未使用的 Radix Select 组合成组件，全仓裸 `<select>` 归零；
2. **数值输入统一**：`NumberInput` 步进器 + 可空语义，全仓裸 `type="number"` 归零；
3. **窄窗响应式**：侧栏 <768px 折叠为图标态，固定宽改弹性，三尺寸无横向滚动；
4. **开箱即用内容**：知识库模板 3 个幂等播种、工作流 starter 3 → 6、「从模板创建」入口；
5. **MCP / 技能入口**：MCP 预置目录 4 个一键填入、技能面板「重新扫描」、全局口径文案；
6. **一致性收尾**：`FormField` 表单排版、MCP 测试连接、设计 token 文档与三尺寸 E2E。

红线不变：沿用既有设计 token，不换 UI 库、不做移动端、不改检索算法与安全口径。

## 3. 核心机制

### 3.1 Radix Select：空值语义才是迁移难点

原生 `<select>` 的观感问题只是表象，真正的坑在**空值语义**：旧代码大量用 `value=""` 表示「未选择 / 跟随默认」，而 Radix Select 的 `value` 必须是非空字符串。

做法不是改写既有业务语义，而是加一层适配：`''` / `null` 先映射到哨兵值（如 `__none__`）再转回，组件单测锁死映射；迁移逐文件回归，不做一次性批量替换。另一个取舍是定位方式：`position="popper"` 依赖 Radix 的持续 rAF 测量，在 jsdom 下会让下拉相关测试从约 0.2s 涨到几十秒，最终改用默认的 `item-aligned`，交互与视觉等效而测试恢复正常。

### 3.2 NumberInput：受控输入 + 本地草稿

步进器拆成「减号 / 输入框 / 加号」三件套，`min/max/step` 统一钳制，保留 `role="spinbutton"` 与 `aria-valuenow/min/max`。两个细节决定了它能不能替掉原生控件：

- **受控 + 本地草稿、失焦提交**：避免逐字符触发网络写；
- **`allowEmpty`**：模型上下文窗口等字段的「空 = 未设置」语义必须保住，不能迁移成 0。

### 3.3 窄窗：断点只是表象，固定宽才是根因

侧栏改成 `w-14 md:w-56`，<768px 自动折叠为图标态，用 `title` 提供可访问名；任务页网格从固定 260px 列改成 `lg:grid-cols-[260px_minmax(0,1fr)_auto]`，按钮与数值框 `shrink-0`；场景模型矩阵的固定标签列加 `sm:` 断点；助手切换器从 `w-44` 改成 `min-w-0 max-w-[12rem]`。

验收不是「看起来没坏」，而是可自动化的三条：文档级横向溢出 ≤1px、主内容可见、窄档侧栏文字隐藏而图标栏保留；外加任务页步进器数字不被裁切。

### 3.4 开箱即用：播种、模板与入口

- **知识库**：新增 3 个模板（产品需求 / 会议纪要 / 研究资料），固定 id、幂等播种，用户改名或删除后不复活不覆盖，对齐既有工作流 starter 策略；新建弹窗提供「从模板开始」，模板默认不带样本文档，避免备份体积膨胀。
- **工作流**：starter 从 3 扩到 6（新增会议纪要整理 / 竞品对比 / 知识库问答），列表空态说明来源。
- **MCP**：预置目录 4 个（filesystem / fetch / git / memory），一键填入表单，避免用户去查命令；每行补「测试连接」，失败给出排查提示。
- **技能**：技能本就是数据目录下的文件夹，落地为「重新扫描」（服务端 reconcile）而不是上传导入，避开新的落盘安全面；面板文案统一为全局启停口径。

### 3.5 表单排版与设计 token

抽 `FormField`（label + 控件 + hint + error 统一间距），先在对话框与设置表单落地，消除「标签紧贴控件」的观感；同时补 `docs/design/tokens.md`：颜色令牌、圆角/间距/字号约定、统一控件清单与硬约束、响应式与 a11y 底线，防止后续再裸用原生控件。

- **未 bump / 未打 tag**：v2.3 以 `--no-ff` 合入 main，但版本号与 Release 流程留到后续统一处理；本总结为追溯补齐。

- **不改检索与安全口径**：编译式 RAG、混合检索、MCP/技能权限确认与黑名单保持不变。
