# v2.29.0 发行说明

> 主题：**文档可信——存量重解析、质量标记与低质收口**
> 发布：待发布 · 一次迁移 v049（`LATEST_SCHEMA_VERSION = 49`）
> 完整方案：[v2.29](../plan/v2.29/README.md)

## 新功能

### 解析版本与存量盘点

- **迁移 v049 纯加法**：`documents` 增加 `parse_version`；已有 `document_blocks` 的文档一次性回填为 1，无结构块的旧文档保持 0，不重写任何解析内容。
- **待重建判定**：版本落后或没有结构块即视为待重建；状态为 pending / processing 的文档不进入候选。
- **列表可见**：知识库页显示「待重建 N 篇」汇总，单篇带「待重建」徽标；点击结构面板可重新解析。
- **质量事实**：结构预览新增待重建、不可重建、OCR 来源、低置信表格、无标题结构等可核实状态，不做主观评分。

### 批量重解析

- **串行队列**：新增进程内单飞队列，逐篇重建，可开始 / 暂停 / 继续 / 取消；暂停与取消都在当前文档结束后生效，不打断正在提交的索引事务。
- **不落库、可续跑**：候选集每次从「待重建」查询重新推导；应用重启后再次开始即自然续跑剩余文档，不新增任务表。
- **失败隔离**：单篇失败只记录文件名与原因，继续下一篇；缺原始文件的文档计入跳过，不反复尝试。
- **进度可见**：知识库页显示完成数 / 总数、失败数、跳过数、当前文档与暂停/停止状态；完成后自动刷新文档列表。
- **引用保护**：文档在引用生成后重建时，查看器提示「定位可能变化，请以引用片段为准」，不静默跳到错误位置。

### 低置信表格收口

- **不再承诺错误坐标**：表格置信度低于 0.75（OCR 重建上限 0.55）时，分片不再写入表号 / 行号，作为普通文本参与检索；回答不会给出看似精确、实际错误的单元格引用。
- **面板说清影响**：结构面板保留置信度与「已降级为文本检索」状态，并说明对回答的影响。
- **文字不丢**：降级只去掉结构化坐标，表格文字仍可被关键词与向量检索命中。

### 关系检索边界

- **可配置上限**：设置新增 `knowledgeRelationMaxHops`（1–3）与 `knowledgeRelationMaxEdges`（4–24），默认仍为 2 跳 / 12 条边。
- **服务层收窄**：非法值统一钳制到范围内，不抛错；默认行为与升级前完全一致。
- **仍是规则关系**：本版不引入模型抽取、指代消解或社区聚类。

## 修正

- **旧文档永远缺结构**：升级前的文档不会自动重解析，结构面板长期显示「尚未解析」；现在可批量盘点并重建。
- **OCR 表格假装可信**：低置信表格仍生成表格坐标，回答可能精确到错误单元格；现在显式降级为文本。
- **复杂关系问题固定断在第二跳**：跳数与边数写死，无法按问题调整；现在可在设置中放宽或收紧。
- **重建后历史引用错位**：查看器不感知文档已重建；现在比较重建时间并提示定位可能变化。

## 升级说明

- 一次迁移：启动时执行 v049，纯加法；已有结构块文档回填 `parse_version = 1`，只改版本号，不重写解析内容。
- 批量重解析不自动执行，必须由用户在知识库页触发；启动时不会扫描或重建全库。
- 低置信表格降级只影响新写入或重建后的分片；未重建的旧索引保持原样，重建后自动应用新规则。
- 关系检索设置默认值不变，不配置时行为与 v2.28 一致。

## 范围说明

本版已交付：解析版本与存量盘点、批量重解析队列与进度、低置信表格降级、引用重建提示、关系检索跳数/边数配置。

本版未交付：单元格级表格编辑与版本回滚、LLM 关系抽取与指代消解、版面模型与新 OCR 引擎、启动时自动重解析全库、跨设备同步。
