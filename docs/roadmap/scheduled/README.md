# 已排期方案归档

> 已进入版本排期的候选方案放这里，命名：`vX.Y-NN-slug.md`。
> 正式版本方案正文见 `docs/plan/vX.Y/README.md`；本目录只保留来源方案，方便追溯「这个版本为什么立项」。

## 规则

1. 候选编号沿用 `candidates/` 中的 `NN`，排期时在前面加版本号，避免同一候选换号。
2. 一个候选一个文件；多主题合并成一个版本时，保留各自文件并在版本方案中做映射。
3. 版本发布后本目录不删除文件；状态改为「已发布」，并在 [roadmap README](../README.md) 登记。
4. 正式方案、实施记录、验收与发行说明仍放 `docs/plan/vX.Y/` 与 `docs/roadmap/` 根目录，不混入本目录。
