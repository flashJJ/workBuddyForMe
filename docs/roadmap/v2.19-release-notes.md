# v2.19.0 发行说明

> 可读懂：章节、表格与出处。

## 重点

- **结构解析与持久化**：PDF 不再只按行合并文本，解析页、章节路径、表格与图注并落入 `document_blocks`；DOCX / PPTX / XLSX / MD / TXT 同步支持。8 份 fixture（多栏 PDF、合同、财报 XLSX、扫描页、DOCX、PPTX、MD、无结构 TXT）均能解析或明确降级。
- **结构感知分块与引用**：表格原子化，超长表格按数据行切分并重复表头；章节上下文进入分片前缀与 `section_path`。Citation 新增 `sectionPath / tableNo / tableRow / tableCell`，分享导出的 Markdown / HTML 同步展示章节、表号与行号。
- **表格问答与单元格引用**：表格意图加权；`locateTableCell` 定位到 Excel 地址（如「表 3 · 第 2 行 · C3」）；未命中明确标注「未覆盖」。
- **跨文档对比**：两份文档按章节与表格匹配，生成 Markdown / HTML 对比产物并落盘；知识库页可预览与下载。
- **文档查看器**：章节树、原文块、表格面板、图注面板与引用定位；对话引用点击可展开章节并高亮目标行/单元格。
- **图表 / 图片理解（可选）**：配置视觉模型后可对 PDF 图注页生成摘要；未配置时明确提示不支持，不阻塞文本阅读与检索。
- **图检索**：`knowledge_relations` 落库，规则抽取同句相邻实体关系；查询命中实体后 BFS 两跳检索，关系事实带来源文档/页/段，引用类型为 `relation`。
- **表格置信度与降级**：缺表头、错列、稀疏等信号降分；OCR 表格置信度上限 0.55；结构 API 与查看器展示置信度与警告。
- **RAG 质量基线进入 CI**：Promptfoo 8 个 fixture 用例覆盖章节定位、单元格、空结果、跨文档对比、直接/多跳关系、扫描表格置信度与旧文档无结构；mock provider 零网络执行。

## 隐私与安全

- 解析、分块、关系抽取与对比全部在本机完成；不引入 Python/Go/Rust sidecar，不新增解析服务。
- 视觉模型仅在用户配置后启用；未配置时 API 返回明确 422，查看器内联提示，不发起模型请求。
- 关系事实与引用只带来源文档/页/段；多跳上限 2 跳 / 12 条边，最多注入 2 条关系事实，避免图噪声污染上下文。
- 文档查看器按纯文本渲染块内容，不注入 HTML；新表与引用字段随分享导出走既有脱敏链路。
- Promptfoo 使用 mock provider，CI 不访问外部模型。
