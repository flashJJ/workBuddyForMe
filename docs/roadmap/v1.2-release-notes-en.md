## WorkBuddy For Me 1.2.0 — Release polish

Release date: **[DATE, 2026-10]** · Platform: **Windows 64-bit** · Installer: `WorkBuddyForMe-Setup-1.2.0.exe`

This release adds no new feature lines. Instead, it closes every gap on the path **from downloading the installer to having your first successful conversation**: a branded installer, a first-run setup wizard, a full English interface, dark mode, accessibility improvements, an in-app help center, and a keyboard-shortcuts overlay.

### ✨ First-run setup wizard

New users now get a 4-step wizard on first launch:

1. **Welcome** — what the app is and how your data stays on this machine.
2. **Connect a model** — choose a cloud OpenAI-compatible API (Base URL + API key, with a connection test) or **detect a local Ollama instance** in one click; discovered models can be added inline, with install and `ollama pull` guidance when Ollama isn't running.
3. **Voice (optional)** — download the offline speech-recognition and/or speech-synthesis models in the background without blocking setup.
4. **Done** — quick pointers to the command palette, voice button, and settings.

The wizard can be skipped at any step and replayed later from **Settings → About → Replay setup wizard**. Existing users upgrading from an older version will **not** see the wizard automatically.

### 🌐 English interface & better error messages

- The core experience is now fully bilingual (**简体中文 / English**), switchable instantly in **Settings → Language** — no restart required, and the choice persists.
- User-facing API failures are now shown as localized messages keyed by error code instead of raw developer text.
- Some advanced/developer panels (flow canvas internals, advanced voice parameters, debugger) remain Chinese in English mode; they will be translated in a later release.

### 📖 In-app Help Center & keyboard shortcuts

- **Settings → Help & FAQ**: ten built-in articles covering getting started, installation/SmartScreen, cloud providers, Ollama, model capabilities, voice downloads, data & backup, uninstall behavior, shortcuts, and updates — each directly linkable via an anchor.
- Press **Ctrl + /** anywhere to open the keyboard-shortcuts overlay (also reachable from Settings → About).
- The main error screen now offers a **View help** action.

### 🎨 Dark mode, refined

- Theme now supports **Light / Dark / System** (follows Windows automatically) with a single source of truth shared between the sidebar toggle and Settings; no more desynced switches or light-on-dark leftovers, including code highlighting.

### ♿ Accessibility

- Skip-to-content link, proper page landmarks, visible keyboard focus rings throughout, and full ARIA semantics for the command palette (combobox/listbox/active option).
- Native browser confirmation dialogs were replaced with accessible in-app dialogs; destructive actions default the focus to **Cancel**.

### 📦 Installer, branding & updates

- Custom application icon across the exe, taskbar, installer/uninstaller, Start Menu, and desktop shortcut; Chinese-first installer UI (switchable to English) with a license page and a dedicated Start Menu program group.
- **Uninstalling keeps your data by default.** Interactive uninstall offers an optional, clearly warned "delete my data as well" choice; automatic (silent) upgrades never delete data.
- Automatic in-app updates from older releases continue to work, and your data and settings are preserved across the update.
- Fixed a packaging issue where the vector-search native component (`sqlite-vec`) could be missing from installed builds.

### 🔒 Local-first, as always

Conversations, knowledge bases, attachments, and API keys stay on your computer. Cloud providers are called directly from your machine; local models (Ollama) and offline voice models let you run fully offline. No account, no telemetry upload.

### ⚠️ Installing this release

The installer is **not yet code-signed** (a signing certificate is planned for a later release). On first run Windows SmartScreen may show a warning:

1. Click **More info**.
2. Click **Run anyway**.

Only download releases from this repository's official Releases page.

### Upgrading

- Use **Settings → About → Check for updates**, or download the installer and install over the existing version — settings and data are preserved.
- Note: API keys entered in the development build (`dev:3000`) use a different local key store than installed builds and may need to be re-entered once in the installed app.
