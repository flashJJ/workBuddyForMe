# v2.11.0 发行说明

> 可扩展 II：六类能力 effect 全接通，本地 CLI 外部代理从接口缝到可用实现。

## 重点

- **六类 effect 全接通**：能力包可安装 / 启停 / 卸载 `skill`、`mcp`、`workflow`、`pet-action`、`event-script`、`report-widget`；坏包逐类 422，失败回滚不留半成品。
- **事件剧本与报告卡片**：事件 schema 支持字面量 `title` / `text`；能力包剧本按短语触发并受导演三道锁约束；报告页渲染声明式卡片，数字复用运行证据汇总口径。
- **外部代理（本地 CLI）**：默认关闭、每次运行先审批、严格 JSON Lines 协议；超时 / 输出上限 / 取消均杀进程树；运行证据落 `subagent_runs` + WorkSignal + `session_events`，终态幂等回投会话。
- **管理页收口**：`/capabilities` 支持 kind 筛选、effect 详情、六类示例下载与外部代理区；设置页新增「来自能力包的剧本」与对话页试演深链；桌面端支持外部代理工作目录选择。
- **数据与迁移**：迁移 v040 纯加法（`workflows.origin_capability_id` + `installed_event_scripts` / `report_widgets` / `subagent_runs`）；旧库升级数据保留。
- **工程门禁**：`pnpm check` 与 8 包单测全绿；生产模式 Web e2e 122/122；桌面冒烟 10/11（`computer-input` 属当前桌面会话环境限制）。

## 安装包

- `WorkBuddyForMe-Setup-2.11.0.exe`（约 192.5 MB）
- `WorkBuddyForMe-Setup-2.11.0.exe.blockmap`、`latest.yml`（自动更新元数据）

Windows 10/11 x64；Web 模式可跨平台。默认不需要云账号，数据、密钥与向量索引留在本机。
