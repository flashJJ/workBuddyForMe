# WorkBuddy For Me v1.7.0 — Release Notes

## WorkBuddy For Me 1.7.0 — Rituals: the right moment, in character

Release date: **2026-10-14** · Platform: **Windows 64-bit** · Installer: `WorkBuddyForMe-Setup-1.7.0.exe`

v1.6 gave your companion feelings that persist. v1.7 gives those feelings **timing**: a declarative scene engine that performs small scripted moments when the context is actually right, persona-voiced reminders you can create simply by asking in chat, and your own phrase-to-scene rules. Every proactive behavior is locally decided, strictly bounded, and measured against one negative north-star metric — **how often it interrupts you**.

### 🎬 A declarative scene engine

- Scenes are data, not ad-hoc code: each script is an ordered list of eight whitelisted step types — **expression, motion, gaze, speech, wait, branch, fx, spatial** — with white-list-only conditions and no dynamic evaluation.
- Eight built-in scenes ship in the box: **morning greeting, goodnight, welcome home, being praised, shy-after-pats, comfort when ruffled, task success, task failure**.
- The engine is a pure, unit-tested core; the renderer (v1.6 Live2D / TTS / pet-window primitives) is just one adapter. Manual **try-run** is always available from the avatar area.
- Per the unattended-use boundary, scenes play **only in an interactive UI session**: API/MCP-triggered turns never perform, they only enqueue.

### 🔒 Three locks before any scene plays

A scene is admitted only when all locks pass:

1. **Do-not-disturb hours** (23:00–8:00);
2. **a conversation is not currently in progress**;
3. **the scene's own cooldown and daily cap** still have budget.

A **frequency tier** scales every cooldown — restrained ×1.5, standard ×1, close ×0.6 — and each of the eight scenes can be switched off individually. Suppressed runs are recorded with their reason, silently.

### ⏰ Role-based reminders

- **Once / daily / weekly** reminders stored as wall-clock plus timezone (fixed Asia/Shanghai, consistent across scheduler and UI); the tick compares only UTC instants, so DST can never double-fire.
- When the main window is not visible, the reminder falls back to an **OS system notification** instead of being lost.
- Create reminders **by just chatting** — say *「提醒我明天下午三点喝水」* and a deterministic local parser creates the task with zero model calls, replying with a bilingual confirmation, or asking for the missing time when it cannot resolve one. Failed/invalid creations fall back to a normal model turn instead of faking success.
- Reminders surviving from a backup are automatically re-timed to the future on restore.

### 🧩 Your own phrase triggers

Bind any combination of **phrases to a scene** per assistant: messages containing the phrase (local, case-insensitive containment match — no regex, nothing leaves the machine) pass a local gate checking **time window, cooldown, daily cap and minimum intimacy**, and then still go through the director's three locks. Rules are fully manageable in Settings (create, edit, enable, delete) with optimistic toggling.

### 💗 Scenes move the relationship

A scene that plays to completion can apply a **praise** or **comfort** emotion delta (comfort is a new v1.7 soul-event type) with `source=event`. Skipped or interrupted scenes apply nothing, the linkage call is best-effort, and it can never affect the actual chat reply.

### 📊 The disturbance scoreboard

A new per-assistant panel shows the last 30 days: **completed plays, acceptance rate, interruption rate**. If the interruption rate reaches 20% it suggests lowering the frequency tier — a suggestion only; the app never changes your settings unprompted.

### 🎭 Personality weights

Custom assistants gain four persona sliders — **frankness, tsundere, shyness, tolerance** — carried into their chat configuration; existing assistants default to neutral 0.5.

### 💽 Backup: the events track (archive schema v3)

The archive's events track now carries custom assistants **with personality weights**, all reminders, the last 90 days of scene-usage ledger, and custom phrase triggers. Restore is idempotent (`INSERT OR IGNORE`), never overwrites local rows, and re-times enabled reminders afterward.

### Known limits

- Only the eight built-in scenes can be bound in this version; custom scene authoring is reserved for a later release. Phrase matching is local containment matching by design.
- Natural-language reminder creation understands Chinese cue phrases ("提醒我/叫我"); confirmations and clarifications are bilingual.
- No audio assets ship in this version; external Live2D model import remains permanently disabled per the Cubism licensing boundary.
