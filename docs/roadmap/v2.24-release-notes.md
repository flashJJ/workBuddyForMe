# v2.24.0 发行说明

> 主题：**过程可读、能力可用——工具调用体验收口与 MCP 能力生态**
> 发布：2026-11-07 · tag `v2.24.0` · 无迁移（`LATEST_SCHEMA_VERSION = 45`）
> 完整方案：[v2.24](../plan/v2.24/README.md)

## 新功能

### 对话过程

- **工具轮收尾**：工具调用轮数用尽且正文为空时，追加一条「只基于已获得结果作答」的收尾指令，以 `tools=[]` 再调用一次模型；只有收尾轮仍拿不到文本，才退回「未能形成回答」的兜底文案。
- **工具调用时间线**：同一回合的调用聚合为一张可折叠卡片，头部显示「工具调用 · N 次 · 成功 X · 失败 Y」；流式期间自动展开，完成后自动收起。
- **四态与失败归一**：成功 / 失败 / 被拒绝 / 已熔断从普通失败中拆出；失败原因归一为超时、限流、鉴权、页面过大、网络、被拒、熔断、未知。
- **失败可操作**：抓取网页失败可「用浏览器打开」目标地址；联网搜索失败可直接跳到搜索设置检查服务。
- **流式相位**：按当前运行中的工具显示「正在搜索网页 / 阅读网页 / 检索知识库 / 执行工具 / 整理结果」。
- **可见用量**：助手消息底部显示「本轮 N tokens」，悬停查看输入、输出与合计；仅对已完成且有用量的助手消息渲染。
- **桌面一致性**：设置保存后通过 `BroadcastChannel` 广播，其余窗口失效查询即时生效；桌宠勿扰、互动短句无需重开桌宠。
- **桌宠气泡收口**：只渲染包含文字或数字的整句碎片，`idle` 时清空并加 8 秒兜底，不再残留纯标点气泡。

### 能力生态

- **MCP 能力目录**：14 个精选服务器，按推荐 / 可选 / 需凭证三档展示；目录项显式声明运行依赖（Node / uv / Chrome）与最低 Node 主版本，参数用 `{{dir}}` / `{{key}}` 占位，安装时由用户填写目录或密钥。
- **运行环境预检**：安装前并行探测 `node`、`npx`、`uvx` 版本（4 秒超时），并按平台探测本机 Chrome；探测失败一律降级为不可用，不抛错、不阻断设置页。
- **批量安装状态机**：逐项预检依赖、跳过同名服务器、创建后每 2 秒轮询连接状态（最长 90 秒）；失败不阻断后续条目，鉴权类失败单独标记为 `needs_auth`。
- **装完启用给助手**：安装成功后可在同一面板把新工具并入助手白名单，默认不勾选，避免权限扩散。
- **远程 MCP 传输**：支持 SSE 回包解析、`Mcp-Session-Id` 会话头、`MCP-Protocol-Version` 协议版本、关闭时 `DELETE`；401 时刷新 OAuth 令牌并重试同一请求一次。
- **MCP OAuth 2.1**：从受保护资源元数据发现授权服务器，支持动态客户端注册、PKCE S256、一次性 state、授权回调页、令牌交换、加密存储与到期前刷新；设置页显示未授权 / 已授权 / 已过期状态，支持重新授权与清除。
- **联网搜索新增 Brave / Tavily**：两家 API Key 加密保存在本机，界面只显示脱敏串；支持保存、测试连接与清除，切换服务时不会把新 Key 存到旧服务名下。
- **公共 SearXNG 提示更新**：不再推荐依赖公共实例，优先引导配置 Brave / Tavily 或自建实例。

## 修正

- **全屏舞台多角色出画**：三个 Live2D 角色原先各建一个 WebGL 上下文，Cubism 模块级共享的裁剪 FBO 跨上下文互相绑定，导致只有第一个角色正常渲染。改为舞台共享单一 PIXI 应用/上下文承载全部 Live2D 模型；省电档只暂停非发言者更新，不再卸载成可能空白的立绘；帧率看门狗增加 6 秒预热并跳过不可见窗口，避免开场加载长帧误判；操作台改为紧凑布局并把背景/场景收进折叠区；散焦后「说台词 / 切换表情」自动回到中槽；F11 经主进程原生全屏切换，避免与浏览器 Fullscreen API 冲突。
- **Windows 下 npx 无法启动 MCP**：`buildSpawnCommand` 给裸命令名 `npx` 也加了引号，cmd 解析 `.cmd` 包装时 `%~dp0` 指向项目目录，npx 找不到 npm 自身模块，进程直接 `code=1`。改为只对含空格或引号的命令加引号，`.exe/.com` 直启；修复后文件系统服务器发现 14 个工具、记忆服务器发现 9 个工具。
- **旧预置服务器失效**：移除命令错误（用 npx 拉取已归档包导致 404）的 fetch / git 预置，改为正确实现或目录项；去掉写死的盘符路径，改为目录选择。
- **公共搜索实例反爬**：实例返回 HTML 反爬页时，`response.json()` 直接抛 `Unexpected token '<'`；改为先读文本并归一为可读的搜索错误。
- **设置与桌宠联动**：治理策略输入框补示例、知识检索步进器不再被 `w-full` 拉满整列、设置保存后桌宠即时刷新、开发态图标路径兼容两种产物布局。
- **页面骨架与主题一致性**：新增 `PageHeader / PageShell / PageBody` 统一样式骨架，审批、能力包、计划、审计、时间线、助手、任务、工作流、运行记录、运行报告、会议、设置统一为全宽头部 + 24px 内容区；审计页哈希链横幅改用语义 `success` 令牌，暗色/夜金主题不再刺眼；会议页主按钮回到共享 `Button`；窄屏下头部操作区自动换行，不再撑破标题。

## 升级说明

- 无数据库迁移，旧库直接可用；`LATEST_SCHEMA_VERSION` 保持 45。
- 不新增 UI 依赖，沿用 Radix + Tailwind；不改变既有业务数据流。
- MCP OAuth 令牌与搜索 API Key 复用现有加密能力写入 `settings_kv`，不新增表。
- Windows 上 `npx` / `uvx` 仍经 `cmd /d /s /c` 包装，仅修正裸命令名的引号规则。
- 需要 Node / uv / Chrome 的目录项会在安装前预检，缺失时直接给出可读原因，不写库。
