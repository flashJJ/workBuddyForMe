# v2.23.0 发行说明

> 主题：**质感升级——把「能用」做成「看起来可靠」，并补桌面常驻入口**
> 发布：2026-11-06 · tag `v2.23.0` · 无迁移（`LATEST_SCHEMA_VERSION = 45`）
> 完整方案：[v2.23](../plan/v2.23/README.md)

## 新功能

- **设计基座**：五套主题逐套补齐三级表面（页底/卡片/浮层）、三档阴影、三档动效时长与统一缓动；字体栈中文优先，数字统一等宽。Button 支持 loading 且四态齐备，Input/Textarea/Select 焦点环与高度对齐，Dialog 改为纯 CSS 关键帧入场 + 毛玻璃遮罩，Badge 三档尺寸。
- **消息与富文本**：用户消息改为右对齐胶囊，复制/重试/反馈收进 hover 与键盘 focus 浮层；代码块增加语言栏与复制按钮（1.5 秒反馈）；表格加斑马纹与首列粘性，补齐标题、列表、引用、分割线的排版节奏；流式光标改为呼吸条。
- **聊天页骨架**：消息区与输入区统一 `max-w-3xl` 居中，超宽窗口不再贴边拉伸；会话列可收成 48px 图标条，形象栏在 1280px 以下默认收起，二者共用同一套持久化收起逻辑；阶段条在窄屏折叠为单行；滚动区上下边缘渐隐。
- **动效与空态**：滚离底部 200px 浮出「回到底部」；首轮生成显示骨架屏；空态改为品牌区 + 三张示例 prompt 卡（点击只填输入框，不自动发送）；EmptyState/ErrorState 收敛为「图标 + 标题 + 说明 + 主按钮」四段式。
- **桌面常驻托盘**：应用启动即常驻托盘，左键/右键弹出按实时状态重建的菜单——显示/隐藏主窗口、桌宠开关、全屏舞台、彻底退出。主窗因桌宠驻留而隐藏时弹一次气泡提示，tooltip 标注「桌宠运行中」。

## 修正

- **开发态图标路径**：tsup 产物的 `__dirname` 是 `dist`，旧逻辑多退一层指向不存在的 `apps/build/icon.ico`，导致开发与 e2e 下窗口图标一直回落到 Electron 默认图标；改为同时兼容 `dist` 与 `src/main` 两种布局，并补硬断言测试。
- 托盘创建失败（无桌面会话等异常环境）降级返回 false，不再拖垮应用启动。

## 升级说明

- 无数据库迁移，旧库直接可用；`LATEST_SCHEMA_VERSION` 保持 45。
- 不新增 UI 依赖（沿用 Radix + Tailwind），未改动业务数据流。
- 主题令牌新增 `--surface-*` / `--shadow-*` / `--motion-*`，老主题无需手工迁移。
