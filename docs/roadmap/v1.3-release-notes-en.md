## WorkBuddy For Me 1.3.0 — Knowledge that answers precisely

Release date: **[DATE, 2026-10]** · Platform: **Windows 64-bit** · Installer: `WorkBuddyForMe-Setup-1.3.0.exe`

This release makes your knowledge bases **answer with the exact facts you stored**. Documents are no longer just chopped into fragments — they are *compiled* into entity facts and document highlights that get injected first when you ask a question, with sentence-level citations down to the page and paragraph. Hybrid retrieval, knowledge governance, and a background compile queue round out the release, and the remaining interface is now fully bilingual.

### 🧠 Knowledge compiler — facts before fragments

- After a document is indexed, WorkBuddy **compiles it automatically** (no model calls needed): it extracts **entity facts** (model numbers, parameters, quoted terms, Chinese/English aliases) and **document highlights** (a one-line TL;DR plus the three most informative sentences and key terms).
- When you ask a question, these compiled facts are injected **ahead of** ordinary retrieved fragments, so the assistant quotes the stored value instead of a paraphrased neighbor chunk. The retrieval routing is on by default and can be turned off in **Settings → Knowledge** (falls back to the previous behavior with zero difference when nothing is compiled).
- Optional **LLM enhancement** while compiling is available but off by default; if it fails or times out, compilation silently falls back to the rule-based result — compilation never blocks or breaks.

### 🔎 Hybrid retrieval

- Search now runs **two channels in parallel** — semantic vector search and keyword full-text search (with CJK-aware tokenization for Chinese) — merged with a reciprocal-rank fusion so exact terms like a model number hit even when embeddings miss, and vice versa.
- A reranking pass pushes chunks that actually mention your query terms to the top. Configure similarity floor, snippet count, and the hybrid switch in **Settings → Knowledge**.

### 📌 Sentence-level citations

- Citations in answers now carry **page and paragraph coordinates** (for PDFs and sectioned documents) and character offsets, shown next to each cited snippet.
- Compiled entity facts and summaries are cited distinctly so you can tell "the document states" from "retrieved fragment says".

### 🛡️ Knowledge governance

- **Conflict detection**: when two documents state different values for the same entity (version numbers, measurements, titles), they are surfaced in the knowledge base page as pending conflicts for you to adjudicate — instead of silently letting the newer chunk win.
- **Duplicate detection**: near-duplicate documents across a knowledge base are flagged using vector similarity between sampled chunks.
- **Same-name replacement**: re-uploading a document with the same filename replaces its content in place, purges stale facts and fragments, and recompiles automatically — no orphaned citations from the old version.

### ⚙️ Background compile queue

- Compilations run in a **single-worker FIFO queue** triggered automatically after ingestion (toggle in Settings), with live progress, status counts, cancel, and per-document retry from the knowledge base page. Model choice for the optional enhancement is yours to pick.

### 🌐 Fully bilingual interface

- The seven domains still shown in Chinese in v1.2 — the **flow canvas editor, flow run history, tool debugger, in-chat tool trace, voice panels, avatar (Live2D) settings, and desktop-pet** — are now translated into English, switchable as before in **Settings → Language**. (Third-party Live2D license text intentionally remains in English as provided.)

### 🔒 Local-first, as always

Conversations, knowledge bases, compiled facts, attachments, and API keys stay on your computer. Knowledge compilation is rule-based by default and calls **no model at all**; cloud providers are called directly from your machine; local models (Ollama) and offline voice models let you run fully offline. No account, no telemetry upload.

### ⚠️ Installing this release

The installer is **not yet code-signed** (a signing certificate is planned for a later release). On first run Windows SmartScreen may show a warning:

1. Click **More info**.
2. Click **Run anyway**.

Only download releases from this repository's official Releases page.

### Upgrading

- Use **Settings → About → Check for updates**, or download the installer and install over the existing version — settings, data, and knowledge bases are preserved. Already-indexed documents are compiled automatically on their next update, or trigger **Compile** manually from the knowledge base page.
- Note: API keys entered in the development build (`dev:3000`) use a different local key store than installed builds and may need to be re-entered once in the installed app.
