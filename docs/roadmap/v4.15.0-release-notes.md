# v4.15.0 发行说明

> 主题：**动作契约收口、桌宠发起聊天与视觉巡检 L1**
> 发布：tag `v4.15.0` 已推送，Release 已正式发布（2026-11-20）
> 覆盖版本：v4.11 → v4.15（v4.11–v4.14 未单独打 tag，随本版一并发布）
> 数据库：无新增迁移，`LATEST_SCHEMA_VERSION` 不变；备份格式不变
> 安装包：由 Release workflow 构建后回填文件名与体积

## 一、核心功能更新

### 1. 动作契约收口

- 删除 `InteractionAction` 中不可达的 `event.fire` 与 `chat.request` 两个变体；
- 移除执行器与录制器中的对应分支，录制器继续依赖联合类型穷尽检查；
- 修正执行器守卫范围：字幕动作不再依赖表现控制器，模型未加载时仍能输出字幕；
- 新增执行器行为测试，覆盖「无控制器仍出字幕」与「有控制器才驱动表现」两类路径。

### 2. 桌宠发起聊天

- 右键菜单新增「聊两句」：问候一下 / 求安慰 / 陪我玩；
- 桌面端主进程聚焦主窗并跳转对话页，通过独立 IPC 通道下发语义键；
- 预加载层对载荷做白名单校验，只接受三个固定语义键，不传自由文本；
- 对话页按当前语言解析文案，仅预填草稿并聚焦输入框，**不自动发送**；
- 共享包新增 `onChatRequest` 桥接方法与语义键类型守卫。

### 3. 视觉巡检 L1

- 新增 Playwright 截图用例，覆盖设置页基础区、记忆面板、上下文洞察面板；
- 固定 1280×800 视口、语言、主题与种子数据，关闭动画与光标，允许 2% 像素差异；
- 明确排除 WebGL 形象、VRM/Live2D、透明桌宠窗与会议舞台；
- 新增 `test:e2e:visual` 脚本，默认跳过，需显式开关；
- 持续集成与夜间流水线接入视觉步骤并上传差异产物，首月 `continue-on-error`。

## 二、累计版本（v4.11–v4.14）

- **v4.11 联网有预算**：抓取权限、并发控制、分层返回与上下文窗口缩放；
- **v4.12 接线与意图可观测**：`hintApplied` 可见、草稿建议、按状态清空记忆；
- **v4.13 代码健康度**：产物导出、热点模块拆分、目录收敛与门禁补强；
- **v4.14 选型规划**：桌宠动作接线评估与视觉巡检分层选型，仅文档，无代码变更。

## 三、重要优化与修复

- 执行器字幕早退缺陷：控制器为空时字幕被一并跳过，已收窄守卫范围；
- 桌宠聊天入口不走动作链：避免绕过会话锁、勿扰、冷却与每日上限；
- 视觉基线只允许在固定 Linux 环境生成，避免跨平台字体差异污染；
- 演示数据在用例结束后清理，不依赖开发机历史数据。

## 四、兼容性变更说明

- **共享类型**：删除两个从未被任何动作链引用的动作变体，内部包无对外发布；
- **IPC**：新增桌宠聊天请求通道与语义键白名单，旧客户端不受影响；
- **数据库 / 备份**：无迁移、无格式变化；
- **设置**：无新增用户可见设置项，默认行为不变。

## 五、升级注意事项

1. 本版无数据库迁移，正常覆盖安装即可；
2. 若曾自行扩展动作配置并引用已删除的两个变体，需要同步移除；
3. 视觉巡检首月为非阻断，失败请查看上传的截图与差异产物；
4. Draft Release 需人工核对安装包、`latest.yml` 与 blockmap 后转正。

## 六、验证

- `pnpm --filter @wbfm/shared test`、`@wbfm/web test`、`@wbfm/desktop test` 全量通过；
- 视觉用例本地默认跳过，首次基线由固定 Linux CI 生成后提交。
