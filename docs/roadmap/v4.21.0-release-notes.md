## 一句话

v4.21 把长期记忆收成一个入口：场景决定预算，同主体只注入裁决后的那一条，固定 / 降权 / 合并 / 归档全部可追溯，召回解释与导出都不越过隐私边界——零迁移。

## 新功能

### 统一召回入口

- 新增 `recall({ query, scene, budget, ... })`，场景预设 `chat` / `task` 3 条 × 600 token，`intent-forget` 5 条 × 750 token；
- token 用字符近似（`ceil(chars / 2)`），不引入 tokenizer；置顶不计 token；
- 超预算按融合分升序丢弃，同分按 id 升序，结果可复算；
- 空查询直接返回空数组，不写召回统计。

### 冲突裁决

- 同一 `subjectKey` 每轮最多注入 1 条；
- 裁决顺序：用户固定 > 新鲜度 > 置信度 > 稳定顺序；
- 输出理由 `pinned / fresher / higher-confidence / stable-order`；
- 落选值保留在库中，可查询但不注入。

### 用户治理

- 设置页新增固定 / 取消固定、升权 / 降权、合并与归档；
- 全部写 `actor='user'` 审计，重复操作不重复写入；
- `constraint` 取消固定返回 409，并内联提示；
- 合并保留目标、归档来源，审计只记 `mergedFrom` id；
- 统计卡新增固定数、降权数与合并数，轮转后仍可复算。

### 解释与导出

- 设置页只读「最近召回」：场景、耗时、通道命中、丢弃原因与裁决理由；
- 轨迹只保存在进程内最近 5 次，不落库、不上报，不含 query 原文与记忆正文；
- 记忆导出 Markdown / JSON，文件名 `memories-YYYYMMDD.md|json`；
- 导出字段白名单，排除来源会话与消息 id、向量与路径。

## 验证

- `pnpm check` 全绿；
- `pnpm verify:local` 全绿（含单测、集成、评测、性能脚本与 Web 生产构建）；
- 定向 E2E：固定 / 取消固定、降权 0.5→0.3、合并归档、导出下载、召回轨迹 1/1 通过；
- 回放对比：16 条 golden 用例 hit@3 `0.875`、零召回率 `0`、关系邻居 4/4，与 v4.20 基线一致。

## 兼容与迁移

- 零数据库迁移，备份格式不变；
- 治理动作复用现有 `pinned / importance / confidence / subject_key / version` 字段与 `memory_events` 审计表；
- `recall` 的返回结构不变，提示词装配不改；
- 不新增运行时依赖，不更换嵌入模型、不重建向量索引。

## 未包含

- Controller Pipeline / DAG 并行；
- 视觉巡检 L2/L3、云端性能上报与多机基线；
- 记忆社区聚类与主题簇摘要；
- 跨设备云同步、LLM 关系抽取与指代消解自动写入。
