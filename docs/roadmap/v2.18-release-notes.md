# v2.18.0 发行说明

> 可交付：图表出图、产物落盘、内容包可选导入、结论有出处。

## 重点

- **产物文件管道**：新增 `artifact_write`，模型生成的 HTML / SVG / Markdown 可落盘为文件；对话内可预览与下载，刷新后仍可用。产物复用 attachments 存储，独立预览路由带 CSP + sandbox，禁止脚本、外链与同源 Cookie。
- **10 类结构化图表**：新增 `diagram_render`，支持架构 / 流程 / 时序 / 状态机 / ER / 时间线 / 四象限 / 泳道 / 柱状图 / 折线图。模型只给类型与结构化数据，布局、箭头、坐标轴由模板生成；数据图校验空序列、缺值与非法数值。
- **SVG / PNG 导出**：图表产物可在对话卡片直接导出 SVG，或用 Canvas 导出 2 倍 PNG；Web 与桌面共用同一客户端实现，不引入服务端 Chromium / resvg。
- **内容包可选导入**：知识库模板页可导入《高性价比人生指南》。正文不随应用分发，用户确认后从固定 commit 下载 34 节 Markdown，逐文件与整包 SHA-256 校验通过才建库；失败不建库。
- **有出处的结论**：`web_search` / `fetch_webpage` / `knowledge_search` 的结果带来源、覆盖范围、未覆盖限制与采集时间，tool-trace 与分享导出可见；空结果与失败也明确标注未覆盖。证据不进模型上下文。
- **生活决策技能**：内置 `life-decision-guide`，急症与进行中的法律程序先分流，再按书检索并引用「第 N 节第 M 条」；没查到不凭记忆作答。

## 隐私与安全

- HTML 产物视为不可信内容：预览路由 `CSP sandbox; default-src 'none'`，iframe 禁止脚本与同源访问。
- 内容包只允许清单内固定 URL；逐文件 + 整包 SHA-256 校验，下载失败或哈希不一致不创建知识库。
- 内容包保留 CC BY 4.0 署名、许可链接与“未修改原文”说明；医疗 / 法律 / 财务内容只做检索引用，不替代医生、律师或会计。
- 证据元数据只用于界面与导出展示，不写入模型消息。

## 迁移

- **零迁移**：`LATEST_SCHEMA_VERSION` 保持 42，不新增表 / 列 / 索引。
- 产物复用既有 attachments 表；证据随 `messages.tool_trace` JSON 存储。
- 不新增运行时依赖；PNG 由客户端 Canvas 生成。
