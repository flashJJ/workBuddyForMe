## 一句话

v4.23 让流程在进程崩溃、窗口关闭、系统重启之后能自己接上：已成功节点不重跑，可续跑的运行自动恢复，可重试错误按退避重试，写操作在途时保持人工介入——零迁移。

## 新功能

### 节点级 checkpoint

- 从 `workflow_runs.input_json` 与 `node_executions` 重建作用域、节点状态与条件分支边；
- `succeeded` 节点复用落库输出，`skipped` 节点维持跳过；
- 续跑复用原 `node_executions` 行，不产生重复记录。

### 启动自动续跑

- 恢复扫描先判定再分流：可续跑运行 `interrupted → queued`，风险运行保持 `interrupted`；
- `waiting_human` 运行重启后重新进入等待；
- human / agent / 写危险工具在途时不自动重放，原因可查；
- 运行版本变化、chat 触发、编译失败均不自动续跑。

### 重试与退避

- 节点 `config.retry`：`maxAttempts`（1–5）、`backoffMs`、`maxBackoffMs`；
- 指数退避、无抖动，事件携带 `attempt`；
- 引用解析、参数校验、权限拒绝、资源缺失不重试。

### 节点超时

- 节点 `config.timeoutMs`（1 秒–10 分钟）；
- 仅对 `llm`、`knowledgeSearch`、只读 `tool`、`end` 生效；
- human、写/危险 `tool`、agent 忽略超时。

### 观测

- `run_started` 新增 `resumed` 与 `resumeReason`；
- `node_started` / `node_failed` 新增 `attempt`；
- 执行面板只读展示「续跑」与「重试 ×N」。

## 改进

- 启动恢复从「一律收敛」变为「按安全矩阵分流」，长流程不再必须人工重放；
- 失败节点支持配置化重试，瞬时错误不再直接终止运行；
- checkpoint 完全复用现有表，无新增存储与依赖。

## 兼容性

- 零数据库迁移，备份格式与 `LATEST_SCHEMA_VERSION` 不变；
- 不新增事件类型；旧读取方忽略新字段即可；
- 未配置重试/超时、无中断时，事件序列与 v4.22 一致；
- 回退代码即可恢复旧恢复策略。

## 验证

- `pnpm check`：类型、Lint、行数、目录、循环依赖、MSW、框图、资产、surface、E2E 隔离全绿；
- `pnpm verify:local`：eval、perf、unit、integration、web build 全绿；
- 定向测试：checkpoint 重建、恢复安全矩阵、续跑幂等、重试次数与退避、超时收敛。

## 已知限制

- 不做分布式执行与跨进程协程复活；
- 写操作在途时仍需要人工确认后重放；
- 定时 / webhook / 文件监听触发尚未提供；
- 超时只标记失败，不强制中断底层执行体。
