# WorkBuddy v2.10 版本总结：会汇报、会计划、可复盘、可扩展

## 1. 主题与价值主张

v2.7–v2.10 不追求功能数量，而是补「工作状态的连续性」：

**看得见在做什么 → 关页也接着干 → 做完能复盘 → 能力可装卸。**

四个阶段按依赖顺序交付，全部验收后统一发布 `2.10.0`，不逐版发布。

## 2. 交付清单（按版本）

| 版本 | 主题 | 交付 |
|---|---|---|
| v2.7 | 会汇报 | WorkSignal 8 态 + 活动/注意力；RunEventHub；桌宠七态、多运行聚合、分场景提示音、深链；审批中心 `/approvals` |

## 3. 核心机制

### 3.1 单一工作状态口径（v2.7）

- task / flow / agent 事件归一为 `WorkSignal`，页面、桌宠、通知共用同一 reducer；不做各页面各写一套优先级。
- 桌宠独立 SSE 订阅，不依赖主窗；待审批 > 失败 > 运行中 > 排队；完成/错误只做一次性脉冲。
- 审批默认 fail-closed：超时/断线统一拒绝并回写可读原因。

### 3.2 服务端持久作业（v2.8）

- Task / Agent 生命周期从「页面 SSE 请求」转为「服务端 job + owner lease」；页面只是观察者。
- 重启时非终态运行统一收敛为 `interrupted` / `cancelled(INTERRUPTED)`，不出现幽灵 running。
- 完成回投以 `run_completions(run_id,kind)` 幂等，只追加一条助手消息。
- Goal / Plan / Todo：Todo 是 Plan 的轻量视图；计划评审 `draft → pending_review → approved/rejected`；未批准计划标注「勿执行高风险步骤」。

### 3.3 事件日志与复盘（v2.9）

- `session_events(scope,scope_id,seq,type,payload)` 只追加；聊天、任务、工作流、协作时间线由事件重建。
- `session_events_fts` 复用 CJK uni-gram，中文 2 字词可检索。
- 导出 ZIP 带 manifest 与业务投影；默认脱敏移除密钥、掩码令牌、省略工具参数原文。
- 工具输出 >100,000 字符写入内容寻址 `spills/<sha256>.txt`，模型只见预览 + `spill://` 引用。

### 3.4 能力包（v2.10）

- ZIP 固定 `wbfm-capability.json` + `payload/**`；校验路径、checksums 全覆盖、必需权限、依赖版本与同 id 冲突，全部 fail-closed。
- 本期 effect：`skill`（复制到 `skills/<name>` + reconcile）、`mcp`（createServer/removeServer）；其余 kind 明确拒绝安装，不伪装生效。
- 能力包记录落库 `capability_packs`，包文件落 `capabilities/<id>/`；停用/卸载同时回滚内存与磁盘。
- 外部代理只提供 `SubagentProvider` 接口与注册表，默认无实现、不影响核心启动。
- 生产导出补齐：v2.8–v2.10 新增域（`work-plan` / `session-log` / `capabilities`）此前只注册了子路径，未聚合进 `@wbfm/core` 根 barrel；开发态走源码条件无感，`next start` / standalone 会命中 `dist/index.*` 缺符号。已补齐并用 CI 模式全量 e2e 验证。

## 4. 迁移与版本

- 迁移 **v037**（运行租约/完成回投/目标计划/定时 payload）、**v038**（事件日志 + FTS）、**v039**（能力包登记）。
- 全部纯加法；旧库可直接升级，回退 v2.6 不破坏数据。
- 版本号 `2.10.0`（root / web / desktop / `APP_VERSION` 同源同步）。

## 6. 已知边界与后续

- v2.10 effect 仅 skill / mcp；workflow / pet-action / event-script / report-widget 待后续接入。
- 外部代理（DSH/ACP/Codex/Claude Code）只有接口，没有具体实现。
- 事件保留策略默认 180 天，清理 API 已有，尚未接设置页定时任务。
- 压缩预算可视化、一键诊断包、桌面控制授权并入审批中心、会议 WorkSignal 仍为候选。
