## 2. 技术要点

- **RunGraph 投影**：`session_events` 纯函数投影生成节点/边/车道；节点身份按业务 id 去重，未知 payload 不抛错；chat/task/flow/agent/meeting 五域统一。
- **只读图 API**：`GET /api/conversations/:id/run-graph` 与 `GET /api/meetings/:id/run-graph`；按 `at` + `scope/seq` 稳定排序；历史加载不依赖前端拼装。
- **图面板**：同一组件复用于聊天右侧与 `/timeline` 图谱；聚焦当前运行、折叠其他、错误隔离与节点上限。
- **Light UI**：自研几何/SVG/环境/图层四模块；同 id 去重、最多 12 条、1200ms；`prefers-reduced-motion` 直接完成、页面隐藏暂停、卸载清理。
- **实时追加**：复用既有 SSE 旁路发布 `meta/tool/done/error/stop` 与协作/会议事件；以快照 `generatedAt` 为历史基线，终态不回退。
- **会议图**：`session_events` 新增 `meeting` scope；`meeting_turn` 带 `turnIndex`，会议页独立图不混入会话根。
- **阶段计划**：`StagePlan { steps[1..8], activeStep }`；标题 ≤40、技能去重 ≤12、目标/交付 ≤4000；非当前阶段可 prepare。
- **服务端校验**：模型必须存在且具备 `chat`；技能必须启用、存在且 manifest 有效；非法配置 422。
- **默认阶段复制**：创建会话按「助手显式 > 角色卡默认 > 空」只填空缺；应用角色卡只在助手 `stagePlan=null` 时复制；不回溯覆盖。
- **会话级模型**：`conversations.model_id` 优先于助手绑定与系统默认；阶段 PUT 在同一事务同步模型；无模型阶段清空覆盖。
- **阶段 UI**：顶部阶段条切换/编辑/载入任务；载入只写输入框不发送；非空草稿、运行中、无目标均受阻。
- **备份恢复**：conversations 轨带 `stagePlan/modelId`；events 轨带助手与角色卡 `stagePlan`；旧备份缺字段按 null。

## 3. 数据与迁移

- **一次迁移**：`v044-stage-plan`，纯加法——`conversation_stage_plans` 表 + `assistants.stage_plan_json` + `character_cards.stage_plan_json` + `conversations.model_id`；`LATEST_SCHEMA_VERSION = 44`。

## 5. 已知边界

- 阶段计划无 UI 的空计划创建入口：无计划的会话不显示阶段条，需助手/角色卡默认或 API 先落计划。
- 阶段技能只展示名称，不展示描述；不支持拖拽排序。
- 载入任务不自动发送；运行中硬锁阶段条，不排队。
- RunGraph 长会话仍可能密集，依赖聚焦/折叠与节点上限。
- 会议事件 best-effort 写入；失败不阻断会议，图降级展示。
