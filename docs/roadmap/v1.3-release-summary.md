## 1. 主题与价值主张

v1.2 封版后，检索链路的核心短板是**「切片漏斗」**：文档切块嵌入后，型号、参数、别名这类硬事实与邻近噪声片段混在一起排名，答案经常引用「语义相近但数值不对」的片段；中文关键词召回依赖嵌入模型的语义泛化，精确词（如 `ZK-900`）反而查不准；引用只有「片段 N」，用户无法核对出处。v1.3 按 A 方案（知识变厚）重做检索链路：

| 断点（v1.2 现状） | v1.3 的回答 |
|---|---|
| 检索单通道（纯向量），精确型号/编号召回不稳 | 混合检索：向量 + FTS5 全文（unicode61 + CJK uni-gram 分词）双路并行，**RRF(k=60) 免标定融合**，规则重排把真正含查询词的片段顶上去 |
| 答案引用「语义邻居」而非存储事实 | **无模型知识编译器**：摄入后机械抽取实体知识（引号/型号/中英别名）与文档要点（tldr + top3 原句 + keyTerms），提问时**静态事实置顶注入**，编译路由可开关（默认开） |
| 引用只有片段编号 | **语句级引用**：page_no/paragraph_no/charStart/charEnd 全链贯通 UI，静态条目独立徽标，「文档陈述」与「片段检索」可区分 |
| 矛盾内容静默共存，新切片赢者通吃 | **知识治理**：冲突检测（版本/标量/标题三维度 + 同文档升级豁免）、重复文档检测（采样 KNN ≥0.92）、同名替换（复用文档行 replaceContent + 世代重置 + 重编译） |
| 编译（M2 起手动触发）不可见不可控 | **后台编译队列**：单并发 FIFO、去重、取消、进度事件（SSE），摄入自动编译（autoCompile 默认开），工具栏状态徽标 + 设置面板 |
| 英文态七域残留中文 | P1 七域英文化：flow-editor / flow-execution / tool-debug / tool-trace / voice / avatar / pet，约 43 组件 + 10 字典文件 |

**关键边界**：编译器默认**零模型调用**（LLM 增强默认关，失败自动降级规则）；不做图检索/多模态检索；不做云端知识库同步；中文 FTS 不引入外部分词器（uni-gram 方案内建）。

## 4. 踩坑记录（均已固化为代码、配置或测试）

1. **sqlite-vec vec0 虚表的读出形态是 BLOB 不是 JSON。** 写入 `json()` 文本、读出 float32 小端 BLOB；`listChunkVectorsByKb` 只处理 string/number[] 两态，Buffer 被按字节遍历成 4 倍长度（64 维→256），duplicates API 直接「查询向量维度 256 与表维度 64 不一致」。修复 `deserializeEmbedding`（DataView getFloat32 little-endian），并加「读出→回喂 KNN」回归单测锁闭环。
2. **摘要题反向验证的根基缺陷：摘要条目就是原句。** compile 态（混合检索开）FTS+重排必召回原文，「关编译」根本无法制造降级信号。 golden 的 breaksWith 改标 fts（纯向量态才被干扰文档压顶），判定矩阵加 SKIP 豁免：标注题只在标注开关态反向，其余态跳过不误导。
3. **组件级 useI18n 依赖在测试态集中爆雷。** 子代理把 13+ 组件/hook 换成 useI18n 后，4 个旧测试文件（tool-trace / use-handsfree-voice / use-voice-recorder / use-vad-monitor）裸渲染触发「useI18n 必须在 I18nProvider 内使用」×24。断言中文文案的包真 Provider（skipHydration），只断言错误码的 hook 测试 mock `@/lib/i18n/use-i18n` 单点替换。
4. **en 字典照抄 zh 结构也会超行。** flow-editor-en.ts 267 行触发 260 行预警——en 比 zh 恰好长 8 行；endpoint 子域拆 `flow-editor-endpoint.ts`（中英同文件，pet/avatar 模式），两主文件分别降到 212/217。
5. **PowerShell `Set-Content` 写 package.json 会加 UTF-8 BOM**，pnpm 直接报 Invalid package.json；版本号变更一律走 `node -e` 或 sync 脚本。
6. **首启向导在全新数据根必弹。** knowledge e2e 首跑挂在供应商「添加」按钮——v1.2 向导吃掉了首屏；spec 加 skipOnboardingIfShown（waitFor 5s catch return + 点「跳过」），且 providerCard 用 filter hasText 限定避免全量跑 strict violation。
7. **`/g` 正则的 lastIndex 陷阱**（M2 教训延续）：MODEL_PATTERN 不能 `.test()`，必须 `new RegExp(source)` 无状态副本，否则摘要产出跨调用非确定。
8. **noUncheckedIndexedAccess 下测试索引访问全要非空断言**：`row.embedding[0]` 是 `number | undefined`，Math.hypot 参数位直接报错。

## 5. Non-Goals（本版本明确不做）

- ❌ 图/表格/多模态检索；不做跨库联邦检索
- ❌ 云端知识库/多端同步；知识数据仍在本机
- ❌ 中文分词引入外部词典/模型（uni-gram 内建方案）
- ❌ 编译 LLM 增强默认开（默认关且失败自动降级规则）
- ❌ Live2D 第三方许可法律段翻译（随附官方英文版，刻意保留）
- ❌ 知识图谱可视化、实体关系编辑器（治理面板只做裁决流）
