# v4.17.0 发行说明

> 主题：**用得顺——关键路径的感知、恢复与复用**
> 发布：tag `v4.17.0` 已推送；GitHub Release 由发布流水线构建草稿，核对后转正（2026-11-21）
> 覆盖版本：v4.16（CI 稳定性，未单独打 tag）+ v4.17（易用性收口）
> 数据库：无新增迁移，`LATEST_SCHEMA_VERSION` 不变；备份格式不变
> 安装包：由 Release workflow 构建并上传 `WorkBuddyForMe-Setup-4.17.0.exe`

## 一、核心功能更新

### 1. 限制可感知

- 新增共享组件 `LimitHint`：未达上限显示「还可选 N 项」，达上限显示「已达上限 N」并使用警示色；
- 助手工具选择接入该组件，达到上限后禁用未选项并明确说明，不再依赖用户自行计数；
- 审计助手、流程、设置等目录的用户多选保存路径，未发现其余静默截断；
- `repo-invariants` 新增「保存路径无静默截断」用例，扫描 `skills / knowledgeBases / inputs / enabledTools / toolNames` 等字段的 `slice(0, N)`，允许清单当前为空。

### 2. 能力状态统一

- 新增 `CapabilityStatusBadge`，统一 `available / enabled / disabled / error` 四态的视觉变体与中英文案；
- 能力中心：已启用但健康检查异常判为「异常」，其余按启用状态区分；
- MCP 目录：已安装但停用、安装状态异常、连接正常分别映射为三种状态，消除「已安装仍可勾选」的歧义；
- 技能列表：文件缺失或加载报错判为「异常」，已启用与可用分别展示；
- 知识库未接入：其字段描述文档处理进度而非能力健康状态，语义不适用，本版主动不接。

### 3. 错误可恢复

- `ErrorState` 新增可选 `action` 插槽，优先渲染传入动作，未传时保持原有「重试」行为，已有调用方零改动；
- 模型未配置：对话区进入阻断式空态，提供「配置模型 / 演示模式 / 从模板开始」三条路径，不让用户先输入再失败；
- MCP 连接异常：沿用服务卡片「测试连接」作为重试动作，保留启用开关用于主动停用；
- 本地搜索未启动：复用一键启动并续跑原请求；
- 语音模型未下载：复用下载引导，先提示体积再提供下载与重试；
- 四类故障均遵循「原因 + 下一步 + 动作」，不重复建设已有修复组件。

### 4. 首启不断链

- 对话空态提供三选一：演示模式、配置我的模型、从模板开始；
- 无模型引导常驻，直到产生第一条会话；已有模型但无消息时只保留模板入口；
- 演示模式继续使用本地模拟回复，不联网、不下载、数据不出机；
- 开发态记录「打开应用 → 第一条回答」耗时，仅供本地排查，不进入生产界面、不上传数据。

### 5. 检索与效率

- 新增消息检索弹层，复用现有 `/api/search` 与本地会话事件日志，不改服务端协议、不建新索引；
- 检索带 300ms 防抖、请求中止、按消息 id 去重与 120 字符片段截断，空结果给出换关键词引导；
- 命中后通过会话与消息双参数跳转，直接定位到具体消息；
- 三处入口：命令面板「搜索会话」、对话页头部搜索按钮、侧栏会话区搜索按钮；
- 命令面板记录最近执行的 5 条命令并置顶展示，本地存储损坏时降级为空列表；
- 「导出会话」从提示改为真正执行导出，无当前会话时才给出引导；
- 新增桌面端「打开桌宠 / 关闭桌宠」命令，复用现有桥接；
- 设置中心顶部新增常用 5 项：模型与供应商、语音与对话、MCP 能力、外观与主题、数据与备份，复用现有面板锚点；
- 首次使用提示命令面板快捷键，只提示一次并写入本地标记。

## 二、累计版本（v4.16）

- **CI 稳定性**：验收脚本退出码收口、超时隔离、E2E 重试策略与视觉基线准备；
- 桌宠点击命中区与原生拖拽浮层两项交互修复随本版一并交付。

## 三、重要优化与修复

- 语音免手 E2E 不再依赖真实假麦克风初始化：桩掉 `getUserMedia`，音频图仍由假工作线程驱动，并补水合等待与按钮可交互断言，消除高负载 CI 下的超时抖动；
- i18n 新增限制、状态、检索、最近使用、设置常用等命名空间，中英双档齐全；
- 公共组件按子域拆分（`limits`、`status`），命令面板桌宠命令独立成模块，满足单文件与目录预算门禁；
- 命令面板 `conv:search` 保留原命令 id，仅替换动作，键盘操作与分组顺序不变。

## 四、兼容性变更说明

- **数据库 / 备份**：无迁移、无格式变化；
- **依赖**：零新增运行时依赖；
- **导航**：不新增侧栏入口，现有导航项与断言不变；
- **错误态**：新增可选 `action`，不传时行为与旧版一致；
- **命令面板**：命令 id 与分组保持兼容，新增最近使用分组仅在无搜索关键词时出现；
- **设置**：新增常用入口，已有快捷项存在时自动隐藏，避免双入口；
- **版本号**：根工程与桌面端统一升至 `4.17.0`。

## 五、升级注意事项

1. 本版无数据库迁移，正常覆盖安装即可；
2. 演示模式关闭后会清理临时供应商与模型，已配置的真实供应商不受影响；
3. 消息检索仅查询本机事件日志，界面已明示「本机检索」，不产生远端请求；
4. 视觉巡检仍为非阻断，空态与设置页改动后的基线需在真机或视觉流水线阶段统一更新；
5. 语音免手 E2E 已降低环境依赖，若仍偶发超时，优先重跑并保留 trace 产物。
