# WorkBuddy v2.10.0 — Work that reports, plans, reviews and extends

Four consecutive stages shipped and verified together:

## v2.7 — It reports

- Unified `WorkSignal` (8 outcomes + activity/attention) across tasks, flows and agent runs.
- Desktop pet subscribes independently: seven states, aggregated bubble, scenario-specific sounds, deep links.
- Global approval inbox (`/approvals`) with fail-closed timeout/disconnect handling.

## v2.8 — It plans, and keeps going

- Tasks and agent runs are now server-owned jobs; closing the page no longer aborts them.
- Lease + startup recovery: stale runs become `interrupted` / `cancelled(INTERRUPTED)`, never phantom `running`.
- Completion write-back is idempotent via `run_completions`.
- Conversation goals, reviewable plans and lightweight todos; scheduled follow-ups inject at most one message.

## v2.9 — It can be reviewed

- Append-only `session_events` per chat/task/flow/agent, with CJK FTS (2-character queries work).
- `/timeline` page: timeline, search and redacted ZIP export (manifest + business projections).
- Large tool outputs spill to content-addressed `spills/<sha256>.txt`; the model sees a preview plus `spill://` ref.

## v2.10 — It can be extended

- `wbfm-capability.json` capability packs: checksums, required permissions, dependency/version checks and fail-closed validation.
- Supported effects: `skill` and `mcp`; install/enable/disable/uninstall with no restart and full rollback.
- `/capabilities` management page and downloadable sample skill pack.
- `SubagentProvider` seam for optional external agents; no provider is bundled and core works without one.

## Upgrade

- Migrations v037–v039 are additive only; existing data remains readable.
- Version: `2.10.0` (root, web, desktop and `APP_VERSION` synced).

## Limits

- Capability effects for workflow / pet-action / event-script / report-widget are not yet wired.
- External agent providers (DSH/ACP/Codex/Claude Code) are interface-only.
- Event retention is 180 days by default; cleanup API exists but is not yet scheduled in settings.
