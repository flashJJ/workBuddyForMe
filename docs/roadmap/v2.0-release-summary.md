# WorkBuddy v2.0 版本总结：有羁绊——情感闭环、VRM 形象与 mod 生态

## 1. 主题与价值主张

v1.6/v1.7 解决了「有情绪」「有仪式」，v2.0 要回答最后一问：**长期陪伴留下了什么**。答案是一条闭环：

**每一次相处都在改变关系 → 关系变化解锁新的相处方式 → 共同经历被沉淀为可回看、可迁移的资产 → 形象与人格可以随你搬家。**

四档关系（陌生→认识→搭档→挚友）由亲密度与信任度双轴演算，等级变化驱动解锁闸门；六个共同里程碑在真实相处达成时触发纪念演出；系统事件感知让主动关怀有了不侵犯隐私的触发源；three.js VRM 第二渲染后端第一次允许你把自己的 3D 形象带进来；收口的 `.wbfm-pack` 生态包与单文件关系报告，让角色、舞台与共同记忆能离线流转。

整版三条红线不变：本地优先（原始系统信号不落盘）、弱模型安全（情绪演算纯函数确定性回落）、授权边界（Live2D 外部模型导入仍永久关闭，VRM 走双校验白名单通道）。

## 3. 核心机制

### 3.1 关系演算：双轴、四档、纯函数

- **双轴**：亲密度（intimacy）与信任度（trust）0–100，复用 v1.6 已在库的 state_json，不重写历史。
- **四档复合门槛**：陌生→认识→搭档→挚友，高档位要求双轴同时过线；迟滞区间防边界抖动，回落地板防情绪事件把关系「一夜打回原形」。
- kernel 是无 IO 纯函数，弱模型场景下情绪输入走 zod 逐字段回落 + 关键词保底，演算结果确定可复现；等级变化产出等级事件，由导演闸门决定是否演出/解锁，演算层不碰 UI。

### 3.2 共同里程碑与纪念演出

- 六个里程碑只认真实落库证据：对话首日、30/100/365 天相伴、10/50 次协作，从消息与协作 run 计数派生，无任何人工标记入口。
- 达成时走 v1.7 既有事件演出通道（三锁：勿扰/对话中/冷却频率）播放纪念演出并写达成日期；面板展示已达成/未解锁两态，关系总开关关闭时整区隐藏。
- 长期记忆新增 `relationship` 类别，里程碑事件进入记忆但不可被模型直接改写。

### 3.3 主动感知：只存边沿，不存原始信号

- desktop 桥只上报 unlock / lock / idle 三类**边沿信号**，tick 仅写去重状态；屏幕内容、窗口名、进程名等原始信号一律不落盘、不出本机。
- web 侧每个系统事件一个授权分组（默认关）+ 上下文剧本可独立停用；三态总开关（情绪/剧情/主动）任一关闭，授权分组与剧本列表一并隐藏。

### 3.4 VRM：第二渲染后端与受控导入

- three.js 渲染栈与 PIXI Live2D 栈分层并存，按形象选择器动态挂载，不进首屏包；Live2D/VRM/默认三后端切换经设置持久化并轮询语音设置生效。
- 导入向导：前端先拒扩展名/大小错误，服务端再做 GLB/VRM 扩展双校验与 meta 解析，必须勾选免责声明方可入库；非法文件 4 负例全拒。
- 文件落 `data/vrm-avatars/`（v030 迁移登记），不随包重分发模型本体。

### 3.5 .wbfm-pack：白名单容器，黑名单兜底

- 容器 = ZIP + `manifest.json`（schemaVersion + zod 校验）；**内容冻结为角色卡 / 舞台场景 / 背景图**三类；events/themes/personas/gestures 键只允许空数组，非空整包拒绝。
- 安全闸：模型/音频二进制与任何 eval/脚本形态一律黑名单拒绝；VRM 只带引用不带本体；`builtin.*` 命名空间不可覆盖；预检不落盘，fatal 错误不给提交按钮，同名条目走「（导入副本）」冲突策略，非法条目逐条禁用勾选。
- 安装记录入 v031 `mod_installs`，向导支持选择性条目导入。

### 3.6 关系报告与备份 v6

- 关系报告聚合情绪状态、事件流水、里程碑、事件用量与助手名，渲染**单文件零外链 HTML**（内联样式/字体回退），五节可选、记忆项可删，中英双语同构；文件名按 locale 下载。
- 备份 schema 升 **v6**：增补 events 轨道与 mod_installs 轨道，export/precheck/恢复事务/manifest 计数五处同步，恢复全部幂等 INSERT OR IGNORE，旧档缺轨按 0 降级。

## 5. 留白与顺延

- 关系指标统计 read-model（G6）与关系活跃看板顺延：本版报告取数走实时聚合，未建滚动统计表。
- mod 市场/一键订阅、主题与人格权重入包：manifest 仅冻结角色卡/场景/背景图三类，其余内容类型留待 v2.x 评审。
- VRM 三维舞台演出（多 VRM 站位/口型）未做：本版 VRM 仅用于单形象对话渲染，舞台仍是 Live2D。
- 「重新认识」软重置 UI 未开放（备份恢复链路已支持数据侧操作）。
- 红线延续：外部 Live2D 模型导入永久关闭（Cubism 授权边界）、不捆绑音色包、无人值守 desktop 永久禁。
