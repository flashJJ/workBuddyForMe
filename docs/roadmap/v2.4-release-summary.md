# WorkBuddy v2.4 版本总结：装完即用——零配置首启、模板可触达、语音开箱与运行可信度

## 1. 主题与价值主张

竞品对比给出的结论很直接：本产品的功能面并不窄，差在**价值兑现链条**——装完之后必须先自备供应商、API Key 与模型，才有第一条回答；模板、语音、能力与运行结果又都藏在设置或原始错误里。

v2.4 回答的是**「装完之后，第一步怎么走」**：

**不填 Key 也能先跑通 → 列表里已有现成模板可点 → 语音一次点击就能开口 → 助手挂了什么一眼可见 → 每次运行都能看懂为什么失败、慢在哪。**

五条主线：

1. **零配置首启**（P0-1）：演示模式产品化 + 三选一来源 + 本机 Ollama 提前探测 + 厂商预设 + 本地小模型引导 + `firstAsk` 示例问题 + 首字延迟自检 + TTFV 里程碑；
2. **模板可触达**（P0-2）：统一 `TemplateGallery`，五个列表空态与顶部入口，15 条模板按类定义「以此开始」语义；
3. **语音可对话**（P0-3）：设置页与对话页双入口、两档默认、模型下载就地引导、默认 TTS 切 MeloTTS；
4. **能力可见性**（P1-2）：助手级技能勾选（`assistants.skill_names`，v034）+ 助手卡片技能/MCP 区 + 表单技能区块 + 对话页头部能力摘要；
5. **运行可信度与体感**（P1-1 / P1-4 / P1-3）：三链路状态/耗时/失败归因统一，协作舞台只读观看前移；delta 合帧、长回复分块、首字指标与慢模型降级建议；运行页状态语言、命令面板覆盖、快捷键舞台组与三尺寸复核。

红线不变：无账号、无遥测、数据不出机；不静默下载；不假装全双工；内置模板只增不改、不覆盖用户改动。

## 3. 核心机制

### 3.1 零配置首启：把「兜底」做成产品能力

演示模式不是假数据：SSE、检索、引用与工作流节点都走真实链路，只有模型输出是确定性文本。向导把三条来源并列（演示模式 / 本地模型 / 云端 API），本机探测到 Ollama 时本地置顶并默认选中；云端路径由厂商卡片预填 Base URL 与模型建议，用户只补 Key。

向导终点不是「配置完成」，而是**第一次成功对话**：选定来源后跑一次极短 prompt 的首字延迟自检，按 M0 冻结阈值给出「流畅 / 偏慢但可用 / 建议换来源」三档结论；`firstAsk` 用同一份模板清单生成示例问题，模型就绪后自动发送一次；四个时间戳落库，`ttfv_ms ≤ 60_000` 作为可验收指标。

### 3.2 模板可触达：空态不是终点

模板清单收敛到单一事实源（知识库 3 + 工作流 6 + 技能 3 + 助手预设 3，共 15 条），由统一 `TemplateGallery` 渲染，每条带来源徽标与「推荐先用」。出现时机冻结为「空态显示一次 + 列表顶部常驻可折叠入口」——既让首启用户看见现成货，又不在任何时刻重复打扰。

「以此开始」按类给语义：知识库与工作流复制为可改自建实例、技能直接启用、助手预填新建表单、角色卡沿用既有复制。工作流克隆走服务端路由，源已被用户删除时回落到播种定义，保证空态入口不会指向一个不存在的对象。

### 3.3 语音可对话：把参数收进「高级」

设置页语音面板顶部与对话页语音按钮旁提供两个一键入口；点击后写入「ASR 开 + 免手模式 + 朗读开 + 默认档位」，不做静默下载。默认路径只留两档：**反应快**（均衡灵敏度 + 600ms 尾静音）与**更宽容**（低灵敏度 + 1200ms）；灵敏度三档与尾静音四档退入默认收起的「高级」。

模型未就绪时在入口处就地给出体积预估、下载、进度与取消，下载器按文件级断点跳过已完成文件。TTS 默认切到 MeloTTS（191MB，单声低延迟），Kokoro 退为「更多音色」；真机工装还暴露了一个致命问题：模型回复中的纯标点片段会让原生层直接终止进程，最终以「可朗读判定 + 分块过滤 + 引擎拒绝」三层护栏兜住。

### 3.4 能力可见性：助手到底挂了什么

新增纯加法迁移 `assistants.skill_names`：空数组 = 跟随全局已启用技能（旧行为不变），非空 = 只注入这些且仍需全局启用。装配层按助手过滤技能，停用技能自然回收；助手卡片补「技能 / MCP 工具」区，表单新增「技能（能力包）」区块（与工具级白名单区分），对话页头部展示当前助手的模型 / 知识库 / 技能 / 工具摘要。M2 遗留的预设技能绑定（周报、会议助手）一并接线。

### 3.5 运行可信度：三套枚举归一

task / agent-run / flow-run 的状态统一为 8 个结果：`queued / running / waiting / succeeded / failed / cancelled / interrupted / budget_exceeded`；`startedAt`（缺失回退 `createdAt`）→ `finishedAt` 作为共同耗时口径，agent 用 `updatedAt` 代替结束时间，运行中按「至今」计算。

失败统一由纯函数分类为「权限 / 鉴权 / 限流 / 超时 / 网络 / 模型 / 工具 / 节点 / 驳回 / 预算 / 步数 / 熔断 / 中断 / 取消 / 未知」，UI 输出「为什么失败 + 下一步」，原始错误折叠保留。协作卡只提供舞台**只读观看**入口并明示「不影响运行；写操作仍需授权弹窗显式允许」，不新增任何写入口。

### 3.6 首字体感与一致性收口

delta 不再逐 token 触发整棵消息树：按 rAF 合帧提交，done / error / 停止 / 重置同步冲刷。长回复 Markdown 按顶级标题切块并逐块 memo（代码围栏内不切，<1.6k 字仍单块），流式期间只重解析变化小节。等待首字超过 1.5s 显示已等待秒数，超过 5s 追加「停止 + 换更小模型 / 缩短上下文」建议；助手消息头部常显首字延迟，分档与首启自检同源。

一致性侧：三个运行页统一 `EmptyState + ErrorState`；命令面板补任务 / 工作流导航与新建知识库 / 工作流 / 助手 / 角色卡，`?new=` 深链接进入即打开创建表单；快捷键浮层补舞台组（H / F11 / Esc / Ctrl+滚轮）；响应式 e2e 扩到三尺寸 × 六个列表/运行页。
