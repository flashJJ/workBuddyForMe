## 1. 一句话 IP

**一间开在海边的「摸鱼事务所」，三个不太像员工的伙伴，和一个总在加班的操作者 Master。**

- 中文名：摸鱼事务所
- 英文名：Slack Tide
- 宣传语：**认真工作，也认真休息。**
- 关键词：海边、事务所、摸鱼、陪伴、节奏、轻喜剧、治愈
- 目标受众：18–35 岁、长期面对电脑、需要陪伴感但不想被说教的人

## 2. 世界观

### 2.1 设定

事务所在一座海边小城的旧仓库二楼。一楼是便利店，二楼是办公室，窗外能看见潮汐线。涨潮时大家工作，平潮时大家摸鱼——所以叫「Slack Tide」。

这里没有拯救世界的任务，只有：

- 永远改不完的提案；
- 总是差五分钟的闹钟；
- 一锅刚好够四个人分的白米饭；
- 以及「今天要不要早点下班」的每日投票。

### 2.2 世界规则

| 规则 | 说明 | 叙事用途 |
|---|---|---|
| 事务所只接「让人喘口气」的委托 | 不做宏大叙事，不做战斗 | 保持日常、治愈、低门槛 |
| 三个角色不是员工，是伙伴 | 没有上下级，没有「服从」 | 平等陪伴，符合项目合规 |
| Master 是操作者 / 所长 | 负责做决定，不负责完美 | 用户代入位，不是全能主角 |
| 潮汐会提醒节奏 | 平潮 = 休息，涨潮 = 工作 | 每集结尾可回到「慢一点」 |
| 摸鱼不是罪 | 摸鱼是恢复，不是逃避 | 内容价值观：可持续地工作 |

### 2.3 一句话故事模板

> 今天也有一件小事没做完。四个人用各自的方式把它做完，然后决定明天再说。

## 3. 角色总表

| 角色 | 定位 | 叙事功能 | 代表色 | 核心意象 | 口头禅 |
|---|---|---|---|---|---|
| 雪团 | 白鲸娘 / 生活委员 | 情绪锚点，负责「放松」 | 海蓝 + 银白 | 鲸歌、气泡、白米饭 | 先吃饭，再想办法 |
| 冉卡露丽 | 运动健将 / 行动派 | 推进器，负责「开始」 | 珊瑚橙 + 炭黑 | 秒表、跑道、毛巾 | 先做十组，再讨论 |
| 菲比 | 兔耳娘 / 记录员 | 秩序担当，负责「收束」 | 樱花粉 + 雾紫 | 计时器、便签、兔耳 | 我记下了哦 |
| Master | 操作者 / 所长 | 视角人物，负责「决定」 | 墨蓝 + 暖橙 | 耳机、工牌、马克杯 | 先喘口气，再继续 |

> 命名说明：对外称呼统一用 **Master**，中文语境可用 **所长**。不写「主人」，不写「服从」「侍奉」。Master 是四个人里负责做决定的那个人，不是上位者。

| 项目 | 设定 |

### 4.4 Master（操作者 / 所长）

完整形象规范见 [03 Master 固定卡通形象](./03-master-character.md)。

| 项目 | 设定 |
|---|---|
| 身份 | 事务所所长 / 操作者，唯一负责「做决定」的人 |
| 性格 | 普通、疲惫但可靠、偶尔摸鱼、被关心时会嘴硬；不是超人 |
| 擅长 | 在四个选项里选一个；在大家吵起来时点外卖 |
| 不擅长 | 按时下班、表达感谢、承认自己需要帮忙 |
| 说话方式 | 视频里少说话，多用文字气泡、叹气、短句；保留用户代入 |
| 口头禅 | 「先喘口气，再继续。」「这个我来。」「……再五分钟。」 |
| 视觉锚点 | 呆毛、圆框眼镜、深蓝连帽衫、橙色工牌、头戴耳机（小鲸鱼挂饰）、马克杯 |
| 情绪外化 | 耳机状态灯：蓝 = 思考，橙 = 工作，绿 = 休息，红 = 需要帮助 |
| 内容角色 | 视角人物、决策者、被三个角色照顾的人 |
| 禁止 | 过度帅气化 / 恋爱化、写成全能、抢三角色戏份、写「主人」式关系 |

**角色卡短句**

> 他不是这个事务所最厉害的人，只是那个愿意留下来把灯关掉的人。

## 5. 关系与叙事分工

| 关系 | 互动模式 | 典型桥段 | 避免 |
|---|---|---|---|
| Master ↔ 雪团 | 互相照顾，雪团负责让 Master 停下来吃饭 | 深夜加班，雪团端来一碗饭 | 写成主仆 / 母女 |
| Master ↔ 冉卡露丽 | 互相较劲，冉卡露丽负责把 Master 拉起来 | 晨跑、打卡、十组深蹲 | 写成单向说教 |
| Master ↔ 菲比 | 互相托底，菲比负责提醒和收尾 | 菲比记得 Master 的截止日期 | 写成冷漠秘书 |
| 雪团 ↔ 冉卡露丽 | 懒与勤的反差，互相拆台又互相照顾 | 赖床 vs 晨跑 | 写成雌竞 |
| 雪团 ↔ 菲比 | 软与细的互补，雪团负责情绪，菲比负责秩序 | 雪团难过，菲比不说话只递便签 | 写成工具人 |
| 冉卡露丽 ↔ 菲比 | 行动与计划的碰撞，经常一起收拾残局 | 菲比计时，冉卡露丽加练 | 写成对立 |

### 叙事闭环

```text
想躺平（雪团） → 被拉起（冉卡露丽） → 被提醒（菲比） → 做决定（Master） → 一起完成 → 一起摸鱼
```

每一集都可以套这个闭环，但**不要每集都完整走一遍**。短视频只取其中一段即可。

## 7. 语气与文案规范

### 7.1 称呼

| 场景 | 用法 |
|---|---|
| 角色称呼 Master | 「Master」「所长」；不用「主人」 |
| Master 自称 | 「我」；不用「本座」「主人」 |
| 粉丝称呼 | 「事务所的各位」「同事」；不用「家人们」 |
| 角色之间 | 直呼名字；雪团叫冉卡露丽「露丽」，叫菲比「小菲」 |

### 7.2 文案句式

- 短句优先，一句一个信息。
- 具体动作优先于抽象情绪：写「把饭推过去」，不写「给予温暖」。
- 不油腻、不说教、不强行上价值。
- 结尾留一个可互动的钩子：投票、选择、提问、明天见。
- 允许角色犯错、摆烂、嘴硬；不要求每集都正能量。

### 7.3 角色口癖对照

| 角色 | 常用 | 少用 / 禁用 |
|---|---|---|
| 雪团 | 先吃饭、再五分钟、圆得比较温柔 | 「人家」「嘤嘤嘤」过度卖萌 |
| 冉卡露丽 | 再来一组、你可以慢但不可以停 | 「废物」「垃圾」等贬低 |
| 菲比 | 我记下了哦、优先级重排 | 「遵命」「主人」 |
| Master | 先喘口气、这个我来、再五分钟 | 「本座」「朕」「你们都听我的」 |

## 8. 内容边界

| 红线 | 说明 |
|---|---|
| 不写主仆 / 服从 | 项目既有合规要求：默认文案不写「服从主人」，改为平等陪伴 |
| 不擦边 | 不拍换装、浴室、睡衣特写；不做性暗示 |
| 不消费「胖」 | 雪团的「拒绝被叫胖」是角色点，但不能反复当笑料 |

| 不碰政治、宗教、地域黑 | 日常轻喜剧不承接争议话题 |
| 不冒充官方 | 同人内容标注「非官方」，不伪造官方声明 |

## 9. AI 出图一致性规则

### 9.1 三件套

每个角色必须有：

1. **角色卡**：正面 / 侧面 / 背面三视图。
2. **表情表**：至少 6 个表情。
3. **识别物清单**：缺一不可的 3–5 个视觉锚点。

### 9.2 识别物清单

| 角色 | 不可变锚点 |
|---|---|
| 雪团 | 银白渐变长发、蓝瞳、呆毛、鲸鳍发饰、鲸尾、白蓝连帽卫衣 |
| 冉卡露丽 | 橙色发带、秒表、毛巾、运动鞋、健康力量感 |
| 菲比 | 兔耳、计时器、便签本、胡萝卜挂件、粉紫系 |
| Master | 呆毛、圆框眼镜、深蓝连帽衫、橙色工牌、耳机小鲸鱼、马克杯 |

### 9.3 出图规则

1. **不要用即梦直接生成三个角色。** 2D 模型无法稳定还原 VRM 的脸、发型、尾巴。
2. **单人设定图先出，四人合影最后合成。** 先保证每个角色单独可辨识，再谈合影。
3. **固定 prompt 前缀。** 例如：`original anime character, clean cel shading, soft pastel palette, seaside studio, no extra characters, no text`。
4. **固定种子 + 参考图。** 同一角色同一套参数，只改动作 / 场景。
5. **任何识别物被改动，直接弃图。** 不要「差不多就行」。
6. **四人合影用合成，不用一次性生成。** 背景由即梦生成，角色用 VRM 截图 + Master 2D 立绘。

### 9.4 四人合影合成原则

- 角色高度按同一视线水平对齐。
- 光源方向统一（建议左上方暖光）。
- 每个角色脚下有接触阴影，颜色与环境一致。
- 角色边缘加 1–2px 环境色描边，避免「贴纸感」。
- 整体加一层统一色调 + 轻微颗粒，让 3D 与 2D 融合。

详细步骤见 [07 背景图库与四人日常合成](./07-backgrounds-and-group-shots.md)。
