## 1. 账号定位

| 项目 | 设定 |
|---|---|
| 账号名 | 摸鱼事务所（Slack Tide） |
| 一句话 | 三个纸片人同事，和一个总在加班的 Master |
| 内容类型 | 轻喜剧 / 日常 / 治愈 / 打工人共鸣 |
| 目标观众 | 18–35 岁、长期用电脑、需要陪伴感的人 |
| 更新频率 | 每周 2 条；每条 15–45 秒 |
| 主平台 | B站（横屏 + 竖屏）、抖音 / 小红书（竖屏） |
| 视觉 | 即梦背景 + VRM 角色 + Master 2D + 剪映字幕 |
| 语气 | 不煽情、不说教、不油腻；结尾留一个钩子 |

### 内容支柱

| 支柱 | 占比 | 说明 | 示例 |
|---|---|---|---|
| 打工人共鸣 | 40% | 加班、提案、摸鱼、周五 | 《提案前夜》《周五 18:00》 |
| 角色反差 | 30% | 懒鲸鱼 / 元气教练 / 细节兔 | 《闹钟响了三遍》《十组深蹲》 |
| 工具梗 | 15% | 耳机灯、计时器、工牌 | 《Master 的耳机灯》 |
| 治愈 | 15% | 雨夜、鲸歌、生日 | 《雨夜站台》《生日特别篇》 |

## 2. 单集公式

```text
0–3 秒：钩子（冲突 / 反常识 / 悬念）
3–15 秒：升级（角色各自出招，至少一次反转）
15–30 秒：解决（Master 做决定 / 三人合力）
30–45 秒：余味（摸鱼、吃饭、看海）+ 互动钩子
```

### 钩子写法

| 类型 | 模板 | 示例 |
|---|---|---|
| 反常识 | 「如果你的 X 是 Y，会怎样？」 | 如果你的室友是一只鲸鱼，早起有多难？ |
| 悬念 | 「今天 X 发生了，但没人知道为什么。」 | 工牌丢了，Master 被赶出自己的事务所。 |
| 共鸣 | 「你有没有过 X 的瞬间？」 | 提案前夜，PPT 第一页写着「新建文档」。 |
| 反差 | 「她看起来 X，其实 Y。」 | 她看起来只会喊「再来一组」，其实也会累。 |

| 项目 | 内容 |

| 画幅 | 9:16 |

| 道具 | 闹钟、被子、水杯、饭团、秒表 |
| 音乐 | 轻喜剧拨弦 + 清晨环境声 |

| 镜号 | 时长 | 景别 | 画面 | 台词 / 字幕 | 音效 |
|---|---|---|---|---|---|
| 1 | 3s | 特写 | 闹钟 7:30，响到第三遍；一只手从被子里伸出来按掉 | 字幕：第 3 次了。 | 闹钟铃 + 被子摩擦 |
| 2 | 5s | 中景 | 雪团裹成一团，呆毛翘着，鲸尾露在被子外 | 雪团：再五分钟……就五分钟。 | 慵懒哼声 |
| 3 | 6s | 中景 | 冉卡露丽推门，运动装，秒表在手 | 冉卡露丽：说好的晨跑呢？太阳都晒到尾巴了。 | 门响 + 秒表滴 |
| 4 | 6s | 近景 | 菲比端水进来，另一只手拿饭团 | 菲比：先喝水。空腹跑步会头晕。 | 水杯轻放 |
| 5 | 7s | 近景 | 雪团突然坐起，眼睛发光，盯着饭团 | 雪团：那……跑完能加一份早饭吗？ | 叮（灵光） |
| 6 | 6s | 中景 | 冉卡露丽拉开门，菲比按秒表 | 冉卡露丽：跑完再说，先出门！菲比：计时开始。 | 秒表 + 脚步声 |

- 雪团的被子可以用 3D 场景里的毯子道具，或在剪映里加一层柔光。
- 冉卡露丽推门用「舞台」的 spotlight 背景，门可以用贴图。
- Master 只露手，避免抢戏；工牌要清晰。

| 2 | 5s | 中景 | Master 敲键盘，灯变橙；屏幕代码滚动 | 字幕：橙灯 = 工作。 | 键盘 + 提示音 |

**制作提示**：
- 状态灯是后期做的：在耳机耳罩上叠一个发光小圆点，颜色用关键帧切换。
- 灯变色时配一个短音效，观众能立刻理解规则。
- 结尾不要拍 Master 正脸，保留代入感。

## 5. 制作管线

| 环节 | 工具 | 具体做法 | 注意 |
|---|---|---|---|
| 背景 | 即梦 | 按 [01 手册](./01-jimeng-loop-background.md) 生成 9:16 循环背景 | 中心低对比，底部留字幕区 |
| 角色 | 应用内舞台 / 桌宠 | 固定机位、固定光照，逐句录制 | 同一集不要换镜头高度 |
| Master | 2D 立绘 / PNG | 只做半身、手部、背影；状态灯单独图层 | 不抢三角色戏 |
| 配音 | Kokoro TTS | 雪团 sid 18、冉卡露丽 sid 32、菲比 sid 3 | Master 用文字气泡或低声 |
| 音乐 | 06 文档 | 主题曲 / 角色曲 / 轻喜剧 BGM | 注意音量 ducking |
| 剪辑 | 剪映 | 3 秒钩子、字幕、音效、片尾卡 | 字幕安全区 |
| 封面 | 剪映 / Photoshop | 角色脸 + 钩子文字 + 事务所 Logo | 3:4 或 9:16 |
| 发布 | B站 / 抖音 / 小红书 | 标题、话题、AI 标注 | 按平台要求标注 |

### 音频参数

| 项目 | 建议 |
|---|---|
| 人声 | -16 LUFS 左右，清晰优先 |
| BGM | 比人声低 12–18dB |
| 音效 | 只保留关键动作音，不要满 |
| 字幕 | 每行不超过 14 个汉字；关键词加色 |
| 片头 | 不超过 1 秒，直接进钩子 |

## 7. 标题、封面与话题

### 标题公式

```text
[角色 / 情境] + [冲突] + [悬念或反转]
```

示例：

- 闹钟响了三遍，鲸鱼室友还没起床
- 提案前夜，我的 PPT 第一页是「新建文档」
- 只要看耳机灯，就知道我今天过得怎么样
- 还有 60 秒下班，三个人堵住了门口

### 封面

| 元素 | 规范 |
|---|---|
| 主体 | 角色脸 / 四人合影 / 状态灯特写 |
| 文字 | 6–10 个字，最多两行 |
| 颜色 | 品牌色 + 白色描边 |
| Logo | 右下角小尺寸潮汐环 |
| 禁止 | 夸张标题党、虚假信息、擦边 |

### 话题

```text
#摸鱼事务所 #桌宠日常 #打工人 #AI伙伴 #治愈系 #原创动画 #虚拟角色
```

## 8. 数据与迭代

| 指标 | 看什么 | 迭代动作 |
|---|---|---|
| 3 秒留存 | 钩子是否成立 | 换开头、前置冲突 |
| 完播率 | 节奏是否拖 | 剪掉 3–5 秒废话 |
| 互动率 | 评论 / 转发 | 结尾加投票、提问 |
| 关注转化 | 人设是否成立 | 固定片尾卡、角色口头禅 |
| 评论关键词 | 观众记住了谁 | 增加该角色戏份 |

> 前 8 条是测试期，不追求爆款；先找到「哪个角色 + 哪种钩子」最稳的组合。

## 9. 合规与边界

| 项目 | 要求 |
|---|---|
| 称呼 | 不写「主人」「服从」；Master 是伙伴 / 所长 |
| 角色 | 不擦边、不恋爱化、不性暗示 |
| 真人 | 不影射真实人物 / 主播 / 同事 |
| 商标 | 不出现 DeepSeek 名称与 Logo |
| AI 标注 | 按平台要求标注「AI 生成 / 虚拟形象」 |
| 音乐 | 使用原创歌词与授权 BGM |
| 素材 | 即梦生成背景保留记录；VRM 为项目自有，对外分发版本保留 CC BY-NC-SA 4.0 标注；商用按项目方授权 |
