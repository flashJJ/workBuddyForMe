# 影视类方案：摸鱼事务所（Slack Tide）

> 版本：v0.4  
> 日期：2026-11-17  
> 适用范围：WorkBuddyForMe 内置角色 IP 化、即梦循环背景视频、短视频、歌曲、周边与四人日常图  
> 状态：可评审，未进入开发排期

## 1. 一句话方案

把「雪团 / 冉卡露丽 / 菲比 + 操作者 Master」四个角色，收进一间海边的「摸鱼事务所」：**即梦只负责环境与氛围，角色一律用项目内 VRM 实拍，Master 用固定 2D 卡通形象出镜。** 这样既能做出可循环的影视级背景，又不会把角色脸生成跑偏。

- 中文名：**摸鱼事务所**
- 英文名：**Slack Tide**（平潮；slack 也有摸鱼之意）
- 宣传语：**认真工作，也认真休息。**
- 内容母题：工作与休息不是敌人，节奏才是。

## 4. 生产管线

| 环节 | 工具 | 输入 | 输出 | 关键控制点 |
|---|---|---|---|---|
| 1. 背景静帧 | 即梦图片 / 本地设计 | 场景描述 | 1920×1080（横屏）/ 1440×2560（桌宠 9:16） | 中心留白、低对比、无文字 |
| 2. 背景循环 | 即梦图生视频（首尾帧） | 同一张静帧作首尾帧 | 5 秒生成，成片 5–15 秒循环 MP4 | 固定机位、微动、无转场 |
| 3. 角色画面 | 应用内舞台 / 桌宠录制 | VRM 三席、固定机位 | 透明或绿幕素材 | 同一镜头高度、同一光源 |
| 4. Master 画面 | 2D 设定图 → PNG / Live2D | 三视图、表情表 | 分层立绘 / 表情包 | 不改变识别物 |
| 5. 合成 | 剪映 / Photoshop | 背景 + 角色 + Master | 横屏或竖屏成片 | 投影、色温、边缘光统一 |
| 6. 音乐 | 即梦音乐 / Suno / 人声合成 | 歌词、风格提示词 | Demo / BGM | 原创歌词，不模仿具体歌曲 |
| 7. 发布 | B站 / 抖音 / 小红书 | 成片、封面、标题 | 周更内容 | 不自动刷屏、不冒充官方 |

### 管线原则

1. **角色不交给即梦重绘。** 即梦负责海、雨、光、房间、粒子；角色由 VRM 渲染，保证脸、发型、服装、尾巴不变。
2. **先静帧，后视频。** 静帧便宜、可控、可反复挑；选中后再做图生视频，失败成本最低。
3. **一条背景，多次复用。** 8 秒循环背景可服务桌宠、舞台、短视频、直播四个场景。
4. **Master 不抢戏。** Master 常以侧脸、背影、手部、文字气泡出现，保留用户代入空间。
