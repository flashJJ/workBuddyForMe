## 1. 音乐方向

| 曲目 | 演唱 | 风格 | BPM | 调性 | 用途 |
|---|---|---|---|---|---|
| 平潮时刻 | 四人合唱 | City Pop / 轻放克 | 104 | F 大调 | 主题曲、片尾、合集 |
| 慢慢游 | 雪团 | Bossa Nova / Lo-fi | 82 | C 大调 | 雪团单人、助眠、日常 |
| 再来一组 | 冉卡露丽 | Pop Rock / Dance | 128 | E 大调 | 运动、晨间、燃向 |
| 我记下了 | 菲比 | Future Pop / City Pop | 100 | A 小调 | 记录、细节、轻悬疑 |
| 耳机里的海 | Master | Lo-fi / Ambient Pop | 76 | D 大调 | 深夜、工作、治愈 |

### 制作原则

- 歌词优先「具体动作 + 生活细节」，少用空泛的大词。
- 每首歌保留一个**可截成 15 秒的副歌钩子**。
- 角色曲的编曲要能听出角色：雪团 = 尼龙吉他 + 气泡；冉卡露丽 = 失真吉他 + 鼓；菲比 = 拨弦合成器 + 时钟；Master = 电钢 + 黑胶噪声。
- 主题曲的副歌要适合四人合唱，音域不要过宽。

## 8. 制作与发布

| 环节 | 建议 |
|---|---|
| Demo | 先做 60–90 秒：1 段主歌 + 副歌，验证旋律与情绪 |
| 演唱 | Kokoro TTS 只适合说话，不适合唱歌；用 ACE Studio / Synthesizer V / 真人歌手 |
| 编曲 | 先用即梦音乐 / Suno 出风格 Demo，再由人重新编曲，避免直接商用 AI 生成伴奏的条款风险 |
| 混音 | 人声 -16 LUFS；BGM 比人声低 12–18dB；短视频里再做 ducking |
| 母带 | 流媒体 -14 LUFS 左右；不要过度压限 |
| 歌词视频 | 用 [01 手册](./01-jimeng-loop-background.md) 的背景，9:16 与 16:9 各一版 |
| 发布 | 先发 15 秒钩子，再发完整版；封面用角色特写 + 歌名 |
| 版权 | 歌词原创；保留工程文件、时间戳、作者信息；不采样未授权歌曲 |

## 9. 歌词使用规范

| 项目 | 要求 |
|---|---|
| 署名 | 词曲作者统一署名项目 / 作者名；如多人协作，提前约定分成 |
| 改编 | 允许角色翻唱、remix，但需标注原曲 |
| 商用 | 音乐商用与角色商用分开确认；即梦 / Suno 条款需单独核对 |
| 敏感内容 | 不写政治、宗教、地域歧视、擦边 |
| 二创 | 允许粉丝非商用翻唱，标注「非官方」 |
