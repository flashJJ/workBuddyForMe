## 4. 四人合成标准流程

### 4.1 准备素材

| 素材 | 来源 | 要求 |
|---|---|---|
| 三个 VRM 角色 | 应用内舞台 / 桌宠截图 | 同一机位、同一光照、中性表情、透明或纯色背景 |
| Master 2D | [03 规范](./03-master-character.md) | 分层 PNG：身体、头、表情、耳机灯、工牌、马克杯 |
| 背景 | 即梦 | 无人物、中心留白、光源方向明确 |
| 道具 | 应用内 / 2D 素材 | 碗、杯子、便签、秒表、饭团 |

### 4.2 截取 VRM 的注意事项

| 项目 | 要求 |
|---|---|
| 机位 | 与背景透视一致；建议平视或轻微俯视 |
| 高度 | 三个角色同一视线高度 |
| 背景 | 纯绿 `#00FF00` 或纯蓝，避免与角色服装同色 |
| 表情 | 统一为 neutral 或轻微微笑 |
| 动作 | 站姿 / 坐姿统一；不要一个站一个坐（除非构图需要） |
| 光照 | 舞台固定光，避免强阴影 |
| 分辨率 | 至少 1080p，角色占画面 60% 以上 |
| 帧 | 选最稳定的一帧，不要用运动模糊帧 |

### 4.3 合成步骤

1. **定画布**：2560×1440（16:9）或 1920×1080；印刷用 300dpi。
2. **放背景**：按光源方向确认窗户 / 灯的位置。
3. **排角色**：先放 Master，再放三个角色；用同一视线水平对齐。
4. **调比例**：站立角色占画面 70–80%；坐姿 50–60%。
5. **去背景**：绿幕抠像，边缘羽化 1–2px；不要留下绿边。
6. **加接触阴影**：角色脚下 / 桌沿，正片叠底，20–35% 不透明度，模糊 8–20px。
7. **加边缘光**：受光侧加 2–4px 环境色边缘光，15–25% 不透明度。
8. **统一色调**：曲线、色彩平衡、色温；让 3D 角色与 2D 背景同一光线。
9. **加颗粒**：2–4% 单色颗粒，抑制色带；不要糊脸。
10. **导出**：PNG 存档；JPG q90 分享；竖屏另做 1080×1920 裁切。

### 4.4 合成参数

| 项目 | 建议 |
|---|---|
| 画布 | 2560×1440 / 1920×1080 / 1080×1920 |
| 角色高度 | 站立 70–80%，坐姿 50–60% |
| 视线高度 | 画面 45–55% 处 |
| 主光 | 左上暖光 5600K |
| 补光 | 右侧冷光 7000K，低强度 |
| 接触阴影 | 20–35% 不透明度，模糊 8–20px |
| 边缘光 | 15–25% 不透明度，2–4px |
| 颗粒 | 2–4% 单色 |
| 导出 | PNG + JPG q90 |

## 6. 质量验收

| 检查项 | 通过标准 |
|---|---|
| 脸 | 四个角色可一眼辨认；没有换发色 / 换瞳色 |
| 识别物 | 雪团鲸尾、冉卡露丽秒表、菲比兔耳、Master 五件套齐全 |
| 比例 | 四人头身比统一；没有「大人国 / 小人国」 |
| 视线 | 同一水平线；看镜头或自然互动 |
| 光源 | 所有人受光方向一致 |
| 阴影 | 每个角色都有接触阴影，不飘 |
| 边缘 | 无绿边、白边、锯齿 |
| 色调 | 3D 与 2D 不割裂；统一色温 |
| 道具 | 遮挡关系正确；手部不穿模 |
| 文字 | 无乱码、无水印（除非设计需要） |
| 分辨率 | 至少 1920×1080；印刷 300dpi |
| 授权 | 官方内容标注官方；粉丝二创标注非官方；商用按项目方授权 |
