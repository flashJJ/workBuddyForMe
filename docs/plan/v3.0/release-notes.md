# WorkBuddyForMe v3.0.0 发布说明

> 版本：3.0.0（2026-11-14）
> 范围：M0 桌面舞台 → M1 动效与陪伴 → M3 声线/画像/决策 → M4 小剧场/分享/角色包 → M5 发布门禁
> 说明：M2 养成已取消，相关「投喂/亲密度」不再作为验收项。

## 1. 本版交付

| 里程碑 | 交付内容 |
|---|---|
| M0 | Electron 主窗 + 桌面宠物窗分离、舞台渲染、Live2D/VRM 双栈、preload IPC 桥 |
| M1 | 分层台词池、首次见面/久无互动/深夜/饿了/被戳/被叫胖、右键快捷动作、待机余兴与点击轮播 |
| M3 | 雪团声线（kokoro sid=18）、用户画像注入剧本、Utility 决策阶段 1–3、主动播放、设置页「最近决策」、低语忙碌静默 |
| M4 | `/stage?stage=play` 小剧场（雪团 / 冉卡露丽 / 菲比三席 VRM）、剧情分享卡 PNG、角色卡 Markdown 导入导出（已有能力验收） |
| M5 | 剧本跨场景 lint + cue 时间线 golden、`pnpm check:scenes`、原创角色与二创包合规声明、版本 3.0.0、本发布说明 |

## 2. 用户可见变化

- 舞台新增「小剧场」模式：三席内置 VRM 角色按句长轮播 6 句台词，支持上一句/下一句/重播与暂停/继续。
- 小剧场新增《办公室小剧场 · 提案夜》《雨夜小剧场 · 等伞》，共 4 集 24 句；每集分幕，幕名显示在轮播角标，幕间可切换背景、配乐与类型标签（喜剧/日常/悲剧/悬疑）。
- 舞台角色按相对位置自动朝向：左席整体略向右、右席略向左，拖拽换位后自动重算，三席说话时更像互相对视。
- 剧场配乐随剧集/幕的类型标签切换为对应 CC0 曲目（温暖/轻快/悬疑/忧郁），换幕淡出旧曲再淡入新曲，换句提示音也按类型改变音色。
- 剧场三席按角色声线朗读台词，说话时背景音乐自动压低；右上角可随时静音/恢复背景音（首次点击解锁浏览器音频）。
- 剧场背景升级为幕布、地板、聚光灯与暗角，聚光灯跟随当前发言者；三席模型加载完成前显示进度幕布，不提前开演。
- 剧场加入开场幕布与换句提示音（WebAudio 合成，无外部素材），与背景音共用静音开关。
- 新增全局背景音乐播放器：主工作区右下角迷你播放条，支持播放/暂停、上一首/下一首、进度、音量、列表循环/单曲循环/不循环。
- 「设置 → 音乐与背景声」可管理 3 首主题曲（组内轮播）、8 首氛围音乐、拖拽/选择导入本地歌曲（单曲 ≤40MB，IndexedDB 持久化），并查看可复制的氛围生成清单。
- 已内置 11 首 **CC0 1.0** 曲目（OpenGameArt）：3 首主题曲 + 8 首氛围曲，覆盖温暖、浪漫、安静、俏皮、活力、忧郁、悬疑与专注；逐曲作者与来源见 `ASSETS-LICENSE.md`。
- 曲目统一转 MP3 192kbps 44.1kHz 立体声（-16 LUFS），合计约 30.4MB；此前豆包 App 生成的 9 首已移出发布目录，仅在本机 `.tmp/personal-music/` 留档。
- 进入舞台路由时全局播放器随主布局卸载，避免与剧场 BGM 叠加。
- 剧场内可打开分享卡：卡面包含剧场标题、日期、当前台词、席位名单、今日主动播放与今日生成数；一键保存 PNG（桌面端原生截图）。
- 设置页「关于」新增原创角色与二创包合规说明。
- 设置页「AI 日常剧情」此前已有的主动播放、最近决策、定时生成保持可用。

## 3. 内部改动

- 舞台深链解析从 `stage-root` 抽到 `stage/theater/stage-target.ts`，新增 `stage=play` 与 `ep` 参数白名单。
- 舞台截图复用于分享卡导出：截图时只隐藏 UI 与按钮，卡面保留在画面内。
- 分享卡数据走 `GET /api/pet/script/playback` 与 `GET /api/pet/script`，失败时显示 `--`，不阻断卡面。
- 新增跨场景剧本 lint：id 唯一、触发键/打断策略白名单、beats 时间单调、可感知 cue、道具成对、`validateScene` 零丢弃。
- 新增内置场景 golden：`id → [{at, kind}]` 快照，场景改动必须显式更新。
- 舞台 VRM 待机只用内置 `daiji`（`motionProfile="stage"`），并剔除腿/脚/脚趾/手指轨道、关闭待机余兴、固定 5° 外旋站姿；同时修正 VRMA 归一化轨道名下的手臂动画判定，避免程序化垂手/手指屈曲叠加。修复小剧场三席手脚交叉、爪状手与鞋子重叠；桌宠仍按原逻辑轮播用户动作。
- 剧场硬化（S0–S6）：`use-stage-theater` 按句长与语音状态推进（15s 上限兜底），新增 `use-theater-audio`（逐句 TTS、BGM 淡入淡出/duck 35%/静音、首次手势解锁）与 `theater-bgm`（WebAudio 合成，无外部音频素材）；`stage-motion-adapter` 把 cue 映射为 VRM/Live2D 安全动作；`TheaterBackdrop` 提供幕布/聚光灯/地板；`use-theater-readiness` 统计三席就绪度并 45s 兜底；切后台暂停时间线与音频，回前台补播。
- 模型体积：morph POSITION 稀疏化 + 贴图 WebP 重编码，三席 74.75MB → 22.29MB（feibi 7.01 / rankaluli 6.00 / xuetuan 9.28MB），表情与 VRM 绑定回读一致。
- 新增 118 个 KK morph 表情目录与 8 组预设，三席表情走 morph 组合，其他 VRM 继续走标准 preset；修复 `surprise` / `smirk` 空操作。
- 表情强度端到端：`StageDirection.expression` 支持 `intensity`（1/2/3），经舞台控制器、`StageActor`、`VrmCanvas`、`VrmSession` 透传到 KK morph 组合；剧场台词可按句标注强度，换 cast 重置为 2。
- 短音效 `theater-sfx.ts`：幕布噪声缓升与换句提示音均用 WebAudio 合成；静音与 BGM 同步，自动播放拦截时静默跳过。
- 剧场数据扩展：`titleEn` / `textEn` 与 `localizeTheaterEpisode()` 支持英文；新增 `morning-drill` 集（聚光灯背景），`?ep=` 可直达。
- 剧场结构：剧集数据拆到 `theater/episodes/`；`TheaterAct` 用台词区间描述幕，`genres` 驱动配乐与音效；新增 `theaterActAt / theaterBackdropAt / theaterMoodAt / theaterGenreAt` 推导函数。
- 舞台朝向：`stageFacingYaw()` 与 `VrmPoseLayer` 的平滑朝向偏移打通，`StageActor → VrmCanvas → VrmSession` 全链透传，最大约 19.5°，所有舞台模式生效。
- 配乐：`TheaterBgm` 改为 HTMLAudioElement 播放 4 首 CC0 曲目（warm / playful / tense / melancholy），`setMood()` 淡出旧曲后换源再淡入；说话时音量压到 35%，静音与暂停同步；换句音效按类型标签选择音高。
- 修复剧场说话时舌头外露：`joy` 强度 3 从 `Mouth_happy_broad_op` 改为闭口版 `Mouth_happy_broad_cl`；说话期间表情层剥离嘴部 morph，只保留眼/眉，嘴型完全交给口型通道，避免张嘴表情与口型叠加。
- 外部音频政策：剧场背景乐复用内置 CC0 曲目，剧场音效仍 WebAudio 合成；背景音乐只接入可分发素材（当前为 CC0），按 `ASSETS-LICENSE.md` 登记来源与许可；豆包 App 输出不进入发布版。
- 桌宠窗 `?model=` 显式指定的形象优先于设置默认值，避免 `pet.open(modelId)` 被默认 VRM 覆盖；主窗后续切换角色仍会热替换。
- 控制通道窗口聚焦增加前台锁绕行（Alt 解锁、前台状态确认、`SwitchToThisWindow` 兜底），受限桌面/远程会话下也能激活目标窗口。
- 音乐模块：`features/music/` 新增 `MusicProvider`、全局迷你播放条、设置面板与曲库工具；播放状态（当前曲、音量、循环模式）存 localStorage，导入音频存 IndexedDB，不上传服务器。
- 内置主题曲槽位固定文件名（`public/audio/music/theme-*.mp3`）；主题曲组内自动轮播，氛围音乐按整库顺序播放；待生成槽位在界面标记「待生成」。
- 导入支持 MP3/M4A/OGG/WAV/FLAC，单曲 ≤40MB，并按文件名猜测情绪标签。
- 新增 `docs/plan/v3.0/music-atmospheres.md`：7 首氛围曲的 BPM、时长、使用场景与可直接复制的豆包提示词；设置面板内也可逐条复制。

## 4. 门禁结果

- 单测：剧场域 10 文件 57 项通过（导演 5 / 音频 7 / BGM 6 / 短音效 4 / 强度 3 / 剧本 11 等）+ 舞台布局 8 项；音乐 2 文件 9 项；设置中心 6 项；舞台 + 场景 + 设置存储 12 文件 62 项通过；`pnpm check:scenes` 6 文件 37 项通过。
- 类型：`pnpm typecheck` 14 tasks 通过。
- Lint：8 包 0 error（28 条存量 warning）。
- 行数：全部手写文件 ≤300 行。
- 结构：目录预算与入口检查通过，`stage/` 存量 21 个直接文件未增长（新代码在 `stage/theater/`）。
- 循环依赖：8 个存量 SCC，无新增。
- ASCII：770 个 Markdown 文件通过。
- 真机（1440×900，`/stage?stage=play`）：三席 3/3 就绪后开演；speakerId 18/32/3 三席语音；BGM 音量 0.3 起播、说话 duck 到 0.105、静音归零；暂停 8s 不推进、继续恢复；上一句/下一句、幕布背景、分享卡均正常；控制台无错误，`/vrm/` 无失败请求。
- 补强真机：表情强度按句切换 2→3→1；第二集 `?ep=morning-drill` 走聚光灯背景；幕布音缓冲 ×1、换句音振荡器 +1、静音后不再发声；`proposal-night` 第 1→2 幕角标、背景与配乐频率切换正常；左右角色整体向内朝向。
- 音乐真机：设置页显示 3 首主题曲 + 8 首氛围曲；Edge 播放主题曲，结束自动切到下一首并在 1/3→2/3→3/3 循环，手动下一首回到 1/3；氛围曲正常播放；导入 3s WAV 后刷新记录仍在。Playwright 内置 Chromium 不含 MP3 解码，音乐验收改用系统 Edge/Chrome。设置页存在既有的水合告警（`search-settings-panel`），与本模块无关。
- 桌面端 PNG：Playwright 启动 Electron，替换保存对话框后经分享卡写出 2561×1601 PNG（1.05MB），toast「截图已保存」、UI 恢复、主进程无错误。

## 5. 已知限制

- 分享卡只在桌面端导出 PNG；浏览器裸访提示 unsupported。
- M2 养成取消，分享卡不含投喂/亲密度；关系等级门槛与低语池间打分仍待后续接口与元数据。
- 小剧场目前 4 集各 6 句，剧本为内置数据，尚未接入生成器队列；剧场背景乐已接入 CC0 曲目，音效仍为 WebAudio 合成。
- 背景音乐模块已内置 11 首 CC0 曲目，无待生成槽位；导入曲库按浏览器/桌面用户目录保存，不进入备份包。
- 音乐许可独立于代码与角色模型：11 首均为 CC0 1.0，可商用、修改与再分发，无需署名；此前豆包 App 生成曲目仅限个人学习娱乐，已从发布目录替换，详见 `ASSETS-LICENSE.md`。
- 生成器弱偏好 `moods/hours` 为可选输出，命中率待观察。
