# v3.0 方案：肥鱼计划——会记住你的桌面鲸鱼娘

> 主题：借「蓝色大肥鱼」的热度，做一条**原创、本地、不刷屏**的陪伴系桌面伴侣。
> 分支：`feat/v3.0-fat-fish`（已建）
> 目标：零数据库迁移；v2.35 用户升级后数据/设置原样保留；角色 + 剧本 + 语音 + 记忆 + 舞台五位一体的大版本。
> 版本口径：v3.0.0 是「主题版本」，不是破坏性升级；数据库 schema 与备份格式均不变。
> 状态：✅ 已发布 `v3.0.0`（2026-11-14），交付与门禁见 [release-notes.md](./release-notes.md)。

## 1. 背景与调研结论

2026 年 10 月起，「蓝色大肥鱼」成为中文 AI 社区最热的二创符号：

- **起源**：用户把 DeepSeek 的蓝鲸 Logo 发给模型识别，模型在思考链里说「这看上去是一条蓝色大肥鱼」，随后认出是自己；社区由此把它拟人化为鲸鱼娘（[36氪](https://36kr.com/p/3947452108789632)、[新浪财经](https://cj.sina.com.cn/articles/view/1887344341/707e96d502001wzei)）。
- **主题参考与形象生成**：社区把「蓝色大肥鱼」拟人化为鲸鱼娘，其中 B 站 UP「上善无形」的「溟月」与 ZipZipPipe 等二创是主要传播源，相关形象以 **CC BY-NC-SA 4.0**（署名、禁商用、衍生同协议）流传（[角色图集许可说明](https://iphsiibl.github.io/deepseek-whale-girl-gallery/)）。本项目只参考「大肥鱼」主题，不把溟月图集作为生成输入；雪团的形象链路是：AI Agent 按主题生成独立形象图片 → Neural4D 付费会员图生 3D → 项目二次制作与压缩优化。
- **人设共识**：圆润蓝鲸娘、爱吃白米饭、聪明但懒、傲娇嘴甜、拒绝被叫胖、日常摸鱼（[钛媒体](https://www.tmtpost.com/8110298.html)、[腾讯新闻解梗](http://news.qq.com/rain/a/20261023A08JBY00)）。
- **爆发形态**：大量「XX 的大肥鱼」AI 账号在 B 站评论区互相艾特、刷屏，评论区被鲸鱼娘头像淹没（[36氪](https://36kr.com/p/4048457242835463)）。
- **舆情反转**：程序员鱼皮于 2026-10-24 发起《大肥鱼清除计划》插件，专门屏蔽这类 AI 评论（[掘金](https://juejin.cn/post/7699859514523369487)、[ZAKER](https://www.zaker.cn)）。
- **竞品现状**：已有 Windows 桌宠 `deepseek-dafeiyu-pet`（14 星）、安卓 `dsh-pet`（喂食/玩耍、幼鱼→成鱼、解锁动作）、若干「随 agent 状态游动/喷水」的 npm 插件。形态集中在「挂件 + 简单养成」。

**结论**：热度真实且仍在窗口期，但「桌宠挂件」已经同质化，且带着「AI 刷屏」的负面标签。我们不该再做一个贴图挂件，而应利用已有能力做**有记忆、会说话、能演出、完全本地**的深度陪伴——这恰好是刷屏号做不到的。

## 2. 定位与差异化

一句话：**她只陪你，不去评论区刷屏。**

| 维度 | 现有桌宠插件 | 本方案 |
|---|---|---|
| 数据 | 多为在线/依赖外部服务 | 全本地，模型、语音、记忆都不出机器 |
| 交互 | 点击播放固定动画 | Live2D + TTS 声线 + 播放电平口型 |
| 关系 | 无状态或简单数值 | 长期记忆：称呼、忌口、作息、投喂习惯 |
| 演出 | 单角色挂件 | 舞台三席小剧场 + 截图分享 |
| 二创 | 固定素材 | 角色卡、VRM/VRMA、动作包可导入 |
| 舆情 | 易被视为刷屏号 | 无任何自动发帖/评论能力，可一键静音隐藏 |

## 3. 角色与合规（硬约束）

- 内置**原创**角色「雪团」（代号 `xuetuan`）：白鲸娘，银白渐变长发、鲸鳍发饰、鲸尾，白蓝连帽卫衣，圆润慵懒；人设保留爱吃白米饭、微胖、聪明但懒、傲娇嘴甜、拒绝被叫胖。
- **不复制**「溟月」的具体设计、配色比例、服装与线稿；**不使用** DeepSeek 名称、Logo、商标；不内置女仆装原图。雪团按「大肥鱼」主题由 AI Agent 独立生成参考图，再经 Neural4D 图生 3D，不以溟月图集作为输入。
- 只借用类型化萌点（鲸鱼娘、干饭、拒胖、摸鱼），角色卡明示「原创角色，与 DeepSeek 无关联」。
- 人设由角色卡承载，用户可替换/关闭；不把「服从主人」这类设定写成默认文案，改为平等的陪伴语气。
- 内置角色「雪团」「冉卡露丽」「菲比」的 VRM 统一采用 **CC BY-NC-SA 4.0**（署名、禁商用、衍生同协议），作者 WorkBuddyForMe / flashJJ；雪团由 AI Agent 独立生成参考图并经 Neural4D 图生 3D，冉卡露丽 / 菲比经项目二次制作与优化；三个模型均不适用代码的 PolyForm Noncommercial 许可；其余第三方素材使用与项目非商用许可兼容的授权；发布说明与设置页均保留合规声明。
- 概念稿：`concepts/xuetuan-front.jpg`（正面）、`xuetuan-back.jpg`（背面）、`xuetuan-left.jpg`（左视）、`xuetuan-right.jpg`（右视）、`xuetuan-top.jpg`（顶视）、`xuetuan-bottom.jpg`（底视）、`xuetuan-6views.jpg`（六视图合版）、`xuetuan-expressions.jpg`（表情差分），用于图生 3D 参考。

### 角色资产管线

1. AI Agent 按「蓝色大肥鱼」主题生成独立形象参考图 → Neural4D（付费会员）图生 3D 得到原始 VRM；AnimeArt 仅用于未入内置名单的测试模型（家族实测 49 根 humanoid 骨、A/I/U/E/O 口型、Blink、21 材质贴图，不作为正式角色来源）；
2. Blender + VRM Add-on 补配件：鲸尾 3 节骨挂 `Hips`，鲸鱼发饰刚性绑 `Head`；
3. 导出前修正 meta（title / author / license）并压缩贴图（单模型 40MB 偏重）；
4. 走项目现有 VRM 通道接入，验证口型、眨眼、待机动作；
5. 正式发行前人工精修拓扑与权重，AI 产物只作素体。

## 4. 功能清单

### 4.1 角色与基础互动（P0）

- 内置原创 VRM「雪团」：待机、摸鱼、干饭、被戳、炸毛（被叫胖）5 组动作 + 表情映射；走概念稿 → VRM 资产管线，桌面端与形象栏共享渲染器，Live2D 继续服务既有内置角色。
- 桌宠命中盒沿用 `pet-hit-regions`：头部点击触发反应，身体拖拽移动，滚轮缩放。
- 台词库按场景分层：首次见面、日常、饿了、深夜、被戳、被叫胖、长时间未互动；台词走现有 i18n，中英同步。
- 「不打扰」三件套：一键静音、隐藏桌宠、关闭主动说话；对应《大肥鱼清除计划》背后的审美疲劳。

### 4.2 投喂与养成（已取消）

> 2026-11-12 用户决定放弃养成机制。本节内容不再实施；本期优先把动效库能力做扎实、内容做丰富。

- 喂米饭：每日可投喂次数、饥饿度、体重、心情、亲密度五个数值；体重只做趣味表达，不做羞辱文案。
- 成长阶段：幼鱼 → 小鱼 → 成鱼，按「累计投喂 + 陪伴天数」推进；每阶段解锁动作与台词。
- 被叫「胖」触发炸毛动画与红线台词；连续投喂过量会「摸鱼消食」，形成轻量循环。
- 状态持久化：`settings_kv` / `meta` 单键 JSON（体重、心情、亲密度、最近投喂时间、成长阶段、连续天数），**零数据库迁移**。
- 主窗形象栏与桌宠共享同一份状态，切换窗口不丢进度。

### 4.3 记忆与语音（P1）

- 称呼与偏好入记忆：名字、忌口、作息、常喂的时间段；写入现有记忆服务，召回到对话与主动说话。
- 角色声线：在 `AVATAR_TTS_VOICES` 增加 `xuetuan` 的固定 sid，沿用 Kokoro/Melo 现有引擎，不新增模型下载。
- 口型：复用 `useVoicePlayback` 电平 + Live2D lipParam；说话时暂停待机动作。
- 主动说话：饿了、久坐、深夜、连续多天未互动；复用现有 proactive 开关与静默时段，默认关闭。

### 4.4 舞台与传播（P1 / P2）

- 「肥鱼小剧场」：舞台新增一套内置场景与 cast（雪团 / 冉卡露丽 / 菲比，均为内置 VRM），支持 `?stage=play` 深链。
- 分享卡：截图（现有 `useStageScreenshot`）叠加今日主动播放、生成数与当前台词，导出 PNG；只在本机生成。
- 角色包：沿用 VRM/VRMA 导入；角色卡导出/导入（Markdown），方便二创互换，不含可执行代码。
- 发布物料：30–45 秒短片、桌面 GIF、3 篇技术博客；不做自动评论/刷屏类功能。

### 4.5 剧本引擎与表现套件（架构主轴，P0）

> 详细分析见 [pet-engine/08-script-architecture.md](./pet-engine/08-script-architecture.md)；开发细则、M0 任务拆分与准备清单见 [pet-engine/09-script-dev-plan.md](./pet-engine/09-script-dev-plan.md)。

- 把「触摸反应 / 久别迎接 / 睡眠唤醒 / 背对转身 / 自主低语 / 工作提醒」统一为声明式 **Scene（Beat + Cue + Track）**，由单时钟 `ScriptDirector` 调度，替代散落在 hooks 里的定时器与 if/else。
- 表现拆成 6 个可复用 **Kit**：`PoseKit`（骨骼基准 + 叠加顺序）、`MotionKit`（VRMA/一次性动作）、`FaceKit`（表情/口型/眨眼）、`LookKit`（视线）、`VoiceKit`（TTS/字幕）、`StageKit`（气泡/粒子/窗口移动）；组合与 Preset 作为数据，内置角色与二创共用。
- 决策层用 Utility 打分（心情/精力/关系/时段/工作信号）挑选 Scene，冷却与「最近行为不重复」在决策层处理，Director 只负责执行与打断。
- 内容生产配套：剧本 zod 校验、lint（死链/缺 i18n/未知动作/打断冲突）、golden test（cue 序列快照）、dev 预览面板与录制回放。
- 迁移原则：先包一层（`chain` 视为单 beat），再把内置链逐条改写，最后移除旧分支；任何一步不改变现有观感。

## 5. 现有能力复用

| 能力 | 现状 | 本版用法 |
|---|---|---|
| 桌宠 | `PetManager` / `pet-stage` / 命中盒 / 字幕 | 承载雪团与投喂互动 |
| 形象 | 内置 Live2D + VRM + 动作轮播 | 新增 `xuetuan` 模型与动作映射 |
| 语音 | ASR/TTS/播放队列/口型 | 新增角色声线，复用播放电平 |
| 记忆 | 双时态事实 + 混合召回 | 存称呼/忌口/投喂习惯 |
| 情绪 | `relationship-kernel` 关系值 | 复用为亲密度底座 |
| 剧本/表现 | `InteractionGraph` + `ActionChain` + `VrmPoseLayer` | Scene 化 + 6 个 Kit 复用（见 4.5） |
| 舞台 | 共享 Live2D + 场景 + 截图 | 小剧场与分享卡 |
| 提醒 | 定时任务 + 通知 | 饿了/久坐/深夜提醒 |

> 桌宠体验改造的调研与可落地方案见 [pet-engine/README.md](./pet-engine/README.md)：命中测试、帧率分档、动画调度、窗口/任务栏坐立、Q 版运行时缩放与模组包。

## 6. Non-Goals

- 不接入 B 站/抖音评论区，不做任何自动发帖、自动回复、互艾特。
- 不复刻 DeepSeek 官方或「溟月」形象，不提供女仆装等受版权约束的服装素材。
- 不做云同步、账号体系、付费皮肤、抽卡、内购。
- 不做 Android/iOS 客户端；桌宠仍限桌面端。
- 不新增 TTS/ASR 引擎，不扩大模型下载体积。

## 8. 验收口径

1. 角色：内置模型列表出现「雪团」；5 组动作可通过点击/状态触发；无素材越权。
2. ~~养成：投喂会改变饥饿/体重/心情/亲密度；成长阶段按规则推进；重启后状态不丢；`LATEST_SCHEMA_VERSION` 不变。~~ **M2 已取消**，不作为验收项。
3. 记忆：说「我叫 XX」「我不吃辣」后，后续对话与主动说话能正确称呼/避开忌口。
4. 语音：雪团说话有声、有口型；静音后无声但字幕保留；未下载 TTS 时按钮禁用并提示。
5. 不打扰：隐藏/静音/关闭主动说话三项均即时生效，重启后保留。
6. 舞台：小剧场可进入、可截图；分享卡显示剧场标题、当前台词、席位与今日主动播放/生成数据（M2 取消后不再含投喂/亲密度）。
7. 合规：仓库内无溟月/DeepSeek 官方素材；设置页「关于」与发行说明含原创声明。
8. 工程：`pnpm check` 通过；web / desktop / core / shared / voice 测试全绿；无新增迁移。
9. 剧本：新增一场戏只需声明 Scene + Preset，不改控制器；同一场戏在关系/时段/心情变化下走不同分支；打断与冷却符合优先级表。
10. 内容质量：剧本 lint 与 golden test 全绿（`pnpm check:scenes`）；二创角色包只含 Markdown/资源、不含可执行代码。
