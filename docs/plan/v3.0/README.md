# v3.0 方案：肥鱼计划——会记住你的桌面鲸鱼娘

> 主题：借「蓝色大肥鱼」的热度，做一条**原创、本地、不刷屏**的养成系桌面伴侣。
> 分支：`feat/v3.0-fat-fish`（已建）
> 目标：零数据库迁移；v2.35 用户升级后数据/设置原样保留；角色养成 + 语音 + 记忆 + 舞台四位一体的大版本。
> 版本口径：v3.0.0 是「主题版本」，不是破坏性升级；数据库 schema 与备份格式均不变。

## 1. 背景与调研结论

2026 年 10 月起，「蓝色大肥鱼」成为中文 AI 社区最热的二创符号：

- **起源**：用户把 DeepSeek 的蓝鲸 Logo 发给模型识别，模型在思考链里说「这看上去是一条蓝色大肥鱼」，随后认出是自己；社区由此把它拟人化为鲸鱼娘（[36氪](https://36kr.com/p/3947452108789632)、[新浪财经](https://cj.sina.com.cn/articles/view/1887344341/707e96d502001wzei)）。
- **形象源头**：B 站 UP「上善无形」2025 年 6 月创作的原创角色「溟月」（蓝发、鲸鳍、鲸尾），后经 ZipZipPipe 等二创为女仆装鲸鱼娘；该形象以 **CC BY-NC-SA 4.0**（署名、禁商用、衍生同协议）流传（[角色图集许可说明](https://iphsiibl.github.io/deepseek-whale-girl-gallery/)）。
- **人设共识**：圆润蓝鲸娘、爱吃白米饭、聪明但懒、傲娇嘴甜、拒绝被叫胖、日常摸鱼（[钛媒体](https://www.tmtpost.com/8110298.html)、[腾讯新闻解梗](http://news.qq.com/rain/a/20261023A08JBY00)）。
- **爆发形态**：大量「XX 的大肥鱼」AI 账号在 B 站评论区互相艾特、刷屏，评论区被鲸鱼娘头像淹没（[36氪](https://36kr.com/p/4048457242835463)）。
- **舆情反转**：程序员鱼皮于 2026-10-24 发起《大肥鱼清除计划》插件，专门屏蔽这类 AI 评论（[掘金](https://juejin.cn/post/7699859514523369487)、[ZAKER](https://www.zaker.cn)）。
- **竞品现状**：已有 Windows 桌宠 `deepseek-dafeiyu-pet`（14 星）、安卓 `dsh-pet`（喂食/玩耍、幼鱼→成鱼、解锁动作）、若干「随 agent 状态游动/喷水」的 npm 插件。形态集中在「挂件 + 简单养成」。

**结论**：热度真实且仍在窗口期，但「桌宠挂件」已经同质化，且带着「AI 刷屏」的负面标签。我们不该再做一个贴图挂件，而应利用已有能力做**有记忆、会说话、能演出、完全本地**的深度陪伴——这恰好是刷屏号做不到的。

## 2. 定位与差异化

一句话：**她只陪你，不去评论区刷屏。**

| 维度 | 现有桌宠插件 | 本方案 |
|---|---|---|
| 数据 | 多为在线/依赖外部服务 | 全本地，模型、语音、记忆都不出机器 |
| 交互 | 点击播放固定动画 | Live2D + TTS 声线 + 播放电平口型 |
| 关系 | 无状态或简单数值 | 长期记忆：称呼、忌口、作息、投喂习惯 |
| 演出 | 单角色挂件 | 舞台三席小剧场 + 截图分享 |
| 二创 | 固定素材 | 角色卡、VRM/VRMA、动作包可导入 |
| 舆情 | 易被视为刷屏号 | 无任何自动发帖/评论能力，可一键静音隐藏 |

## 3. 角色与合规（硬约束）

- 内置**原创**角色「小澜」（代号 `lan`）：蓝发鲸鱼娘、鲸鳍与鲸尾、爱吃白米饭、微胖、聪明但懒、傲娇嘴甜、拒绝被叫胖。
- **不复制**「溟月」的具体设计、配色比例、服装与线稿；**不使用** DeepSeek 名称、Logo、商标；不内置女仆装原图。
- 只借用类型化萌点（鲸鱼娘、干饭、拒胖、摸鱼），角色卡明示「原创角色，与 DeepSeek 无关联」。
- 人设由角色卡承载，用户可替换/关闭；不把「服从主人」这类设定写成默认文案，改为平等的陪伴语气。
- 所有素材自制或使用可商用授权；发布说明与设置页均保留合规声明。

## 4. 功能清单

### 4.1 角色与基础互动（P0）

- 内置原创 Live2D「小澜」：待机、摸鱼、干饭、被戳、炸毛（被叫胖）5 组动作 + 表情映射；复用舞台共享渲染器，单 WebGL 上下文。
- 桌宠命中盒沿用 `pet-hit-regions`：头部点击触发反应，身体拖拽移动，滚轮缩放。
- 台词库按场景分层：首次见面、日常、饿了、深夜、被戳、被叫胖、长时间未互动；台词走现有 i18n，中英同步。
- 「不打扰」三件套：一键静音、隐藏桌宠、关闭主动说话；对应《大肥鱼清除计划》背后的审美疲劳。

### 4.2 投喂与养成（P0）

- 喂米饭：每日可投喂次数、饥饿度、体重、心情、亲密度五个数值；体重只做趣味表达，不做羞辱文案。
- 成长阶段：幼鱼 → 小鱼 → 成鱼，按「累计投喂 + 陪伴天数」推进；每阶段解锁动作与台词。
- 被叫「胖」触发炸毛动画与红线台词；连续投喂过量会「摸鱼消食」，形成轻量循环。
- 状态持久化：`settings_kv` / `meta` 单键 JSON（体重、心情、亲密度、最近投喂时间、成长阶段、连续天数），**零数据库迁移**。
- 主窗形象栏与桌宠共享同一份状态，切换窗口不丢进度。

### 4.3 记忆与语音（P1）

- 称呼与偏好入记忆：名字、忌口、作息、常喂的时间段；写入现有记忆服务，召回到对话与主动说话。
- 角色声线：在 `AVATAR_TTS_VOICES` 增加 `lan` 的固定 sid，沿用 Kokoro/Melo 现有引擎，不新增模型下载。
- 口型：复用 `useVoicePlayback` 电平 + Live2D lipParam；说话时暂停待机动作。
- 主动说话：饿了、久坐、深夜、连续多天未互动；复用现有 proactive 开关与静默时段，默认关闭。

### 4.4 舞台与传播（P1 / P2）

- 「肥鱼小剧场」：舞台新增一套内置场景与 cast（小澜 + 现有角色），支持 `?stage=play` 深链。
- 分享卡：截图（现有 `useStageScreenshot`）叠加今日投喂、亲密度、台词，导出 PNG；只在本机生成。
- 角色包：沿用 VRM/VRMA 导入；新增角色卡导出/导入（Markdown），方便二创互换。
- 发布物料：版本短片（Live2D 录屏）、桌面 GIF、5 篇技术博客；不做自动评论/刷屏类功能。

## 5. 现有能力复用

| 能力 | 现状 | 本版用法 |
|---|---|---|
| 桌宠 | `PetManager` / `pet-stage` / 命中盒 / 字幕 | 承载小澜与投喂互动 |
| 形象 | 内置 Live2D + VRM + 动作轮播 | 新增 `lan` 模型与动作映射 |
| 语音 | ASR/TTS/播放队列/口型 | 新增角色声线，复用播放电平 |
| 记忆 | 双时态事实 + 混合召回 | 存称呼/忌口/投喂习惯 |
| 情绪 | `relationship-kernel` 关系值 | 复用为亲密度底座 |
| 舞台 | 共享 Live2D + 场景 + 截图 | 小剧场与分享卡 |
| 提醒 | 定时任务 + 通知 | 饿了/久坐/深夜提醒 |

## 6. Non-Goals

- 不接入 B 站/抖音评论区，不做任何自动发帖、自动回复、互艾特。
- 不复刻 DeepSeek 官方或「溟月」形象，不提供女仆装等受版权约束的服装素材。
- 不做云同步、账号体系、付费皮肤、抽卡、内购。
- 不做 Android/iOS 客户端；桌宠仍限桌面端。
- 不新增 TTS/ASR 引擎，不扩大模型下载体积。

## 7. 阶段拆分

| 阶段 | 内容 | 验证 |
|---|---|---|
| P0-M1 | 原创角色 `lan` 入内置模型表 + 5 组动作 + 台词库 + 不打扰开关 | 桌宠/主窗均可见；动作与表情切换正确；静音/隐藏即时生效 |
| P0-M2 | 投喂与五维状态 + 成长阶段 + 状态持久化 + 主窗/桌宠联动 | 重启后状态保留；跨窗口一致；零迁移 |
| P1-M3 | 称呼/忌口/作息入记忆 + 角色声线 + 主动说话 | 记忆可召回；语音与口型同步；静默时段不打扰 |
| P1-M4 | 肥鱼小剧场 + 分享卡 + 角色卡导入导出 | 场景可深链；PNG 可导出；角色卡可互导 |
| P2-M5 | 发布物料、合规声明、验收 | 门禁全绿；发布说明/博客/短片就绪 |

## 8. 验收口径

1. 角色：内置模型列表出现「小澜」；5 组动作可通过点击/状态触发；无素材越权。
2. 养成：投喂会改变饥饿/体重/心情/亲密度；成长阶段按规则推进；重启后状态不丢；`LATEST_SCHEMA_VERSION` 不变。
3. 记忆：说「我叫 XX」「我不吃辣」后，后续对话与主动说话能正确称呼/避开忌口。
4. 语音：小澜说话有声、有口型；静音后无声但字幕保留；未下载 TTS 时按钮禁用并提示。
5. 不打扰：隐藏/静音/关闭主动说话三项均即时生效，重启后保留。
6. 舞台：小剧场可进入、可截图、分享卡含投喂与亲密度数据。
7. 合规：仓库内无溟月/DeepSeek 官方素材；设置页与发行说明含原创声明。
8. 工程：`pnpm check` 通过；web / desktop / core / shared / voice 测试全绿；无新增迁移。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 版权（溟月 CC BY-NC-SA 禁商用） | 只用原创角色；不复制具体设计；素材来源与授权逐项登记 |
| 商标（DeepSeek） | 全链路不出现其名称/Logo；宣传语只提「鲸鱼娘」品类 |
| 舆情审美疲劳（清除计划） | 不做刷屏能力；默认不主动打扰；提供一键隐藏/静音 |
| 竞品先发（桌宠插件/安卓养成） | 差异化压在记忆、语音、舞台与本地隐私，而不是贴图数量 |
| 热度衰减 | M1 先出可演示版本；发布节奏紧跟窗口，物料一次备齐 |
| 常驻性能 | 复用省电档、帧率看门狗与共享 Live2D 上下文；桌宠默认 30fps |
| 设定争议（服从/身材羞辱） | 默认平等语气；体重只做趣味表达；台词过审清单 |
