# WorkBuddyForMe v3.0.0 版本总结

> 版本：3.0.0（2026-11-14）
> 主题：肥鱼计划——会记住你的桌面鲸鱼娘
> 范围：M0a/M0b/M0c → M1 → M3 → M4 → M5（M2 养成已取消）
> 真源：[release-notes.md](./release-notes.md)、[progress-log.md](./progress-log.md)

## 1. 这一版解决了什么

v2.x 的桌宠已经能站立、待机、被戳、说话，但表现是「一堆散装触发」：动作、台词、表情各走各的，新增一段互动就要同时改三处；主动说话只有冷却和预算，没有「为什么选这场」。v3.0 把陪伴拆成四层：

| 层 | 交付 | 作用 |
|---|---|---|
| 剧本 | Scene / Beat / Cue + `ScriptDirector` | 把一次互动写成受约束的时间线，动作与台词共用一条时钟 |
| 决策 | Utility 纯函数打分 + 理由码 | 在合法候选之间排序，设置页可回看选场理由 |
| 舞台 | `/stage?stage=play` 小剧场 + 分享卡 | 三席 VRM 按句轮播，分享卡导出 PNG |
| 资产 | 原创 VRM、表情目录、CC0 曲库 | 角色、表情与背景音乐可随安装包分发 |

## 4. 用户可见变化

- 桌宠空闲时会按预算主动开演一场生成剧情；设置页可看到最近 5 条决策得分与理由。
- `/stage?stage=play` 进入小剧场：三席 VRM、逐句语音、幕布/聚光灯、上一句/下一句/重播、暂停继续。
- 小剧场右上角可开分享卡，包含标题、日期、当前台词、席位、今日主动播放与生成数，桌面端保存 PNG。
- 设置页「音乐与背景声」管理 3 首主题曲 + 8 首氛围曲，支持导入本地歌曲；内置曲目全部 CC0 可分发。
- 桌宠窗支持显式 `?model=` 指定形象；主窗切换角色后桌宠会热替换，不重建窗口。

## 5. 已知限制

- 小剧场目前是 4 集内置剧本，尚未接入生成器队列；每集只有 6 句。
- 生成器的弱偏好 `moods/hours` 是可选输出，命中率仍需在真实数据上观察。
- 分享卡 PNG 仅桌面端支持，浏览器裸访会提示不支持。
- 关系等级门槛与低语池间打分仍待后续元数据接口。
- 32 位 Windows 未构建；安装包未签名，Smart App Control 环境需走官方 Electron 宿主降级路径。
