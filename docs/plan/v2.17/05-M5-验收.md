## 3. 本版偏差汇总

| 来源 | 偏差 | 处置 |
|---|---|---|
| M1/M2 | `failed` 仍由 HTTP 502/504 表达，成功响应才返回三态 | 保持既有错误层；设置页映射红色失败 |
| M3 | 搜索 provider 只实现 SearXNG + mock | API Key 型 provider 留 P1 |
| M3 | `web_search` 专用审计事件未接 | 查询正文不入审计；后续补 kind 或复用 run 级审计 |
| M4 | 目录不含 MCP 预置，`mcp-preset` 安装返回 422 | 后续版本接入 MCP 预置安装 |
| M4 | 未实现可选 `capability_list` | 检索结果已带 installed / status |
| M4 | 未新增 capability 专用审计 kind | 安装 / 拒绝复用审批审计链与 `HITL_REQUIRED` |
| M4 | 未新增浏览器端审批 e2e | mock 模型不产出 function call；由权限门 + 工具单测覆盖 |
| M4 | 审批框复用通用工具确认，不展示目录元数据 | 由 `capability_search` 在调用前说明；结构化审批载荷后续版本 |
| M5 | 未新增 opt-in 真 Key 冒烟 | 默认 CI 不跑真实 Key；nightly / 手动脚本留后续版本 |

## 4. 验收口径对照

1. ✅ 新增厂商只改描述文件；预设 id 与表单行为不变（M1 单测）。
2. ✅ 不提供 `GET /models` 的厂商可走「配置 → 添加模型 → 三态测试 → 对话」；三态不伪造成功（M2 单测 / 设置页用例）。
3. ✅ 未装能力包、配置搜索服务后可「搜索 → 读取 → 带来源回答」；未配置时明确提示（M3 单测）。
4. ✅ 搜索密钥不出本机；查询不入审计正文；结果按外部不可信数据处理（M3）。
5. ✅ 能力目录可检索、展示权限与来源；经审批后安装，未批准不落库；只读工具下一轮可用，write/danger 手动（M4 单测）。
6. ✅ 零迁移；`pnpm check` / 单测 / Web e2e 不降级；`/settings` First Load 增长 0.42%。
7. ⏳ 版本 2.17.0、安装包 + blockmap + latest.yml、Release 置 Latest：M6 执行，不在本轮。
