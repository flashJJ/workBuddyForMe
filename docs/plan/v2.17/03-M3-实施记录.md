## 2. 关键口径

- **默认关闭**：`provider: 'none'`，未配置时 `web_search` 返回可执行错误，不伪造结果。
- **SearXNG 优先**：P0 先实现无 Key 的自建 SearXNG；mock 仅用于测试 / 演示。
- **endpoint 校验**：公网要求 https + DNS 公网校验；自建 SearXNG 可显式允许私网（`allowPrivateEndpoint`）。
- **结果清洗**：只取 title/url/snippet/source/publishedAt；去 HTML、截断摘要；搜索结果按外部不可信数据处理。
- **引用**：`web_search` 把每条结果映射为 Citation（`sourceUrl` 指向原文），分享/导出沿用既有引用渲染。
- **零迁移**：搜索设置写入既有 settings JSON；不新增表 / 列。

## 3. 契约偏差

| # | 事项 | 说明 |
|---|---|---|
| 1 | P0 只实现 SearXNG + mock | Tavily / Brave / 博查等 API Key provider 需要先解决密钥加密存储，留到 P1；设置类型当前只接受 `none / searxng / mock` |
| 2 | 审计暂未接 `web_search` 专用事件 | 现有审计枚举没有通用工具事件；P0 先保证查询不落正文，后续在治理层补 `web_search` kind 或复用 run 级审计 |
| 3 | 搜索工具不自动抓正文 | 保持 `fetch_webpage` 独立，避免搜索结果页批量抓取导致超时与注入面扩大 |
