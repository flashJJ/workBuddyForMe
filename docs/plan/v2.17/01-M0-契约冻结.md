# v2.17 M0 契约冻结：可连通

> 里程碑：M0（方案见 [README](README.md)）
> 冻结时间：2026-11-02
> 范围：厂商描述、模型发现、连接测试三态、内置联网工具、能力目录与安装代理
> 结论：契约冻结，进入 M1；实现中若偏离本文件，必须在对应实施记录登记偏差

## 1. 冻结的决策

| # | 决策 | 说明 |
|---|---|---|
| D1 | 厂商描述数据放 shared，查询层放 ai | UI 与服务端共用同一份预设；`packages/ai/src/vendors/` 只做查询/匹配，不复制数据 |
| D2 | 发现策略按「/models → 厂商专用 → 推荐模型 → 手动」 | 全部失败才要求手填；错误语义区分 404/405、401/403、429、超时、空列表 |
| D3 | 连接测试返回三态，保留 `ok` 兼容字段 | `status: verified / reachable_unverified / failed`；`ok = status === 'verified'` |
| D4 | `web_search` 是内置工具，不是能力包 kind | 搜索后端可插拔；无 provider 时明确报错，不伪造结果 |
| D5 | 能力目录只覆盖内置精选包 + MCP 预置 | 不开放任意远程下载；安装必须 HITL 审批 |
| D6 | 安装后下一轮绑定，不做同轮热替换 | 只读工具自动追加；危险工具仍需显式勾选 |
| D7 | 零迁移 | settings JSON、`assistant.enabledTools` JSON、既有能力包表；`LATEST_SCHEMA_VERSION = 42` |
| D8 | 搜索查询不入审计正文 | 只记 provider、结果数、耗时、成功/失败与查询哈希/长度 |
| D9 | 协议扩展不在本版 | 仍只有 `openai-compatible` 与 `ollama`；Anthropic / Responses 留后续版本 |
| D10 | 连接测试 API 可以破坏性升级 | 本仓库唯一消费方是设置页；保留 `ok` 一个版本，新增 `status` / `checks` |

## 2. 厂商描述契约

`ProviderPreset` 扩展为厂商描述：

```ts
type VendorDiscovery = 'openai-models' | 'ollama-tags' | 'manual-only';
type VendorKeyScope = 'data' | 'plan' | 'coding';

interface ProviderPreset {
  id: string;
  name: string;
  baseUrl: string;
  keyUrl: string;
  models: Array<{ modelId: string; capabilities: ModelCapability[] }>;
  protocol?: ProviderProtocol;       // 默认 openai-compatible
  discovery?: VendorDiscovery;       // 默认 openai-models
  modelIdHint?: string;
  keyScope?: VendorKeyScope;
  notes?: string;
}
```

查询层（`packages/ai/src/vendors/registry.ts`）：

- `listVendors()`：返回全部描述；
- `getVendor(id)`：按 id 查找；
- `findVendorByBaseUrl(baseUrl)`：归一化尾部 `/` 后匹配，用于已保存供应商；
- `resolveDiscovery(vendor)`：返回发现策略，缺省 `openai-models`。

首批描述：

| id | discovery | keyScope | 说明 |
|---|---|---|---|
| deepseek / moonshot / dashscope / zhipu / siliconflow / openrouter / openai | openai-models | data | 现有预设保持不变 |
| volcengine-ark | openai-models（404 时回落首字探活） | data | 可填 Model ID 或 `ep-*` 接入点 |
| volcengine-agent-plan | manual-only | plan | `/api/plan/v3`，套餐专属 Key |
| volcengine-coding-plan | manual-only | coding | `/api/coding/v3`，新增预设 |

## 3. 模型发现与错误语义

优先级：

1. `GET /models`（`openai-models`）；
2. 厂商专用接口（Ollama `/api/tags`，`ollama-tags`）；
3. 描述文件的推荐模型；
4. 手动填写。

| 情况 | 内部语义 | UI |
|---|---|---|
| 404 / 405 | `models_unsupported` | 提示手填 Model ID；不显示「鉴权失败」 |
| 401 / 403 | `auth_failed` | 检查 Key / 套餐作用域 |
| 429 | `rate_limited` | 稍后重试，不自动狂重试 |
| 超时 / 网络 | `unreachable` | 检查 Base URL / 网络 |
| 空列表 | `empty` | 手填或使用推荐模型 |

M1 只要求把 `models_unsupported` 与 discovery 策略接通；其余错误语义沿用现有 `ProviderError`，M2 再细分文案。

## 4. 连接测试三态

返回结构：

```ts
type ProviderConnectionStatus = 'verified' | 'reachable_unverified' | 'failed';

interface ProviderConnectionResult {
  ok: boolean;                 // 兼容字段：status === 'verified'
  status: ProviderConnectionStatus;
  checks: Array<{
    step: 'models' | 'chat-probe' | 'protocol';
    ok: boolean;
    message?: string;
  }>;
  modelId?: string;
}
```

判定：

- `verified`：`/models` 成功，或首字探活成功；
- `reachable_unverified`：厂商标记 manual-only 且暂无对话模型；或模型列表可达但没有可验证的对话模型；
- `failed`：鉴权、网络、协议或首字探活明确失败。

约束：不伪造成功；无模型时提示先添加模型；首字探活只使用已配置的对话模型。

## 5. 内置联网工具契约

`web_search`：

| 项 | 约定 |
|---|---|
| 权限 | `read` |
| 参数 | `query` 1–200 字；`maxResults` 1–8（默认 5）；`freshness` / `site` / `locale` 可选 |
| 返回 | `{ results: [{ title, url, snippet, source, publishedAt? }], provider }` |
| 正文 | 由 `fetch_webpage` 按需读取 |
| 超时 | 10s |
| 错误 | `not_configured / auth_failed / rate_limited / unreachable / empty` |
| 审计 | provider、结果数、耗时、成功/失败；不落查询正文 |

搜索设置（settings JSON）：

```ts
interface SearchSettings {
  provider: 'tavily' | 'brave' | 'exa' | 'serpapi' | 'bocha' | 'searxng' | 'none';
  apiKey?: string;        // 走既有 cipher
  endpoint?: string;      // SearXNG / 自建
  maxResults: number;     // 1–8，默认 5
  timeoutMs: number;      // 默认 10000
  allowPrivateEndpoint: boolean; // 仅 SearXNG 自建时允许
}
```

P0 首批适配器至少实现一个真实 provider + 一个 mock provider（测试用）；其余 provider 可后续补齐，但接口与设置项先冻结。

## 6. 能力目录与安装代理契约

```ts
interface CapabilityCatalogEntry {
  id: string;
  name: string;
  kind: CapabilityKind;
  description: string;
  tags: string[];
  permissions: CapabilityPermission[];
  effects: string[];
  source: 'bundled' | 'mcp-preset';
  version: string;
  toolNames: string[];
  installStrategy: 'bundled-pack' | 'mcp-preset';
}
```

工具：

- `capability_search(query, kind?)`：`read`，返回候选；
- `capability_install(catalogId, reason?)`：`write`，必须 HITL；
- 可选 `capability_list()`：`read`。

安装后：

- 只读工具追加到 `assistant.enabledTools`；
- `write` / `danger` 工具不自动追加；
- 返回「已安装，下一轮可用」；
- 失败按能力服务 fail-closed 回滚，不改白名单。

## 7. 安全与隐私

- 搜索密钥不出本机；掩码展示；不共享 Key；
- 搜索查询不入审计正文；结果去 HTML、限长、按外部不可信数据标注；
- `fetch_webpage` 复用 SSRF 防护；搜索 endpoint 只允许 https，私网默认拒绝；
- 能力安装只允许内置 / 可信签名来源；无人值守与定时 Agent 拒绝安装；
- 安装、搜索、拒绝都写审计。
