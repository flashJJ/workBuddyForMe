## 2. 关键口径

1. **厂商描述数据仍在 shared**：设置页 onboarding 与服务端共用同一份 `PROVIDER_PRESETS`；`packages/ai/src/vendors` 只做查询，不复制数据。
2. **Ark 数据面仍尝试 `/models`**：部分账号可用，404 时回落首字探活；只有 Agent Plan / Coding Plan 标为 `manual-only`。
3. **manual-only 无对话模型**：返回 `ok:false / reachable_unverified`，不请求网络、不伪造成功；提示先添加模型。
4. **未知厂商 404**：有对话模型时首字探活；无模型时返回 `reachable_unverified`。
5. **三态兼容**：成功响应保留 `ok`（`status === 'verified'`），设置页据此展示；现有调用方不需要立刻改。

## 3. 契约偏差

| # | 事项 | 说明 |
|---|---|---|
| 1 | `failed` 仍由既有 HTTP 错误层表达 | 服务端成功响应只返回 `verified / reachable_unverified`；失败继续走 502/504，设置页映射为红色「连接失败」。不把错误改成 200，避免破坏既有错误处理与测试 |
| 2 | P0 搜索后端先实现 SearXNG 与 mock | API Key 型（Tavily / Brave 等）需要先解决密钥存储，留到 P1；契约字段仍可扩展 |
