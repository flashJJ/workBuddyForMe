## 0. 范围决策

v4.18 交付了稳、找得到、可评测三条线，但主动顺延了五项；v4.17 还有两项小遗留。v4.19 不启动新主线，只把这些遗留补完。

| 归属 | 方案 | 来源 |
|---|---|---|
| **v4.19** | 会话级备用模型覆盖 + 备用模型链 | v4.18 顺延 |
| **v4.19** | 供应商健康度与失败统计面板 | v4.18 顺延 |
| **v4.19** | 回放历史趋势与报告对比 | v4.18 顺延 |
| **v4.19** | 知识结果动作扩展（复制引用） | v4.18 顺延 |
| **v4.19** | 桌宠主窗入口 + 窄窗三尺寸复核 | v4.17 遗留 |
| 后续 | 首答与长会话体感（B） | v4.19 候选 |
| 后续 | 统一记忆治理（D） | v4.19 候选 |
| 后续 | 全量 Controller Pipeline（F）、并行/DAG（G）、视觉巡检 L2/L3（H） | v4.19 候选 |

不把 B/D/F/G/H 塞进本版的原因：

1. B 需要真机性能采样与窄窗复核配套，单独成版更稳；
2. D/F/G 都会改核心编排或记忆模型，属于结构性改动，不适合与「补完」混在一起；
3. H 依赖外部视觉工具链，属于测试基础设施版本。

## 1. 判断基线

v4.18 上线后，A/C/E 三条线都已闭环，但留下五处「能用但不完整」：

- 备用模型只有助手级一个，临时需要换模型的会话无法覆盖；
- 备用模型只能配一个，多模型降级需要手动改配置；
- 失败与切换有事件，但没有汇总视图，排查仍靠翻时间线；
- 回放报告只有单次结果，没有历史对比；
- 知识检索结果只能打开知识库，不能复制引用。

另外 v4.17 的桌宠主窗入口与窄窗复核一直未做，属于「用户看得见但没入口」的收尾项。

## 2. 目标（可验收）

1. 会话可以覆盖助手级备用模型；未覆盖时行为与 v4.18 完全一致；
2. 助手可配置最多 3 个备用模型，按顺序切换，单轮最多 2 次；
3. 供应商健康面板能看到最近 7 天的失败次数、切换次数与最近失败时间；
4. 回放命令能对比最近一次报告，并输出每项指标的相对变化；
5. 知识检索结果可复制引用（标题 + 深链），复制内容不含正文；
6. 桌宠可从主窗一次点击打开；窄窗 1024/1280/1440 无遮挡与横向溢出。

## 3. 非目标

- 不做跨供应商负载均衡、自动购买额度；
- 不做回放 UI 面板与长期指标仓库，只做本机历史文件与 CLI 对比；
- 不做记忆治理、Controller Pipeline、DAG 并行、视觉巡检 L2/L3；
- 不改数据库 schema、不新增运行时依赖；
- 不重做视觉风格，只修遮挡与溢出。

## 4. 风险与回退

| 风险 | 影响 | 缓解 |
|---|---|---|
| 备用模型链配置复杂 | 用户不理解切换顺序 | 最多 3 个、UI 明示顺序、切换事件带 attempt |
| 会话覆盖与助手配置冲突 | 行为难解释 | 覆盖只作用于当前会话，设置处显示来源 |
| 健康面板统计口径偏差 | 误导排查 | 只统计本机事件、标注 7 天窗口与代理口径 |
| 回放历史文件膨胀 | 占磁盘 | 只保留最近 20 份，超出自动清理 |
| 窄窗修复引发桌面端回归 | 布局抖动 | 只改断点样式，补三尺寸截图对比 |
