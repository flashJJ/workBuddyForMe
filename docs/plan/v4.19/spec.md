## 1. 背景

v4.18 交付了三条质量线，并把五项非阻塞能力主动顺延；v4.17 还有两项小遗留。v4.19 不启动新主线，只把这些遗留补完，避免「永远排在下一版」。

## 2. 备用模型补完

### 2.1 会话级覆盖

- 会话可单独指定备用模型，作用于该会话的所有轮次；
- 未设置时跟随助手配置，行为与 v4.18 完全一致；
- 覆盖值为 `null` 表示显式清除，回到助手配置；
- 覆盖仅影响备用路径，不改变主模型；
- 设置位置在会话设置内，并显示当前来源（会话覆盖 / 助手配置 / 未配置）。

### 2.2 备用模型链

- 助手可配置最多 3 个备用模型，顺序即切换顺序；
- 第一个备用仍然写回旧的单值键，保证旧客户端与旧数据可读；
- 链中不得包含主模型，重复项自动去重；
- 单轮最多切换 2 次，已尝试过的模型不重复尝试；
- 链为空时回落到旧的单值备用模型。

### 2.3 可见性

- 切换事件与提示沿用 v4.18：`model_switched` 四字段 + 消息流一行提示；
- 健康面板的切换次数以事件为准，不新增统计存储。

## 3. 供应商健康度

- 数据源：本机会话事件的 `model_switched` 与 `message_error`；
- 窗口：最近 7 天；
- 聚合维度：供应商；
- 指标：失败次数（按错误码）、切换次数、最近失败时间；
- `message_error` 事件补充目标模型 id，用于归属供应商；不记录正文；
- 面板只读，位于设置页「Agent / 供应商」相关分组，不新增侧栏入口；
- 模型或供应商已删除时，历史事件归入「未知」分组，不丢弃。

## 4. 回放历史与对比

- `eval:replay` 每次成功生成报告后，额外写入 `test-results/eval-replay/history/`；
- 历史最多保留 20 份，超出按时间删除最旧；
- `--compare=last` 读取最近一份历史报告，与本次结果对比五项指标；
- 对比输出写入 Markdown 报告新增小节，并打印到控制台；
- 对比不改变原有阈值门禁；历史文件与报告遵循同一隐私约束。

## 5. 知识结果动作

- 知识检索结果新增「复制引用」动作；
- 复制内容为文档标题 + 站内深链，不含正文；
- 现有「打开知识库」动作保留；
- 「继续任务」「打开审批」没有稳定关联数据，本版不做。

## 6. 桌宠主窗入口与窄窗

- 主窗提供一次点击打开桌宠的入口，放在侧栏底部工具区，桌面端可见；
- 窄窗复核三档：1024 / 1280 / 1440；
- 修复范围仅限横向溢出、遮挡与不可点击，不调整视觉风格；
- 复核记录写入 version summary，截图不入库。

## 7. 质量约束

- `pnpm check` 与 `pnpm verify:local` 全绿；
- 单测覆盖：链解析顺序、会话覆盖优先级、健康度聚合、回放对比、复制内容；
- E2E 覆盖：会话覆盖生效、知识结果复制；
- 零数据库迁移、零新增运行时依赖；
- 单文件 ≤300 行、目录直接文件 ≤12。

## 9. 验收标准

1. 会话覆盖后，错误态「换备用模型」使用覆盖值；清除后回到助手链；
2. 链顺序切换，单轮最多 2 次，不重复尝试；
3. 健康面板数字可由事件复算；
4. `--compare=last` 输出的差异与两份报告一致；
5. 复制内容不含正文与密钥；
6. 三档窄窗无遮挡与横向滚动条；
7. 零迁移、i18n 中英双档、门禁全绿。
