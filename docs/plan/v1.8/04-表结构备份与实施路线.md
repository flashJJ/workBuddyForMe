# v1.8 M0-4 · 表结构、备份与实施路线（冻结稿）

## 1. v026 迁移：角色卡库（纯加法，IF NOT EXISTS/列存在性守卫，重复执行幂等）

对齐 v024/v025 既有风格；迁移文件 `packages/database/src/migrations/v026-character-cards.ts` + 版本链断言测试（19 个老迁移测试统一更新到 26）。

```sql
CREATE TABLE IF NOT EXISTS character_cards (
  id               TEXT PRIMARY KEY,
  -- builtin=内置只读卡；custom=用户自建/导入
  source           TEXT NOT NULL CHECK (source IN ('builtin','custom')),
  name             TEXT NOT NULL,
  description      TEXT NOT NULL DEFAULT '',
  -- 原始 Markdown（回显/导出/再编辑真源）
  raw_markdown     TEXT NOT NULL,
  -- 解析结果 JSON（M2 落库时为 ParsedCharacterCard；冗余存储避免每轮重新解析）
  parsed_json      TEXT NOT NULL,
  default_emotion  TEXT NOT NULL DEFAULT 'neutral',
  voice            TEXT,
  -- 内置卡固定 id（capable-colleague 等），自建卡 newId()
  created_at       TEXT NOT NULL,
  updated_at       TEXT NOT NULL
);

-- 来源列表（卡库 UI 按 source 过滤）
CREATE INDEX IF NOT EXISTS idx_cards_source ON character_cards(source);
```

```sql
-- assistants 加列：当前选用的卡；NULL=使用默认卡（内置第一张/系统默认组装）
ALTER TABLE assistants ADD COLUMN card_id TEXT;
-- 不加外键约束：删卡时应用层把引用置空（避免卡表维护/内置卡升级换 id 时迁移复杂化），
-- 与「删卡不级联删助手」语义一致。
```

迁移幂等守卫与 v024 人格四列同模式（`PRAGMA table_info(assistants)` 先查后加）。

### 1.1 内置卡播种（M2）

种子逻辑（ensureSeedData 同批，幂等 upsert，固定 id）：
- `capable-colleague` 干练同事 / `cheerful-buddy` 元气搭子 / `calm-advisor` 沉稳顾问；
- raw_markdown 放 shared 常量（`character-card/built-in-cards.ts`），播种时解析一次写 parsed_json；
- 内置卡 source=builtin，UI 禁删禁改原文，支持「复制为自建卡」。

### 1.2 旧助手迁移（M2 应用启动期一次性，非 SQL 迁移）

遍历 assistants：
1. `card_id IS NULL` 且 `system_prompt` 非空 → 创建 custom 卡「我的自定义人格」（identity=原文，其余默认），回写 card_id；
2. system_prompt 为空 → 不建卡，card_id 保持 NULL（默认卡）；
3. 迁移在仓储初始化的 ensureSeed 阶段做，带「已迁移」守卫（settings_kv 记 `characterCardsMigrationDone=1`，防重复生成卡）。

## 3. 备份：schema v3 → v4（events 轨扩展）

角色卡属于「角色与人设」，并入既有 **events 轨**（UI 勾选文案「角色与提醒」不变，副文案补「角色卡」）：

- events 轨新增负载文件 `characterCards.json`（全量卡行；助手→card_id 关联已随助手机行导出，恢复后自动对上）；
- `CURRENT_BACKUP_SCHEMA_VERSION` 3→4；manifest.tracks.events 追加可选 `cardCount`（v3 归档无此键/无此文件，恢复按 0 处理，向前兼容链沿用 v1/v2 适配器模式）；
- 恢复：INSERT OR IGNORE 幂等；内置卡固定 id 冲突时跳过（以机内内置版本为准）；助手机行恢复时 card_id 指向不存在卡的，恢复后由仓储解析回落 NULL（不阻断）；
- 导出/恢复 roundtrip 单测：全卡+引用助手场景、v3 旧档（无卡文件）恢复不报错、内置卡跳过三条。

settings 轨自动带上新键（全量 KV 导出，无额外改动）；precheck 计数加 `cards`。
