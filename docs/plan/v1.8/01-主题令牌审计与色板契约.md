# v1.8 M0-1 · 主题令牌审计与色板契约（冻结稿）

## 1. 现状审计（基于 apps/web/src/app/globals.css 实际清点）

当前主题机制：`<html>` 上 toggle `.dark` class；偏好 `light/dark/system` 持久化在 settings 表（真源）+ localStorage `wbfm-theme`（缓存），`themeInitScript` 水合前执行防 FOUC，system 态监听 matchMedia（`components/theme/theme-provider.tsx`）。Tailwind 消费 HSL 三元组变量（`hsl(var(--token))`）。

`:root` 与 `.dark` 各 **31** 个自定义属性，按用途分五组：

| 组 | token | 数量 | 说明 |
|---|---|---|---|
| 表面与正文 | background/foreground、card(+foreground)、popover(+foreground) | 6 | 页面/卡片/浮层底与字 |
| 交互色 | primary(+foreground)、secondary(+foreground)、muted(+foreground)、accent(+foreground)、destructive(+foreground) | 10 | 主按钮、次级、弱底、悬停、危险 |
| 结构 | border、input、ring、radius | 4 | 描边/输入框/焦点环/圆角（radius 非色彩） |
| 语义状态 | success/warning/info 各自带 `-bg` | 6 | Badge/状态文案（前景色过 4.5:1，bg 为 95% 浅底/深底） |
| 代码块 | code-bg/border/text/comment/keyword/string/number/function/builtin | 9 | rehype-highlight token 色 |

另有非 token 的硬编码需在 M1 收口：`.event-fx-heart/sweat/spark`（v1.7 特效色，heart `350 85% 65%`、sweat `205 80% 60%`、spark 用 primary）——M1 改为引用 primary/语义变量，保证主题切换时特效不违和。

**审计结论**：现有组件 100% 经语义 token 取色（无业务组件硬编码 hex/HSL，除 fx 特效外），故 v1.8 只需要「同一套 token 名 × 多组取值」，不改任何组件类名。这是本次改造回归面可控的根本原因。

## 2. 命名模型：主题与明暗正交

- 主题选择器（4 个命名主题）与既有 light/dark/system 三态的关系：**命名主题自带明暗归属**，选命名主题即确定该套色板（不再叠加 dark class 翻转）；`system` 保留原语义（无命名主题时跟随系统，在星际蓝亮/暗两套间切）。
- DOM 契约：`<html data-theme="<id>">`，亮主题不加 `.dark`，暗主题由主题注册表在应用时同步加 `.dark`（兼容既有只认 `.dark` 的第三方/历史样式）。
- settings 新键：`themeId`（默认 `stellar`；`system` 时 `themeId=null` 或 `'system'`，二者映射在注册表层收口，M1 定）。
- 防 FOUC 内联脚本扩为同时读 `wbfm-theme-id`；水合后以 settings 为真源校正（沿用 v1.2 机制）。

## 3. 四套色板（HSL 三元组，M0 冻结）

> 取值均为本文件冻结值；M1 原样落入 globals.css 的 `:root[data-theme='…']`（暗色主题再附 `.dark` 兼容选择器）。代码块 9 色 M1 按各主题基调微调，约束为 comment 对比度 ≥3:1、正文 code-text ≥4.5:1。

### 3.5 主色档（G2 有限档，首期随 M1 定 6 档）

不开放任意取色。预设档只替换 `--primary/--primary-foreground/--ring` 三个 token，每档在该主题底色上按钮字对比度必须 ≥4.5:1（M1 用同一脚本出表入档）：星际蓝（默认）/ 靛紫 / 翡翠绿 / 琥珀 / 石墨 / 玫瑰。语义色（success/warning/destructive）不随主色档变。

## 4. 验收（M1 出口）

1. 四主题 + system 五态切换，刷新无 FOUC、无结构抖动（只换 CSS 变量值）。
2. 对比度计算脚本进 `scripts/theme-contrast.mjs`（M0 计算稿转永久脚本），M1 补齐四套完整 token 后对全部「文字类 token on 其底色」配对算一遍，结果写入本文件附录，正文类不得低于 4.5:1。
3. axe 扫设置/对话/助手三页（每主题各一次）serious/critical = 0。
4. 现有 e2e 全绿（主题不改变 testid/结构）；新增主题切换 e2e（切主题→重载持久化→html[data-theme] 断言）。
5. 事件 fx 硬编码色收口为变量引用。
