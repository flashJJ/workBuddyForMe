# v1.8「会打扮」· 实施总览（M0 冻结稿）

> 分支：`feature/v1.8-personalize` · 基线：main `a2da775`（v1.7 已发布）
> 上游路线：[../v1.6-v2.0/v1.8-皮肤角色卡与模型调优.md](../v1.6-v2.0/v1.8-皮肤角色卡与模型调优.md)
> 主题：把「人格、外观、生成参数」从开发常量变成**用户可配置、可切换、可分享**的组合。全部是纯数据配置，不碰任何模型/音频资产。

## 一句话价值主张

让同一个助手拥有可切换的**外观（命名主题）、人格（Markdown 角色卡）、手感（生成参数与音色收藏）**，且每一项改完立即生效、可预览、可恢复默认、可跨机器备份——旧助手零配置迁移后行为完全不变。

## 目标（机械可验证）

| 编号 | 目标 | 衡量方式 |
|---|---|---|
| G1 | 4 套命名主题（星际蓝/夜金/月白/樱粉） | 切换无刷新水合同步；关键色对全部 ≥4.5:1（M0 对比度报告为据）；axe 设置页 serious/critical = 0 |
| G2 | 明暗与命名主题正交 | 现有 light/dark/system 三态不破坏；每套主题声明明暗归属；system 解析正确 |
| G3 | Markdown 角色卡库 | frontmatter + 约定章节解析为结构化人格；内置 ≥3 张原创卡；自建/导入/导出/重置；旧 systemPrompt 自动包装一张卡，对话快照测试零变化 |
| G4 | 全局追加提示词 | 设置域一份，固定注入位置（卡之后），开关即时生效，多窗口 storage 事件同步 |
| G5 | 调优中心 | 每助手 temperature/topP/maxTokens 露出 + 上下文条数 2–50（服务端钳制）+ 情绪开关聚合 + 恢复默认 |
| G6 | 场景化模型矩阵 | 聊天/记忆/planner/executor/reviewer 绑定一页可见可改，未配置显式「跟随默认」 |
| G7 | 音色收藏 | 云 TTS voice id 命名收藏、按 provider+model 分组、一键写回当前音色 |

## Non-Goals（本版明确不做）

1. **不做主题商店/在线分发**：无账号体系；最多支持本地 `.wbfm-theme.json` 导入（排在 v2.0 mod 包，本版仅内置 4 套）。
2. **不做任意取色器/字体上传**：首期主色只给预设档；中文字体体积与对比度不可控。
3. **不做任何 Live2D 资产扩展**（换装贴图/挂件/外部动作/音色包捆绑模型）——Cubism 授权红线，角色卡永远是纯文本，分享 UI 明示禁止夹带模型资产。
4. **不做云端角色卡同步/社区**。
5. **角色卡不做模板转义/沙箱**：它就是用户写给模型的指令（prompt 数据），UI 明示「只导入你信任的卡」；导入不执行代码、不读字段外文件。
6. 不重写 v1.2 主题三态持久化机制（settings 真源 + localStorage 缓存 + 防 FOUC 内联脚本），只在其上扩 data-theme 维度。
