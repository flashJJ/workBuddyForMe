## M0 契约冻结

- [ ] M0.1 错误分类契约：七类错误码、可自动切换判定、事件字段（`fromModelId/toModelId/reason/attempt`）
- [ ] M0.2 检索结果契约：`{domain,id,title,snippet,timestamp,deepLink,action}`，五域枚举与单域上限
- [ ] M0.3 回放报告契约：指标字段、绝对下限、相对退化阈值、报告路径与隐私约束
- [x] M0.4 冻结四个待决策：助手级备用模型、自动切换默认开启、token 预算 80/100、检索与命令面板共存（见 spec §11）

## M1 稳：失败分类与备用模型

- [ ] M1.1 扩展 `packages/ai` 的错误分类：HTTP 状态、超时、断流、上下文超限映射到统一错误码
- [ ] M1.2 助手级 `fallbackModelId` 配置与校验（模型必须存在且具备 chat 能力）
- [ ] M1.3 首字前自动切换路由，最多 2 次；首字后不自动切换
- [ ] M1.4 会话级覆盖（P1）：仅在实现成本可控时纳入，否则顺延
- [ ] M1.5 单测：401/403、429、超时、5xx、上下文超限、首字前/后断流六类路径
- [ ] M1.6 单测：最多 2 次、切换顺序、无可切换模型时停止
