# v4.18 规格：稳、找得到、可评测

> 状态：已立项，M0–M5 已完成（契约、备用模型、预算、五域检索、快捷键发现、A/B 回放）（2026-11-22）
> 契约：[contracts.md](./contracts.md)
> 选题依据与备选对比：[README.md](./README.md)
> 任务清单：[tasks.md](./tasks.md)
> 上游：v4.17 已发布（`v4.17.0`）

## 1. 背景与目标

v4.17 完成了易用性收口，但三条关键路径仍缺少闭环：

1. **失败不可自动恢复**：供应商 401、429、超时或半途断流会中断整轮对话，只能手动换模型；
2. **内容不可跨域找到**：检索只覆盖会话消息，任务、流程、会议与知识文档仍各找各的；
3. **质量不可回归**：上下文策略与检索改动缺少离线 A/B 与保真指标，只能靠单测与人工体验。

v4.18 用一个版本同时交付三条线：

- **A 稳**：失败可分类、可降级、可解释，成本有护栏；
- **C 找得到**：跨域检索与结果行动入口；
- **E 可评测**：离线 A/B 回放与上下文保真报告，作为 A/C 的质量底座。

成功标准：可重试故障能自动恢复且用户看得见；五类内容能被一个入口检索并直达；A/C 的策略改动能用固定 golden 用例证明没有让上下文变差。

## 2. 范围与原则

- 三条线都必须可独立验收，不做半成品；
- 零数据库迁移，不引入新运行时依赖；
- 本地优先：检索、回放、报告全部留在本机，不上传内容与截图；
- 不改变默认单模型、单轮对话行为；所有降级必须显式可见；
- 复用已有能力：错误码、错误态动作、供应商测试连接、会话事件日志、`eval:context` 与 golden 夹具。

## 3. A 稳：模型故障恢复与成本护栏

### 3.1 失败分类

统一错误码，至少覆盖：

| 错误码 | 触发 | 可自动切换 |
|---|---|---|
| `auth_failed` | 401 / 403 | 否，提示检查密钥 |
| `rate_limited` | 429 | 是 |
| `timeout` | 连接或首字超时 | 是 |
| `stream_interrupted` | 已建立连接但中途断流 | 仅首字前 |
| `context_overflow` | 上下文超限 | 否，提示压缩或换大窗口模型 |
| `provider_5xx` | 供应商 5xx | 是 |
| `unknown` | 其他 | 否 |

映射入口集中在 AI 包的 provider error 层，UI 只消费统一错误码，不解析原始报文。

### 3.2 备用模型

- 仅助手级配置 `fallbackModelId`（D1 冻结）；会话级覆盖列为 P1，不阻塞首版；
- 自动切换默认开启（D2 冻结），但每次切换必须在消息流可见并写事件；
- 仅对可自动切换错误生效；
- **首字前**允许自动切换，最多 2 次；**首字后**不自动切换，避免重复输出，只给「换模型继续」动作；
- 切换顺序固定：当前模型 → 备用模型 → 停止并提示；
- 每次切换写事件：`fromModelId`、`toModelId`、`reason`、`attempt`，不记录正文。

### 3.3 可见性

- 消息流内显示一行系统提示：「当前模型不可用，已切换到 X」；
- 运行报告与事件时间线可查切换记录；
- 错误态保留「重试」「换备用模型」「保留输入」三个动作。

### 3.4 成本护栏

- 会话级 token 预算（D3 冻结），未设置上限时不生效；设置后默认 80% 提示、100% 拦截；
- 金额换算不做首版能力，避免依赖供应商计价表；
- 预算不新增数据库列：优先复用会话设置 JSON 与事件计数；若确实需要新列，降级为 P2 并单独评审。

### 3.5 验收

- mock 供应商可稳定模拟六类错误；
- 401/上下文超限不自动切换；429/超时/5xx 自动切换且可见；
- 首字后断流不自动切换；
- 最多 2 次后停止；
- 预算阈值与拦截可复现；
- 切换事件字段完整，但不含正文。

## 4. C 找得到：跨域检索与行动入口

### 4.1 检索范围

| 域 | 数据源 | 首版动作 |
|---|---|---|
| 会话 | 会话事件日志（`scope=chat`） | 打开会话并定位消息 |
| 任务 | `scope=task` | 打开任务详情 |
| 流程 | `scope=flow` | 打开运行详情 |
| 会议 | `scope=meeting` | 打开会议记录 |
| 知识 | 文档表（标题/来源/摘要） | 打开文档或所在知识库 |

不做向量化全文检索；知识库只做文档级匹配，避免引入新索引与 embedding 成本。

### 4.2 交互

- 全局检索与命令面板共存（D4 冻结）：命令面板内保留检索入口，页脚常驻快捷键提示；检索首屏聚焦输入框；
- 300ms 防抖、请求中止、按域分组、单域最多 10 条、总计最多 50 条；
- 结果项显示域、标题/片段、时间与来源；
- 键盘：上下选择、回车打开、`Ctrl+Enter` 在新面板打开；
- 空结果给出「换关键词 / 去掉过滤器 / 只搜当前域」；
- 界面明示「本机检索」。

### 4.3 知识文档检索

- 复用知识库列表与文档列表接口，增加 `q` 查询参数（标题、来源、摘要）；
- 按知识库并发查询，限制并发 4，单库最多 5 条；
- 不读取文档正文全文，不触发解析或编译。

### 4.4 快捷键与隐藏用法可发现

v4.17 只在首次启动弹一次 `Ctrl+K` toast，用户仍可能长期不知道有命令面板与快捷键浮层。本版把「怎么用」也当作可检索内容：

- 命令面板固定首组「快捷键与用法」：列出 `Ctrl+K`、`Ctrl+/` 等（真源 `KEYBOARD_SHORTCUTS`，缺失项补齐），回车打开现有快捷键浮层；
- 隐藏用法清单：消息检索、会话朗读、`@` 引用、`/` 命令、桌宠开关等，每条直达对应界面或设置页锚点；
- 常驻提示：侧栏底部或命令面板页脚显示「Ctrl+K 命令面板 · Ctrl+/ 快捷键」，可关闭且不再打扰；
- 不新增独立页面，复用快捷键浮层、帮助中心与命令面板；
- 验收：用户不读文档也能从任一主界面两次点击内打开快捷键清单。

### 4.5 验收

- 五类域各至少一条结果与正确深链；
- 无结果引导可点击；
- 键盘操作与鼠标一致；
- 检索不发送远端请求；
- 单域失败不影响其他域（错误隔离）。

## 5. E 可评测：离线 A/B 回放与上下文保真

### 5.1 回放入口

- 同一组 golden 用例分别用基线策略与候选策略执行；
- 复用 `eval-context` 的 mock server、golden 夹具与报告工具；
- 新增命令 `pnpm eval:replay`，输出 JSON 与 Markdown 报告到 `test-results/`。

### 5.2 指标

| 指标 | 说明 |
|---|---|
| 预算占用 | `promptTokens / usableWindow` 的分布 |
| 截断率 | `truncated=true` 的用例占比与丢弃条数 |
| 记忆保留 | golden 中的关键记忆是否仍在上下文中 |
| 引用保留 | 关键来源/文档片段是否仍被引用 |
| 约束保留 | 用户显式约束是否仍生效 |

### 5.3 门禁

- 绝对下限：记忆/引用/约束保留率不得低于基线设定值；
- 相对退化：任一指标相对基线下降超过阈值即失败；
- 报告确定性：同一输入两次运行结果一致；
- 报告不含绝对路径、正文或密钥；
- 首期接入 nightly 非阻断，稳定后转 PR 门禁。

### 5.4 验收

- 基线策略与候选策略能产生可解释差异；
- 修改策略导致退化时退出码非 0；
- 报告可在本机独立复算。

## 6. 架构影响

| 区域 | 影响 |
|---|---|
| `packages/ai` | 错误分类扩展、备用模型路由、重试策略 |
| `packages/shared` | 错误码、检索结果与回放报告 schema、i18n |
| `apps/web` | 聊天错误态与切换提示、全局检索 UI、知识文档查询参数 |
| `apps/desktop` | 无强制改动；仅在事件时间线展示切换记录时复用现有通道 |
| `scripts/eval` | 新增 A/B 回放入口与报告 |
| 数据库 | 零迁移；检索复用现有表，预算优先用设置 JSON |

## 7. 非目标

- 不做云同步、云索引、跨设备检索；
- 不做语义/向量全文检索；
- 不做跨供应商负载均衡、自动购买额度、云密钥托管；
- 不做全量 Controller Pipeline、并行/DAG、视觉巡检 L2/L3；
- 不做首答性能专项与窄窗视觉复核（留 v4.19）；
- 不改数据库 schema，不引入新运行时依赖。

## 8. 里程碑

| 阶段 | 内容 | 可独立验收 |
|---|---|---|
| M0 | 错误码、检索结果、回放报告三份契约冻结 | 是 |
| M1 | 失败分类与备用模型路由 | 是 |
| M2 | 切换可见性、预算护栏、错误态动作 | 是 |
| M3 | 四域全局检索与深链 | 是 |

| M5 | A/B 回放与保真报告，nightly 接入 | 是 |

## 9. 验收标准

1. `pnpm check` 与 `pnpm verify:local` 全绿；
2. A：六类错误 mock 矩阵通过；切换可见、最多 2 次、首字后不切换；
3. C：五域检索、深链、空结果、键盘与错误隔离通过；
4. E：A/B 报告可复算，退化超阈值时退出码非 0；
5. 零数据库迁移；i18n 中英双档；单文件 ≤300 行、目录直接文件 ≤12；
6. 新增 E2E 覆盖一条「429 → 自动切换 → 正常回答」与一条「跨域检索 → 打开结果」；
7. 命令面板内可看到快捷键入口；常驻提示可关闭且不重复打扰；隐藏用法清单可达对应功能。

## 10. 风险与回退

| 风险 | 影响 | 缓解 |
|---|---|---|
| 自动降级改变回答质量或费用 | 用户不信任 | 默认关闭或首次确认；切换可见；最多 2 次 |
| 首字后断流误判 | 重复输出 | 首字后不自动切换，只给动作 |
| 跨域检索结果噪音 | 找不到重点 | 按域分组、单域上限、过滤器与空结果引导 |
| 知识文档检索扩大范围 | 性能下降 | 只查标题/来源/摘要，限制并发与条数 |
| A/B 指标被当成用户满意度 | 错误决策 | 报告注明代理指标口径，只做相对比较 |
| 大版本范围膨胀 | 无法按时收口 | 三线独立里程碑；P2 可整体顺延到 v4.19 |

## 11. 决策冻结（2026-11-22）

| 编号 | 决策 | 结论 |
|---|---|---|
| D1 | 备用模型配置层级 | 仅助手级 `fallbackModelId`；会话级覆盖为 P1 |
| D2 | 自动切换默认值 | 默认开启，切换必须可见并写事件 |
| D3 | 预算口径与阈值 | 仅 token；未设上限不生效，设置后 80% 提示、100% 拦截 |
| D4 | 全局检索入口 | 与命令面板共存；命令面板内保留入口并显示快捷键 |

补充决策：新增「快捷键与隐藏用法可发现」到 C 线（见 §4.4），不单独设版本。
