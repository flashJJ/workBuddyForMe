# v4.18 版本总结：稳、找得到、可评测

> 版本：4.18.0（2026-11-22 发布，tag `v4.18.0`）
> 主题：故障可恢复、内容可跨域找到、策略可离线复算
> 迁移：无数据库迁移；备份格式不变；零新增运行时依赖
> 博客：[blog/v4.18](../../blog/v4.18/) 7 篇
> 发行说明：[v4.18.0-release-notes.md](../../roadmap/v4.18.0-release-notes.md)

## 1. 本版解决什么

v4.17 把关键路径补成了「用得顺」，但三条链路仍没有闭环：

1. **失败不可自动恢复**：限流、超时、首字前断流会中断整轮对话，只能手动换模型；
2. **内容不可跨域找到**：检索只覆盖会话消息，任务、流程、会议与知识文档仍各找各的；
3. **质量不可回归**：上下文策略与检索改动缺少离线 A/B 与保真指标，只能靠单测和人工体验。

本版用一个版本同时交付三条线：A 稳、C 找得到、E 可评测。E 不是附属功能，而是 A/C 后续改动的质量底座。

## 3. 关键设计

### 3.1 只切一次，且必须看得见

自动切换的三个边界：只对可自动切换错误生效、只在首字前、单轮最多 2 次。首字后断流不自动切换，避免同一回答被重复生成。

切换同时写两处：消息流一行提示，会话事件一条记录。事件固定四字段（`fromModelId / toModelId / reason / attempt`），不记录正文，既方便 UI 解释，也不扩大隐私面。

备用模型只做助手级，不做会话级覆盖。配置层级越少，行为越可解释；会话级覆盖留到有明确需求再加。

### 3.2 预算不新增列

token 预算存在既有设置 JSON：助手备用模型、会话预算都走 `settings_kv`。零迁移让升级可以覆盖安装，也避免为一个可选功能改主表。

未设置上限时不生效；设置后 80% 提示、100% 拦截。金额换算不做，避免绑定供应商计价表。

### 3.3 检索复用本机事件日志

事件四域复用 `/api/search` 与会话事件日志，知识域复用文档列表接口的 `q` 参数；不建新索引、不做 embedding。

三个实现细节决定体验：300ms 防抖与请求中止、按域分组与单域上限、单域失败隔离。知识库按并发 4、单库 5 条查询，单库失败静默跳过，不让一个坏库拖垮整个弹层。

深链是检索的最后一公里：会话定位到具体消息，任务/流程/会议定位到运行记录，知识定位到知识库。结果不可行动，检索就只是列表。

### 3.4 快捷键不能只存在于文档

v4.17 只在首启弹一次提示，用户仍可能长期不知道命令面板存在。本版把「怎么用」当成可检索内容：

- 命令面板固定首组列出快捷键与隐藏用法，回车直达；
- 侧栏常驻提示可关闭且记住；
- 快捷键真源补齐全局检索组合键，浮层与实际注册同源。

### 3.5 回放只认相对差异

五项指标都是代理指标：预算占用、截断率、记忆/引用/约束保留。报告明确注明「只做相对比较，不代表用户满意度」。

门禁分三层：绝对下限（保留率）、相对退化（对基线）、预算硬上限。策略参数只切上下文预算，不切模型行为，保证差异可解释。

报告固定落本机 `test-results/`，不含绝对路径、正文与密钥；同一输入两次运行除时间戳外完全一致。

## 4. 数据与验证

- `pnpm check`：typecheck、lint、行数、目录、循环依赖、MSW、ASCII、资产、surface、E2E 隔离全部通过；
- 单元测试：826 个文件、4614 条用例通过；
- API 集成测试：11 条通过；
- 回放报告单测：5 条通过；
- 定向 E2E（生产模式）：429 自动切换、跨域检索打开结果 2/2 通过；
- `pnpm eval:replay`：默认策略 PASS；`degraded-2k` 按预期 FAIL，退出码 1；
- 数据：零迁移，覆盖安装即可。

## 5. 已知限制

- 自动切换只支持一个助手级备用模型，不做模型链；会话级覆盖顺延；
- 知识检索只匹配文档标题/来源/摘要，不做正文全文与向量检索；
- 回放指标是代理指标，不能替代真实用户反馈；历史趋势与报告对比顺延；
- 窄窗三尺寸与首答性能专项未在本版处理，留 v4.19；
- `eval:replay` 首次运行会在数据目录创建固定评测知识库与助手，需要时手动清理。

## 6. 下一步

2. 评估会话级备用模型覆盖与备用模型链，先有真实多模型需求再扩；
3. 把回放报告接入趋势对比，稳定后由 nightly 非阻断转为 PR 门禁；
4. 继续把「快捷键与用法」的发现路径复用到设置页与空态。
