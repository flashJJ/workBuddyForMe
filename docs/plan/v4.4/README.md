# v4.4 方案：背景与壁纸——内置背景、本地图片/视频与 `wallpaper-pack`

> 主题：把舞台、主窗口与桌宠窗的背景变成可配置、可分发的一等能力。
> 分支：`feat/v4.4-background-and-wallpaper`
> 口径：复用现有能力包管道；背景只做展示资源，不执行代码；桌面端支持本地文件，Web 只用内置背景。
> 来源：[候选 12 背景与壁纸](../../roadmap/scheduled/v4.4-12-background-wallpaper-video.md)。
> 状态：🚧 开发中。

## 1. 背景

v4.3 收口了内容包与资产预算，但“环境氛围”仍是最弱的一环：舞台只有剧集内置的 `TheaterBackdrop` 变体，聊天主界面与主窗口整屏没有背景层，桌宠窗固定透明，用户自有的图片与循环视频没有入口。与此同时，三席角色的循环视频已经具备，缺的是配置模型与分发通道。

v4.4 做三件事：

1. 统一的背景源模型（内置 / 图片 / 视频 / `wallpaper-pack`）；
2. 三处独立配置：舞台与小剧场、主窗口（聊天与整屏互斥）、桌宠窗；
3. 本地文件与能力包两条引入通道，桌面端优先，Web 只读内置。

### 2.2 不做（本版）

- 在线壁纸市场与远程下载；
- 视频音频轨播放（背景视频一律静音）；
- Web 模式自定义上传；
- 动态壁纸的交互（点击/滚动响应）；
- 非 MP4/H.264 视频编码转码流水线。

## 3. 关键设计

### 3.1 背景源是数据，不是组件

```ts
type BackgroundSource =
  | { kind: 'builtin'; id: string }
  | { kind: 'image'; id: string }   // userData 或包内资源
  | { kind: 'video'; id: string };  // MP4/H.264，静音循环
```

设置按 `scope` 分开存：

```ts
interface BackgroundSettings {
  scope: 'main' | 'stage' | 'pet';
  source: BackgroundSource;
  fit: 'cover' | 'contain';
  dim: number;    // 0–1 压暗
  blur: number;   // 0–20px
}
```

主窗口额外有 `mode: 'chat' | 'window'`，两者互斥，共用同一份背景源；桌宠窗独立，默认 `builtin:none`（保持透明）。

### 3.2 内置素材与预算

- 内置视频 1 个：雨夜小客厅循环，720p、H.264、6.42MB；
- 内置图集 28 张：用户生成场景图，统一压到 1920px WebP，合计 5.06MB；
- 内置渐变 2 套：黄昏/清晨，不占体积；
- 安装包预算保持 300MB（4.3.0 为 264.84MB），`check:assets` 增加媒体预算项；
- 内置素材必须自建或 CC0，许可证随资源入库；图集为用户自用素材。

### 3.3 本地文件只走桌面端

- 选择：主进程 `dialog.showOpenDialog`，仅 `png/jpg/jpeg/webp/mp4`；
- 复制：写入 `userData/backgrounds/<uuid>.<ext>`，记录 `id` 而非绝对路径；
- 上限：图片 ≤20MB、视频 ≤50MB；超限拒绝并提示；
- 读取：受控路由或自定义协议，禁止任意路径穿越；
- 缺失：启动时校验，缺失则回退 `builtin:default` 并提示；
- Web：不提供上传入口，设置页显示“仅桌面端可用”。

### 3.4 `wallpaper-pack` 复用能力包管道

- manifest `kind: 'wallpaper-pack'`，`entry: 'payload/wallpaper-pack.json'`；
- payload 内 `backgrounds: [{ id, kind: image|video, file, license }]`，id 强制 `wallpaper.` 或 `pack.` 前缀；
- 单文件 ≤50MB、整包 ≤200MB；只接受 CC0-1.0 / CC-BY-4.0；
- 启用后进入背景源聚合，停用后下一次读取生效；不做热替换；
- 与 `scene-pack` / `prop-pack` 共用签名、校验和、升级与回滚。

### 3.5 渲染与性能

- 背景层永远在最底层，角色画布与 UI 不变；
- 视频：`muted`、`loop`、`playsInline`，窗口隐藏或最小化时 `pause()`；
- 省电档与 `prefers-reduced-motion` 下回落到首帧静态图；
- 主窗口“聊天”模式按内容宽度留白，“整屏”模式全幅 `cover`；
- 桌宠窗开启背景后为不透明矩形，点击穿透与命中区逻辑不变。

## 4. 验收口径

1. 舞台、聊天、整屏、桌宠四处可独立选择背景，重启后保持；聊天与整屏互斥。
2. 内置视频循环播放无可见卡顿；窗口隐藏时暂停；减少动态效果时回落静帧。
3. 本地图片/视频选择、复制、重启、删除后的回退全部符合预期。
4. `wallpaper-pack` 可安装、启用、停用、卸载；停用后背景回退。
5. 路径穿越、超限文件、非法格式均被拒绝并有提示。
6. 安装包 ≤300MB，`pnpm check` 全绿，零数据库迁移。

## 5. 风险

| 风险 | 对策 |
|---|---|
| 视频解码与多角色渲染抢资源 | 720p/8Mbps 上限、不可见暂停、省电档静帧 |
| 透明桌宠被背景破坏 | 独立配置、默认透明、开启时明确提示 |
| 本地路径失效 | 复制到 userData、存 id、启动校验与回退 |
| 包内大视频拖慢启用 | 单文件 50MB、整包 200MB，启用前校验并提示 |
| 内置素材许可不清 | 只收自建/CC0，许可证入库 |
| 主窗口与舞台配置串味 | `scope` 分离 + 互斥模式共用一份主窗口配置 |
