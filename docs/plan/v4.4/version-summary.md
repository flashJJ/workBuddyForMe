# v4.4 版本总结：背景与壁纸

> 版本：4.4.0（2026-11-17）
> 主题：三处独立背景、三源引入与视频/壁纸素材收口
> 分支：`feat/v4.4-background-and-wallpaper`
> 迁移：零数据库迁移，`LATEST_SCHEMA_VERSION` 不变

## 1. 本版解决什么

v4.3 收口了内容包与资产预算，但“环境氛围”仍是最弱的一环：舞台只有剧集内置的 `TheaterBackdrop` 变体，聊天主界面与主窗口整屏没有背景层，桌宠窗固定透明，用户自有的图片与循环视频没有入口。

v4.4 把背景变成一等能力：

1. **统一模型**：`builtin / image / video` 三种来源、`main / stage / pet` 三作用域，只存 `kind + id`，不存绝对路径；
2. **三条通道**：内置素材、桌面端本地文件（复制到 `userData/backgrounds`）、`wallpaper-pack` 能力包；
3. **三处渲染**：舞台/小剧场、主窗口（聊天与整屏互斥）、桌宠窗独立配置，视频静音循环并在不可见时暂停；
4. **素材收口**：内置图集 28 张、主窗视频 3 个、桌宠 9:16 背景 5 个，全部压缩后入库。

## 3. 关键设计

### 3.1 背景是数据，不执行代码

三种来源统一收敛为 `BackgroundSource`，由解析纯函数按“内置 → 本地文件 → 包内资源”顺序定位，缺失时主窗口/舞台回退雨夜内置视频，桌宠回退透明。渲染层只消费解析结果，不关心来源类型。

### 3.2 三作用域隔离，主窗口模式互斥

`main / stage / pet` 各自保存 `source / fit / dim / blur`；主窗口额外有 `mode: chat | window`，聊天模式只铺内容区、整屏模式铺满窗口，两者共用同一份背景源，不会出现两套配置串味。

### 3.3 本地文件只走桌面端

主进程打开文件选择，复制到 `<dataRoot>/backgrounds/<uuid>.<ext>`，按内容嗅探类型而非扩展名；图片 ≤20MB、视频 ≤50MB。Web 读取走 `GET /api/backgrounds/[id]`，只接受 uuid + 白名单扩展名，缺失返回 404 由渲染层回退。

### 3.4 `wallpaper-pack` 复用能力包管道

只做声明式内容：payload 1–10 项、`wallpaper.` 前缀、许可白名单 CC0/CC-BY、单文件 50MB / 整包 200MB。启用后按已启用能力行聚合，版本为 `wallpapers:<sha256>` 快照；停用后下一次读取生效，不热替换正在播放的视频。

### 3.5 桌宠 9:16 与木相框

桌宠窗由 260×400 改为 270×480（9:16），便于生成同比例背景图/视频；有背景时渲染纯 CSS 木纹圆角相框（外 22px / 内 15px / 框宽 7px），背景层同步内缩裁圆角，层级在角色画布之上、字幕与右键菜单之下，不影响点击穿透。

## 4. 数据与验证

- 全量测试：9 包 745 文件 4219 项通过（web 285/1445、core 272/1664、database 75/283、shared 48/413、desktop 35/227、ai 16/86、voice 9/85、config 4/14、motion 1/2）。
- `pnpm check`：typecheck、lint、行数、结构、循环依赖、ASCII、资产全部通过。
- 素材体积：
  - 图集 28 张：75.7MB → 5.06MB（1920px WebP q80，约 93% 降幅）；
  - 主窗循环视频 3 个：16.21MB → 1.52MB（30fps、H.264 CRF23、去音轨）；
  - 桌宠背景：2 个视频 5.8MB → 0.58MB，3 张图 4.06MB → 121KB。
- 安装包：`WorkBuddyForMe-Setup-4.4.0.exe` 272.37MB（285,598,054 字节），预算 300MB 内；较 v4.3.0 增加 7.53MB。
- 数据库：零迁移；备份 schema 不变。

## 5. 已知限制

- 本地背景文件仅桌面端可用，Web 模式只读内置素材；
- 背景视频一律静音，不支持音轨；只接受 MP4/H.264，不做转码；
- 包内背景不做热替换，安装/停用后下一次读取生效；
- 暂无在线壁纸市场与远程下载；
- `check:assets` 尚未接入背景媒体预算表（`background-budget.json` 待补）。

## 6. 下一步

真机验证通过后，v4.4.0 合并 main、打 tag 并推送工蜂；后续版本再评估在线壁纸目录、动态壁纸交互与媒体预算门禁。
