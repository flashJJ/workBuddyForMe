## 2. 关键语义

- 工作流包启用后立即可在列表看到且可试运行；停用不删行、不影响历史运行；卸载时「无运行且无端点」才真正删行（外键级联删除版本），否则保留禁用行并带来源标记。
- 动作包只登记动作资产，不生成自定义动画图 step；`source` 写 `capability:<packId>`，卸载只删自身动作。
- 安装失败回滚规则沿用 v2.10：工作流在建行后失败会先删行再抛错；`disable` 失败保留 enabled 与可读 `lastError`。

## 4. 与 M0 的偏差

1. 工作流复用：M0 未写「停用后再次启用」的句柄策略；实现选择「按来源包查找并复用同一工作流」，避免反复 enable 产生重复行。
2. `mcp` 示例仍为后续项：M1 的示例只覆盖 skill / workflow / pet-action；`mcp` 模板包与其余两类示例在 M2/M4 补齐（仍遵循 D10，不伪造可连）。
3. `sampleMotionAsset` 命名：M0 写 `sampleAssets`，实现为单一读取函数 `sampleMotionAsset`（只服务 pet-action 示例），语义不变。
4. 评审 R2 判断更正：`deleteWorkflow` 在 `foreign_keys=ON` 下已级联删除版本；实现改用「前置判定 + 现有 delete」，不新增仓储方法。
