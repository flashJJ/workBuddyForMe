## 4. M1 实施清单（评审补充，不改变契约）

1. `AppSettings` + `settingsUpdateSchema` + `DEFAULT_SETTINGS` 增加 5 个外部代理字段；服务端钳制超时与输出上限；中英文文案。
2. `WORK_SOURCES` 与 `APPROVAL_SOURCES` 增加 `subagent`；审批页/桌宠/工作信号相关文案与测试枚举同步。
3. `installed_event_scripts.id === definition.id` 强校验；启用时重复检查。
4. `deleteWorkflowCascade` 事务内删除主表与全部版本；端点引用查询走 `workflow_endpoints`。
5. effect 实现按 kind 拆分文件，分派器保持薄；每条 effect 一个单测文件。
6. 示例接口 `kind` 缺省仍为 `skill`，六类互斥。
7. 备份导出/恢复新增三表轨；恢复顺序：能力包 → 剧本/卡片 → 运行记录。
