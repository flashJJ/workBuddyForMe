## 1. 落地清单

| 项 | 落地 |
|---|---|
| 能力包页 | kind 筛选 chips（全部 + 六类）；effect 句柄按 kind 标注（技能名/服务器 id/工作流 id/动作 id/剧本 id/卡片 id） |
| 六类示例 | 头部「kind 选择 + 下载示例包」，链接携带 `?kind=`；六类均可下载（mcp 为模板包） |
| 外部代理区 | `/capabilities` 底部嵌入外部代理面板（与 `/settings` 同一设置源同一组件） |
| 运行深链 | `/capabilities?run=<id>` 自动滚动到外部代理区并高亮对应运行记录 |
| 设置页剧本 | 「来自能力包的剧本」列表：标题、短语、包 id、来源徽章；「试演」跳 `/chat?previewEvent=<id>` |
| 对话页试演 | 读取 query 后按启用剧本定义手动预览一次并清除 query（不依赖 App Router，单测安全） |
| 桌面目录 | `dialog:pick-directory` 单通道 IPC + `window.wbfm.dialog`；外部代理 cwd 输入旁出现「选择目录」（浏览器环境隐藏） |
| e2e | 能力包新增 kind 筛选/effect/六类示例用例；外部代理新增「启用 → 审批 → 运行 → 证据 → 注销」全链路 |

## 2. 关键语义

- kind 筛选纯前端过滤，不新增 API 参数；筛选后为空给出独立空态，不影响安装/启停/卸载。
- effect 详情只读清单里的 `effect_ref`，按 kind 给出人类可读字段名；不额外查询资源表（避免把管理页变成资源浏览器）。
- 剧本试演不绕过能力包启停：仅 `/api/event-scripts` 返回的启用剧本可试演；导演侧仍走 CONV 锁与忙碌检查（冷却/勿扰按手动预览口径绕过）。
- 深链高亮只作用于运行记录视觉，不改变任何运行状态；运行审批仍在审批中心执行。
- 桌面目录选择是可选能力：无 Electron 桥时保持文本输入，不降级安全校验。

## 4. 与 M0 的偏差

1. **设置页试演**：设置页没有形象/TTS 出口，M0 的「支持试运行」实现为跳转对话页深链（`previewEvent`），由对话页导演播放一次；不是设置页内联预览。
2. **外部代理区复用**：`/capabilities` 直接复用 `/settings` 的 `SubagentPanel`，没有复制第二套运行对话框；同一设置源、同一运行记录与取消逻辑。
3. **kind 筛选位置**：筛选在客户端完成，未扩展 `GET /api/capabilities` 查询参数（列表规模小，避免 API 面扩大）。
4. **桌面目录选择**：新增可选桥；未做符号链接 realpath 校验（仍按 M0 留 P1）。
5. **示例下载**：`mcp` 仍为模板包（安装 422 提示替换端点），不宣称可连。
