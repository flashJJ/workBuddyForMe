## 3. 迁移与兼容

- v040 纯加法：`workflows.origin_capability_id` 列 + `installed_event_scripts` / `report_widgets` / `subagent_runs` 三表 + 索引。
- 旧库升级验证：以 v039 完整 schema 建库并写入工作流/能力包，升级到 v040 后原数据保留、新列与三表就位；重复迁移幂等。
- 回退口径：新增列/表不被旧版本读取，旧版本可继续打开同一数据库（只读兼容），不删除既有数据。

## 4. 与 M0 的偏差（汇总）

1. 导演不引入全局剧本注册表，能力包剧本按定义直接准入（三道锁不变）。
2. 设置页剧本试演通过对话页深链播放（设置页无形象/TTS 出口）。
3. `/capabilities` 外部代理区复用设置页同一面板，不复制第二套运行对话框。
4. `.bat/.cmd` 在 `shell:false` 下视为不可用；符号链接 realpath 校验按 M0 留 P1。
5. 设置页剧本列表只列启用剧本；停用剧本不可试演。
6. 能力包签名仍只记录不验证（P1）。

## 4.1 发布打包修复

- **安装包膨胀**：首次 `dist:win` 产物 1.23 GB——Next 15 standalone 在本次构建序列下把 `apps/web/.next/cache`（约 1.6 GB webpack 缓存）与本地测试产物一并复制进 `resources/server`。`prepare-server.mjs` 增加归集后裁撤（`.next/cache` / `coverage` / `playwright-report` / `test-results` / `.turbo`），重打后安装包 **192.49 MB**，与 v2.10（191.1 MB）同量级。
- **归档脚本编码**：`scripts/archive-installer.ps1` 补 UTF-8 BOM，修复 Windows PowerShell 5 把中文脚本按 ANSI 解析导致的语法错误（`pnpm archive:win` 现可直接运行）；同时修正同级清理不再删除受版本控制的 `apps/desktop/build`（图标/许可/NSIS 源资源）。
