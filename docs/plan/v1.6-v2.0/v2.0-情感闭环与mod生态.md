# v2.0「活在桌面」· 情感闭环、主动感知与 mod 封版

> 主题：五个版本的收口——让情绪、记忆、剧本、角色卡**互相咬合**成长期关系，并把个性化成果打包成可分享的本地 mod；同时对 3D 路线给出明确 go/no-go。
> 基线：v1.9；分支建议 `feature/v2.0-companion-loop`
> 性质：大版本，允许包含 1–2 个 spike 结论驱动的决策点，但仍遵守「一版一主题」——主题是**关系闭环**，不是功能大杂烩

---

## 1. 目标（全部可机械验证）

| 编号 | 目标 | 衡量方式 |
|---|---|---|
| G1 | 关系养成闭环 | 亲密度/信任等级 → 解锁内容（称呼、专属剧本、小动作）；等级只升有保底（长期不互动缓慢回落但不清零），规则全可见 |
| G2 | 记忆×情绪联动 | v0.5 记忆中的 relationship/event 类内容喂料情绪与台词；里程碑事件（首次使用百日、协作第 N 次成功）自动纪念 |
| G3 | 主动感知 2.0 | 时段/连续工作时长/任务成败/久未对话等**本地上下文**触发恰当的关怀；系统事件（解锁/空闲）须显式授权，默认关 |
| G4 | 本地关系报告 | 年度/月度回顾：单文件 HTML 本地生成（沿用 v0.4 分享报告技术栈），含关系曲线、共同里程碑、年度关键词（来自本地记忆，可逐项删除） |
| G5 | mod 包封版 | `.wbfm-pack`：角色卡 + 剧本 + 皮肤色板 + 人格参数的单文件 JSON/ZIP 导入导出；schema 校验、来源标记、不含任何模型/音频二进制 |
| G6 | VRM 路线决策 | 完成 3D VRM 授权/成本/体验 spike 并产出结论文档（go→单独立 v2.1，no-go→写明原因归档） |
| G7 | 情绪价值总验收 | v1.6–v1.9 本地指标体系首次完整读数；关情绪/关主动/极简模式三态回归全绿 |

## 2. 功能清单

### P0

1. **关系等级与解锁体系**
   - 等级映射（如 陌生→认识→搭档→挚友，阈值基于 intimacy/trust 组合，具体数值在 v1.6 真机数据上调）；解锁内容：称呼（角色卡可声明等级称呼）、2–3 个高等级专属剧本、1–2 个专属微动作配置。
   - 规则透明：情绪面板可看「距离下一级还缺什么」（文案化，不制造打卡焦虑）；连续不互动情绪照常衰减、**等级只做慢速回落保底不清零**，杜绝惩罚感。
   - 防刷：praise/chat 增长有日增量上限（防连刷夸奖冲等级），事件来源全记录。
2. **记忆联动（不重写检索）**
   - v0.5 记忆类型扩 relationship/event（若尚无）：每日提取时识别「共同经历」（一起完成的任务、用户说过的偏好、低谷时刻）；情绪剧本台词生成时优先引用相关记忆（仍走现有 RRF 检索通道，不改 RAG 架构）。
   - 里程碑计数（本地）：首日、30/100/365 天、第 N 次协作成功、第 N 个知识库；到点触发专属剧本（复用 v1.7 引擎）。
3. **主动感知 2.0（确定性触发优先）**
   - 上下文源：时段（早/午/晚/深夜，纯本地时间）、连续工作时长（Electron 活跃计时，复用 v1.7 勿扰框架）、Flow/协作终态事件（成功庆祝/失败打气，仅在 UI 会话）、久未对话（分级：数日→轻问候）。
   - 系统级事件（解锁/锁屏/空闲 API）：独立授权开关，默认关闭，设置中说明用途；不接任何应用内内容（不读屏、不读窗标题）。
   - 全部触发走 v1.7 事件引擎（新 trigger 类型），频率受同一档位/勿扰/总开关管辖。
4. **关系报告**：本地生成单文件 HTML（v0.4 分享导出同款自包含），内容全部来自本地库且预览页可取消勾选任一节；默认存本地，不分享不外发。
5. **`.wbfm-pack` mod 包**
   - 内容白名单：character card(s) md、event JSON、theme token JSON、personality 参数、（可选）原创背景图（压缩/尺寸限制，用户自有图片责任声明）。
   - 校验：manifest + schemaVersion + zod 逐项校验 + 大小上限；导入预览（列出将新增/覆盖内容）；内置项不被覆盖（命名空间 `builtin.*` 保护）。
   - 明确不含且导入器拒绝：.moc3/.model3.json/.motion3.json/.wav/.mp3 等模型与音频二进制（红线在代码层拦截+提示）。
6. **三态回归**：完整功能态 / 关闭情绪与主动（纯工具模式，行为回到 v1.5）/ 极简视觉（无舞台无 fx）三态 e2e；面向「只想要效率工具」的用户保留一键极简。

### P1

- 纪念日历（生日/纪念日/自定义周年，提前一天预告剧本）。
- 关系数据导出（JSON，归属权透明）与「重新认识」（清空情绪关系但保留记忆，区分于全量重置）。
- 多助手各自关系的总览页（小卡片陈列）。

### P2 / 决策点

- **VRM 3D spike（go/no-go）**：调研 three-vrm(MIT) 在 Electron 的接入成本、模型可再分发来源、与 Live2D 共存/替换策略、授权（Live2D 与 VRM 并存是否仍触发 Cubism 条款需法务口径核实）；产物是结论文档。**no-go 的默认概率不低**——2D Live2D 五模型已是合规稳态，3D 主要价值是舞台空间感，v1.9 2D 舞台若真机达标，3D 可长期搁置。
- 外部事件适配器（音乐播放器状态、番茄钟）：仅在主动感知框架验证稳定后评估，仍坚持本地、不读隐私内容。
- mod 包的签名/可信来源（本地文件体系下只做来源标记，不做 CA）。
- 云端同步（与本地优先宪法冲突，不做；未来若做需独立宪法修订评审）。

## 3. 架构影响

- core：relationship 等级纯函数（阈值/解锁判定/日增量上限/回落保底）、记忆类型扩展与每日提取 prompt 增量、上下文触发器（接 v1.7 trigger 注册表）、里程碑计数器。
- web：关系总览/等级详情、报告生成页（预览-勾选-导出）、mod 包导入导出向导、授权开关组（系统事件）。
- desktop：活跃计时/电源事件桥接（已有 powerMonitor 基座）、报告文件保存对话框。
- 存储：解锁记录表、里程碑表（或 counters JSON）、mod 包安装记录；全部进备份并可随「重新认识」选择性清除。
- 与 v1.3 记忆/编译知识的边界：本版只加记忆**类型与消费场景**，不动检索算法与编译流水线。

## 4. 里程碑

| 阶段 | 出口 |
|---|---|
| M0 | 等级/解锁/回落规则评审（基于 v1.6–v1.7 真机数据定阈值）；mod 包 manifest 规范；VRM spike 立项 |

## 5. 风险与取舍

- **养成游戏化反噬工具定位**：不做任务化打卡、不做奖励货币、不做数值条恐吓 UI；关系是「被记住」的质感而非 KPI。等级规则必须让用户随时可看、可关、可清。
- **记忆联动产生错误记忆/尴尬引用**：引用走现有引用可溯机制；台词对记忆的提及必须是「可选软引用」，模型没把握就不提；用户可删除单条关系记忆并立即不再被引用（删除一致性复用 v1.3 软删除）。
- **主动感知滑向监控**：上下文源枚举制（代码里能列全），不读窗口标题/文档内容/屏幕；系统事件默认关、授权文案具体；所有感知只产出「触发信号」，原始信号不落盘。
- **mod 包红线被绕过**：扩展名白名单在解包层硬校验（不只看 manifest）；测试构造伪装包（改后缀/嵌套 zip）验证拒绝；导入文案明示红线。
- **v2.0 范围爆炸**：本版只收「关系闭环」一条线；VRM、外部事件都是决策点/预留口，做不成立刻砍，不拖封版。
- **大版本期待管理**：2.0 不重写 UI、不换技术栈、不做云；发布叙事强调「同一个 WorkBuddy，现在真的认识你」。
