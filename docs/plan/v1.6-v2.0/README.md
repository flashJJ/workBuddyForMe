# v1.6–v2.0 产品规划 · 从「能用的工作台」到「有情绪的桌面伙伴」—— 总览

> 版本：跨版本规划（基线 main `3b1226c`，v1.5 已合 main 待 bump/tag）
> 日期：2026-10-12
> 主题：**借鉴 Servant（VRM AI 桌宠，PolyForm Noncommercial 许可）的陪伴式设计，补足 WorkBuddy「互动不足、情绪价值低」的短板**
> 上一版方案：[v1.4 会分工](../v1.4/README.md)；v1.5 为无独立方案的真机打磨增量
> 性质：**远期组合规划**。每版开工前仍须按 [版本方案文档标准结构](../../roadmap/README.md#版本方案文档标准结构) 细化四篇并评审，本套文档只锁定主题顺序、能力边界与红线

## 1. 为什么做这件事

v1.0 让 WorkBuddy「会说话、有形象」，v1.3–v1.5 把它练成了「会查资料、会分工的同事」。但站在用户桌面的视角，当前的桌宠更像一个**状态显示器**：

- 表情只从「当前这一条回复」的标签推导，上一轮哭过、这一轮立刻平静——**没有跨轮的情绪，也没有关系积累**；
- 桌宠本体能做的只有「拖、挥手、双击回主窗、右键菜单」——**没有可探索的互动反馈**；
- 主动搭话是单条 LLM 消息，**没有演出、没有仪式、没有纪念日**；
- 三角色协作只存在于泳道时间线里，**看不见角色在「讨论」**；
- 外观只有明暗二元、人格只有一个提示词文本框——**没有可玩的个性化（mod）**。

Servant 是同赛道里把「陪伴感」做得最系统的开源原型：情绪状态机、结构化情绪输出协议、声明式剧情引擎、Galgame 多角色舞台、Markdown 角色卡、命名主题与模型注册表。本规划对其做**机制级拆解与适配评估**，把可迁移的「设计与协议」映射到 WorkBuddy 的 **Electron + Next.js + Live2D** 技术栈，分五个版本交付。

## 2. 一句话版本节奏

| 版本 | 主题 | 一句话 | 核心借鉴对象 |
|---|---|---|---|
| **v1.6** | 有情绪 | 情绪/关系状态机 + 结构化情绪输出 + 桌宠可互动 | Servant SoulState、情绪双 JSON 协议、摸头/微动作 |
| **v1.7** | 有仪式 | 声明式剧情事件引擎 + 内置剧本包 + 主动关怀调度 | EventDirector/EventRunner、Scheduler、人格权重 |
| **v1.8** | 会打扮 | 命名主题皮肤 + Markdown 角色卡（文本 mod）+ 配置式模型调优 | uiPreferences 主题、CharacterSkill 卡库、Provider 注册表与音色库 |
| **v1.9** | 有舞台 | v1.4 协作可视化 + 用户主持的多助手会议舞台 | Galgame Stage、MeetingPage 调度与防串角协议 |
| **v2.0** | 活在桌面 | 关系养成 × 记忆联动 × 主动感知 × mod 包封版 | DailyMemoryJob、纪念事件、外部事件边界 |

依赖主线：**v1.6 情绪内核是一切的地基**（v1.7 的剧本条件、v1.9 的舞台反应、v2.0 的关系养成都读它）；v1.7 事件引擎是 v1.9 舞台的演出底座；v1.8 相对独立，可与 v1.7 并行或按真机反馈插队。

## 3. 四条贯穿红线（每版 Non-Goals 共同部分）

1. **不放开外部 Live2D 模型导入**。Live2D Cubism Core 为专有 SDK，「支持用户加载外部模型」会把产品归类为可扩展应用、触发 Cubism 付费授权条款。内置 5 套官方样本模型（Sample Content License）是长期上限；个性化只能走**角色卡（文本人格）、皮肤配色、动作/剧本配置、内置模型组合**。3D VRM 方向（MIT 生态无此限制）仅在 v2.0 做授权与成本 spike，不承诺立项。
2. **本地优先宪法不动摇**：情绪、关系、记忆、剧本数据全部本机 SQLite/文件；mod 包是本地文件导入导出，不做云账号、不做在线市场。
3. **Servant 代码与资产不复制**：其仓库为 PolyForm Noncommercial 1.0.0 且捆绑的 VRM/VRMA/音效素材各有版权。我们只借鉴**机制设计与协议思想**，全部重新实现；上线前逐条核对机制来源不构成表达实质相似。
4. **工程与安全宪法不降级**：TS strict、单文件 ≤300 行（260 预警）、四层测试、i18n 中英双语随版补齐（zh-CN 真源 + MessageKey 编译期锁定）；无人值守 desktop 永久禁（v1.4 红线），任何主动演出只在 UI 会话内发生。

## 5. 成功之后长什么样

用户摸桌宠的头，它会缩脖子、脸红、发出小声的抗议；连续加班到深夜，它会主动演一段「关灯睡觉」的小剧情而不是弹一条通知；三个月后它记得你们的纪念日、称呼会随亲密度变化；三角色协作出结果时，三个形象在舞台上依次发言、最后一起面向用户；换一套角色卡和樱粉色主题，同一个模型就变成另一个性格的人——而所有数据、密钥、模型仍然不出这台电脑。
