## 1. 本里程碑做了什么

| 类型 | 内容 |
|---|---|
| 导出工具 | `artifact-export.ts`：从 HTML 提取内联 SVG / 规范化 SVG / 生成下载文件名 / Blob 下载 / Canvas 栅格化 |
| 卡片入口 | `ArtifactCard` 新增“导出 SVG”“导出 PNG”，`html`/`svg` 产物展示，`md` 产物隐藏 |
| 交互状态 | 导出中禁用两个按钮并显示 spinner；无 SVG 与导出异常分别提示 |
| 文案 | `toolTrace.artifact.exportSvg/exportPng/exporting/exportFailed/noSvg`（zh/en） |
| 依赖 | 零新增依赖；不引入服务端 Chromium / resvg / Playwright 生产依赖 |

## 2. 关键口径

- **仅图表产物**：`html` 取第一个内联 `<svg>`；`svg` 直接解析根节点；Markdown 与无 SVG 的通用 HTML 不承诺导出，点击时提示“产物中没有可导出的 SVG”。
- **规范化**：补 `xmlns`，按 `width/height` 或 `viewBox` 补齐明确尺寸，序列化为独立 SVG；模板本身使用内联 presentation 属性，不依赖 HTML 外层 CSS。
- **PNG**：`Image` 加载 SVG Blob URL → Canvas 绘制 → `toBlob('image/png')`；默认 **2 倍图**，白底，导出前等待 `document.fonts.ready`。
- **下载**：Blob URL + 锚点 `download`，与既有 `downloadApiFile` 一致，避免桌面端直接导航丢失托管令牌。
- **文件名**：保留原基名与中文标题，仅替换扩展名（`architecture.html` → `architecture.svg/png`）。
- **两端一致**：桌面端加载同一 Web UI，导出逻辑在渲染进程客户端完成，无需主进程新增能力。

## 4. 契约偏差

| # | 事项 | 说明 |
|---|---|---|
| 1 | 导出入口在对话产物卡片 | 现有预览为 `<iframe sandbox="">`，无法在 iframe 内注入工具栏；卡片即预览入口，导出按钮放在卡片操作区 |
| 2 | 仅提取第一个 SVG | 一个图表产物只含一张 SVG；多图产物建议拆分为多个文件，不递归合并 |
| 3 | 未做桌面“另存为”对话框 | Electron 渲染进程的锚点下载沿用系统默认下载目录，不新增主进程 IPC |

## 5. 已知边界

- 通用 HTML 仅预览/下载，不承诺 PNG；含外链字体/图片的 HTML 不在导出范围。
- Canvas 受浏览器最大画布尺寸限制；当前模板固定 960/1280/1080 宽，2 倍图远低于限制。
- 导出失败只显示统一文案，不区分网络失败与解码失败；网络错误可重试。
- 自定义图内字体未内嵌，PNG 使用系统字体栈渲染，跨机器可能有轻微字形差异。
