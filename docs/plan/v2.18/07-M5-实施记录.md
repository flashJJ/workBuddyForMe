## 2. 关键口径

- **只展示，不入模**：`evidence` 不进入 `ToolResult.output`，压缩层与模型消息均不包含证据；只用于 UI/导出。
- **失败也标明未覆盖**：未配置搜索、空结果、抓取失败、无知识库、检索异常、超时/中断都给出 `limitations`，不伪装成功。
- **来源可追溯**：搜索服务名、网页最终 URL、知识库文档名；覆盖写结果条数/片段数/正文字符数/HTTP 状态。
- **截断明示**：搜索摘要截断 300 字符、输出截断 8000 字符、网页正文截断均写入 `limitations`。
- **零迁移**：证据随 `messages.tool_trace` JSON 存储，不新增表/列。
