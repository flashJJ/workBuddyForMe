# v2.18 方案：可交付——图表、内容包与有出处的产物

> 状态：🚧 规划中（2026-11-02）；M0 关键决策已冻结（[01-M0 决策记录](01-M0-决策记录.md)），待契约落盘；分支 `feature/v2.18-planning`
> 上一正式版：v2.17.0（2026-11-02，已发布并置 Latest）
> 主题一句话：**让 Agent 不只回复文字，还能交付可打开的图表、可检索的内容包与有出处的结论。**
> 来源分析：[00-能力借鉴分析](00-能力借鉴分析.md) · 来源方案：[v2.18-01](../../roadmap/scheduled/v2.18-01-deliverable-artifacts-and-content-packs.md)

## 1. 为什么是「可交付」

v2.17 解决了「接得上、搜得到、装得进」：厂商可描述、联网搜索可用、能力目录可安装。下一层断点不在连接，而在**产出物**：

1. 模型能写 HTML/Markdown，但当前聊天没有「把生成内容存成文件」的工具，用户拿不到可打开的图表/报告；
2. 内置技能只有周报/纪要/文件检索，缺少高质量图表设计规范；45 类图表的选择与排版仍靠模型自由发挥；
3. 知识库模板只有空壳，缺少「内容 + 决策流程」的可选示例包；
4. 工具结果只有文本，没有统一的来源、覆盖率与未知项，用户难以判断结论可信度。

v2.18 不做更大的能力市场，只把「产出物」这条链路补齐：**产物文件、图表技能、内容包、证据元数据**。

## 2. 目标与成功指标

| 指标 | 现状（v2.17） | v2.18 目标 |
|---|---|---|
| 把模型生成的内容变成文件 | 无工具，只能留在对话里 | 一次工具调用落盘 HTML/SVG，可在对话内预览/下载 |
| 图表质量 | 无内置图表技能 | 10 类结构化图表的类型选择 + 设计规范 + anti-pattern；Web/桌面可导出 SVG/PNG |
| 内容型知识库 | 只有空模板 | 可选导入《高性价比人生指南》示例包，带署名/版本/哈希 |
| 结论可信度 | 只有文本与引用 | 工具结果带来源/覆盖/未知项，trace 与报告可见 |
| 行为回归 | 2922 单测 / Web e2e 139 | 不降级；新增产物/图表/内容包用例 |
| 迁移 | `LATEST_SCHEMA_VERSION = 42` | 目标零迁移（复用 attachments / 知识库 / 文档表；如需新表在 M0 重评） |

## 3. 功能清单

### 3.1 P0（本版必须）

| # | 功能 | 用户故事 | 验收 |
|---|---|---|---|
| P0-1 | 产物文件管道 | 模型生成的 HTML/SVG 能保存、预览、下载 | `artifact_write` 工具；复用 attachments 表；独立预览路由 + CSP/sandbox；对话产物卡片 |
| P0-2 | 图表渲染 | 用户说「画一张架构图/流程图/柱状图」，模型按规范产出图表 | `diagram_render` 结构化模板；10 类：架构/流程/时序/状态机/ER/时间线/四象限/泳道/柱状图/折线图；数据图做数值校验 |
| P0-3 | SVG / PNG 导出 | 图表能进 PPT、文档、社交平台 | Web + 桌面都支持；预览页从内联 SVG 导出 SVG/PNG，不引入服务端 Chromium |

### 3.2 P1（本版锁定）

| # | 功能 | 用户故事 | 验收 |
|---|---|---|---|
| P1-1 | 内容包示例 | 用户想直接问「替朋友担保签不签」 | 知识库模板页可选导入 HowToLiveBetter；运行时下载 + SHA-256；CC BY 4.0 署名；急症/法律程序先分流 |
| P1-2 | 证据元数据 | 用户想知道结论从哪来、没覆盖什么 | `ToolResult.evidence`（来源/覆盖率/未知项/时间）；trace 与报告展示；不进模型上下文；先覆盖 web/knowledge 工具 |
| P1-3 | 图表类型扩展 | 更多图表需求 | 模板注册表扩到 15–20 类；补中文字体与离线样式 |

### 3.3 P2（明确不做或后续版本）

- **REA 逆向工程产品化**：只借证据契约，不做二进制/Electron 逆向工具（双用途、原生依赖、合规风险）。
- **Moli Rust 浏览器 sidecar**：不引入新二进制；只借 structure-first 输出形态与等待策略，改进 `fetch_webpage` / `browser_read`。
- **ArtCraft 创作套件**：不移植 Rust/Tauri/egui 与 62 模型目录；仅在远期评估生成式创作时参考 Omni API 形状。
- **全量 45 类 Diagram Design references**：需要多文件技能 assets 或图表模板引擎，放后续版本。
- 远程能力市场、任意 URL 内容包、静默下载、任意 HTML 脚本执行、同轮热替换。

## 4. 设计要点（M0 已决策，细节待契约）

### 4.1 产物文件

- 新工具 `artifact_write`（`write`，需 HITL）：输入 `filename`、`format: html|svg|md`、`content`、`title?`；限制单文件 2 MB、单轮 3 个。
- **复用 attachments 表**：扩展 MIME→扩展名映射（`text/html`、`image/svg+xml`、`text/markdown`）与服务层 `saveArtifact`，不新增表。
- HTML 预览必须独立路由：`Content-Security-Policy: sandbox; default-src 'none'; style-src 'unsafe-inline'; img-src data:`；禁脚本、禁外链、禁同源 Cookie。
- 对话产物卡片展示标题/格式/大小/打开/下载；刷新后从附件记录恢复。
- 清理策略：随对话删除/导出；不进入备份核心，不做无限增长。

### 4.2 图表

- 新工具 `diagram_render`（`read`）：输入 `type`、`title`、`data`、`size?`，服务端模板生成自包含 HTML（内联 SVG）；不直接写盘，由 `artifact_write` 落盘。
- 10 类模板：架构 / 流程 / 时序 / 状态机 / ER / 时间线 / 四象限 / 泳道 / 柱状图 / 折线图。
- 内置技能 `diagram-design` 只负责类型选择、数据整理与设计规范（精简自 MIT 上游）；全量 45 类 references 不做。
- 数据图必须校验有限数值、空序列与缺值；坐标轴/标签由模板生成，不让模型手写 SVG。
- 样式默认系统字体栈（含中文），不依赖 Google Fonts；保留上游版权与 MIT 声明。

### 4.3 内容包

- 新增「内容包」概念但不扩 capability kind：复用知识库模板 + 文档导入 + 技能。
- 内容包声明：id、名称、来源 URL、许可证、版本、SHA-256、目标知识库固定 id、说明/免责声明。
- **运行时可选下载**：用户确认后从固定版本 URL 下载，校验 SHA-256 再走既有 ingestion；失败不建空库。
- 入口放**知识库模板页**，与知识库绑定/检索链路一致。
- 回答引用「第 N 节第 M 条」，并在页脚展示 CC BY 4.0 署名与「以医生/律师/当地部门为准」。

### 4.4 证据元数据

- `ToolResult.evidence?: { source: string; coverage?: string; limitations?: string[]; capturedAt?: string }`。
- **只做 UI / 导出展示，不进模型上下文**；先由 `web_search` / `fetch_webpage` / `knowledge_search` 填充。
- tool-trace 折叠区展示，报告导出保留；失败/空结果也要标明「未覆盖」。

### 4.5 SVG / PNG 导出

- 仅对图表产物的内联 SVG：预览页直接序列化下载 SVG；PNG 用 Canvas 绘制 SVG data URL 后导出。
- Web 与桌面同一套预览页实现；不引入服务端 Chromium / resvg / Playwright 生产依赖。
- 通用 HTML 产物只保证预览/下载，不承诺 PNG；外链字体/CSS 的 HTML 不在 PNG 支持范围。

## 7. 风险与取舍

| 风险 | 影响 | 缓解 |
|---|---|---|
| HTML 产物执行脚本/外联 | XSS、数据外泄 | CSP + sandbox + 禁脚本；预览与主站不同源 |
| CC BY 4.0 与 GPL-3.0 分发 | 许可冲突 | M0 法务口径复核；保留署名/许可链接；必要时内容包只做运行时下载 |
| 高风险内容（医疗/法律/财务） | 误导用户 | 只按书检索与引用；急症/法律程序先分流；显著免责声明；不个性化诊断/投资建议 |
| 10 类模板工作量失控 | 做不完、图表质量下降 | 先做 10 类；全量 45 类放 P2；模板与数据 schema 在 M0 固定 |
| PNG 字体/样式 | 导出错版 | 仅支持图表内联 SVG；系统字体栈；导出前等待字体；失败明确报错 |
| 产物无限增长 | 磁盘与备份膨胀 | 单轮数量/体积限制；随对话清理；不纳入核心备份 |
| 与 v2.17 发布节奏冲突 | 版本管理混乱 | v2.17.0 已发布；v2.18 可独立推进 |

## 8. Non-Goals

- 不做逆向工程产品、不引入 Hopper/Ghidra/IDA 工作流；
- 不引入 Moli Rust 二进制或新浏览器 sidecar；
- 不移植 ArtCraft 创作套件、不做图像/视频生成市场；
- 不做任意 HTML 脚本执行、不做远程内容市场、不做静默下载；
- 不新增数据库迁移（除非 M0 明确批准）；
- 不在本版重写对话主结构或导出系统。

## 9. 验收口径

1. 10 类图表都能经 `diagram_render` 生成；数据图的空序列/缺值/非有限数字被拒绝并给出可执行错误。
2. 图表产物经 `artifact_write` 落盘，对话卡片可打开/下载，刷新后仍可用。
3. Web 与桌面预览页都能导出 SVG/PNG；通用 HTML 产物只要求预览/下载。
4. HTML 产物在浏览器离线打开可用；无外链字体/脚本；预览路由有 CSP/sandbox。
5. 内容包可选导入；未确认不下载；哈希校验失败不建库；回答带节/条引用与 CC BY 署名。
6. 工具结果证据字段在 trace/报告可见；失败/空结果标明未覆盖；不进入模型上下文。
7. `pnpm check` / 单测 / Web e2e / 桌面冒烟不降级；零迁移口径不变；`/settings` 包体增长 ≤5%。
