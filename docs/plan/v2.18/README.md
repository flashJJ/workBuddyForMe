# v2.18 方案：可交付——图表、内容包与有出处的产物

> 状态：🚧 规划中（2026-11-02）；分支 `feature/v2.18-planning`
> 上一开发版本：v2.17（M0-M5 已完成并合并 main `1d542d2`；M6 版本号 / 安装包 / Release 尚未执行）
> 主题一句话：**让 Agent 不只回复文字，还能交付可打开的图表、可检索的内容包与有出处的结论。**
> 来源分析：[00-能力借鉴分析](00-能力借鉴分析.md) · 来源方案：[v2.18-01](../../roadmap/scheduled/v2.18-01-deliverable-artifacts-and-content-packs.md)

## 1. 为什么是「可交付」

v2.17 解决了「接得上、搜得到、装得进」：厂商可描述、联网搜索可用、能力目录可安装。下一层断点不在连接，而在**产出物**：

1. 模型能写 HTML/Markdown，但当前聊天没有「把生成内容存成文件」的工具，用户拿不到可打开的图表/报告；
2. 内置技能只有周报/纪要/文件检索，缺少高质量图表设计规范；45 类图表的选择与排版仍靠模型自由发挥；
3. 知识库模板只有空壳，缺少「内容 + 决策流程」的可选示例包；
4. 工具结果只有文本，没有统一的来源、覆盖率与未知项，用户难以判断结论可信度。

v2.18 不做更大的能力市场，只把「产出物」这条链路补齐：**产物文件、图表技能、内容包、证据元数据**。

## 2. 目标与成功指标

| 指标 | 现状（v2.17） | v2.18 目标 |
|---|---|---|
| 把模型生成的内容变成文件 | 无工具，只能留在对话里 | 一次工具调用落盘 HTML/SVG，可在对话内预览/下载 |
| 图表质量 | 无内置图表技能 | 8–10 类高频图表的类型选择 + 设计规范 + anti-pattern |
| 内容型知识库 | 只有空模板 | 可选导入《高性价比人生指南》示例包，带署名/版本/哈希 |
| 结论可信度 | 只有文本与引用 | 工具结果带来源/覆盖/未知项，trace 与报告可见 |
| 行为回归 | 2922 单测 / Web e2e 139 | 不降级；新增产物/图表/内容包用例 |
| 迁移 | `LATEST_SCHEMA_VERSION = 42` | 目标零迁移（复用 attachments / 知识库 / 文档表；如需新表在 M0 重评） |

## 3. 功能清单

### 3.1 P0（本版必须）

| # | 功能 | 用户故事 | 验收 |
|---|---|---|---|
| P0-1 | 产物文件管道 | 模型生成的 HTML/SVG 能保存、预览、下载 | `artifact_write` 工具；体积/扩展名/单轮次数限制；独立预览路由 + CSP/sandbox |
| P0-2 | 内置图表技能 | 用户说「画一张架构图/流程图」，模型按规范产出图表 | 精简版 Diagram Design 技能（MIT 署名）；先覆盖架构/流程/时序/状态机/ER/时间线/四象限/柱线图 |
| P0-3 | 产物在对话内可见 | 用户不用去文件夹找文件 | 对话消息显示产物卡片；支持打开/下载；刷新后仍可访问 |

### 3.2 P1（本版争取）

| # | 功能 | 用户故事 | 验收 |
|---|---|---|---|
| P1-1 | SVG / PNG 导出 | 图表能进 PPT、文档、社交平台 | SVG 由 HTML 导出；PNG 桌面端离屏渲染；Web 端至少 HTML/SVG |
| P1-2 | 内容包示例 | 用户想直接问「替朋友担保签不签」 | 可选导入 HowToLiveBetter；CC BY 4.0 署名；知识库 + 精简决策技能；急症/法律程序先分流 |
| P1-3 | 证据元数据 | 用户想知道结论从哪来、没覆盖什么 | `ToolResult.evidence`（来源/覆盖率/未知项/时间）；trace 与报告展示；先覆盖 web/knowledge 工具 |
| P1-4 | 图表类型扩展 | 更多图表需求 | 模板注册表扩到 15–20 类；补中文字体与离线样式 |

### 3.3 P2（明确不做或后续版本）

- **REA 逆向工程产品化**：只借证据契约，不做二进制/Electron 逆向工具（双用途、原生依赖、合规风险）。
- **Moli Rust 浏览器 sidecar**：不引入新二进制；只借 structure-first 输出形态与等待策略，改进 `fetch_webpage` / `browser_read`。
- **ArtCraft 创作套件**：不移植 Rust/Tauri/egui 与 62 模型目录；仅在远期评估生成式创作时参考 Omni API 形状。
- **全量 45 类 Diagram Design references**：需要多文件技能 assets 或图表模板引擎，放后续版本。
- 远程能力市场、任意 URL 内容包、静默下载、任意 HTML 脚本执行、同轮热替换。

## 4. 设计要点（待 M0 冻结）

### 4.1 产物文件

- 新工具 `artifact_write`（`write`，需 HITL）：输入 `filename`、`format: html|svg|md`、`content`、`title?`；限制单文件 2 MB、单轮 3 个。
- 落盘到数据根 `artifacts/<conversationId>/<id>.<ext>`，复用 attachments 表登记；返回 `artifactId` / 预览 URL / 大小。
- HTML 预览必须独立路由：`Content-Security-Policy: sandbox; default-src 'none'; style-src 'unsafe-inline'; img-src data:`；禁脚本、禁外链、禁同源 Cookie。
- 清理策略：随对话删除/导出；不进入备份核心，不做无限增长。

### 4.2 图表技能

- 内置技能 `diagram-design`（名称可改）：压缩上游 MIT 技能的选择树、设计规范、anti-pattern、输出协议到 1–2 段提示词。
- P0 不引入 45 个 reference 文件；由模型生成自包含 HTML，产物工具落盘。
- 样式默认使用系统字体栈（含中文），不依赖 Google Fonts；颜色/字号/间距按上游 design tokens 的精简版。
- 保留上游版权与 MIT 声明；技能描述标注「基于 Diagram Design v2.6 精简」。

### 4.3 内容包

- 新增「内容包」概念但不扩 capability kind：复用知识库模板 + 文档导入 + 技能。
- 内容包声明：id、名称、来源 URL、许可证、版本、SHA-256、目标知识库固定 id、说明/免责声明。
- 导入必须用户显式确认；只允许白名单 URL；下载后校验哈希再走既有 ingestion；失败不建空库。
- 回答引用「第 N 节第 M 条」，并在页脚展示 CC BY 4.0 署名与「以医生/律师/当地部门为准」。

### 4.4 证据元数据

- `ToolResult.evidence?: { source: string; coverage?: string; limitations?: string[]; capturedAt?: string }`。
- 先由 `web_search` / `fetch_webpage` / `knowledge_search` 填充；tool-trace 折叠区展示，报告导出保留。
- 不改变模型上下文格式；只是附加字段，失败/空结果也要标明「未覆盖」。

## 7. 风险与取舍

| 风险 | 影响 | 缓解 |
|---|---|---|
| HTML 产物执行脚本/外联 | XSS、数据外泄 | CSP + sandbox + 禁脚本；预览与主站不同源 |
| CC BY 4.0 与 GPL-3.0 分发 | 许可冲突 | M0 法务口径复核；保留署名/许可链接；必要时内容包只做运行时下载 |
| 高风险内容（医疗/法律/财务） | 误导用户 | 只按书检索与引用；急症/法律程序先分流；显著免责声明；不个性化诊断/投资建议 |
| 45 类图表范围失控 | 做不完、模板质量下降 | P0 只做 8–10 类；全量放 P2 |
| PNG 字体/中文字体 | 导出错版 | 系统字体栈；导出前 `document.fonts.ready`；失败明确报错 |
| 产物无限增长 | 磁盘与备份膨胀 | 单轮数量/体积限制；随对话清理；不纳入核心备份 |
| 与 v2.17 发布节奏冲突 | 版本管理混乱 | v2.18 开发可先行；M6 必须等 2.17 发布口径明确 |

## 8. Non-Goals

- 不做逆向工程产品、不引入 Hopper/Ghidra/IDA 工作流；
- 不引入 Moli Rust 二进制或新浏览器 sidecar；
- 不移植 ArtCraft 创作套件、不做图像/视频生成市场；
- 不做任意 HTML 脚本执行、不做远程内容市场、不做静默下载；
- 不新增数据库迁移（除非 M0 明确批准）；
- 不在本版重写对话主结构或导出系统。

## 9. 验收口径

1. 模型生成图表 → `artifact_write` → 对话卡片可打开/下载，刷新后仍可用。
2. 架构图/流程图/时序图三类请求能命中内置图表技能，产出符合选择/密度/配色规范。
3. HTML 产物在浏览器离线打开可用；无外链字体/脚本；预览路由有 CSP/sandbox。
4. 内容包可选导入；未确认不下载；哈希校验失败不建库；回答带节/条引用与 CC BY 署名。
5. 工具结果证据字段在 trace 可见；失败/空结果标明未覆盖。
6. `pnpm check` / 单测 / Web e2e / 桌面冒烟不降级；零迁移口径不变；`/settings` 包体增长 ≤5%。
