## 1. 产物契约

```ts
type ArtifactFormat = 'html' | 'svg' | 'md';

interface ArtifactRef {
  attachmentId: string;
  title: string;
  filename: string;
  format: ArtifactFormat;
  mimeType: string;
  byteSize: number;
}
```

| 项 | 约定 |
|---|---|
| 格式 | 仅 `html` / `svg` / `md` |
| 大小 | 单文件 ≤ 2 MB |
| 数量 | 单轮 ≤ 3 个（工具在 `ToolContext` 层不做计数，由调用方/工具自身限制） |
| 存储 | 复用 `attachments` 表；文件落 `<dataDir>/attachments/<id>.<ext>` |
| MIME | `text/html` / `image/svg+xml` / `text/markdown` |
| 文件名 | 去路径分隔符与非法字符，强制匹配格式扩展名 |
| 标题 | 1–80 字，仅展示与下载名，不落库 |
| 零迁移 | 不改 attachments 表结构；仅扩展 MIME→扩展名映射 |

## 2. `artifact_write` 工具

- 权限：`write`（走既有权限门；确认框展示标题/格式/大小）。
- 参数：

```json
{
  "title": "string, 1-80",
  "filename": "string, 1-120, 可省略扩展名",
  "format": "html | svg | md",
  "content": "string, ≤ 2 MB"
}
```

- 成功返回：`ToolResult.artifacts: ArtifactRef[]`；`output` 为「已生成产物：…」；`summary` 含标题/格式/大小。
- 失败：参数错误抛 `ToolArgError`；服务不可用/校验失败返回 `ok=false` 可读错误，不抛未捕获异常。
- 落盘失败不生成半成品记录：先写文件再建行；任何一步失败清理文件。

## 3. 预览与下载 API

- `GET /api/artifacts/:id`：返回原始字节；`id` 为 attachments id。
- `GET /api/artifacts/:id?download=1`：`content-disposition: attachment; filename="<safe>"`。
- 响应头（全部）：
  - `content-type: <mime>`
  - `content-security-policy: sandbox; default-src 'none'; style-src 'unsafe-inline'; img-src data:`
  - `x-content-type-options: nosniff`
  - `cache-control: private, max-age=3600`
- 仅允许三种产物 MIME；图片附件走原 `/api/attachments/:id`。
- 鉴权沿用 `defineRoute`（桌面需 `X-WBFM-Token`）；前端用带令牌的 fetch 取 blob，不直接把 URL 放进 `<a href>`。

## 4. 对话产物卡片

- `ToolTraceEntry` / SSE `tool end` 增加可选 `artifacts?: ArtifactRef[]`。
- tool-trace 卡片展示：标题、格式、大小、预览、下载。
- 预览：带令牌 fetch → Blob URL → `<iframe sandbox="">`；下载走 `downloadApiFile`。
- 刷新/历史消息：从 `messages.tool_trace` JSON 恢复，无需新增消息片段。
- 产物不进模型上下文；tool output 只给模型可读摘要。
