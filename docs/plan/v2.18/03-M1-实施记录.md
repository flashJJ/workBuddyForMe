## 1. 本里程碑做了什么

| 类型 | 内容 |
|---|---|
| 共享契约 | `ArtifactRef` / `ArtifactWriteInput` / `ArtifactFormat` / 产物常量（2 MB、3 个/轮、标题/文件名上限） |
| 存储 | 复用 `attachments` 表与目录；扩展 MIME→扩展名映射（html/svg/md）；新增 `saveArtifact` / `readArtifact` |
| 工具 | `artifact_write`（`write`）：标题/文件名/格式/内容；返回 `ToolResult.artifacts` |
| 运行时 | `ServiceDeps.artifacts` + `ToolContext.writeArtifact`；容器复用同一附件服务 |
| 追踪 | `ToolTraceEntry` / SSE `tool end` 增加 `artifacts`，历史消息从 `tool_trace` 恢复 |
| API | `GET /api/artifacts/:id`：产物 MIME 白名单、CSP sandbox、nosniff；`?download=1` 返回附件头 |
| UI | tool-trace 内产物卡片：标题/格式/大小、sandbox iframe 预览、带令牌下载 |
| 门禁 | `pnpm check` 通过；定向单测 42 例 |

## 2. 关键口径

- **零迁移**：只扩展代码层 MIME 映射与附件服务，不改表结构；图片附件继续走原 `/api/attachments/:id`。
- **存储失败回滚**：先建附件行再写文件；写盘失败删除元数据行与残留文件，不留下半成品。
- **不可信 HTML**：预览页 CSP 禁止脚本/外链/同源；UI 用 `<iframe sandbox="">`，不把产物 URL 直接作为 `<a href>`。
- **产物不进模型上下文**：`ToolResult.artifacts` 只用于 trace/SSE/UI；模型只看到 output 摘要。
- **对话卡片落在 tool-trace**：不新增消息 content part，避免改动多模态消息协议；刷新后从 `messages.tool_trace` JSON 恢复。
- **单轮数量**：契约写 3 个/轮，但 M1 未在运行时计数；后续可在工具/编排器加计数，不阻塞当前链路。
