# v4.17 用得顺——关键路径的感知、恢复与复用

> 状态：已实现（T5.1 真机视觉基线待补）
> 关联：[v4.16 CI 稳定性](../v4.16/spec.md) · [竞品差距诊断](../archive/v2/v2.4-product-comparison/01-竞品体验对比与差距诊断.md) · [缺陷预防手册](../../wiki/bug-prevention-playbook.md) · [Bug 记录表](../../wiki/bug-registry.md)

## 1. 背景

v4.16 把 CI 与验收的可靠性收口后，v4.15.0 安装包已可稳定真机验证。最近一轮用户复验暴露的 6 个问题（B-61～B-66）几乎都不是「功能缺失」，而是**同一类易用性缺口**：

| 现象 | 本质 | 归属 |
|---|---|---|
| MCP 工具勾选保存后消失（B-61） | 上限 20 静默截断，保存成功但数据被丢 | 限制不可感知 |
| 助手技能/知识库、流程入参达上限无提示（B-62） | 同上，UI 不告知剩余额度 | 限制不可感知 |
| 能力中心已安装 MCP 仍可勾选（B-64） | 「已安装 / 已启用 / 异常」状态语义不清 | 状态有歧义 |
| 本地搜索未启动时对话直接失败 | 失败无「原因 + 下一步 + 一键修复」 | 失败不可恢复 |
| 桌宠有背景时点击空白穿透（B-65） | 点击命中区与视觉不一致 | 交互不跟手 |
| 拖动侧栏/按钮弹出 URL 浮层（B-66） | 浏览器原生行为未收口 | 原生行为未收口 |

结论：**功能面已经足够宽，短板在「用户能不能感知到、失败了能不能自己修、常用动作能不能少点两下」。** v4.17 只做这一件事。

## 2. 目标

1. **可感知**：任何数量上限、能力状态、异步进度，界面上都要有唯一、可读的表达，禁止静默截断/静默失败。
2. **可恢复**：四类高频故障（模型未配置、MCP 连接异常、本地搜索未启动、语音模型未下载）都能看到「为什么 + 下一步」，并能一键跳到修复位置。
3. **可复用**：已有数据与已有 API 接到界面上——会话/消息检索接线、命令面板补最近使用与缺口命令、设置中心提供常用入口与深链。
4. **首启不断链**：跳过向导的用户，在对话空态仍能通过「演示模式 / 配置模型 / 用模板开始」三条路产生第一条回答。

## 3. 非目标（与功能清单同权重）

- 不做图片/视频生成、全双工实时语音（属于模态代差，成本高且与本地优先定位冲突）；
- 不做云同步、移动端、团队协作；
- 不引入新的 UI 框架、图标库或状态管理库；
- 不改数据库 schema、备份格式（目标零迁移）；
- 不重做视觉风格；本版只做信息层级与反馈，不做品牌改版；
- **不重复建设已具备的能力**：首启向导（5 步可跳过）、供应商「测试连接」、命令面板（导航/创建/设置深链）、模板中心、助手卡片技能与 MCP 徽标、流式渲染帧节流（`use-stream-frame`）均已存在，只做缺口补齐。

## 4. 竞品对照与取舍

> 口径：豆包 / Trae 的结论沿用 [v2.4 竞品诊断](../archive/v2/v2.4-product-comparison/01-竞品体验对比与差距诊断.md)（2026-10-19 采集）；本地优先同类（Cherry Studio / Chatbox / LobeChat）为公开产品形态对照。**排期前需用 30 分钟实测复核一次**，避免照抄过时结论。

| 体验点 | 竞品通行做法 | 本产品现状（已核验） | v4.17 动作 |
|---|---|---|---|
| 首次价值 | 装完即用，内置模型/额度 | 向导可跳过；设置页空态有「新增供应商」；对话空态缺三选一 | P0-4 空态三选一 + 跳过后的持续入口 |
| 失败恢复 | 错误提示带操作按钮/跳转 | [state.tsx](../../../apps/web/src/components/common/state.tsx) 的 `ErrorState` 只有「重试」 | P0-2 扩展为「原因 + 下一步 + 动作/深链」 |
| 状态语义 | 一个徽标只表达一种状态 | MCP 已改只读（B-64），能力中心/技能/知识库仍各自为政 | P0-3 统一三态徽标与图例 |
| 数量限制 | 达上限即禁用并说明 | 助手/流程已补，其余多选未全量核对 | P0-1 全量审计 + 不变量门禁 |
| 历史复用 | 会话/消息全局检索 | `/api/search` 与 `chatApi.search` 已存在，但无 UI 消费；命令面板「搜索会话」只跳 `/chat` | P1-1 接线检索弹层 |
| 高频动作 | 命令面板 + 最近使用 | 命令面板覆盖导航/创建/设置深链，无最近使用，导出仅弹提示 | P1-2 最近使用 + 导出真正执行 |
| 设置可找 | 常用置顶 + 搜索 | 已有搜索与 `#panel-*` 深链 | P1-3 常用 5 项 + 错误提示深链复用 |

## 5. 需求

### P0-1 限制可视化收口

- 审计所有「用户可多选/可添加」字段的保存路径，找出仍用 `slice(0, N)` 或 schema 静默截断的位置；审计命令与结果写入 tasks。
- 达上限时：禁用未选项 + 显示「已达上限 N」+ 剩余额度；保存前不再静默丢弃。
- 新增共享组件 `apps/web/src/components/common/limit-hint.tsx`（≤50 行，zh/en 文案）。
- 在 [repo-invariants.test.ts](../../../packages/config/src/repo-invariants.test.ts) 增加用例：用户多选保存路径不得出现无提示的 `slice(0,` 截断（允许清单显式登记）。

### P0-2 错误可恢复

- 扩展 [state.tsx](../../../apps/web/src/components/common/state.tsx)：`ErrorState` 增加 `action?: React.ReactNode`，保留 `onRetry` 兼容现有调用。
- 四类高频故障接入统一口径（每条都要有「原因 + 下一步 + 动作」）：

| 故障 | 触发点 | 动作 |
|---|---|---|
| 模型未配置/默认模型缺失 | 对话发送前 | 「打开设置」深链 `#panel-providers`、「先用演示模式」 |
| MCP 连接异常 | 设置-能力中心卡片 | 「重试连接」、「查看日志/禁用」 |
| 本地搜索未启动 | 搜索类工具失败 | 「一键启动本地搜索」并续跑（沿用 `local-search-autostart` 规格） |
| 语音模型未下载 | 语音输入/播报 | 「去下载」深链语音面板 + 体积提示 |

### P0-3 能力状态三态统一

- 新增 `apps/web/src/components/common/capability-status-badge.tsx`：`可用 / 已启用未连接 / 异常` 三态 + 统一颜色语义与 tooltip。
- 接入能力中心、MCP 目录、技能列表、知识库列表；每处提供一行图例说明（仅首次展示）。
- 禁止同一卡片同时出现「可勾选」与「已安装」两种含义（B-64 的泛化）。

### P0-4 首启不断链

- 对话空态（[message-list.tsx](../../../apps/web/src/features/chat/message/message-list.tsx) 的空态分支）提供三选一：
  1. 「用演示模式试一句」→ 开启 `demoModeEnabled` 并发送内置示例；
  2. 「配置我的模型」→ `settings#panel-providers`；
  3. 「从模板开始」→ 复用 [template-launcher.tsx](../../../apps/web/src/components/common/template-launcher.tsx)。
- 跳过向导后，该空态常驻直到产生第一条会话；已配置模型时只保留模板入口。
- 开发态记录「打开应用 → 第一条回答」耗时（复用 v2.4 自检口径），不进入生产 UI。

### P1-1 会话/消息检索接线

- 新增 `apps/web/src/features/chat/search/use-message-search.ts`（防抖、Abort、空结果态）与 `message-search-dialog.tsx`（输入 + 结果分组 + 跳转到消息）。
- 复用 `chatApi.search`（[endpoints/chat.ts](../../../apps/web/src/lib/api/endpoints/chat.ts#L31-L32)）与 `/api/search` 路由，不改服务端协议；无结果时给出「换关键词 / 扩大范围」提示。
- 入口三处：命令面板 `conv:search`、对话页头部搜索按钮、侧栏会话区搜索。

### P1-2 命令面板缺口与最近使用

- [use-commands.ts](../../../apps/web/src/features/command-palette/use-commands.ts)：`conv:search` 改为打开检索弹层；`conv:export` 真正调用导出 API 而不是只弹提示。
- 记录最近执行的 5 条命令（本地存储），置顶展示；不改变现有分组顺序与键盘操作。
- 补「打开桌宠 / 关闭桌宠」命令（仅桌面端可见），复用现有 pet bridge。

### P1-3 设置中心常用与深链

- [settings-page.tsx](../../../apps/web/src/features/settings/base/settings-page.tsx) 顶部增加「常用」5 项：供应商与模型、语音、MCP、外观、数据与备份；点击滚动到对应 `#panel-*`。
- 复用 [catalog.ts](../../../apps/web/src/lib/settings/catalog.ts) 的锚点与搜索；不新增第二套索引。

### P2 体感与一致性（可延后，不阻塞封版）

- P2-1 窄窗三尺寸（1024/1280/1440）与长路径/长模型名溢出复核，更新视觉基线。
- P2-2 首次使用提示 `Ctrl+K` 与快捷键入口，补「快捷键浮层 vs 真实绑定」一致性测试。
- P2-3 桌宠入口与状态在主窗可见（放在设置-外观或头像菜单，**不新增第 14 个侧栏项**，避免破坏现有 13 项导航断言）。

## 6. 验收标准

1. `pnpm check` 全绿（typecheck / lint / 行数 / 目录 / 循环依赖 / MSW / ASCII / 资产 / surface / E2E 隔离 / repo-invariants）。
2. 每条 P0 有可复现测试：
   - 上限：达上限禁用 + 文案断言 + 不变量用例；
   - 恢复：四类故障各一条「动作可见且可点击」断言；
   - 状态：三态徽标在四处的渲染断言；
   - 空态：三选一存在且演示模式路径可发出第一条消息。
3. 检索：命令面板/头部/侧栏三入口可用；空结果显示引导；跳转定位到消息（e2e 覆盖一条）。
4. 零数据库迁移；i18n zh/en 双档齐全；单文件 ≤300 行、目录直接文件 ≤12。
5. 首启实测：新数据根下，从打开应用到第一条回答 ≤5 分钟；演示模式路径 ≤60 秒。

| 风险 | 影响 | 缓解/回退 |
