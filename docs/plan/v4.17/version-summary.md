> 迁移：无数据库迁移；备份格式不变；零新增运行时依赖

## 1. 本版解决什么

一轮用户复验暴露的六个问题，被归为三类缺口：

1. 限制不可感知：多选工具保存后勾选消失，其他表单达上限也没有提示；
2. 状态有歧义：能力中心里「已安装」的服务仍可被勾选；
3. 失败不可恢复：本地搜索未启动时直接失败，错误态只有「重试」。

此外还有两个长期痛点：跳过首启向导后对话区没有任何入口；已有搜索接口与命令面板缺口没有被界面消费。

本版只做易用性，不扩功能面：不引入新依赖、不新增侧栏项、不改数据库、不重做视觉风格。

## 2. 里程碑结果

| 阶段 | 结果 |
|---|---|
| M1 感知层 | `LimitHint` 统一上限提示；`CapabilityStatusBadge` 统一四态；能力中心/MCP/技能接入；保存路径不变量门禁 |
| M2 恢复层 | `ErrorState` 支持动作插槽；模型未配置、MCP 异常、本地搜索未启动、语音模型未下载四类故障给出原因与下一步 |
| M3 首启收口 | 空态三选一（演示 / 配置 / 模板）；有模型时只保留模板入口；开发态 TTFV 埋点 |
| M4 效率层 | 消息检索三入口与消息深链；命令面板最近 5 条、导出执行、桌宠开关；设置常用 5 项 |
| M5 体感收口 | 首次 `Ctrl+K` 提示；窄窗视觉复核留待真机阶段 |

## 3. 关键设计

### 3.1 上限提示与不变量

达上限时同时做两件事：禁用未选项、显示「已达上限 N」。只有禁用没有说明，用户会以为控件坏了；只有说明没有禁用，用户会继续点。

保存路径的规则写成测试而不是文档：扫描用户多选字段的 `slice(0, N)` 截断，匹配即失败，允许清单当前为空。

### 3.2 四态徽标

能力状态收为一个枚举：`available / enabled / disabled / error`。颜色与文案由状态决定，不由页面决定；调用方可以覆盖文案，但不能覆盖颜色语义。

知识库未接入：其字段描述文档处理进度，不是能力健康状态，硬套四态会造成新的混淆。

### 3.3 错误态动作化

`ErrorState` 增加可选 `action`，优先于原有 `onRetry` 渲染。已有调用方零改动，新场景可以给「打开设置」「去下载」「一键启动」这类具体动作。

四类故障中有三类复用已有修复能力：测试连接、本地搜索一键启动、语音模型下载。本版的工作重点是把已有能力放到错误发生的位置，而不是重造组件。

模型未配置采用阻断式空态，而不是发送前弹提示：让用户先输入再被打断，比一开始就说清楚更差。

### 3.4 首启三条路

空态提供三种意图各自最短的路径：

1. 想先看效果 → 演示模式；
2. 知道要配置 → 模型供应商深链；
3. 手里有模板 → 模板中心。

有模型但无消息时只保留模板入口，避免重复提醒已经完成配置的用户。

### 3.5 检索复用已有数据

消息检索不建新索引、不改服务端协议，直接消费已有搜索接口与本地会话事件日志。

三个实现细节决定体验：300ms 防抖、`AbortController` 中止旧请求、按消息 id 去重；片段截断 120 字符，空结果给出换关键词引导。

命中后链接同时携带会话与消息 id，直接定位到具体消息。入口统一为命令面板、对话页头部、侧栏会话区三处，共用同一个弹层。

### 3.6 命令面板与设置常用

最近使用只记录 5 条，置顶但不改变原有分组顺序；搜索时隐藏最近使用分组，键盘操作不变。

导出命令从「提示」改为「执行」，条件不足时才退化为提示。桌宠命令复用现有桥接，不新增窗口逻辑。

设置常用 5 项复用已有面板锚点，用户已有固定快捷项时自动隐藏。

## 5. 已知限制

- 知识库未接能力状态徽标，原因见 3.2；
- 窄窗 1024/1280/1440 与长文本溢出复核未在真实浏览器完成，需真机或视觉基线阶段补做；
- 桌宠只提供命令面板开/关，未新增主窗显式入口；
- 语音免手 E2E 曾因「点击后才注册请求监听」错过瞬时完成的 ASR 请求而超时；已改为先监听再点击，并去掉假麦克风与音频上下文自动播放依赖，本地生产模式 4/4 通过；
- 发布流水线可能因并发上传产生两个草稿，需要在转正前人工合并资产。

## 6. 下一步

1. 补做窄窗视觉复核并更新基线；
2. 继续观察语音免手 E2E 在 CI 的稳定性，必要时把回复断言也改为事件驱动；
3. 评估桌宠主窗入口，不新增侧栏项的前提下放在设置或头像菜单；
4. 把本地验证与 CI 对齐：至少覆盖 `pnpm check`、全量单测、Web 构建与受影响 E2E，减少「CI 才发现」的问题。
