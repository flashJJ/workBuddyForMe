# v2.29 方案：文档可信——存量重解析、质量标记与低质收口

> 主题：让旧文档能被重新读懂，让不可信的表格退回文本，让图检索的边界可见可调。
> 分支：`feat/v2.29-document-trust`
> 目标：一次迁移（v049，纯加法）、零接口破坏、单一主题。

## 1. 背景与目标

v2.19 把文档解析做深了：章节、表格、引用坐标、结构面板与关系检索都已落地。但解析能力只覆盖「新上传且解析成功」的文档，存量与低质输入仍有四个断点：

- 升级前的文档不会重解析，结构面板显示「尚未解析」，只能逐篇手动点重建；
- 扫描件表格由 OCR 文本启发式重建，置信度被压到 0.55，界面只给警告，不说明「这会怎样影响回答」；
- 低置信表格仍会生成表格分片，回答可能给出看似精确、实际错误的单元格引用；
- 关系检索固定 2 跳 / 12 条边，复杂问题在第二跳断掉时没有任何可调入口。

用户感知是三个问题：「我的旧文档为什么没有章节？」「OCR 表格答错了，我能做什么？」「复杂关系问题为什么只答到一半？」

本版目标：**存量可盘点、可批量重建；低质可识别、可降级；图检索边界可见可调。** 不引入新解析服务，不做模型级关系抽取。

## 2. 盘点结论

| 来源 | 未交付项 | 本版取舍 |
|---|---|---|
| 候选 04 A | 存量重解析：按旧 schema / 无结构块筛选，后台逐个重建 | 纳入 P0/P1，批量队列只处理「无结构块」文档 |
| 候选 04 B | OCR 表格修正：低置信单元格手工修正并回写 | 降级为「低置信表格不参与表格问答 + 面板标注」，不做单元格编辑 |
| 候选 04 C | 关系抽取升级：规则 + 模型补指代与跨句 | Non-Goal，本版不碰模型抽取 |
| 候选 04 D | 多跳放宽：跳数与边数可配置 | 纳入 P2，只在设置层开放上限 |
| v2.19 已知边界 | 旧文档不自动重解析；OCR 上限 0.55；关系为规则实现 | 本版逐条收口或显式标注 |

结论：不新增解析引擎，不改上传链路；只做「盘、重建、标注、降级、调边界」五类治理动作。

## 3. 主题与边界

一句话：**旧文档要能补齐，低质文档要说得清，不可信的结构要退得回。**

- 盘：用解析版本与结构块是否存在来判定「待重建」，不靠上传时间猜。
- 重建：批量是用户触发的维护动作，不是启动时自动跑全库。
- 标注：质量不是打分，是一组可核实的事实（旧解析、缺原始文件、OCR、低置信表、无标题）。
- 降级：低置信表格退回文本检索，是显式行为，界面必须说明。
- 调边界：只开放跳数与边数，不改变关系抽取算法。

## 4. 功能清单

### 4.1 解析版本与存量盘点（P0）

- 迁移 v049：`documents` 增加 `parse_version INTEGER NOT NULL DEFAULT 0`；随后做一次性**元数据回填**：已有 `document_blocks` 的文档置为 1。回填只改版本号，不重写任何解析内容。
- 新增常量 `DOCUMENT_PARSE_VERSION = 1`；新上传与重解析成功后写入当前版本。
- 「待重建」判定为纯函数：`parse_version < 当前版本` 或 `document_blocks` 为空；同时检查原始文件是否保留，缺文件标记为「不可重建，请重新上传」。
- 文档记录新增 `parseVersion`，知识库页据此显示「待重建 N 篇」；缺原始文件在批量预检与结构面板中单列，不在列表阶段做磁盘探测。
- 质量事实统一由纯函数产出，列表徽标与结构面板读同一份结果，避免两处各算一套。

### 4.2 批量重解析队列（P1）

- 新增进程内 `document-reparse-runner`：串行执行、单飞、限速（逐篇，不并发），提供开始 / 暂停 / 继续 / 取消。
- 队列不落库：候选集每次从「待重建」查询重新推导。暂停只是停止取下一篇；应用重启后再次开始即自然续跑，不依赖持久化任务表。
- 批量范围是全部「待重建」文档；在当前版本下只会选中无结构块的旧文档。未来解析版本升级时同一队列可直接复用，历史引用漂移由快照校验兜底。
- 单篇重建复用现有 `pipeline.ingest` 事务：新分片与结构块提交前，旧索引保持可用；失败只记录该篇失败，继续下一篇。
- 缺原始文件的文档在预检阶段跳过，不进入队列；返回跳过原因与数量。
- 进度通过轮询文档列表/状态获得，不新增 SSE；界面显示当前文档、完成数、失败数与暂停状态。
- 历史引用保护：打开引用时校验目标分片是否仍包含引用快照的 `snippet`；不包含则在文档内搜索该片段，仍找不到时提示「文档已重建，原引用片段不可用」，不静默跳到错误位置。

### 4.3 质量标记与低置信表格收口（P1）

- 文档列表增加「待重建」「OCR 来源」徽标；低置信表格与无标题结构在结构面板标注。
- 结构面板保留现有警告，并补充可操作入口：本篇重新解析、缺原始文件时提示重新上传；每条警告说明「对回答的影响」。
- 表格分片规则收紧：表格置信度低于 `0.75`（OCR 重建上限 `0.55`）时，不再写入表号 / 行号等结构化坐标，只作为普通文本分片参与检索。回答因此不会给出精确到单元格的引用，但表格文字仍可被检索到。
- 结构面板对每张表显示置信度与「已降级为文本检索」状态；表格列表不再承诺不可信的坐标。
- 不提供单元格编辑：整批替换的写入模型与局部修正冲突，需要版本化块才能安全回写，成本高于本版主题。

### 4.4 图检索边界可配置（P2）

- 设置新增两个可选字段：`knowledgeRelationMaxHops`（1–3，默认 2）与 `knowledgeRelationMaxEdges`（4–24，默认 12）。
- 接入现有 `collectMultiHopRelations` 的 `maxHops / maxEdges` 参数；默认值与当前行为完全一致。
- 非法值在服务层收窄到范围内，不抛错；设置页说明「跳数越高召回越广，噪声与 token 也越多」。
- 关系仍为规则抽取；本版不做指代消解、不做模型生成、不做社区聚类。

## 5. Non-Goals

- 不做单元格级表格编辑、表格版本历史与回滚。
- 不做 LLM 关系抽取、指代消解与跨句推理升级。
- 不引入版面模型、新 OCR 引擎或 Python/Go/Rust 常驻服务。
- 不在启动时自动重解析全库；批量必须由用户触发。
- 不做文档级评分排名，只用可核实事实标注。
- 不做跨设备同步、云端重解析。

## 6. 阶段拆分

| 阶段 | 内容 | 交付物 |
|---|---|---|
| P0-M1 | v049 + 解析版本 + 待重建判定 + 列表质量事实 | 迁移、纯函数与单测 |
| P1-M2 | 批量重解析 runner + 开始/暂停/继续/取消 + 进度 UI | 队列、接口与组件测试 |
| P1-M3 | 低置信表格降级 + 结构面板说明 + 引用漂移保护 | 分片规则、面板与引用用例 |
| P2-M4 | 跳数 / 边数设置与接线 | 设置项、范围收窄与检索用例 |
| 收尾 | 发行说明、路线图状态、博客 10 篇 | `docs/roadmap/v2.29-release-notes.md` |

顺序理由：解析版本与判定是后续所有动作的基础，先做；批量队列依赖判定，但风险集中在任务执行与失败隔离，单独一段；低置信降级动分片规则与引用体验，放在队列稳定之后；图检索边界只改参数，最后做。

## 7. 验收口径

1. 迁移 v049 为纯加法、可重复执行；`LATEST_SCHEMA_VERSION = 49`；无结构块的旧文档保持 0，已有结构块的文档一次性回填为 1，新上传为 1；回填不改解析内容。
2. 待重建数量等于「版本落后或无结构块」的文档数；缺原始文件的文档被单列为不可重建，不进入批量队列。
3. 批量重解析串行执行，可暂停 / 继续 / 取消；单篇失败不影响后续；重建失败时旧索引仍可检索；应用重启后再次开始能续跑剩余文档。
4. 低置信表格不再生成表格坐标引用，文字仍可被检索；结构面板显示置信度与降级状态，并解释对回答的影响。
5. 引用打开时若分片与快照不匹配，能回退搜索或明确提示不可用，不跳到错误片段。
6. `knowledgeRelationMaxHops` 与 `knowledgeRelationMaxEdges` 生效且默认行为不变，非法值被收窄。
7. `pnpm check`（typecheck / lint / 300 行 / 目录预算 / 循环 / ASCII）与 `pnpm test` 全绿；i18n 中英键成对。
8. 发行说明、路线图索引、博客 10 篇同版本收尾。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 批量重建占用 CPU、拖慢对话 | 串行 + 逐篇限速 + 可暂停/取消；失败不重试风暴 |
| 重建改变分片序号，历史引用漂移 | 引用打开时校验快照并回退搜索；批量前提示重建会更新分片坐标 |
| 低置信表格降级后检索召回下降 | 只去掉表格坐标，不丢文本；面板明确说明降级原因 |
| 解析版本写入遗漏，旧文档被误判 | 上传与重解析共用一个写入函数；用例断言两条路径都写入当前版本 |
| 质量事实两处计算不一致 | 纯函数单一出口，列表与结构面板共用 |
| 设置项非法值导致检索异常 | 服务层统一收窄到范围；默认值保持 2 / 12 |
| 缺原始文件导致重建永久失败 | 预检单列标记，引导重新上传，不进入队列 |
