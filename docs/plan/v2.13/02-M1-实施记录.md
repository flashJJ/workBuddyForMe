## 2. 关键行为

1. 默认模式 `confirm_each`，与 v2.12 的 write/danger 审批行为一致。
2. `full_access` 必须服务端收到 `acknowledgeFullAccess: true`，否则 422（防止直接调 API 绕过确认）。
3. 工作目录失败返回 422 `WORKSPACE_INVALID`；越界校验函数返回 403 `WORKSPACE_ESCAPE`（M2 接入策略）。
4. 迁移旧库：既有运行自动获得 `confirm_each`，`workspacePath` / 定时来源为 `null`；旧版本忽略新增列与审计表。

## 4. 已知边界（承接后续里程碑）

- 工作目录本版只用于创建校验与 M2 路径策略；内置文件 / shell 工具不在本版，外部代理的 cwd 由 M2 的路径规则约束。
- `policy_snapshot_json` 已落库，策略哈希由快照计算；M3 起写入审计事件。
- 任务模式仅作用于 `task_runs`；聊天 / 协作 Agent 按策略 `defaultMode`（M2）。
