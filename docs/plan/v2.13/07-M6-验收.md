## 4. 已知边界（随发行说明）

- 运行时限额按工具来源粗分（MCP / `fetch_webpage`）；重定向仅复核域名与私网字面量，未做二次 DNS 私网解析。
- 定时 Agent 仅在应用进程存活时触发，不补跑 / 不重试；窗口全关时审批超时按拒绝。
- 审计账本不自动清理；尾部截断不可检出。
- 隔离网页仅桌面端；纯 Web 降级。
