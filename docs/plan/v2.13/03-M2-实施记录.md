## 2. 关键行为

1. 求值顺序：系统硬拒绝 → 策略 deny → 权限记录 deny → 模式 → 策略 allow → 持久授权 → 默认询问。
2. `smart_approve` 的 `dangerAllow` 对桌面控制类工具（键鼠 / 启动 / 关窗 / 窗口焦点）**不生效**；只允许逐次审批或 `full_access`。
3. 策略 `allow` 只放宽 write 类；read 默认放行；`plan_only` 拒绝所有变更 / 高危操作。
4. 审批绑定覆盖工具、参数哈希、cwd、环境哈希、策略哈希；执行前重算，漂移抛 409 `APPROVAL_BINDING_DRIFT`。
5. 外部代理运行前检查命令与 cwd 路径规则；审批绑定 command / args / cwd / env；设置在审批等待期间变化则判漂移。
6. 任务创建时按策略 `limits.maxSteps` 钳制步数，并把策略快照写入运行；`TaskRunView.policyHash` 由快照计算。
