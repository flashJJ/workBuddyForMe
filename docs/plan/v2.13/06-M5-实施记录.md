## 2. 工具行为

| 工具 | 级别 | 行为 |
|---|---|---|
| `browser_open` | danger | 仅 http/https；core 先做 URL / DNS / SSRF 校验，desktop 再按域名规则放行；重定向逐次复核；返回域名、URL 哈希、标题、状态 |
| `browser_read` | read | 返回页面纯文本（默认 8000，上限 20000），标注是否截断 |
| `browser_snapshot` | read | 截图 ≤1568 边长；视觉模型注入图片，否则提示改用 `browser_read` |
| `browser_click` | danger | selector 或可见文本定位，返回是否命中 |
| `browser_type` | danger | selector / 占位文本定位，可先清空，写回 input/change 事件 |
| `browser_close` | read | 关闭会话并清理 storage / cache |

- 所有工具必须带 `runId`；聊天等无运行上下文返回「仅在任务运行中使用」的降级说明（`ok:true`，不计熔断失败）。
- 纯 Web / 通道未就绪统一返回降级说明。

## 3. 会话与安全边界

1. 每个 `runId` 一个 `BrowserWindow` + 非持久 `session.fromPartition(...)`；不导入主浏览器 Cookie，不持久登录态。
2. 窗口可见，用户可观察；`will-navigate` / `will-redirect` 逐次检查协议、私网字面量与 `domains.deny` → `domains.allow`（deny 优先，allow 非空才收敛）。
3. 禁止下载（`will-download` 取消）、权限请求（全部拒绝）、新窗口（`setWindowOpenHandler` deny）、外部协议。
4. 运行终态 / 急停后由任务运行服务调用 `browser_close`；应用退出再由 `closeAll` 兜底。
5. 审计只写域名 / URL 哈希 / 原因；不记录完整 URL 或页面内容。

## 5. 已知边界

- **重定向只复核域名与 IP 字面量**：未对重定向目标再做 DNS 私网解析（防 DNS rebinding 的解析时校验只在首次 open）；需要更强边界时在 `will-redirect` 异步解析。
- `browser_snapshot` 走 `capturePage`，窗口最小化 / 被遮挡时可能截到桌面合成结果；不做离屏渲染。
- 点击按可见文本使用 includes 匹配，复杂页面建议优先 selector。
- 登录态只在本次运行内有效；关闭即清理，无法跨运行续用。
- 纯 Web 模式无浏览器能力；桌面控制通道启动失败时同样降级。
