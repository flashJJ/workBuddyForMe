## 4. M1–M5 实施清单（评审补充，不改变契约）

1. **shared**：`agent-permission.ts`（模式枚举）、`agent-policy.ts`（策略 schema / 默认值 / 逐层求值类型）、`agent-binding.ts`（binding 类型与摘要）、`audit.ts`（事件类型）；`canonical-json.ts` 抽通用函数；`task.ts` 增字段与 `policy_limit`；`scheduled-task.ts` payload 判别联合。
2. **database**：`v041-agent-governance.ts`；`audit-event-repo.ts`（append / list / verify 游标）；`task-run-repo` 增字段映射与 `originScheduledTaskId` 查询。
3. **core**：`governance/policy-service.ts`（求值 + 缓存 + 哈希）、`governance/binding.ts`（计算 / 比对）、`governance/audit-service.ts`（哈希链 + 分级失败）、`governance/workspace.ts`（路径校验）；接入 `gateToolPermission`、`task-loop`、`subagent-run-service`；`scheduler` 新增服务端循环与 agent_task 触发。
4. **web**：`/api/agent-policy`、`/api/audit/events|verify|export`；`/api/tasks` 增字段；`/api/schedules` 增 payload；任务启动对话框、设置治理分组、审计页、定时表单、审批中心 binding 展示。
5. **desktop / 浏览器**：独立临时 session、BrowserWindow 生命周期、控制通道 browser 方法组；core 新增 browser 工具组并接入策略 / 绑定 / 审计；Web 模式返回降级说明。
6. **测试顺序**：先 shared 黄金向量与策略矩阵 → core 求值 / 绑定 / 审计链 / 调度 / 浏览器边界 → web API → e2e；迁移测试与 v2.12 既有单测必须全绿。

## 5. 产品口径（已确认）

| # | 事项 | 结论 |
|---|---|---|
| Q1 | `full_access` 是否允许无人值守 | **不允许**；不进无人值守白名单 |
| Q2 | 审计账本本版是否清理 | **不清理**；保留完整链，导出归档后置 |
| Q3 | 无人值守运行边界 | **应用进程存活期间**；不做开机自启；窗口全关审批超时拒绝 |
| Q4 | 五档模式适用范围 | **仅桌面任务运行**；聊天 / 协作按 `defaultMode` |
| Q5 | 桌面 danger 与策略自动放行 | **永不自动放行**；逐次审批或 `full_access` |
| Q6 | 隔离网页会话 | **进本版 M5**；独立会话、不共享主浏览器登录态、Web 模式降级 |

**2026-10-31 产品口径确认：六项均按选择采纳**，M0 正式冻结，进入 M1。里程碑调整为 M4 定时 Agent、M5 隔离网页、M6 验收与发布。
