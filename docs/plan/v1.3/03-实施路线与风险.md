# v1.3 实施路线与风险：M0–M5 合同式任务板

> 每条任务带可机械验证完成标准。顺序：M0 坐标+FTS 基座必须先行（后续全部依赖坐标与第二召回通道）；M1 混合检索/重排是编译层的消费前提；M2 编译层最重；M3 引用与治理依赖编译产物；M4 调度让编译可日常运行；M5 eval+伴随翻译+封版收尾。每里程碑一个提交批次，批间保持 typecheck/lint/单测/e2e 全绿。
>
> 分支：`feature/v1.3-knowledge`（从 main `9ff38c7` 切出；基线 tag `v1.2.0`）。

## M0｜坐标与索引基座（v017）

| # | 任务 | 完成标准 |
|---|---|---|
| T0.1 | **中文 FTS 方案 spike 固化**：用仓库 better-sqlite3（SQLite 3.53.2）跑 trigram 与 unicode61+uni-gram 基准表（2 字词/3 字词/中英混合/型号编号/索引体积） | 基准脚本与结论入 docs/开发记录；实测已得：trigram 2 字词不中、uni-gram 2 字词命中且中英兼容；最终选 unicode61+`tokenizeForFts` uni-gram |
| T0.2 | 纯函数 `tokenizeForFts`/`buildFtsQuery`（CJK 逐字插空格、拉丁数字保留整词小写、FTS 特殊字符转义、空串安全） | 单测 ≥15 例（纯中文/中英混/型号 `qwen2.5:7b`/连字符/引号注入/空白）；中文 2 字词在真实虚表可命中 |
| T0.3 | v017 迁移：document_chunks 加 page_no/paragraph_no；建 chunks_fts 虚表与 chunk_id/kb_id 列；document_summaries/knowledge_entities/mentions 三表 + documents 编译状态列（02 §2） | 迁移幂等单测（旧 v016 库直升：列存在旧行为 NULL、空 FTS、三表空）；老库检索结果与 v1.2 一致 |
| T0.4 | 提取结构：extractDocumentText 返回 blocks（字符偏移+pageNo+paragraphNo）；PDF 复用 readPdfPageTexts 记页偏移；纯函数 `mapChunkCoordinates` | 给定 blocks+slices 的坐标映射单测（跨页取起始页、无页格式回落 null、段号连续）；PDF 摄取后 chunk 带正确页码 |
| T0.5 | chunk 仓储扩坐标列；ingestion 事务内同步 chunks_fts（删旧/重灌）；`rebuildFts(db)` 全量重灌 | 摄取后 FTS 可按 2 字中文词命中该 chunk；重传文档后旧 FTS 行不残留；rebuild 幂等 |
| T0.6 | 回归核对：retrieval.test、critical-path ⑤ RAG e2e、备份恢复（向量/派生不导出契约） | 全绿；备份归档不含 fts/编译表；恢复后检索不报错（空 FTS 回落） |

## M1｜混合检索与重排

| # | 任务 | 完成标准 |
|---|---|---|
| T1.1 | 向量召回候选化：candidateN=20、sim=1-distance/2、MIN_VEC_SIM 阈值（默认 0.55，可配） | 阈值纯函数单测；低相关不入候选；无阈值时行为对照旧 top4 有测试 |
| T1.2 | FTS 召回 `recallFts`（kb 过滤、bm25 归一化、topN） | SQL 注入用绑定参数；中文型号/编号查询命中；空 FTS 表返回空不抛 |
| T1.3 | 纯函数 `reciprocalRankFusion(k=60)`（加权、同 chunk 合并、稳定排序） | 单测：单路退化/双路一致/权重/同分稳定/空输入 |
| T1.4 | `diversify`（每文档上限 3）+ 预算自适应装配（候选池→fitContextBlock 预算决定条数，上限 8） | 单测；实际注入条数随预算变化且编号连续；critical-path RAG 引用数断言不回归 |
| T1.5 | 规则重排纯函数 `ruleRerank`（双通道命中/文档名/连续短语/词覆盖率加权，权重常量） | 单测锁定排序；构造用例证明精确词问题经 FTS+重排排名高于纯向量 |
| T1.6 | retrieval-service 重构为「recall→fuse→diversify→rerank」编排（每文件 ≤300 行）；设置 hybridEnabled 开关（默认 true，关则纯向量=旧行为） | 关掉混合检索结果严格等同 v1.2 通道；web 单测/集成/e2e 全绿 |
| T1.7 | 知识检索设置区第一版（混合开关、相似度阈值）；文案走 t() 中英 | 切换即时生效（PUT 设置）；英文态无中文硬编码 |

## M2｜知识编译层

| # | 任务 | 完成标准 |
|---|---|---|
| T2.1 | 无模型摘要纯函数（tldr 首实质段首句；bullets 数字/专名/定义句 top-3 原句；key_terms 高频+型号正则+停用词） | 固定样例输入输出确定性快照；选出的 bullets 必须是原文句（可回指）；空文档安全 |
| T2.2 | 无模型实体抽取（专名/型号/数字模式、normalized_name、括号中英别名归并）+ `locateMentions`（句子↔chunk/页/段 char 区间映射纯函数） | 单测覆盖型号/缩写/同句多实体/跨块映射；归一合并键测试（全半角/大小写/空白） |
| T2.3 | 编译器写入：文档级 upsert summaries/entities/mentions，世代事务（插新→删旧→更新 compiled_at/generation），(kb,normalized_name) 去重累加 mention_count | 仓储单测：重复编译幂等、实体跨文档归并、世代换代后旧产物不可见、编译失败不影响 chunk |
| T2.4 | 实体/摘要的查询仓储（按 normalized_name/别名精确命中、key_terms 包含命中、实体带出处 mention） | 仓储单测；未编译库查询返回空不抛 |
| T2.5 | 编译优先检索路由：查询抽词→实体/摘要命中→高置信静态事实（≤2 实体+1 摘要，带原句出处）前置注入；未命中/未编译零差异回落 | 纯函数选择器单测（上限、去重、回落）；golden 样例证明静态命中缩短定位；关编译=旧链路 |
| T2.6 | 可选 LLM 增强通道（compileWithLlm 默认关、模型选择、zod 校验 JSON、单文档预算/超时、失败降级规则产物并标记 extractor） | mock 模型单测（合法/畸形 JSON/超时三态）；未配置模型不产生额外调用；降级后仍有规则产物 |

## 测试策略

- **纯函数密集单测**（本版的质量主战场）：tokenize/FTS query、坐标映射、RRF、diversify、ruleRerank、规则摘要/实体抽取/locateMentions、冲突检测、世代选择——全部零 I/O、固定输入快照，行/分支覆盖目标 ≥95%（进 vitest 门槛，沿用 v1.1 压缩模块先例）。
- **仓储/迁移测试**：v017 幂等与老库升级；FTS/向量/编译三索引同事务一致性；世代换代可见性。
- **集成/e2e**：扩展知识库 e2e——PDF 摄取→编译完成→精确词问答命中→引用带页码；文档替换→旧内容不命中；关混合开关回退旧行为。
- **eval 门禁 + 反向验证**：knowledge golden 进 scripts/eval，CI 可跑（mock 模型/本地规则通道，不依赖外网）；每个增强开关配「关掉就退化」取证（v1.1 eval 自证规则）。
- **不引入视觉回归框架**：治理/实体 UI 以功能 e2e 与单测覆盖。

## 风险与回滚

| 风险 | 概率 | 影响 | 缓解 / 回滚 |
|---|---|---|---|
| FTS uni-gram 索引膨胀拖慢大库/迁移 | 中 | v017 迁移与写入变慢 | FTS 为可重建派生表，v017 只建表不灌旧数据，旧 chunk 走「首次重建/懒填充」；T0.1 基准先量体积；膨胀超预算则只对「类字母数字 token + CJK bigram」收窄分词（仍是纯函数改动） |
| 规则抽取噪声实体过多 | 高 | 实体表脏、静态层误命中 | 保守阈值+只把高置信实体注入上下文（默认上限 2）；实体仅建议不自动改文档；LLM 通道可选提纯；提供「清空编译产物」回落到纯 chunk 检索 |
| LLM 抽取质量不稳/成本 | 中 | 编译慢、摘要失真 | 默认关闭；bullets 只取原句不允许模型造新句；zod 校验+预算+超时；任何失败降级规则产物；设置明示成本 |
| 混合检索反而拉低既有 RAG 成绩 | 中 | 回答质量回归 | 三开关（hybrid/rerank/compile）均可独立关，关 hybrid 严格等同 v1.2；T5.3 基线对照是合并红线，不达标不封版；critical-path ⑤ 保持断言 |
| 编译与对话争用本地模型/嵌入限流 | 中 | 问答变慢 | 单并发队列、编译可取消、问答优先（编译任务让位实时检索）；规则通道零模型调用 |
| 页码映射跨页/多栏 PDF 不准 | 中 | 引用页码错 | 坐标只标起始页且允许 null；OCR 文档页码标注「可能偏差」；T3.2 不强依赖页码正确性，段落/原文始终可见 |
| v017 老库升级风险 | 低 | 现有知识库不可用 | 纯加法迁移 + 旧坐标 NULL + 派生表懒重建；迁移四分支单测；备份恢复契约不变（升级前用户可导出） |
| 实体/关系设计过早定型 | 中 | v1.4 返工 | 本版不建显式关系边表，仅 mention 共现；schema 留 kind/aliases 最小集；关系表延到 LLM 通道成熟版本 |

## Non-Goals 复核（与 README §2 一致）

无云端知识服务/多用户；无多智能体（v1.4）；无新重型依赖（FTS5 内置）；编译产物/向量不进备份；无知识图谱画布；页码首期仅 PDF；无跨语言 query 改写；不自动删除用户资料；不做全局实体模糊合并写库（仅建议）。
