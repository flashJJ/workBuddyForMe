# v2.10 M5：可扩展——验收记录

> 状态：✅ 已完成（2026-10-29）
> 范围：[M0 契约](00-M0-契约冻结.md) 的能力包清单/校验/安装/启停/卸载、示例包、插件管理页、外部代理接口缝。
> 未接入：workflow / pet-action / event-script / report-widget 四类 effect；外部代理具体实现（DSH/ACP/Codex/Claude Code）。

## 1. 交付

| 项 | 落地 |
|---|---|
| 清单契约 | `wbfm-capability.json` + `payload/**`；`capabilityManifestSchema` 校验 id/version/kind/permissions/entry/dependencies/checksums |
| 校验 | ZIP 结构、路径穿越、checksums 全覆盖与逐一 sha256、必需权限、依赖版本、同 id 冲突；全部 fail-closed |
| 存储 | 迁移 v039 `capability_packs`；包文件在 `capabilities/<id>/` |
| 生命周期 | install（校验+落盘+建行+自动启用，失败回滚）；enable/disable 成对 effect；uninstall 先撤销再清理 |
| effect | `skill`：复制 payload 到 `skills/<name>/` + reconcile；`mcp`：读取 server.json → `createServer/removeServer` |
| API | `/api/capabilities`、`/install`、`/:id/enable`、`/:id/disable`、`DELETE /:id`、`/sample` |
| UI | `/capabilities`：上传安装、权限/状态/effect/错误、启停、卸载、示例包下载；侧栏新增「能力包」（11 项） |
| 外部代理缝 | `SubagentProvider` 接口 + 注册表（默认无实现、不影响启动）；`available=false` 时不阻断核心 |
| 示例包 | 内置 `capability-demo` 技能（current_time 工具），可下载/安装/停用/卸载 |

## 3. 与 M0 的偏差

1. **kind 覆盖**：清单层保留 6 类；本期只实现 `skill` / `mcp`，其余安装明确 422，不伪装生效。
2. **签名**：清单可带 `signature`，本期只记录不验证（checksums 已提供完整性校验）。
3. **外部代理**：只落接口与注册表，不接具体 DSH/ACP/Codex/Claude Code 实现；默认关闭。
4. **浏览器/电脑使用**：沿用现有工具权限闸门，未作为能力包接入 browser-use/computer-use。
5. **能力包健康/日志**：列表展示 `lastError`；独立日志文件与健康检查列入后续版本。
