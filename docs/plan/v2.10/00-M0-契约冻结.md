# v2.10 M0：能力包与可选外部代理契约冻结

> 状态：已实现（v2.10，2026-10-29）
> 范围：能力包清单/校验/安装/启停/卸载、示例包、插件管理页；外部代理最小接口缝（默认关）。
> 不做：远程市场、任意 npm 安装、自动更新、全套 Cordis 插件框架、跨平台 ACP/SDK。

## 1. 能力包清单（`wbfm-capability.json`）

```json
{
  "id": "com.example.weekly-review",
  "version": "1.0.0",
  "kind": "skill",
  "name": "周复盘助手",
  "description": "……",
  "permissions": ["skill:install"],
  "entry": "payload/skill.json",
  "dependencies": [{ "id": "com.example.base", "version": "1.0.0" }],
  "checksums": { "payload/skill.json": "<sha256>" }
}
```

- `id`：`^[a-z0-9][a-z0-9._-]{2,80}$`，全局唯一。
- `kind`：`skill` / `mcp` / `workflow` / `pet-action` / `event-script` / `report-widget`。
- `permissions`：`skill:install` / `mcp:connect` / `workflow:install` / `pet:action` / `events:write` / `report:widget`；未知权限拒绝。
- `entry`：ZIP 内相对路径，必须在 `payload/` 下且存在于 `checksums`。
- `checksums`：覆盖 `payload/` 下全部文件；缺失/多余/哈希不符拒绝安装。
- 签名可选：本期不验证签名，只记录清单；后续可扩展。
- ZIP 结构固定：根目录 `wbfm-capability.json` + `payload/**`，不允许其它散落文件。

## 2. 生命周期

```
install（校验 → 落盘 capabilities/<id>/ → 建行 disabled → 自动 enable）
  enable（按 kind 注册 effect，失败回滚安装）
  disable（撤销 effect，保留包文件与记录）
  uninstall（先 disable → 删包目录 → 删记录）
```

- 注册即 effect：每种 kind 的 enable/disable 必须成对；失败 fail-closed（不留下半启用状态）。
- `effect_ref` 记录副作用句柄（技能目录名 / MCP server id）。
- 依赖：要求依赖包已安装且版本匹配（写 `version` 时精确匹配）；缺失拒绝。
- 同名技能 / 同 id 包冲突拒绝。
- 停用/卸载在内存与磁盘同时回滚，无需重启。

### 2.1 本期实现的 kind

| kind | effect | 撤销 |
|---|---|---|
| `skill` | 把 `payload/` 复制到 `skills/<skill name>/`，`skills.reconcile()` | 删除该技能目录并移除技能状态行 |
| `mcp` | 读取 `payload/server.json`，`mcp.createServer(...)` | `mcp.removeServer(serverId)` |

`workflow` / `pet-action` / `event-script` / `report-widget` 在清单层保留，但安装返回 422「该能力类型尚未接入」，避免假装生效。

## 3. 存储

| 路径 | 用途 |
|---|---|
| `capabilities/<id>/` | 解包后的清单与 payload（唯一真源） |
| `capability_packs`（迁移 v039） | id/kind/version/name/permissions/manifest/status/effect_ref/last_error/时间 |
| `spills/` | v2.9 大输出溢出（与能力包无关） |

## 4. API 与 UI

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/capabilities` | 列表（状态/权限/effect/错误） |
| POST | `/api/capabilities/install` | multipart ZIP 安装（校验+自动启用） |
| POST | `/api/capabilities/:id/enable` / `disable` | 启停 |
| DELETE | `/api/capabilities/:id` | 卸载 |
| GET | `/api/capabilities/sample?kind=skill` | 下载示例包（示例技能） |

- `/capabilities` 页面：能力列表、权限徽章、状态、错误、启停/卸载、上传安装、下载示例包。
- 侧栏新增「能力包」（导航 11 项）。
- 技能/MCP 生效后仍走各自既有入口（技能设置、MCP 设置、对话工具）。

## 5. 外部代理缝（默认关）

- `SubagentProvider` 接口：`{ id, label, available(), run(input, signal) }`；提供方注册后才可用。
- 本期只落接口与注册表，不接入 DSH/ACP/Codex/Claude Code 实现；缺失时核心功能不受影响。
- 未来接入必须复用统一预算、审批与证据回传；不共享密钥。

## 6. 验收

1. 安装示例技能包后，技能列表出现且对话可注入；停用后效果消失，无需重启。
2. 未声明权限/未知权限/校验和不符/缺依赖的包被拒绝（fail-closed）。
3. 同一 id 重复安装 409；卸载后文件与记录均清理。
4. `mcp` 包启用后 MCP 服务器出现，停用后断开并移除。
5. 外部代理接口在无实现时不影响启动与核心功能。
6. `pnpm check`、四层测试、300 行门禁通过；迁移只做加法。

## 7. Non-Goals

- 不做远程市场、自动更新、任意 npm 安装。
- 不做 Cordis profile/bundle/patch 全量插件化。
- 不把能力包做成可执行任意代码的入口；本期只登记既有资源类型。
