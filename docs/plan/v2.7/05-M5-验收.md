## 3. 与 M0 的偏差

1. **待机节奏**：`workIdlePacing` 字段与默认值保留，但未接角色控制器（Live2D idle 计时器需改控制器签名）；本版不做 UI 入口，列入 v2.8/v2.9 评估。
2. **气泡点击**：气泡保持 `pointer-events-none`（不破坏点击穿透）；深链通过双击头部/右键菜单进入。若后续需要气泡内审批按钮，再扩展命中盒。
3. **桌面控制授权**：未并入审批中心（P1）；当前仅工具确认与 Flow 人工/工具节点。
4. **会议信号**：未纳入 WorkSignal（P1）；会议仍由舞台/会议页自身状态展示。
5. **运行归属**：Task 仍绑定页面 SSE，关页中断；v2.8 迁移为服务端持久 job。
