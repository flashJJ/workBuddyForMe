## 2. 由决策派生的实现口径

### 2.1 RunGraph

- 图只读，不做乐观节点；节点必须先有事件/落库，再进入图与光线。
- 节点身份稳定：同一业务实体（task step、flow node、handoff、meeting message）只更新状态，不重复建节点。
- 历史加载以 snapshot 为基线，不补演光线；实时 SSE 只追加基线之后的新身份。
- 未知/截断 payload 降级为通用节点，不抛错、不阻塞整图。
- 图读取失败按运行隔离，保留已缓存图；重试只请求当前运行，不写入对话转录。
- 节点状态前 8 个沿用 `RunOutcome`；节点级额外允许 `skipped` / `unknown`，不参与运行态统计。

### 2.2 会议事件

- `session_events` 增加 `meeting` scope，`scopeId = meetingId`。
- 事件类型：`meeting_turn_start`、`meeting_message`、`meeting_status`；载荷只带图需要的字段，不复刻完整会议记录。
- 写入发生在会议落库成功之后；写入失败只记录警告，不影响会议继续。
- `/timeline` 的 scope 列表增加 `meeting`；旧事件/旧备份不受影响。
- 会议图入口：`GET /api/meetings/:id/run-graph` + 会议页图；会话图不混入会议根。

### 2.3 Light UI

- API 形状参考上游：`createLightLayer(root?)` 返回 `emit / pause / resume / destroy`；`emit` 返回 `{ finished, cancel }`。
- 锚点在发射时解析：元素、坐标或返回元素的函数；目标缺失返回 `missing-anchor`，不射向附近节点。
- 默认 `duration=1200ms`，两端慢、中段快；`seed` 可固定轨迹。
- 同时最多 12 条；超出时丢弃新发射并返回 `cancelled`，不排队。
- `prefers-reduced-motion` 直接完成不飞行；`document.hidden` 暂停，恢复可见继续；`destroy()` 取消全部并移除 SVG/监听器。
- 颜色只从语义 token 映射，不写死十六进制；同一车道同色。
- 流动边框只挂活跃节点；必须同时有文字状态，不只靠动效表意。

### 2.4 阶段计划

- 阶段数据：`StagePlan { steps: StagePlanStep[]; activeStep: number | null }`；`StagePlanStep` 含 `title / modelId / skillNames / goal / deliverables`。
- `modelId` 引用本仓 `models.id`，不是 provider/modelId 组合；`null` 表示清除会话覆盖、回落到助手/系统默认。
- 来源优先级：会话自有 > 助手显式 `stagePlan` > 角色卡默认 `stagePlan` > 空；只在目标为空时复制，任何一层已有内容都不被下层覆盖。
- 内置预置：6 张内置角色卡各自带默认阶段（干练同事/元气搭子/沉稳顾问/暖心伙伴/调研先锋/学习教练），不新增内置助手。
- 开关：创建会话时若助手有阶段计划，复制一行 `conversation_stage_plans`；无则按角色卡默认补齐；仍为空则不建行。
- 校验：shared Zod Schema + core service 双层；API 入参失败 422；技能不存在/未启用拒绝；模型不存在或非 chat 拒绝。
- 提示词：包含阶段名、目标、技能真实路径、交付要求，并要求沿用当前会话上下文；启用技能命令时只用第一个技能的 slash command。
- 载入任务：非空草稿阻止并保留原文；运行中禁止改阶段/载入；载入只准备任务文本，不自动发送。
- 阶段模型：切到带 `modelId` 的阶段写入 `conversations.model_id`；切到无模型阶段清空该列；不改助手绑定。
- 阶段状态：只高亮 `activeStep`，不把选过/跳过标成“已完成”。

### 2.5 迁移与备份

- `v044` 只做 `CREATE TABLE IF NOT EXISTS` 与 `ADD COLUMN`；建 `conversation_stage_plans`，给 `assistants`/`character_cards` 加 `stage_plan_json`，给 `conversations` 加 `model_id`。
- `LATEST_SCHEMA_VERSION` 43 → 44；旧迁移测试的版本断言与 applied 数组同步。
- 备份 schema 保持 7，新增 `stagePlan` / `modelId` 字段为可选；旧备份缺字段时按空计划/默认模型恢复，不报错。
- conversations 轨每个会话序列化 `stagePlan` 与 `modelId`；events 轨助手与角色卡序列化 `stagePlan`；不新增备份轨。
