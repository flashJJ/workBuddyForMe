- 发布动作（push / PR / tag / GitHub Release）在本地验收通过后执行，执行前向用户确认。
- 本机 3100 被 Docker 占用，Web e2e 继续使用 `WBFM_E2E_PORT` 空闲端口；CI 默认端口不变。
- 本机环境 `CI=true` 会让 electron-builder 触发隐式发布，且 Electron 缓存缺 45.0.0 时直连 GitHub 超时；桌面冒烟/安装包改用 `CI=false` + `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 后通过。CI 流水线不受影响。
