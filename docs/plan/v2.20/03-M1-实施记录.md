## 2. 投影口径

- 根节点：`root:<conversation|meeting>:<rootId>`，仅作为边锚点，状态 `unknown`。
- 节点：chat 消息/工具、task run/step、flow run/node、agent run/phase/handoff/review、meeting turn/message/status、artifact、error。
- 边：`root_to_node`、`conversation_to_run`、`run_to_node`、`node_to_node`、`round_to_handoff`、`meeting_to_turn`、`turn_to_message`、`node_to_artifact`、`node_to_error`。
- 身份：同一业务 id 只更新状态；重复事件按节点 id 幂等。
- 排序：`createdAt → scope → seq → id`（seq 只在同 scope 内比较）。
- 限制：默认 500、最大 1000；超限保留根节点 + 最近 `limit-1` 个节点，`truncated=true`，边只保留两端仍存在的。
- 未知/缺失载荷：不抛错、不造空节点；能识别状态时按状态映射，否则 `unknown`。
- 会议：独立 `rootKind='meeting'`，会话图过滤掉 meeting 事件。
