## 2. 行为口径

- 阶段条只在会话有阶段计划时显示；`activeStep=null` 时载入任务禁用。
- 切换阶段写 `activeStep`，保存走 `PUT /api/conversations/:id/stage-plan`，失败提示服务端原因。
- 载入任务：无当前阶段/目标为空/草稿非空/流式中均不请求；成功后只把 `taskText` 写入输入框并聚焦，不自动发送。
- 非空草稿时点击载入提示「输入框已有内容，先发送或清空再载入任务」；目标为空的按钮直接禁用并在 title 说明原因。
- 模型切换写当前阶段的 `steps[activeStep].modelId`，同一 PUT 同步 `conversations.model_id`；切回「跟随助手默认」清空覆盖。
- 编辑对话框标题全部非空才允许保存；删除阶段时 `activeStep` 同步修正或清空；保存 422 在对话框内与 toast 同时展示。
- 流式中阶段条 chips/编辑/载入/模型选择全部禁用；编辑入口另外给出「运行中」提示。
- Composer 不传受控 props 时保持内部状态；传入后父级草稿与输入框双向同步，`focusToken` 变化即聚焦输入框。

## 4. 与 M0 契约的偏差

1. **模型切换复用阶段 PUT**：未新增会话模型专用接口；切换写入当前阶段 `modelId`，由服务端在同一事务同步 `conversations.model_id`，与 M4 服务口径一致。
2. **无计划不渲染阶段条**：聊天页暂不提供「为空会话创建阶段计划」入口；计划来源仍是助手/角色卡默认或 API。自定义空计划入口留待后续版本评估。
3. **`useChatModelView` 位置调整**：为控制 `features/chat/hooks` 目录预算与 `ChatPage` 行数，移入 `features/chat/stage/`，公开入口不变。
4. **e2e 自带 mock 供应商**：不依赖同数据根其他套件的执行顺序；首次运行会创建 `v220-stage-mock` 并在结束时清理。
5. **本地端口**：开发机 3100 被 Docker 占用，e2e 通过 `WBFM_E2E_PORT` 改用空闲端口；CI 仍走默认端口与 `next start`。
6. **目标为空时按钮禁用**：此时无法点击触发 `noGoal` toast，改由 `title` 提示；服务端仍保留目标校验。

## 5. 已知限制

- 阶段技能选择依赖 `useSkills` 的 enabled + manifest 结果；暂不展示技能描述。
- 阶段条不含拖拽排序与阶段跳转快捷键。
- e2e 未覆盖流式中的锁定路径（单测已覆盖）。
- 无计划的旧会话在 UI 上无阶段入口，需要助手/角色卡或 API 先落计划。
