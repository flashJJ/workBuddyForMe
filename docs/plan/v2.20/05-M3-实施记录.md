## 2. 行为口径

- `createLightLayer(root?)`：默认挂到 `document.body`，SVG `position:fixed`，不阻塞交互。
- `emit` 立即返回 `{ finished, cancel }`；目标缺失时等待一帧重试一次，仍缺失返回 `missing-anchor`。
- 同 id 运行中重复发射 → `cancelled`；同时最多 12 条；`duration` 默认 1200ms，范围 120–4000ms。
- `prefers-reduced-motion: reduce` → 不创建轨迹，直接 `arrived`。
- `document.hidden` → 自动暂停；恢复可见继续；`pause()/resume()` 手动控制同一状态机。
- `destroy()` 取消全部未完成光线、移除 SVG 与 visibilitychange 监听；React 只在挂载/卸载持有图层。
- 光线源：优先聊天消息气泡 `[data-message-id]`；无气泡时用图中父节点卡片；目标为节点卡片。
- 新节点判定：面板首次快照只建立基线，不发射；后续新增身份每帧最多按图层上限发射。
- 实时追加：以快照 `generatedAt` 为历史基线，之前收到的帧不补演；已终态节点不被迟到帧回退。
- 会议轮次：`turnIndex` 由服务端落库消息数生成，实时与快照节点身份一致；旧事件回落到 scope 内 `seq`。

## 4. 与 M0 契约的偏差

1. **实时追加复用既有 SSE 旁路**：聊天/协作/会议 hook 在收到帧后 `publish` 到模块总线，图面板 `subscribe`；契约 §4.2 的「不新增 SSE 端点」保持不变。
2. **快照校准频率改为 10 秒**：M2 为 2 秒轮询；M3 实时帧已覆盖新节点，10 秒只做服务端权威校准。timeline 入口关闭轮询，保持契约的快照 + 手动刷新。
3. **光线源增加父节点兜底**：优先消息气泡；任务模式/新会话没有可见气泡时，用图中父节点卡片指向新节点，避免 `missing-anchor` 丢光。
4. **实时 reducer 只覆盖 chat/agent/meeting**：当前 UI 没有独立的 task/flow 流消费方；task/flow 节点由 10 秒快照补齐，契约 §4.2 的 scope 范围未扩大。
5. **`meeting_turn` 载荷新增可选 `turnIndex`**：M0 契约 §5 未列该字段；新增是为让实时帧与快照投影使用同一节点身份，旧事件不受影响。
6. **会议旧事件身份回落 `seq`**：原先 `autoRounds` 作为兜底会让 manual 模式多轮都落到 `turn:0`；M3 修正为 `turnIndex > seq`，属 M2 投影缺陷修复。

## 5. 已知限制 / M4 待办
