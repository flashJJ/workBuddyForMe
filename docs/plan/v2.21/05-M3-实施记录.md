## 1. 决策

1. **分支事件 payload 带父会话 id**：投影时以 `parentConversationId` 过滤，避免把嵌套分支事件串到父图。
2. **父图只收直接分支**：`run-graph-service` 用 `listByParent(id, true)` 取分支 id 再读事件；深度 2 的分支只出现在其父会话图中。
3. **子会话运行不重放聊天事件**：父图用分支节点 + 子会话占位节点 + 回传节点表达；细节回子会话查看。
4. **evidence 产物只计数量**：M3 投影 evidence 的 `artifacts.length` 到回传节点摘要；逐项产物节点留 M4 前补。
5. **事件写入 best-effort**：`branch-events.ts` 捕获异常并 `console.warn`，不影响派生/运行/取消结果。
6. **预算随列表返回**：`GET /api/conversations/[id]/branches` 增加 `budget`（契约原为 `{branches}`，属附加字段）。
7. **设置字段独立类型**：`AppSettings` 主类型保持 300 行门禁，新增 `BranchLimitSettings` 供设置页与 PUT 使用。
8. **不发回传消息**：父会话仍不插入消息，回传只在分支面板/图里以「需核对」卡片展示。

## 4. 偏差与后续

1. **预算为附加字段**：列表接口返回 `budget`，未单开端点；已在契约 §3 之外登记。
2. **产物节点未逐项**：回传节点只显示「产物 N」；逐项 ArtifactRef 需从消息 tool_trace/artifacts 提取，留 M4。
3. **子会话节点为占位**：不重放子会话 chat 事件；状态与分支同步，展开细节由「打开子会话」完成。
4. **实时帧不含分支**：分支状态靠面板 5s 轮询与图 10s 快照；未接入 `runGraphLiveBus`。
5. **重启恢复未做**：与 M2 偏差一致，M4 验收前把 `running/waiting` 收敛为 `interrupted`。
6. **设置项无独立校验反馈**：保存失败只显示通用文案，原因码文案随 API 错误透出。
