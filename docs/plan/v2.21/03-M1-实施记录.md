## 2. 行为口径

- 八态：`queued/running/waiting/succeeded/failed/cancelled/interrupted/budget_exceeded`；终态不可回 `running`。
- 四项默认：并发 3、深度 2、每父未归档 6、会话树 200k Token；默认值在 shared 常量，设置项在 M2 接线。
- 准入顺序固定；环检测用「新子会话 id 是否已在祖先链」防御性判断。
- 预留：`reserveBranchTokens` 返回 `max(1, 预估)` 与剩余预算的较小值；剩余为 0 返回 0。
- 删除只删 `conversation_branches` 关联；子会话与消息保留为普通会话。
- `archived_at` 与状态正交；`listByParent` 默认排除归档，`includeArchived=true` 可查。
