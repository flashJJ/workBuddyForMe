# v2.21 M0 契约冻结：自由分支会话与回传

> 状态：草案（决策已定，v2.20 已发布，待 M0 正式冻结）
> 关联：[01-M0 决策记录](01-M0-决策记录.md) · [v2.21 方案](README.md)
> 原则：本契约冻结后实现不得静默偏离；偏离登记在实施记录并说明影响。

## 1. 数据模型

### 1.1 新表 `conversation_branches`（迁移 `v045`）

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT PK | 分支 id |
| `parent_conversation_id` | TEXT NOT NULL | 派生来源会话；FK `conversations(id)` ON DELETE CASCADE |
| `child_conversation_id` | TEXT NOT NULL | 子会话；FK `conversations(id)` ON DELETE CASCADE |
| `root_conversation_id` | TEXT NOT NULL | 会话树根；FK `conversations(id)` ON DELETE CASCADE |
| `title` | TEXT NOT NULL | 分支标题（默认取目标首行，≤40） |
| `goal` | TEXT NOT NULL | 派生目标；≤4000 |
| `status` | TEXT NOT NULL | 八态枚举，默认 `queued` |
| `status_reason` | TEXT NULL | 失败/预算/中断原因 |
| `return_evidence_json` | TEXT NULL | 终态 evidence；损坏时回落 null |
| `reserved_tokens` | INTEGER NOT NULL DEFAULT 0 | 准入预留；结束结算后归零 |
| `depth` | INTEGER NOT NULL | 根为 1；最大 2 |
| `archived_at` | TEXT NULL | 归档时间；非 NULL 表示已归档 |
| `created_at` / `updated_at` | TEXT NOT NULL | ISO 时间 |
| `ended_at` | TEXT NULL | 进入终态时间 |

索引：`parent_conversation_id`、`child_conversation_id`、`root_conversation_id`、`(parent_conversation_id, status)`。
约束：`child_conversation_id` 唯一（一个会话最多属于一个分支关系）；不改 `conversations` 核心表。

### 1.2 状态机

```text
queued -> running -> waiting -> running
queued|running|waiting -> succeeded | failed | cancelled | interrupted | budget_exceeded
```

- 终态：`succeeded / failed / cancelled / interrupted / budget_exceeded`；终态不可回 `running`。
- `waiting` 只由运行器在等待子分支/审批/外部依赖时写入；恢复后回到 `running`。
- `archived_at` 与状态正交；归档不改写终态。
- 删除运行中分支：先写 `cancelled`，停止运行后再删关联。

## 2. 上限与设置

| 设置键 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `branchMaxConcurrent` | 3 | 1–10 | 同一会话树内 `running + waiting` 分支数 |
| `branchMaxDepth` | 2 | 1–4 | `depth` 上限；根为 1 |
| `branchMaxChildren` | 6 | 1–20 | 单个父会话未归档分支数 |
| `branchTokenBudget` | 200000 | 10000–1000000 | 会话树累计 Token 上限 |

- 准入顺序：环检测 → 深度 → 子节点数 → 并发 → Token 预留；任一失败返回 `422` + 原因码。
- 原因码：`BRANCH_CYCLE`、`BRANCH_DEPTH_EXCEEDED`、`BRANCH_CHILDREN_EXCEEDED`、`BRANCH_CONCURRENCY_EXCEEDED`、`BRANCH_BUDGET_EXCEEDED`。
- 预留：创建/启动前按 `min(剩余预算, 单次预估)` 写 `reserved_tokens`；终态按实际 usage 结算并释放。
- 设置页高级区可调，恢复默认值走现有设置重置入口。

## 3. API

| 方法 | 路径 | 输入 | 输出 |
|---|---|---|---|
| POST | `/api/conversations/[id]/branches` | `{ title?, goal, autoStart? }` | `201 { branch, conversation }` |
| GET | `/api/conversations/[id]/branches` | `?includeArchived=true` | `{ branches }` |
| GET | `/api/branches/[id]` | — | `{ branch, childConversation, evidence }` |
| PATCH | `/api/branches/[id]` | `{ title }` | `{ branch }` |
| POST | `/api/branches/[id]/start` | — | `{ branch }` |
| POST | `/api/branches/[id]/cancel` | — | `{ branch }` |
| POST | `/api/branches/[id]/archive` | — | `{ branch }` |
| POST | `/api/branches/[id]/restore` | — | `{ branch }` |
| DELETE | `/api/branches/[id]` | — | `{ id }`；子会话保留 |

- 统一信封 `{ success, data }`；错误走现有 `errorCodes`。
- `autoStart=true` 时创建后立即进入运行；否则停在 `queued`，由 `start` 触发。
- 删除：运行中先停止并等待终态；只删分支关联，不删子会话与消息。
- 父会话不插入回传消息；回传以 evidence 卡片/分支列表展示，用户核对后自行汇总。

## 4. 回传 evidence

```ts
interface BranchEvidence {
  branchId: string;
  parentConversationId: string;
  childConversationId: string;
  rootConversationId: string;
  status: BranchStatus;
  summary: string;              // ≤4000
  artifacts: Array<{ id: string; title: string; kind: string }>;
  usage: { promptTokens: number; completionTokens: number; totalTokens: number } | null;
  needsReview: true;            // 固定为真：父会话先核对再汇总
  createdAt: string;
}
```

- 只在终态生成；`failed/cancelled/interrupted/budget_exceeded` 允许 `summary` 为空但必须有 `statusReason`。
- 损坏 JSON 读取回落 null，不阻断分支列表。
- 摘要与产物由运行器生成；父会话 UI 标注「需核对」，不自动重试、不自动派生。

## 5. RunGraph 扩展

| 类型 | 新增 |
|---|---|
| `RUN_GRAPH_SCOPES` | `branch` |
| `RUN_GRAPH_NODE_KINDS` | `branch`、`branch_return` |
| `RUN_GRAPH_EDGE_KINDS` | `parent_to_branch`、`branch_to_child`、`branch_to_return` |
| `RunGraphLane.kind` | `'branch'` |

- 根仍为父会话 `conversation`；分支节点挂在父会话根下，子会话 run 节点挂在其后。
- 事件：`branch_created / branch_started / branch_status / branch_returned` 写入 `session_events`，`scope='branch'`，`scopeId=branchId`。
- 历史快照只按事件投影；实时追加沿用 v2.20 帧总线；归档分支默认折叠。
- 回传节点引用 evidence 摘要与产物，`artifactUnverified` 沿用现有规则。

## 6. 迁移与备份

- 迁移 `v045-conversation-branches`：`CREATE TABLE` + 索引；`LATEST_SCHEMA_VERSION = 45`。
- 备份 schema 保持 7：conversations 轨新增可选 `branches.json`；旧归档缺文件按空数组。
- 恢复顺序：先恢复全部 conversations（父子会话都在其中），再恢复 `branches.json`；父/子会话任一缺失则跳过该分支并计数。
- 恢复时状态保持原值；`reserved_tokens` 归零，运行中状态改为 `interrupted`。

## 7. UI 状态与闸门

- 派生入口：消息右键「从此分支」、命令面板、API；创建对话框填目标/标题，默认 `autoStart=true`。
- 分支列表：状态徽标、Token、归档/恢复、取消、删除；运行中删除需确认并先停止。
- 父会话回传卡片：状态、摘要、产物、`需核对` 标记；提供「打开子会话」与「归档」。
- 上限拒绝：对话框内展示原因码对应文案；不静默失败。
- 子会话顶部显示来源：父会话标题、分支目标、返回父会话入口。
- 预算视图：按会话树聚合，展示已用/预留/上限与触顶原因。
