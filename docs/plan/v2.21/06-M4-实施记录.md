## 3. 决策

1. **备份不升 schema**：仍为 7，`branches.json` 与 `conversations.branchCount` 均为可选加法字段；旧归档缺文件按空数组。
2. **恢复顺序**：先 conversations（含父子会话），再分支；父或子会话缺失则跳过该分支并计入 `skipped.branches`。
3. **恢复状态**：保留归档与终态；`running/waiting` 改写为 `interrupted`，原因「恢复时运行中断」，`reserved_tokens=0`。
4. **重启收敛独立入口**：`recoverInterruptedBranches` 只在容器启动时调用，避免测试构造服务时误伤。
5. **真实模型 e2e 不纳入门禁**：用注入 runner 覆盖并行/失败隔离；真实模型路径留发布后观察。
6. **发布动作需确认**：push / PR / tag / GitHub Release 在本地验收通过后执行，执行前向用户确认。

### 4.1 门禁与环境说明

1. `pnpm test:unit`（turbo 全包并发）在本机两次因资源竞争失败：一次 `config` 扫描到 core 正在写的 `coverage/index.html`，一次 web worker `Channel closed`/`JavaScript heap out of memory`。逐包串行复跑全部通过；web 以 `--maxWorkers=2` 复跑 724/724。与 v2.20 M6 记录的「资源竞争型抖动」一致，不改产品代码。
2. 真实模型并行 e2e 不纳入门禁：本机无可用供应商密钥；并行/失败隔离由注入 runner 的服务测试覆盖。
3. e2e 回归修复：
   - `ops-v215` 审计锚点 `schemaVersion` 由 44 更新为 45（`v045` 迁移后的既有约定）；
   - 分支面板允许归档 `queued` 分支（运行中/等待中仍隐藏归档），与「归档优先、保留历史」一致；
   - 子会话来源条改用 `next/link`，避免测试环境未挂载 App Router 时 `useRouter` 抛错。

残余缺口（不修，记录原因）：

1. **分支事件不随备份导出**：沿用 v2.20 备份边界（conversations 轨只含 `branches.json`）；恢复后 `session_events` 为空，图车道需重新运行产生事件。
2. **`waiting` 未由运行器写入**：当前没有子分支、审批或外部依赖等待场景；重启收敛仍按契约处理 `running/waiting`。
3. **真实供应商并行 e2e 未纳入门禁**：本机无供应商密钥；回传卡片链路已由 `WBFM_MOCK_AI` 运行用例覆盖，并行/失败隔离由注入 runner 单测与 API 测试覆盖。
4. **分支实时帧未接**：面板 5s、图 10s 轮询；`runGraphLiveBus` 沿用 v2.20 范围。
5. **`budget_exceeded` 终态未写入**：预算触顶在准入阶段返回 422，不创建/不启动分支；运行中超预算仍按模型结果落终态。该状态保留在枚举中，供后续「运行中预算熔断」使用。
6. **补丁发布**：上述修复需要新 tag（建议 `v2.21.1`）才会进入安装包与自动更新通道。
