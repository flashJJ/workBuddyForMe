## 2. 状态机

```text
queued -> running -> waiting -> running
running -> succeeded | failed | cancelled | interrupted | budget_exceeded
waiting -> failed | cancelled | interrupted | budget_exceeded
```

- `waiting`：等待子分支、审批或外部依赖；恢复后回到 `running`。
- `interrupted`：宿主退出/进程中断；重启后可人工恢复或终止。
- `budget_exceeded`：会话树 Token 或子节点/深度/并发触顶，不再继续调用模型。
- 终态不可回到 `running`；重试只重试当前分支，父转录不自动改写。

## 3. 上限与准入

| 项 | 默认 | 落点 |
|---|---|---|
| 并发分支数 | 3 | 设置项 + 准入纯函数 + 仓储事务 |
| 最大深度 | 2 | 同上；派生时检查祖先链 |
| 每父最大子节点 | 6 | 同上 |
| 会话树 Token | 200k | 设置项 + 会话树聚合 + 预留 |

- 准入顺序：深度/环检测 → 并发 → 子节点数 → Token 预留；任一失败返回可读原因。
- 先预留 Token 再 await 子运行，结束按实际用量结算，失败释放预留。

## 4. 删除与归档

- 归档：只改分支状态/可见性，保留子会话与消息。
- 删除：先停止运行中的子会话；删除 `conversation_branches` 关联；子会话保留为普通会话，不级联删消息。
- 父会话与分支关联删除后，RunGraph 车道隐藏，但子会话仍可单独打开。
