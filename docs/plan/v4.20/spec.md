# v4.20 规格：快——首答与长会话体感

> 状态：M0 契约冻结（2026-11-22）
> 选题：[README.md](./README.md) · 契约：[contracts.md](./contracts.md) · 任务：[tasks.md](./tasks.md)
> 上游：v4.19 已发布（`v4.19.0`）
> 原则：每项可独立验收；迁移必须可回滚；不新增无法随 standalone 打包的依赖

## 1. 背景

v4.19 把功能欠账清完，并补了流式 TTS、在线朗读与寒暄快路径。当前剩下的主要体感问题是：

1. 首字、首段与完成三段没有统一指标，无法判断优化是否有效；
2. 首字等待没有预算与提示，用户只能干等；
3. 长会话一次性渲染全部消息，滚动与流式追加缺少预算；
4. 冷启动与长文本在窄窗下的表现没有回归基线；
5. 语音与评测还有两项小遗留，可以顺手收口。

## 2. 目标

### 2.1 分段指标与本地报告

- 采集四个指标：冷启动、发送→首字、首字→首段、完成耗时；
- 指标只在本机记录，不含正文、令牌与绝对路径；
- 每次性能运行写入 `test-results/perf/report-<ISO>.json` 与 `latest.json`，保留最近 20 份；
- 报告可由脚本复算，同一数据集两次运行的指标差异在容差内。

### 2.2 首字预算与提示

- 相对基线：客户端维护最近 20 轮首字耗时 P50（localStorage）；
- 阈值 = 有基线时 `min(P50 × 1.5, 10s)`，无基线时 10s；
- 超过阈值在本轮给出非阻断提示：「停止 / 换更小模型 / 缩减上下文」；
- 每轮最多提示一次，可关闭；不静默切换模型或截断上下文。

### 2.3 长会话渲染

- 默认按需分块挂载：先渲染最近 50 条，向上滚动分批加载；
- 消息数超过 200 时切换虚拟化窗口渲染；
- 流式追加、自动回到底部、深链定位与高亮、编辑重发、复制行为保持不变；
- 提供设置开关 `chatVirtualizationEnabled`（默认开）；关闭后行为与 v4.19 一致；
- 500 条消息会话作为性能验收基线。

### 2.4 冷启动与长文本

- 识别启动关键路径，非首屏模块延迟加载；
- 1024 / 1280 / 1440 三档 + 长文本场景无横向溢出、无遮挡、无不可点击；
- 冷启动指标进入本地报告，不设绝对值门禁，只做相对回归。

### 2.5 并入项

- 语音：寒暄快路径跳过回合后记忆提取；Edge TTS 在解码器支持增量时改为边收边解码；
- 回放对比：CI 增加 PR 非阻断对比任务，写入 Job Summary，不改变阈值门禁；
- 知识动作：「以引用新建任务」打开 `/tasks?draft=<标题 + 深链>`，只预填目标，不自动提交；
- 备用链：上限从 3 放宽到 5，单轮切换次数仍是 2；
- 健康度导出：设置页健康面板支持导出 Markdown/CSV，不含正文。

## 3. 非目标

- 不做统一记忆治理、Controller Pipeline、DAG 并行、视觉巡检 L2/L3；
- 不做模型自动降级（首字超时只提示，不自动换模型）；
- 不做云端性能上报；
- 不为性能指标新增数据库表；
- 不重做聊天视觉风格。

## 4. 验收标准

1. 四个指标在固定数据集上可复算，报告结构稳定，隐私扫描通过；
2. 首字超过阈值时出现提示，三个动作可用且不自动执行任何降级；
3. 500 条消息会话滚动 p95 帧间隔 ≤ 20ms，无 >200ms 长任务；关闭开关后行为与 v4.19 一致；
4. 深链定位、高亮、回到底部、流式追加在分块与虚拟化两种模式下均通过 E2E；
5. 三档窄窗与长文本无横向溢出、无遮挡；
6. 寒暄轮不再产生记忆提取任务与 `memories` 事件；
7. PR 上的回放对比任务不阻断合并；
8. 知识「新建任务」只预填、不自动提交，内容不含正文；
9. 备用链最多 5 个，第 3 个之后仍不会突破单轮 2 次切换；
10. 健康度导出的 Markdown/CSV 不含正文、令牌与绝对路径。

## 6. 质量约束

- `pnpm check` 与 `pnpm verify:local` 全绿；
- 单文件 ≤300 行、目录直接文件 ≤12、循环依赖与 surface 门禁不退化；
- 性能相关逻辑优先纯函数，便于单测；
- 报告与导出遵循同一隐私约束；
- 迁移（若发生）必须可回滚并带备份校验。
