# v4.20 性能基线（相对 v4.19）

> 测量时间：2026-11-22 · 机器：win32 / x64 / 16 核 · Node 22 · 生产模式（`pnpm build:web` + Playwright）
> 结论先行：v4.19 没有分段指标，无法做数值同比；本报告用「同一台机器 + 同一场景」对比可观测性、DOM 挂载量与帧间隔。

## 1. 指标可得性

| 指标 | v4.19 | v4.20 |
|---|---|---|
| `coldStartMs` | 未采集 | 有（`wbfm:app-ready`） |
| `firstTokenMs` | 未采集 | 有（发送 → 首个非空 delta） |
| `firstParagraphMs` | 未采集 | 有（换行或累计 ≥80 字符） |
| `completionMs` | 未采集 | 有（发送 → `done`） |
| 报告 | 无 | `test-results/perf/report-<ISO>.json` + `latest.json`，保留 20 份 |

## 2. 本次实测

| 场景 | 结果 | 说明 |
|---|---|---|
| 冷启动（`/chat` 生产包） | `coldStartMs = 2605ms`（单次样本） | E2E `v420-cold-start.spec.ts`，只做相对回归，不设绝对值门禁 |
| 500 条消息滚动 | `p95 帧间隔 = 16.7ms` | E2E `v420-long-session.spec.ts`，窗口化 + overscan 10 |
| 同场景优化前 | `p95 帧间隔 = 33.4ms` | 首轮测量；后将 scroll 更新合并为每帧一次（`requestAnimationFrame`） |
| 虚拟化关闭 | 500 条全量挂载 | 行为等同 v4.19，作为功能回退对照 |
| 首字预算提示 | 注入 P50=1ms → 阈值 2ms 即触发 | E2E `v420-first-token-budget.spec.ts`，只提示不自动降级 |

## 3. 相对 v4.19 的变化

1. **DOM 挂载量**：500 条会话在窗口化下只挂载可见区 + 前后各 10 条；v4.19 为 500 条全量。
2. **滚动帧间隔**：本机从 33.4ms 降到 16.7ms，达到契约 `p95 ≤ 20ms`。
3. **可观测性**：v4.19 只能靠体感；v4.20 四段指标可复算，报告结构稳定并做隐私扫描。
4. **首字等待**：v4.19 无预算；v4.20 超过本机基线给出非阻断提示（停止 / 换更小模型 / 缩减上下文）。

## 4. 已知限制

- 冷启动、首字为单机单次样本，不作为绝对值门禁；跨机对比需固定机器与场景。
- 本次未采集到 v4.19 的数值基线（v4.19 无埋点），因此没有数值同比表。
- 性能报告与导出仅在本机生成，不上传云端。
