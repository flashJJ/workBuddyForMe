## 3. e2e 关键设计

1. **技能升版产生两版**：安装 v1 后升级 v2，快照列表得到两版；v2 为 active，v1 可删。
2. **删除后重新读取**：删除 v1 后再次请求版本列表，断言仅剩 v2 且 `totalBytes` 下降，避免只看 UI 缓存。
3. **归档锚点时机**：`/audit` 页打开时链校验会写 `audit_verified`，因此 UI 校验用的锚点必须在页面校验落账后重新归档生成；否则区间计数会立刻失配。
4. **锚点四态独立构造**：分别抬高 `ledger.lastSeq`、篡改 `range.lastHash`、置 `chain.ok=false`、提交空对象，覆盖四种业务码与 422。
5. **对比只读断言**：对比前后读取工作流详情，`currentVersion=2`、`publishedVersion=1` 保持不变。
6. **UI 默认基准**：工作流发布 v1 后保存 v2，版本抽屉默认 `from=1`、`to=2`，直接点「开始对比」即可看到差异。
