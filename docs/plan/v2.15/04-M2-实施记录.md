## 1. 本里程碑做了什么

| 能力 | 行为 |
|---|---|
| 归档 | `GET /api/audit/archive?from=<ISO>&to=<ISO>` 返回 ZIP：`events.jsonl`（按 seq 升序） + `anchor.json` |
| 锚点 | 记录应用 / schema 版本、生成时间、区间信息与全账本尾（`ledger.lastSeq/lastHash`） |
| 链校验 | 生成锚点时只读校验全账本；超过 10 万条只校验最近 10 万条并标 `truncated` |
| 校验 | `POST /api/audit/anchor/verify` 只读比对区间与全账本尾，返回 200 + 业务码 |
| 业务码 | `ANCHOR_OK` / `ANCHOR_TAIL_TRUNCATED` / `ANCHOR_MISMATCH` / `ANCHOR_CHAIN_BROKEN` |
| 限额 | 区间 ≤366 天、事件 ≤5 万、ZIP ≤20 MB；超限 422 `AUDIT_ARCHIVE_TOO_LARGE` |
| UI | 审计页新增「导出归档 ZIP」与「验证锚点」；默认最近 7 天，锚点校验结果就地展示 |

## 3. 关键口径

1. **区间语义**：`from` / `to` 为带时区 ISO 时刻，`created_at` 闭区间；UI 将筛选框的本地时间转为 ISO，未填时默认最近 7 天。
2. **双尾锚点**：`range.lastHash` 证明区间内容，`ledger.lastSeq/lastHash` 证明生成时的账本尾；只记录区间尾无法发现归档之后的尾部删除。
3. **校验只读**：锚点校验不写 `audit_verified`，也不写任何审计事件；既有「校验完整性」按钮仍保持原行为。
4. **业务失败 200**：截断 / 不一致 / 断链是校验结果，不是请求错误；仅锚点 JSON 结构非法返回 422。
5. **链校验截断**：`range.chain.truncated = 全账本条数 > 10 万`；锚点对「未校验的部分」有明确标记。
6. **归档导出不删账本**：只读导出，不做自动清理。

## 4. 契约偏差与说明

| # | 事项 | 说明 |
|---|---|---|
| 1 | ZIP 内存组装 | 事件上限 5 万、ZIP 上限 20 MB；超过返回 422，不做流式压缩（P1 可升级） |
| 2 | 链校验范围 | `range.chain` 校验全账本而非仅区间；更严格，且能复用既有 `verify`，避免第二套哈希链实现 |
| 3 | UI 时间选择 | 复用审计页筛选框的起止时间，未填默认最近 7 天；不新增独立日期弹窗 |
| 4 | 锚点校验结果 | 返回完整 anchor 便于排查；不额外返回事件正文 |
