## 1. 本里程碑做了什么

| 能力 | 行为 |
|---|---|
| 差异形状 | `FlowGraphDiff`：节点新增 / 删除 / 类型变化 / config 变化，边新增 / 删除，六项 summary |
| 节点身份 | 节点 `id`；同一 id 类型变化只报 `typeChanged`，不再报 `configChanged` |
| 配置比较 | 只比较 config 顶层键；键新增 / 删除 / 值变化都计入 `keys`，按字母升序 |
| 边身份 | `source → target → handle`（无 handle 记 `null`）；忽略 edge id |
| 布局忽略 | 节点坐标、viewport 不参与 diff，纯拖动不产生噪音 |
| API | `GET /api/flows/:id/versions/compare?from=&to=` 返回差异摘要，不返回完整图 |
| UI | 版本抽屉新增基准 / 目标选择器与「开始对比」按钮；结果按分组展示；全零显示「没有差异」 |
| 只读 | 对比不改变 current / published 版本，不触发保存 |

## 3. 关键口径

1. **比较顺序**：先按节点 id 建映射，再处理边；`from` / `to` 仅用于回显，不参与排序。
2. **类型优先**：同一 id 类型变化时跳过 config 比较，避免把整份配置差异误报成字段变化。
3. **顶层键比较**：使用 `canonicalJson` 比较值，嵌套对象内部变化会命中该顶层键，但不展开子键。
4. **边句柄**：`sourceHandle` 变化视为「旧边删除 + 新边新增」，与图引擎的路由语义一致。
5. **稳定性**：所有分组按 id / 边键升序输出，同一输入多次调用结果一致。
6. **只读**：路由只调用仓储读取；不写审计、不改版本状态。
7. **默认基准**：抽屉打开时 `from = publishedVersion ?? currentVersion`，`to = currentVersion`；点击按钮才发请求，避免无意义请求。

## 4. 契约偏差与说明

| # | 事项 | 说明 |
|---|---|---|
| 1 | 差异请求时机 | 契约只要求「可对比」；实现改为点击「开始对比」后才请求，避免打开抽屉即拉取 |
| 2 | 空态判定 | 以六项 summary 之和为 0 判定「没有差异」，与各分组为空等价 |
| 3 | 参数校验 | `from` / `to` 由 zod 强转为正整数；缺参 / 非数字统一 422 `VALIDATION_ERROR` |
| 4 | 审计 | 对比为只读操作，按 D12 不写审计 |
