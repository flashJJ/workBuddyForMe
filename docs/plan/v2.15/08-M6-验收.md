## 3. 零迁移与兼容

- `LATEST_SCHEMA_VERSION` 保持 42，不新增表 / 列 / 索引。
- 复用 `skill_versions`、`providers.api_key_cipher`、`workflow_versions.graph_json`、`audit_events`。
- Web 主密钥升级为 `keys/master-keyring.json` 文件格式，旧 `master.key` 作为 legacy 读入；`failed===0` 时同步旧文件，v2.14 可解密重封装行。

## 5. 已知边界（随发行说明）

- 技能版本删除不可逆，只允许逐条删除；active 与唯一剩余版本受保护；审计写 `skill_version_deleted`。
- 审计归档区间 ≤366 天、事件 ≤5 万、ZIP ≤20 MB；锚点只存文件，不落库；校验只读，不写 `audit_verified`。
- 凭证轮换 P0 仅 Provider API Key；MCP `env/headers` 留 P1；Web keyring 最多 3 把，干净轮换后裁剪到 active + previous。
- Desktop safeStorage 只重新封装密文，不更换系统密钥；文案不宣称更换 OS 密钥。
- 工作流 diff 只比较节点 id、边 `source→target→handle`、config 顶层键；忽略坐标 / viewport / edge id；字段级高亮列 P1。
- 审计尾部整段截断仅在锚点校验中检出；账本不自动清理。
