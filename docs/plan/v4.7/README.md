> 状态：已随 v4.10.0 发布
> 主题：任务上下文注入、步骤压缩、检查点续跑、计划确认与完整回投

| 文档 | 内容 |
|---|---|
| [调研与实施计划](./00-agent-task-research-plan.md) | 现状盘点、业界参考、P0–P2 方案、实施口径、真机与收尾记录 |

核心落点：

- 任务上下文块：摘要 → 事实/检查点 → 计划 → 近期对话 → 长期记忆；
- 预算按窗口收敛：上下文 15%（320–2000）、步骤历史 12%（320–1200）；
- 步骤 Condenser：首 2 步 + 最近 8 步 + 中段省略；
- `task_run_checkpoints` 与续跑入口；
- 计划只读预览与完整回投；
- 任务记忆与 per-role token usage。
