## 3. 与 M0 的偏差

1. **事件真源方向**：本期以「事件 = 时间线真源，业务表 = 查询投影」；导出同时带业务投影，便于人工核对。
2. **报告下钻**：运行报告是链路聚合表，没有单次运行行；本期提供报告页时间线入口 + 任务行下钻，单次运行的 Flow/Agent 下钻列入 v2.10 评估。
3. **压缩预算可视化**：沿用现有摘要/预算记账，不在本期新增面板（M0 已列 P1）。
4. **溢出阈值**：100,000 字符（高于常规工具压缩预算），避免与 v1.1 大输出压缩互相抢占；预览 2,000 字符。
5. **保留策略**：`purge` 只提供 API/服务能力，未挂定时任务；默认 180 天，后续可在设置页接入。
