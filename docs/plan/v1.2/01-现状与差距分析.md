### 1.2 NSIS（yml L42-48，仅 6 个基础项）

已配：`oneClick:false`（辅助安装器）、`perMachine:false`（按用户、免 UAC）、`allowToChangeInstallationDirectory:true`、桌面+开始菜单快捷方式、shortcutName。

**未配（grep 零命中）**：`installerLanguages`（界面仅英文）、`license`（根目录 GPL-3.0 LICENSE 未接入）、`menuCategory`（无独立程序组）、`uninstallDisplayName`（卸载列表只有 productName，无版本/发布者）、`deleteAppDataOnUninstall`（卸载数据策略未声明）、任何自定义 `.nsh`（全仓零 .nsh 文件）、installer/uninstaller 图标。

### 1.3 代码签名：明确关闭

`win.signAndEditExecutable: false`（yml L34-36，注释「无证书，避免 signApp 失败」）。全仓 `certificate|signtool|CSC_` 仅此 1 命中，CI 零签名 secret。副作用是 **rcedit 被一同关闭**：exe 无图标、无版本资源（文件属性里没有产品名/版本/版权）。SAC 环境已有历史代价——e2e 只能复制官方签名 electron.exe 改名加载 app.asar 冒烟（`scripts/run-e2e.mjs:10-36`）。

### 1.4 自动更新：接线完整，但发布源落后两个版本

- 主进程 `updater-bootstrap.ts`（10s 后检查、isPackaged 门控）、`updater.ts`（stable/beta 通道、完整 IPC）、updater-state 持久化、preload 白名单、About 面板全套已在 v0.4 接通。
- GitHub 仓库实查**仅 1 个 Release：v0.9.0**（2026-10-05，latest.yml + Setup 118MB + blockmap 三件套齐全）。**v1.0/v1.1 从未发布 Release**。
- 本地 `release/` 仅 `win-unpacked/`（--dir 冒烟产物，无 app-update.yml）。
- 结论：v0.9.0 装机用户检查更新永远 not-available；更新链「代码能通但无新版本可喂」。0.9.0→1.2.0 跨级 + 未签名包的差分更新有效性从未验证。GitHub 国内可达性无兜底（沿用 GitHub 源，本版本不做镜像）。

### 1.6 CI 与构建脚本

- `.github/workflows/ci.yml` 单 job、ubuntu-latest、push main/PR 触发，只有 check/unit/集成/build:web/web e2e；**无 windows runner、无打包 job、无 tag 发布、无 GH_TOKEN/签名 secret、无产物上传**。
- `dist:win`（nsis）与 `pack:dir` 都要求手工先跑 prepare-server.mjs；`dist:win` 不依赖 web build，忘记先 build 会在 standalone 缺失时 exit 1（有防呆但不自动）。
- prepare-server.mjs（96 行）职责：standalone 归集 + MCP bin + 同版本官方 node.exe + .next/static 与 public + 原生包 FALLBACK 清单兜底。

## 2. 体验面现状（apps/web）

### 2.1 深色模式：底座好、覆盖薄、状态分裂

- `darkMode:'class'`（tailwind.config.ts:4）；shadcn 风格语义 token 齐全（:root 与 .dark 两套 HSL 变量，globals.css:6-45）。
- 切换：侧栏图标按钮 → **只写 localStorage**（key `wbfm-theme`，theme-provider.tsx；默认强制 light，无跟随系统）。
- 设置页「默认偏好」主题下拉 → **只 PUT 设置表**（后端 `theme` 字段早存在，enums.ts:36）。两个入口互不联动、不实时换肤——**现存功能缺陷**。
- 覆盖词频：`dark:` 仅 14 文件/30 处；彩色状态色类 38 文件/**156 行，其中约 130+ 行无 dark: 配对**（重灾：flow-editor 51、flow-execution 21、settings 21、voice 17）。
- 现存两个视觉 bug：toast 用了未定义的 `bg-popover`（透明底）；rehype-highlight 已启用但**全仓无 highlight.js 主题 CSS**（明暗都无语法着色）。

工作量：中（2-4 人日，密集状态色面板对比调优是主要成本）。

### 2.2 a11y：有骨架无体系、零运行时验证

- 已就位：Radix Dialog 焦点陷阱、toast aria-live、jsx-a11y lint、Ctrl+K 命令面板（含 ↑↓Enter Esc）、焦点环在 UI 基元齐备、语音按钮 aria-pressed、主侧栏 nav/aria-current。
- 硬伤：
  1. 命令面板无 label/listbox/combobox/activedescendant 语义、Radix Dialog 无 Title（屏幕阅读器不可用）；
  2. 33 个原生 `<button>` 与侧栏链接普遍缺 `focus-visible` 环；
  3. 无 skip link，`<main>` 无 id/landmark，12 个设置面板长页无区域导航；
  4. **12 文件/13 处 `window.confirm/alert`**（删除确认散落 knowledge/settings/memory/flows）；
  5. 无任何 axe/运行时无障碍检测（axe-core 仅作为 lint 插件的传递依赖躺在 lockfile）。
- package.json 声明了 7 个 radix 包，实际只用 3 个（scroll-area/select/separator/tabs/tooltip 零 import）。

工作量：中（2-3 人日）。

### 2.3 i18n：基本为零，schema 还把语言锁死

- 无任何 i18n 库；非测试 tsx **113/127 文件含中文（89%）、约 11,233 个汉字**（350+ 单引号串行/71 模板串行/220 JSX 文本行）；lib/server 另有 1,465 个汉字，**用户可见错误消息在服务端拼中文**。
- 分布：voice 2417 字、flow-editor 1883、settings 1861、chat 1464 为四大文案域。
- 已有的半集中点：nav-config、命令分组、badge 枚举、状态 label——是字典抽离的天然锚点。
- `AppSettings.language` 字段存在但 schema 是 `z.literal('zh-CN')`（锁死，需放 enum）；`<html lang="zh-CN">` 已在。
- 本地化敏感点：4 处日期写死 `'zh-CN'`、about 手拼日期、无 Intl.NumberFormat、「N 个文档」类复数裸拼。

工作量：框架+核心路径双语为中（3-5 人日）；全量中英双语为大（1-2 周，本版本不做）。

### 2.4 帮助与引导：完全空白，空态底子尚可

- onboarding/向导/帮助中心/快捷键说明/首启判断：**零命中**；根路径直接 redirect('/chat')，无 hasOnboarded 状态。
- 已有可复用资产：通用 EmptyState（9 处使用）、无模型时 chat-setup-guide 引导卡（「说明→行动按钮」模式已验证）、供应商表单对 Ollama 的安装/pull 提示、About 面板（版本/更新/许可声明）。
- 缺口：About 无帮助/快捷键/反馈入口；错误边界与错误 toast 无错误码/文档锚点（全仓 tsx 外链仅 3 处：Ollama 下载、HF 镜像、Releases）；31 处原生 `title=` 充当 tooltip 且键盘不可达。

工作量：中（3-5 人日）。

### 2.5 工程约束对新 UI 的影响

- 单文件 260 预警/300 硬门禁：web 最大文件 234 行，Top15 在 186-234，新向导/帮助/i18n 模块**平均只有 60-110 行余量**，必须按子组件+纯函数/字典外迁落地（本目录 02 设计稿已按此约束拆分）。
- v1.1 边界门禁 error 态：跨包共享只能走 packages 既有方向（错误码/语言枚举放 shared 合法）。
- 无视觉回归基建：深色/a11y 改动需要自带取证（e2e 截图/axe 断言）。
