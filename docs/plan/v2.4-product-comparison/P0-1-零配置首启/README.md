## 一页结论

- **向导骨架已在**（v1.2 M5：四步 + 云端/Ollama 二选一 + 手动重放入口），所以缺的不是「有没有向导」，
  而是**「有没有一条不需要用户前置动作就能跑通的路径」**。
- 现状三条路径都要用户动作：云端要自备 API Key；本地要先装 Ollama 再 pull 模型（数百 MB 起）；
  `WBFM_MOCK_AI` 兜底只是服务端环境变量，用户看不到也开不了。
- 本分册的核心新增三件事：
  1. **演示模式**——把 mock 兜底产品化成向导内可勾选项，离线、零配置、**真实链路真跑**（SSE/检索/引用/工作流节点），仅模型输出为确定性文本；
  2. **一键本地小模型**——把「本地」从「给指引」升级为「一键引导 + 推荐模型收窄到 1–2 个 + 明示体积耗时」；
  3. **厂商预设云**——云端从「手填 baseURL」升级为「常用厂商卡片 + Key 申请直达 + 模型建议」。
- 再把向导终点从「配置完成」推进到**「第一次成功对话」**：首字延迟自检 + 预计体感结论 + 预置示例问题点即发送。

## 待拍板（决策点）

1. **演示模式是否可作为默认首启路径**（vs 仅作为本地/云端都不通时的兜底）。倾向：默认聚焦但不强制，三条并列。
2. **是否接受内嵌/自动下载本地小模型**（体积与磁盘占用）。倾向：**只做引导，不内置权重、不静默下载**。
3. **是否引入免费云兜底**。倾向：**不做**——与「不引入云端账号、数据不出机」的红线冲突，改用厂商预设 + 成本提示。
