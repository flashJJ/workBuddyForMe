# P0-3 功能设计

> 目标：**「一键开启语音对话」** —— 不懂参数、不用先搞清模型体积，就能开口连续对话；
> 同时**如实声明半双工边界**，不假装全双工。

## 1. 验收口径（可自动化）

| # | 验收 | 判定方式 |
|---|---|---|
| A1 | 模型未就绪时，「开启语音对话」给出**体积/耗时预估 + 一键下载 + 可取消** | e2e（拦截下载接口）断言预估文案与按钮态 |
| A2 | 模型就绪后，「开启语音对话」**一次点击**即进入可说话的免手模式（默认参数） | e2e 断言 `handsfree-button` 进入 armed |
| A3 | 参数默认值生效（灵敏度=均衡、尾静音=默认档），且**高级区默认折叠** | e2e 断言默认值与折叠态 |
| A4 | 边界声明可见：半双工/打断语义有文案，不是暗示全双工 | 断言文案存在 |
| A5 | 下载中断后重入**不重下已完成文件**（文件级断点） | e2e 断言二次进入下载不重复请求已完成文件 |

## 2. 功能设计

### 2.1 F1 · 一键开启语音对话（主入口）

- **落点**：设置页语音面板顶部 + 对话页语音按钮旁（[待拍板 1](README.md#待拍板)）。
- **两态**：
  - **模型未就绪** → 主按钮为「开启语音对话（需先下载约 X MB）」，点击进入**下载引导**（F3），完成后自动继续；
  - **模型就绪** → 主按钮直接**武装免手模式**并跳/切到对话（默认参数，无需二次配置）。
- **默认行为（待拍板 2）**：倾向「开启即免手」，同时保留一键切回 PTT。

### 2.2 F2 · 参数收进「高级」

- 只保留一个人话档位选择：**「反应快」/「更宽容」** 二选一，映射到现有的灵敏度 + 尾静音组合
  （`vad-config.ts` 的纯函数映射已存在，新增一层档位→参数的映射常量）。
- 灵敏度/尾静音/半双工提示移入「高级」折叠区（默认收起），保留可调但不阻塞主路径。
- 「说完了」与「打断响应」两个默认值在高级区以人话标注（如「约 0.9s 未说话即认为说完」）。

### 2.3 F3 · 模型下载体验（入口级成本透明）

- 下载引导卡展示：**总体积（取自 `manifest.ts`，不硬编码）**、镜像（默认 hf-mirror，可切官方）、
  「约 X MB · 视网速而定」的耗时口径、进度、**取消**、失败后**重试**。
- 复用 [downloader.ts](../../../../packages/voice/src/models/downloader.ts) 已有的文件级跳过，实现「中断后再进不重下」。
- 磁盘占用提示（模型会落到数据根，需用户知情）。

### 2.4 F4 · 边界声明（半双工 / 打断）

- 在开启处与下载完成页写明：**「当前为『说完再答』模式，说话时可打断正在播放的语音」**，
  并明确「同时说话与聆听（全双工）不在本版」。
- 目的：把「不如豆包」的落差从「隐性失望」变成「已知边界」。

### 2.5 F5 · 不做全双工（列入 P2 候选）

- 全双工（边听边说）需要模型侧原生支持，**本版不做**，只在 P2 候选清单里保留。

## 3. 红线

1. **不假装全双工**：文案与 UI 必须如实（D4）。
2. **不静默下载**：必须显式点击；下载可取消且不留残文件（复用现有取消逻辑）。
3. **默认值可解释**：不给用户「必须调才对」的参数；默认即可用。
4. 新增文案走 i18n zh/en 双档；新增组件 ≤150 行、单文件 ≤300 行。
