## 一页结论

- **模板已经在播**（v2.3 起）：6 个工作流模板、3 个内置技能、3 个内置知识库模板，另有 6 张内置角色卡。
  所以缺的不是「内容」，而是**露出与起手**：
  - 五个列表的**空态都只有「创建按钮 / 一句空文案」**，用户不知道已有现成货；
  - 唯一有「内置/自建分区 + 一键复制」先例的是**角色卡**（[character-cards-panel.tsx](../../../../apps/web/src/features/character-cards/character-cards-panel.tsx#L189-L210)）；
  - 内置来源在列表内**不可见**（除角色卡有「内置」徽标）。
- 本分册新增三件事：
  1. 统一 **`TemplateGallery`** 组件（卡片 = 名称 / 说明 / 来源徽标 / 「以此开始」）；
  2. 五处接线（知识库 / 工作流 / 技能 / 助手 / 角色卡），各自定义「以此开始」的语义；
  3. 列表内**来源标注** + 模板**分类与推荐**（不再只平铺列出）。
- 与 **P0-1 耦合**：P0-1 的 `firstAsk` 示例问题与这里的模板清单**复用同一份单一事实源**，避免两处各写一套。

## 待拍板

1. **模板区出现时机**：仅空态显示 vs 空态显示 + 列表顶部常驻入口（倾向后者：空态露一次，之后留一个可折叠入口）。
2. **「以此开始」的产物语义**：复制为可改实例（知识库 / 工作流 / 角色卡）｜直接启用（技能）｜预填新建表单（助手）——三项语义不同，需逐类确认。
3. 模板是否需要**分组标签**（如「研究 / 办公 / 开发」）或只按列表自然顺序（倾向：分组，但标签先固定 3 类）。
