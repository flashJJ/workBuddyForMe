## 一页结论

- **不是功能不够**：本产品功能面（对话 / RAG / 工作流 / 本地 API-MCP 服务 / 桌面 Agent / 技能 / 角色卡 / 形象 / 桌宠 / 语音 / 情绪关系 / 主动感知）比多数同类更宽。
- **差在价值兑现链条**：豆包/Trae「装完即用」（模型与算力由产品兜底），本产品必须**自备供应商 + API Key + 模型**才有第一条回答 —— 这是「不好用」的最大来源（致命档）。
- **次差在多模态代差与打磨欠账**：无图片/视频生成、无实时全双工语音；语音还要先下 191–394MB 模型；观感/窄窗/空态/入口存在欠账（v2.3 已修一批，仍有剩余）。
- **优势必须守住**：本地私有（数据不出机 · 语音链路可离线 · 接本地模型后可完全离线）、可编程可扩展（Flow Studio + 本地 API/MCP Server + `.wbfm-pack`）、有形象与性格的长期关系。
