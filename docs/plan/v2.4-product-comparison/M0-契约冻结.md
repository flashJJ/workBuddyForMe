## 3. 冻结产物 A · 模板清单（单一事实源）

- **落点**：`apps/web/src/lib/templates/starter-templates.ts`（web 侧映射，**不改 `packages/*` 的播种实现**）。
- **形状（冻结）**：

```ts
export type StarterTemplateKind = 'knowledge' | 'flow' | 'skill' | 'assistant';
export interface StarterTemplate {
  kind: StarterTemplateKind;
  id: string;                                  // 与内置对象同 id（seed 固定 id）
  name: string;
  description: string;                         // 适用场景一句话
  recommended?: boolean;                       // 该列表「推荐先用」
  startAction: 'clone' | 'enable' | 'prefill'; // 对应 D5
}
```

- **条目（冻结 15 条）**：知识库 3 + 工作流 6 + 技能 3 + 助手预设 3。**角色卡 6 张不进本清单**（沿用既有内置/自建分区，不重写）。

| kind | 条目 | id | 「以此开始」 | 推荐 |
|---|---|---|---|---|
| knowledge | 产品需求 / 会议纪要 / 研究资料 | `c0000000-…-0001/0002/0003` | `clone` | 产品需求 |
| flow | 资料研究助手 / 周报流水线 / 网页摘要器 / 会议纪要整理 / 竞品对比 / 知识库问答 | `b0000001…b0000006` | `clone` | 资料研究助手 |
| skill | weekly-report 周报生成 / meeting-notes 纪要整理 / file-search 文件检索 | 三者的 `name` | `enable` | weekly-report |
| assistant | 资料研究助手 / 周报助手 / 会议助手 | 预填（见下表） | `prefill` | 资料研究助手 |

**助手预设（冻结绑定）**：

| 预设名 | 绑定角色卡 | 绑定技能 | 绑定知识库 |
|---|---|---|---|
| 资料研究助手 | `research-scout` 调研先锋 | — | 研究资料（`…0003`） |
| 周报助手 | `capable-colleague` 干练同事 | `weekly-report` | — |
| 会议助手 | `calm-advisor` 沉稳顾问 | `meeting-notes` | — |

> 只绑定**确定可用**的能力：技能不依赖外部服务；`file-search` 需先接 MCP filesystem，故不作预设默认绑定（口径问题在 P1-2 一并修）。

## 4. 冻结产物 B · 语音档位映射

| UI 档位 | `vadSensitivity` | `vadSilenceMs` | 说明 |
|---|---|---|---|
| **反应快**（默认） | `balanced` | **600** | 小停顿即认为说完；耳机 / 安静环境 |
| **更宽容** | `low` | **1200** | 外放 / 嘈杂环境，减少误触发 |

- 原「灵敏度三档（高/均衡/低）× 尾静音四档」**在默认路径收敛为两档**；灵敏度与尾静音仍可在「高级」单独覆盖档位。
- 「高」灵敏度不再出现在默认路径（保留在高级区）。

## 5. 冻结产物 C · 语音默认模型 + 真机工装护栏

- **ASR**：现有唯一 ASR（239.5MB）。
- **TTS 默认**：**MeloTTS（191MB，单声低延迟）**；Kokoro（394MB，103 音色）为可选。
- **M0 工装护栏（关卡，未通过不得进 M3）**：干净 Windows 真机上以 MeloTTS 跑通
  「开启语音对话 → 说 3 句 → 打断 1 次」，判定 **中文可懂度** 与 **首字延迟** 可接受；
  **不达标 → D9 回退 Kokoro 为默认**，并按 §1 登记变更。
- ⚠️ 本项**未经真机验证**（本次冻结只给出值 + 关卡条件），M3 开工前必须先跑该工装。

## 6. 冻结产物 D · 向导口径（P0-1 / P0-3 共享）

| 项 | 冻结值 |
|---|---|
| 步骤序列 | `welcome → provider → voice → firstAsk → finish`（**保留 `provider` id**，其语义改为三选一来源；新增 `firstAsk`） |
| 三来源默认顺序 | 演示模式 → 本地模型 → 云端 API；**已检测到本机 Ollama 时本地置顶** |
| `firstAsk` 示例问题数 | **3 个**（通用 1 + 知识库 1 + 语音 1，按已就绪能力显隐） |
| TTFV 里程碑字段 | `first_launch_at` / `first_model_ready_at` / `first_answer_at` / `ttfv_ms` |
| **TTFV 验收阈值** | `ttfv_ms ≤ 60_000`（e2e 以演示模式断言，无外网依赖） |
| 延迟自检结论分档 | ≤1.5s「流畅」／≤5s「偏慢但可用」／>5s「建议换来源」 |

## 7. 红线（重申，不变）

1. 无账号、无遥测、**数据不出机**；不引入免费云兜底。
2. **不静默下载**（模型 / 权重均需显式确认）。
3. **不假装全双工**（语音界面如实声明半双工与 barge-in 打断）。
4. 内置模板**只增不改、不覆盖用户改动**。
5. 单文件 ≤300 行（新组件 ≤150 行）；新增文案 zh/en 双档。
