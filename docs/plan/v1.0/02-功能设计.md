# 02 · 功能设计（v1.0 Voice Companion）

## 1. 用户故事与验收

### F1 回复朗读（M1，P0）

- **故事**：用户在对话页打开「朗读」开关后发送问题，AI 回复一边出字一边按句出声，可随时点停止。
- **验收**：
  1. 开关默认关（纯文字用户零打扰）；打开后本轮起生效；
  2. 首句在 LLM 首逗号后即开始合成播放，不等待整段；
  3. 多句严格按序播放不重叠；停止生成立即中止未播音频且状态回 idle；
  4. 表情标签文本不被朗读，仅正常句子出声；
  5. 引擎/模型缺失时开关旁出现明确引导（去下载），不弹 500。

### F2 模型下载与管理（M1 TTS、M2 ASR，P0）

- **故事**：首次启用语音时，设置面板显示两个模型状态，一键下载（默认镜像），进度可见、可取消；已下载可重新校验/打开目录。
- **验收**：落盘文件大小与清单不符标红；下载状态写 v014 `voice_models`，重启后状态恢复；支持自定义模型目录（指向已自备模型）。

### F3 按住说话（M2，P0）

- **故事**：输入框旁麦克风按钮，按住录音、松开识别，识别文本进入输入框（可再编辑）并自动发送；识别中显示状态。
- **验收**：16k 单声道 WAV 上传 `/api/voice/asr`；空语音不发空消息；识别失败 toast 且不丢输入上下文；无麦克风权限给出引导。

### F4 语音设置（M2，P0）

- 朗读开关、引擎（sherpa/none）、sid、语速、线程、输入模式（PTT/VAD）、VAD 静音时长、镜像地址、模型目录；改动持久化到 settings_kv 并即时生效（引擎按需重建）。

### F5 Live2D 形象（M3，P0）

- **故事**：设置打开「形象」后，对话页右侧出现 Live2D 角色；说话时口型随音量张合、表情随回复中的 `[joy]` 等标签切换、静默时有待机动作；不说话时不占音频资源。
- **验收**：Cubism/PIXI 为独立懒加载 chunk（关闭形象不下载、不初始化）；首屏 JS 体积不回退；About 页展示 Live2D 许可。

### F6 桌宠模式（M4，P0）

- **故事**：托盘/侧栏「桌宠」开关弹出半透明小窗角色，置顶陪在桌面；可拖动定位，右键菜单切换「鼠标穿透」；点角色挥手，双击回主窗；对话时桌宠口型/字幕同步。
- **验收**：
  1. 穿透态点击落到下层应用，模型本体区域始终可交互；指针在边缘抖动不发生穿透状态翻转（滞回 180ms）；
  2. 位置/大小/穿透偏好重启后保留；
  3. 主窗与桌宠同一时刻只有一个声音出口（语音会话按 conversationId 单例）；
  4. 关窗/退出干净，无残留透明窗与进程。

### F7 免手语音（M5，P0）

- **故事**：设置切「自动（VAD）」模式，无需按键：停顿后自动发送；AI 说话期间麦克风自动关闭防自激，说话结束恢复。
- **验收**：vad-web（Silero onnx）端点检测，静音阈值/时长可配；误触发率通过真人 10 轮对话冒烟；播放中绝不把 TTS 当输入（半双工）。

### F8 主动说话（M5，P1）

- **故事**：开启后，空闲超过阈值（默认 300s）AI 可主动发起一句轻量对话（跳过历史存储），桌宠气泡+语音呈现。
- **验收**：设置开关+空闲阈值；仅桌宠/形象启用时生效；不与正在进行的轮次并发；可一键关闭。

## 2. 语音设置模型（settings_kv key=`voice`）

完整 zod 契约见 `shared/schemas/voice.ts`（`voiceSettingsUpdateSchema` / `DEFAULT_VOICE_SETTINGS`）。要点：

- TTS：`ttsEnabled`、`ttsEngine('sherpa_onnx'|'none')`、`ttsSpeakerId`、`ttsSpeed`、`ttsNumThreads`
- ASR：`asrEnabled`、`asrEngine`、`asrNumThreads`、`inputMode('ptt'|'vad')`、`vadSilenceMs`
- 模型：`modelMirrorBase`、`modelsDir`
- 形象/桌宠：`avatarEnabled`、`avatarModelId`、`petEnabled`、`petClickThrough`
- 主动：`proactiveEnabled`、`proactiveIdleSeconds`

## 3. 状态与交互规约

- 语音状态机（`voice/session/voice-state.ts`）：idle/listening/thinking/speaking；迁移表与半双工打断语义已固化并有 14 个单测。
- 打断：speaking 时 `listen_start` 合法（barge-in → listening）；`cancel/error` 任意状态回 idle；客户端收到取消需同时 abort：LLM 请求、未完成 TTS fetch、Audio 队列。
- 表情：复用 VTuber 标签集合（neutral/anger/disgust/fear/joy/sadness/surprise/smirk）；助手配置加「启用表情指令」开关，仅开启时向系统提示词追加表情指令片段。

## 4. 错误与降级

| 场景 | 行为 |
|---|---|
| 模型未下载 | 引擎不初始化；朗读/听写开关给出下载引导；其余功能不受影响 |
| 麦克风无权限/无设备 | 输入按钮置灰 + 系统设置引导，不报错弹窗 |
| 引擎初始化失败（文件损坏等） | VoiceEngineError 带 hint；自动回退纯文字并 toast |
| TTS 单句失败 | 该句仅出字幕不阻断后续句；记录错误事件 |
| 离线且未配镜像 | 下载器报网络错误，可切镜像/选本地目录 |
