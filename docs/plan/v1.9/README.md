## 红线（全版不变）

1. 舞台不新增任何执行权限：协作舞台无审批/返工按钮，会议成员无工具、无 MCP、无桌面控制。
2. 队列所有方在 web 主会话：关舞台窗不退协作、不退会议。
3. 主窗唯一 AudioContext：舞台不建音频管线，只收电平/状态中继做口型（与桌宠瘦终端同构）。
4. 无 agents 自发闲聊：会议每条发言必须由用户议题或 `@` 触发；auto ≤8 轮硬上限。
5. Cubism 授权红线沿用：不做外部模型导入、不捆绑音色包。
