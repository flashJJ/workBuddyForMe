# v1.7 M0 · 8 个内置剧本 JSON 初稿（文案评审稿）

> 状态：M0 评审稿 ｜ 搭配 [01-step契约与三锁状态机.md](./01-step契约与三锁状态机.md)
> 约定：台词全部原创、本地 i18n、单条 ≤32 字、无变量插值；每剧本 ≤20s、可 Esc/点击跳过。
> JSON 内 `lineKey` 对应词条 `packages/shared/src/i18n/messages/event.ts`（M1 新建，zh 真源 + en 全量）。
> `trigger` 块是给 M3 触发器的**意图备注**，非引擎执行字段（触发判定不写在剧本内）。

通用闸门：总开关关 / 勿扰 23:00–8:00（本版无紧急级）/ 冷却 / maxPerDay / 频率档系数，全部在 Director 准入层，剧本不重复声明。

## 1. 日常族

### 1.1 早安 `ev.greeting.morning`

- 触发：当日首次交互（`counters.interactionsToday == 0`）且 `time.hour ∈ [5,11)`。
- 冷却 12h，每日 1 次，priority 1，ignore，speechLock=queue。

```json
{
  "id": "ev.greeting.morning",
  "titleKey": "event.greeting.morning.title",
  "priority": 1,
  "interruptPolicy": "ignore",
  "cooldownMs": 43200000,
  "maxPerDay": 1,
  "speechLock": "queue",
  "builtIn": true,
  "trigger": { "intent": "firstDailyInteraction", "when": [{ "path": "counters.interactionsToday", "op": "eq", "value": 0 }, { "path": "time.hour", "op": "gte", "value": 5 }] },
  "steps": [
    { "kind": "spatial", "action": "slideIn" },
    { "kind": "expression", "tag": "joy" },
    { "kind": "fx", "id": "fadeIn" },
    { "kind": "speech", "lineKey": "event.greeting.morning0" },
    { "kind": "wait", "ms": 1200 },
    { "kind": "speech", "lineKey": "event.greeting.morning1", "tts": false },
    { "kind": "wait", "ms": 900 },
    { "kind": "expression", "tag": "neutral" }
  ]
}
```

| lineKey | 中文初稿 |
|---|---|
| event.greeting.morning0 | 早呀，今天也一起加油。 |
| event.greeting.morning1 | 醒啦？我等你好久了。 |

### 1.3 欢迎回家 `ev.greeting.welcome`

- 触发：归来事件（v1.6 `decideReunion` 三档 8h/24h/72h），触发器把档位写入**临时上下文** `counters.reunionTier`（0/1/2），不落库。
- 每波离开只迎一次（沿用 v1.6 迎接去重），冷却 8h，每日 ≤3，priority 2，replaceLowerPriority，speechLock=queue。
- 迁移说明：M3 把 `useReunionGreeting` 直发气泡改为投递本事件；切换期二者只保留一个出口，禁止双播。

```json
{
  "id": "ev.greeting.welcome",
  "titleKey": "event.greeting.welcome.title",
  "priority": 2,
  "interruptPolicy": "replaceLowerPriority",
  "cooldownMs": 28800000,
  "maxPerDay": 3,
  "speechLock": "queue",
  "builtIn": true,
  "trigger": { "intent": "reunion" },
  "steps": [
    { "kind": "spatial", "action": "slideIn" },
    { "kind": "fx", "id": "fadeIn" },
    { "kind": "expression", "tag": "joy" },
    { "kind": "branch", "when": [{ "path": "counters.reunionTier", "op": "gte", "value": 2 }], "goto": 9 },
    { "kind": "branch", "when": [{ "path": "counters.reunionTier", "op": "gte", "value": 1 }], "goto": 7 },
    { "kind": "speech", "lineKey": "event.greeting.welcome0" },
    { "kind": "wait", "ms": 900 },
    { "kind": "speech", "lineKey": "event.greeting.welcome1" },
    { "kind": "wait", "ms": 1200 },
    { "kind": "speech", "lineKey": "event.greeting.welcome2" },
    { "kind": "wait", "ms": 1000 },
    { "kind": "expression", "tag": "neutral" }
  ]
}
```

branch 落点（下标 3/4 路由到互斥支线）：tier≥2 → goto 9（welcome2）；tier=1 → goto 7（welcome1）；不满足顺序进入 5（welcome0）。

| lineKey | 中文初稿 |
|---|---|
| event.greeting.welcome0 | 你回来啦。 |
| event.greeting.welcome1 | 一整天没见，有点想你。 |
| event.greeting.welcome2 | 可算回来了，好久不见！ |

评审点：

1. 15 条台词中文朗读是否自然、是否够"短且不腻"；英文版 M1 同键补齐。
2. welcome 与 v1.6 迎接的切换时机（建议 M3 一次切净，不留双出口）。
3. touch/praised 默认 `tts:false`（气泡字幕）是否认可——摸头/被夸频率高，出声易腻；朗读党可在高级设置按剧本开。
4. 冷却/每日上限初值真机一周后按接受率/打断率回调（只改注册表常量，不动引擎）。
