## 2. scheduled_tasks（提醒调度）

```sql
CREATE TABLE IF NOT EXISTS scheduled_tasks (
  id            TEXT PRIMARY KEY,
  assistant_id  TEXT NOT NULL REFERENCES assistants(id) ON DELETE CASCADE,
  kind          TEXT NOT NULL CHECK (kind IN ('once','daily','weekly')),
  -- 本地墙钟时间（按 timezone 列解释），与系统时区设置解耦
  hour          INTEGER NOT NULL CHECK (hour BETWEEN 0 AND 23),
  minute        INTEGER NOT NULL CHECK (minute BETWEEN 0 AND 59),
  weekday       INTEGER,                              -- weekly 必填 0..6（0=周日，同 JS getDay）；其余 NULL
  at_date       TEXT,                                 -- once 必填 'YYYY-MM-DD'；其余 NULL
  timezone      TEXT NOT NULL DEFAULT 'Asia/Shanghai',-- IANA；创建时固化，避免用户改系统时区后漂移
  text          TEXT NOT NULL,                        -- 提醒原文（≤200，应用层截断）
  enabled       INTEGER NOT NULL DEFAULT 1,
  next_run_at   TEXT NOT NULL,                        -- ISO-8601 UTC，tick 唯一 seek 依据
  last_fired_at TEXT,
  created_at    TEXT NOT NULL,
  updated_at    TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_sched_next_run
  ON scheduled_tasks(enabled, next_run_at);
CREATE INDEX IF NOT EXISTS idx_sched_assistant
  ON scheduled_tasks(assistant_id);
```

设计要点：

1. **墙钟 + 时区双存储**：用户编辑的是本地 hour/minute（+weekday/date），`timezone` 固化 IANA；写入/触发后由纯函数换算 `next_run_at`（UTC ISO）。tick 只比 UTC 时刻，不碰时区细节。
2. **once 语义**：触发后置 `enabled=0`、`last_fired_at=now`；若创建时刻已过期（`next_run_at < now`），UI 直接拒绝并提示时间无效（不静默丢弃）。
3. **daily/weekly 滚动**：每次 fire 后立即重算下一个 `next_run_at`；daily 跨过 DST 不补不跳（按本地 HH:mm 重新落点，与手机日历提醒一致）。
4. **管理面**：列表/增删/启停/编辑；编辑任一时间字段都重算 next_run_at；停用不删行。
5. tick 由 web 会话存活期 `setInterval` 驱动（复用 proactive 的 10s 心跳粒度）；主窗/桌宠都不可见时只标记到点、走 Electron 通知兜底，不申请 EVENT/TTS 锁（M4）。

### 2.1 next-run 纯函数（core，时间可注入，单测 ≥90%）

```ts
// packages/core/src/scheduler/next-run.ts
interface ScheduleSpec {
  kind: 'once' | 'daily' | 'weekly';
  hour: number; minute: number;
  weekday?: number | null;   // 0..6
  atDate?: string | null;    // YYYY-MM-DD
  timezone: string;          // IANA
}
/** 从 fromMs（UTC 毫秒）起算严格晚于当前时刻的下一次触发；once 过期返回 null */
export function computeNextRunMs(spec: ScheduleSpec, fromMs: number): number | null;
```

测试矩阵（注入固定时钟）：daily 当天未到/已过、weekly 本周/下周、once 未来/过期、跨月跨年、UTC+8 边界、非法时区回落（Asia/Shanghai，记日志）。

## 3. event_usage（演出闸门与统计）

```sql
CREATE TABLE IF NOT EXISTS event_usage (
  id           TEXT PRIMARY KEY,
  assistant_id TEXT NOT NULL REFERENCES assistants(id) ON DELETE CASCADE,
  event_id     TEXT NOT NULL,                  -- ev.* / usr.*
  date_key     TEXT NOT NULL,                  -- 本地日 'YYYY-MM-DD'（按用户时区取日界）
  played_at    TEXT NOT NULL,                  -- ISO UTC
  outcome      TEXT NOT NULL CHECK (outcome IN ('played','skipped','interrupted','suppressed')),
  reason       TEXT,                           -- 结构化原因码（见下）
  priority     INTEGER NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_usage_daily
  ON event_usage(assistant_id, event_id, date_key);
CREATE INDEX IF NOT EXISTS idx_usage_recent
  ON event_usage(assistant_id, played_at);
```

- **冷却闸门**：`SELECT MAX(played_at) WHERE event_id=? AND outcome='played'`，与当前时刻比对 `cooldownMs`（绝对墙钟，不区分日期）。
- **每日上限**：同 event_id + date_key 且 outcome='played' 的计数 ≥ maxPerDay 即拒绝。
- **统计（M4 打扰率）**：played/skipped/interrupted/suppressed 四态计数；suppressed 原因码区分 `master_off / dnd / cooldown / daily_cap / queue_full / no_outlet`，供"建议降档"提示只读使用。
- **保留策略**：应用启动清理 90 天前流水（统计表小，但不无限增长）；冷却/每日判定只看近期，老数据可删。

outcome/reason 枚举在 shared 固化为 const 数组（与 schema 同步），仓储写入只接受白名单值。

## 4. 仓储与模块落位

| 层 | 文件（M4 新增） | 职责 |
|---|---|---|
| database | `repositories/scheduled-task-repo.ts` | CRUD、`listDue(nowMs)` 走 idx_sched_next_run、enable/disable、fire 后重算 |
| database | `repositories/event-usage-repo.ts` | append、`lastPlayed`、`countToday`、`stats(windowDays)`、purge |
| core | `scheduler/next-run.ts` | computeNextRunMs 纯函数 |
| core | `scheduler/scheduler-tick.ts` | 到点选取→投递事件/通知；幂等（同一 next_run_at 只 fire 一次，先更新后演出） |
| core | `event/`（M1） | director/runner/conditions/cooldown 读 event_usage 仓储 |
| web/desktop | API `/api/schedules`、管理 UI、Electron notification 兜底 | M4 |

索引支撑：tick 周期内 `enabled=1 AND next_run_at <= now` 走 `idx_sched_next_run`，全表无扫描。
