# v4.5 版本总结：一眼启动

> 版本：4.5.1（2026-11-17）
> 主题：启动画面、真实阶段反馈、首启品牌短片与视频壁纸复用
> 分支：`feat/v4.5-boot-animation`
> 迁移：零数据库迁移，`LATEST_SCHEMA_VERSION = 51`

## 1. 本版解决什么

v4.4 收口了背景与壁纸，但应用启动仍是黑箱：主进程要先清版本缓存、启动密码桥、`fork` 托管 Next 服务并每 250ms 健康检查，主窗 `ready-to-show` 之前没有任何窗口。用户只能盯着桌面，分不清“正在启动”“启动失败”和“被安全软件拦截”。

v4.5 把启动过程变成一条可见、可解释的状态链：

1. **先看见**：`app.whenReady()` 后最先创建 640×360 无边框启动窗，不阻塞服务与主窗创建；
2. **真阶段**：只显示主进程真实发生的事件，不伪造百分比；
3. **可交接**：主窗在后台加载，确认 `ready-to-show` 后启动画面退场，避免白屏/黑屏；
4. **有品牌**：日常紫团子 SVG；首次安装/覆盖升级首启播放 8 秒《潮汐开门》，可跳过、只播一次；
5. **可复用**：同一片源作为内置主窗口视频壁纸，不再维护第二套启动/回放逻辑；
6. **可解释**：启动超过 8 秒/20 秒有等待提示；失败时启动画面显示原因与日志路径。

## 3. 关键设计

### 3.1 启动画面是旁路窗口，不是启动前置条件

启动画面只负责渲染，不参与服务拉起与主窗创建。主进程仍然按原顺序清缓存、起密码桥、`fork` 服务、健康检查、建主窗；启动画面通过 IPC 接收阶段事件。这样即使启动画面本身加载失败，应用仍能正常启动，只是少了一层可见反馈。

### 3.2 三阶段来自真实事件

用户只看到 `prepare / server / workspace` 三段，内部 stage 细到 `app-ready / session-cleared / cipher-ready / server-forked / server-healthy / main-created / main-ready`。阶段事件按 `phaseForStage` 纯函数映射，主进程与测试共用同一份契约，避免“文案说载入工作台，实际还在 fork 服务”。

### 3.3 主窗受控显示，交接不闪

主窗以 `show: false` 创建，`revealMainWindow` 统一负责最大化与显示；启动画面收到 `boot:done` 后先播 240ms 退场，再由主进程显示主窗并关闭 splash。这条顺序避免了“主窗先出现、splash 还压在上面”或“splash 先消失、主窗还没画好”的两类闪烁。

### 3.4 SVG 与视频双层交接

日常模式只播 SVG/CSS，不加载视频；首启完整片在 1 秒内 `canplay` 才切到视频层，否则认为首帧太慢，直接留在 SVG 等待态。视频 `error`、`prefers-reduced-motion`、高对比都会回落到 SVG。完整片最多播到 8 秒片尾或 9 秒上限；主窗仍未就绪时回到等待态，不黑屏。

### 3.5 首启标记与安装器行为分开

`last-version` 只负责“版本变了要清 session 缓存”；新增的 `intro-seen-version` 只在启动画面真正显示且主窗 reveal 后写入。这样即使安装器自动拉起、窗口被挡住或用户在画面出现前退出，也不会把“首启”消费掉。NSIS 同时改为 `runAfterFinish: false`，覆盖安装后不自动拉起，避免安装完成页挡住小窗。

### 3.6 素材只保留一份

8 秒原片 6.27MB，转码为 854×480 / 30fps / 去音轨 / CRF24 / faststart 后 581KB，封面 26KB；同一份 `cinema.mp4` 既作为启动视频，也复制到 Web 静态目录作为主窗口视频壁纸。启动逻辑与壁纸逻辑互不复用，只共享素材。

- 单测：splash 20 项通过；desktop 全量 247 项、shared 413 项通过。
- 打包态 e2e：12/12 通过（smoke 5、splash 1、pet 4、computer-input 2）。

- 性能：首启 mainVisible 9094ms（8 秒片）、chat 9281ms；日常 mainVisible 2307ms、chat 2366ms；内存 694→707MB，峰值 728MB。
- 安装包：4.5.1 286,493,155 字节（273.22MB），SHA256 `c5dc07ac…717acefd`；manifest 3 个产物复核通过。
- 数据库：零迁移；备份 schema 不变。

## 5. 已知限制

- 片源 854×480，150% DPI 或整屏视频壁纸下会轻微软化；
- 启动画面固定品牌深色，不跟随主题；无启动音效；
- 完整片只在首次安装/覆盖升级首启播放一次，无菜单回放；
- 首启完整片总时长上限 9 秒，超时回到等待态；
- 安装完成后需手动启动应用（`runAfterFinish: false` 的有意行为）；
- macOS/Linux 只保证逻辑可用，本版只验收 Windows。
