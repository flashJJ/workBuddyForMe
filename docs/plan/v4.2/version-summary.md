## 1. 这一版解决了什么

全局音乐、剧场 BGM、语音与音效原本各管一套播放器和静音状态，靠舞台路由卸载避免叠音；语音说话时只有剧场 BGM 会 duck，全局音乐不会；静音在三个地方各存一份。v4.2 把状态收进一个浏览器侧 AudioDirector：

| 环节 | 改造前 | 改造后 |
|---|---|---|
| 背景乐互斥 | 靠舞台路由卸载 | 导演统一 `setBackground`，音乐与剧场 BGM 同时最多一条 |
| 语音 duck | 只有剧场 BGM 压到 35% | 语音活跃时音乐与 BGM 同步压低，多来源 Set 计数 |
| 全局静音 | 音乐与剧场各存一份 | `wbfm.audio.muted` 单一状态，两个入口同步 |
| 舞台返回 | 音乐停在暂停 | `sessionStorage` 恢复播放意图与上一首 |
| 首次解锁 | 剧场与语音各自监听手势 | 根布局统一监听，导演分发解锁回调 |
| 音效并发 | 无上限 | 同时最多 2 个，超出直接丢弃 |
| 曲库响度 | 无登记 | 内置 11 首统一 -16 LUFS 元数据 |

## 4. 技术与产品收益

- **状态单一真源**：mute、语音活跃与背景互斥只在导演里算，播放器保留自己的淡变与队列，回退风险低。
- **多窗口语音不打架**：来源 Set 记录主窗、桌宠与舞台，任一说话即 duck，全部结束才恢复。
- **路由切换可恢复**：播放意图与会话绑定，进剧场暂停、返回恢复，不要求用户重新点播放。
- **解锁只做一次**：根布局统一监听首次手势，音乐、语音与音效共享，不再各自加 `window` 监听。
- **规则可测**：duck、静音、背景互斥、音效限流与解锁失败隔离都有纯状态单测。
- **响度有基线**：内置曲库统一登记 -16 LUFS，后续导入曲目可按同一口径补齐。

## 5. 已知限制

- 不做输出设备选择，仍跟随系统默认设备。
- 不做 WebAudio 全图与压缩器；各播放器仍独立。
- 不做运行时响度测量与自动归一化。
- 语音与音乐不共享播放队列，只共享 duck 与解锁。
- 本版不构建 exe 安装包；需要时单独执行 `pnpm release:win`。
- 真机音频验证与截图待补。
