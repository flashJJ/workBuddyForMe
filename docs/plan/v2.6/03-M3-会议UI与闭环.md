## 2. 关键行为

### 2.1 行动项转提醒

- 仅 `finished` 会议；行动项必须有 `dueAt`，否则 422。
- 出声助手必须是本会议成员，否则 422；同一行动项重复转换 409。
- 按行动项 `dueAt` + 请求时区换算墙钟，当前仅支持 `Asia/Shanghai`。
- 提醒文本取行动项内容，超过 200 字截断；成功后写 `linked_reminder_id`。

### 2.2 运行已发布 Flow

- 仅 `finished` 会议；Flow 必须存在且 `status=published`，草稿 422。
- 未显式传 `input` 时，把行动项内容同时映射到 `actionItem / query / topic / question`。
- `createRun(trigger=manual)` → `enqueueRun` → 写 `linked_flow_run_id`；重复运行 409。

### 2.3 Markdown 导出

- `GET /api/meetings/:id/export` 返回 `text/markdown` 与 `attachment; filename="meeting-<id>.md"`。
- 内容含议题、状态、成员、转录、结论（摘要/决策/未决问题）、行动项勾选（`[ ] / [x] / [-]`）、负责人与截止时间。
- 支持 zh / en 标签；不包含密钥、系统提示词或内部 id 之外的敏感信息。

### 2.4 UI

- 结论面板四态：加载中、加载失败（可重试）、空态（生成入口）、已生成（摘要 / 决策 / 未决问题 + 时间戳）。
- 重新生成前二次确认；提示「替换自动行动项、保留手动行动项」。
- 结论支持摘要 / 决策 / 未决问题行内编辑（按行拆分保存）。
- 行动项：新增（内容 / 负责人 / 截止）、行内编辑、`open → done`、`done → open`、`cancelled → open`。
- 转提醒使用确认框，默认由负责人（缺失时首位成员）出声。
- 运行 Flow 只列出已发布 Flow；默认选中第一条，运行后展示「已运行 Flow」。
- 导出按钮直接下载 Markdown，文件名取后端 `content-disposition`。
- 会议室结束后隐藏输入区，结论面板限高滚动，避免挤压转录区。
