## 2. 关键行为

### 2.1 数据与来源

- 新提取记忆写入 `source_conversation_id` 与 `source_message_id`（本轮助手消息）。
- 会话摘要记忆只有来源会话，`source_message_id=NULL`（摘要来自多条早期消息，不伪造单一来源）。
- 手工新建记忆两者均为 `NULL`；旧记忆升级后同样为 `NULL`，UI 显示「来源未知」。
- 去重合并保留首次来源，不把来源改写到最近一次对话。

### 2.2 召回计数与分数

- 语义召回命中后：`last_accessed_at=now`、`recall_count += 1`。
- 分数由归一化向量的 L2 距离换算：`score = clamp(1 - d²/2, 0, 1)`。
- 载荷同时下发 `reason='semantic'`；UI 只显示「语义召回 · 相关度高/中/低」，不展示伪精确百分比。
- 主动搭话的关系记忆走仓储直读，不属于语义召回，不计数（保持既有轻量路径）。

### 2.3 对话内溯源

- 折叠态显示「本轮参考了 N 条长期记忆」；展开后逐条展示类别徽标、内容、相关度与来源入口。
- 有来源消息 → 「来源消息」；只有来源会话 → 「来源会话」；两者皆无 → 「来源未知」。
- 点击来源进入 `/chat?conversation=<id>&message=<id>`：页面解析会话并切到对应助手，消息列表滚动到目标消息并高亮。
- 来源会话已删除 → 捕获 404 并提示「来源会话已删除」，不阻断普通对话。
- 来源消息已删除 → 会话正常打开但目标消息不存在时提示「来源消息已删除」，且不误高亮其他消息。

### 2.4 管理面板

- 每条记忆展示「已召回 N 次 / 尚未召回」、最近召回时间、来源链接或「来源未知」。
- 原有搜索、类别/状态筛选、时间线、编辑、删除、清空行为不变。
