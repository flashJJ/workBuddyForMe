## 4. P1-3 性能基线

新增 `apps/desktop/scripts/perf-baseline.mjs`（`pnpm --filter @wbfm/desktop perf:baseline`）：
在 `pack:dir` 产物上测量 launch → firstWindow → DOMContentLoaded → chat 可交互，以及空闲内存采样。

2026-10-27 本机实测（Electron 45.0.0，packaged exe，idle 15s）：

| 指标 | 数值 |
|---|---|
| launch | 2832 ms |
| firstWindow | 5576 ms |
| DOMContentLoaded | 5646 ms |
| chat 可交互 | 5910 ms |
| 空闲工作集（早期 → 15s） | 470 MB → 477 MB（+7 MB） |
| 峰值工作集 | 498 MB |
| 进程数 | 4 |
