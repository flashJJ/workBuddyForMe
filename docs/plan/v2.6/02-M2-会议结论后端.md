## 2. 关键行为

- 只有 `finished` 会议可生成结论；`active / aborted` 返回 409。
- 生成为显式触发，不随每轮发言自动调用；同会议并发生成返回 409。
- 模型输出必须通过 Zod；非法 JSON / 形状错误 → `PROVIDER_ERROR`，**不落伪结论**。
- 长转录 > 24,000 字符：先按 8,000 字符块压缩（最多 6 块，保留首尾），再出结论。
- 结论 `modelId` 记录会议 `modelId`；未指定时记录实际系统默认模型 id。
- 行动项：
  - `source=generated` 随结论重生成替换并重置 `open`；`source=manual` 保留。
  - 负责人只允许本会议成员；生成项非法 owner id 自动降级为 null。
  - 状态机：`open→done/cancelled`、`done→open`、`cancelled→open`；其余 409。
  - 取消用 `status=cancelled`，不物理删除，保留审计。
- 结论编辑只覆盖 `summary / decisions / openQuestions`，写 `edited_at`。

2. **M3**：行动项转提醒、运行已发布 Flow、Markdown 导出；后端字段已预留 `linked_reminder_id / linked_flow_run_id`。
