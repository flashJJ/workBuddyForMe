## 2. 分块规则

- 标题块触发章节边界：上一节先收束，避免跨章节合并导致首块路径丢失下级章节。
- 普通块沿用 `chunkText` 段落/句子策略；字符区间直接映射回 `ParsedDocument.text`。
- 表格块不进入普通文本流：
  - 完整表格 + 章节前缀 ≤ chunkSize → 单块；
  - 超长表格按数据行贪心切分，每片重复表头，`tableRowStart/tableRowEnd` 为数据行 1-based 闭区间；
  - 所有表格分片共享表格块字符区间，引用可按 `tableNo` 定位。
- 章节前缀只影响 chunk 内容，不改变 `charStart/charEnd`；无章节文档不加前缀。
- 旧文档/解析失败文档仍走纯文本回退，`section_path='[]'`。

## 3. 引用与分享

- `Citation` 新增可选 `sectionPath/tableNo/tableRow/tableCell`，旧引用缺省不产生新键。
- 数据库分片详情查询新增结构列并解析 `section_path` JSON；检索结果映射到 Citation。
- 引用展示优先级：表格（表 N · 第 M 行 / 单元格）→ 页/段；章节路径单独展示。
- Markdown/HTML 导出的脚注同步展示章节与表格定位；旧引用保持原格式。
- M2 只写 `tableRow`（表格分片起始行）；单元格级 `tableCell` 由 M3 表格问答生成。

## 4. 结构 API 与重建

`GET /api/documents/:id/structure` 返回：

```json
{
  "documentId": "...",
  "parsedAt": "...",
  "structureAvailable": true,
  "pages": [{ "pageNo": 1, "blockIds": ["b1", "b2"] }],
  "sections": [{ "path": ["合同", "付款条款"], "blockIds": ["b2"] }],
  "blocks": [{ "id": "b2", "kind": "table", "sectionPath": ["合同", "付款条款"], "...": "..." }],
  "tables": [{ "tableNo": 1, "header": ["阶段", "比例"], "rows": [["首付", "30%"]] }],
  "warnings": ["表 1 第 1 行单元格数与表头不一致"]
}
```

- 无结构旧文档返回 `blocks: []`、`structureAvailable: false` 与可读提示。
- 警告未单独持久化：API 从结构块与文档 OCR 状态派生（标题缺失、表头/错列、OCR 降级）；M1 解析期的多栏告警不进入 API。
- `POST /reparse` 返回 202 `{ queued: true }`；文档状态由 `processing` 进入 `indexed/failed`。
- 摄入时原始文件落盘 `documents/<documentId>.bin`；重建读取该文件重新解析，删除文档同步清理。
- 解析/嵌入失败发生在写入事务前，旧 chunks/vec/fts/document_blocks 保留。

### 4.1 兼容与偏差

- M1 之前入库的旧文档没有原始文件：重建返回 422「原始文件未保留，请重新上传」；不自动全库重跑。
- 结构面板暂不做「点击引用回原文/高亮定位」，该能力在 M4 文档面板闭环；M2 已提供章节/表/行数据与面板入口。
- 表格超长时同一表格的多个分片共享 char 区间；引用按 `tableNo + tableRow` 而非字符偏移定位。
