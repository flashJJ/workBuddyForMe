## 1. 已冻结的决策

| # | 决策 | 选择 | 影响 |
|---|---|---|---|
| D1 | 版本主题 | **「看得懂文档」——深度文档解析与可信 RAG** | 主线从“产出格式”转向“知识输入质量与引用可信度” |
| D2 | 版本范围 | **P0 + P1 + P2 全做** | 解析、表格问答、跨文档对比、图检索与评测都在承诺内 |
| D3 | 技术路线 | **TS/Node 原生扩展**：复用 pdfjs / mammoth / xlsx / pptx 解析器 | 不引入 RAGFlow/LightRAG/RAGFlow 服务、不引入新的 Python/Go/Rust sidecar |
| D4 | 数据迁移 | **允许一次迁移 `v043-document-structure`**：文档结构表/分块结构列/知识关系表 | 不再坚持“零迁移”；旧库兼容、备份恢复测试列为 M1 门禁 |
| D5 | 引用模型 | 在既有 Citation 上增加可选 `sectionPath` / `tableNo` / `tableRow` / `tableCell` | 只改 JSON 结构，不改 messages 表；旧引用保持兼容 |
| D6 | 解析边界 | 先做**文本层 PDF + 表格/章节结构**；扫描件沿用现有 OCR，不引入版面模型 | 复杂多栏/表单/手写表格放 P2，不承诺 100% 版面还原 |
| D7 | 评测 | **Promptfoo 纳入 CI**；Ragas 指标只借规范，不引入 Python | P0 起建立 RAG 评测集，P2 扩指标与红队 |
| D8 | 图检索 | P2 用现有 `knowledge_entities` + 新增 `knowledge_relations` 做实体/关系多跳检索 | 不做社区检测/GraphRAG 全量实现 |
| D9 | 旧文档 | 默认保持原文本检索；提供“重建结构/重新解析”入口，不自动重跑全库 | 避免升级后大批量重摄入与不可控耗时 |
| D10 | 会议/语音 | v2.19 不做会议录音；上一轮选择的音频范围不适用于本主题 | 会议与长期记忆转为后续候选 |

## 2. 由决策派生的实现口径

### 2.1 P0 解析与结构

- 解析器输出统一的 `ParsedDocument`：页 → 章节路径 → 块（heading/paragraph/list/table/figure）。
- PDF 使用 `pdfjs-dist` 文本项坐标做行合并、标题/段落识别与表格启发式；DOCX/PPTX/XLSX 在现有解析器上补 heading/table 结构。
- 表格识别只处理文字层；扫描件先 OCR，再按行/列对齐做表格启发式；失败时回退为普通文本块，不阻塞入库。
- 结构持久化到 `document_blocks`；分块表增加结构列，支持按章节/表格粒度检索与引用。

### 2.2 分块与检索

- 表格块**原子化**：不跨块切断表格；超长表格按数据行切分并重复表头，保留 `tableNo` 与行范围。
- 章节路径进入 chunk 元数据，并在 chunk 内容前加轻量上下文（如 `[合同 › 付款条款]`），改善 embedding 与 FTS。
- 混合检索继续走现有向量 + FTS + RRF + 重排；结构过滤（按章节/表格）在 SQL 层追加，不改召回算法。
- 表格问答优先命中表格块，回答引用到「表 N · 第 M 行 · 单元格」。

### 2.3 引用与 UI

- Citation 扩展字段：`sectionPath?: string[]`、`tableNo?: number`、`tableRow?: number`、`tableCell?: string`。
- 引用角标展示章节/表格/行；点击可在文档结构面板定位到页/章节/表格。
- 新增文档结构预览：页、章节树、表格列表与解析警告；解析质量可见、可重建。

### 2.4 评测

- Promptfoo 覆盖：章节定位、表格单元格问答、跨文档对比、引用准确性、空结果/未覆盖说明。
- CI 阈值先建立基线，再设回归门槛；不达基线不发布。
- Ragas 的 faithfulness / context precision / recall 作为 P2 指标命名参考，评测在 Node 侧执行。

## 3. 仍需在契约中落盘的细节

1. `ParsedDocument`、`DocumentBlock`、表格 schema 与坐标口径。
2. `v043-document-structure` 的列/表/索引、旧库兼容与回滚方式。
3. 表格分块规则、章节上下文注入、引用字段映射。
4. 结构预览 API、重建解析 API 与文档状态机。
5. Promptfoo 配置、fixture 文档、指标阈值与 CI 接入点。
6. P2 图检索的边模型、多跳上限与引用字段。

## 4. 明确不做

- 不整库移植 RAGFlow / LightRAG / Graphiti / Ragas；
- 不引入新的 Python/Go/Rust 服务或版面模型；
- 不做文档编辑器、协同批注、云端文档同步；
- 不自动重解析全库历史文档；
- 不做会议录音、屏幕感知与长期记忆（留后续版本）。
