## 2. 表格意图与检索

- 意图识别只做轻量词面判断，不进入模型上下文，也不改变向量/FTS 召回。
- `ruleRerank` 新增可选 `blockKind` 与 `tableIntent` 选项；表格分片在表格意图查询下获得固定小幅增益，普通查询排序完全不变。
- 权重常量化并单测锁定：普通段落问题不误判、裸「表示/行业」不命中、英文按单词边界匹配。
- 表格答案仍由模型阅读 Markdown 表得出；本轮不做生成式表格计算，避免引入额外模型调用。

## 3. 单元格定位规则

`table-cell` 拆为两层：`table-cell-parse`（Markdown 表解析/列名/中文数字/字面匹配）与 `table-cell`（定位决策）。

### 3.1 定位优先级

1. 显式 Excel 地址：`B3`（校验列数/行范围，避免把 `Q4` 误判为单元格）；
2. 显式「第 N 行 / 第 N 列」（支持中文数字，按原表数据行号换算）；
3. 表头 + 行首标签唯一命中 → 交叉单元格；
4. 唯一数据值命中（如「30% 是哪个阶段」）→ 对应单元格；
5. 行标签唯一但列不唯一 → 仅给行定位；列唯一且只有一行 → 给单元格；
6. 全部歧义 → 返回 `null`，引用回落分片起始行，不编造单元格。

### 3.2 坐标口径

- `tableRow` 为文档内数据行号（从 1，表头不计），超长表格分片按 `tableRowStart` 偏移换算。
- `tableCell` 为 Excel 风格地址，表头占第 1 行：表头存在时数据行 1 → Excel 第 2 行。
- 无表头表格按数据行原样换算（数据行 1 → Excel 第 1 行）。

## 4. 跨文档对比

### 4.1 产物内容

- 标题与生成时间、两侧文档名/章节数/表格数；
- 章节并集表：共有 / 仅左 / 仅右；
- 表格匹配表：表号+标题、表头是否一致、行数、行标签差异计数；
- 匹配表详情：仅左侧/仅右侧的行标签；
- 未匹配表格清单与解析警告（含旧文档未解析结构提示）。

### 4.2 表格匹配

- 先按表头签名精确匹配（无表头时按标题），再对未匹配表按表头 Jaccard ≥0.6 一对一匹配。
- 仅比较表头、行数与前两列行标签，不比对单元格数值；避免在没有明确列语义时输出错误结论。
- 旧文档或解析失败文档不自动重建：`structureAvailable=false` 时明确写入「尚未解析结构」警告，产物仍可生成。

### 4.3 API 与 UI

`POST /api/documents/compare` 请求：

```json
{ "leftDocumentId": "a", "rightDocumentId": "b", "format": "html", "locale": "zh" }
```

响应包含：

```json
{
  "artifact": { "attachmentId": "...", "format": "html", "filename": "...", "mimeType": "text/html", "byteSize": 0, "title": "..." },
  "content": "<!DOCTYPE html>...",
  "filename": "...",
  "mimeType": "text/html",
  "summary": {
    "sections": { "total": 4, "shared": 2, "leftOnly": 1, "rightOnly": 1 },
    "tables": { "left": 2, "right": 2, "matched": 1 },
    "warnings": []
  }
}
```

- 产物复用 v2.18 `attachments` 表与 `/api/artifacts/:id` 预览/下载（CSP 禁止脚本与外联）。
- 同一文档、未知文档分别返回 422 / 404；产物超 2MB 由既有产物服务拒绝。
- UI 格式切换：HTML 走 iframe 预览，Markdown 直接展示可复制正文；统计与解析警告同屏展示。

## 5. 兼容与偏差

- 表格单元格定位为启发式：表头/行标签字面相同、查询同时命中多行多列时宁可不给单元格；M5 评测会用 fixture 量化准确率。
- 同一表格的多个分片共享原表行号；显式「第 N 行」按原表数据行解释，不按分片内序号。
- 对比产物不调用模型、不重写原文、不做数值差异；只对比结构、表头与行标签。
- Promptfoo 用例未在本里程碑加入；按计划在 M5 与检索评测一起接入 CI，M3 以单测/路由/UI 用例作为门槛。
- 旧文档对比不自动重解析；与 M2 口径一致，由用户手动「重建结构」。
