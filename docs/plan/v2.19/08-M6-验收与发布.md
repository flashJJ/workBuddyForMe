## 6. 已知边界与偏差

| # | 事项 | 说明 |
|---|---|---|
| 1 | PDF 表格为启发式重建 | 缺表头/错列/稀疏时降置信度并给出警告；不承诺所有复杂版面 |
| 2 | OCR 表格置信度上限 0.55 | 扫描件表格由 OCR 文本启发式重建，结构可能不准确 |
| 3 | 关系抽取仅规则 | 同句相邻实体 + 动词/连接词；不做指代消解、事件抽取或 LLM 关系生成 |
| 4 | 多跳上限固定 | 2 跳 / 12 条边，最多注入 2 条关系事实，避免长链噪声 |
| 5 | Promptfoo 使用 mock provider | 锁定评测口径与 CI 稳定性，不代表真实模型回答质量 |
| 6 | 旧文档不自动重解析 | 默认保留原文本检索；知识库「结构」入口手动重建 |
| 7 | 视觉模型为可选能力 | 未配置时明确 422/提示，不阻塞文本链路 |
