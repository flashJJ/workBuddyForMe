## 2. 图检索

### 2.1 关系抽取与写入

- 编译规则 seed 后，`extractRuleRelations` 在同一句内按实体出现顺序取相邻实体对（每句最多 3 对）。
- 关系标签优先取两实体之间的动词/连接词（收购、合作、供应、签署、includes、supports…）；无明确动词回落「共同提及」。
- 置信度：动词关系 0.75，共同提及 0.55；描述截断 240 字，关系标签截断 40 字。
- 只保留「两端实体均已落库 + 原句可映射 chunk」的关系；关系描述必须逐字来自缝合文本。
- 与实体编译同一事务：重编译整批替换该文档关系；重摄取 `purgeForReingest` 同步清理关系。

### 2.2 多跳与引用

- `collectMultiHopRelations` 从查询命中的实体集合出发 BFS：第 1 跳直接关系，第 2 跳通过中间实体展开。
- 边去重、实体去重、总边数封顶 12；选择器最多注入 2 条关系事实，避免图噪声污染上下文。
- 排序：两端都在命中实体的直接边优先，其次跳数、置信度。
- 关系事实文本：`关系：A —[收购]→ B。原句：…`；必须带来源文档；无来源文档的边只参与遍历，不进入引用。
- `Citation.staticKind` 增加 `relation`；RAG 资料块抬头为「关系知识：《文档》」，聊天引用显示「关系知识」徽标。
- 没有实体/关系的旧库零差异回落普通 chunk 检索。

### 2.3 局限

- 只做规则关系抽取：实体来自既有引号/型号/括号别名规则，不做指代消解、事件抽取或 LLM 关系生成。
- 不做社区检测/GraphRAG 全量图；多跳上限固定，避免长链噪声与上下文膨胀。
- 关系质量依赖实体抽取覆盖；正式评测先以含明确实体名的 fixture 为准。

## 3. 表格置信度与降级

- `tableConfidence` 纯函数按以下信号降分：无表头、数据行 ≤1、表头/行单元格数不一致、空单元格比例 >30%、列数 <2。
- 置信度区间 [0.25, 1]；低于 0.75 写入结构化警告，结构 API 与查看器展示「置信度 N%」徽标。
- OCR 路径在文本启发式重建表格后统一将置信度压到 ≤0.55，并追加「扫描件表格由 OCR 文本启发式重建」警告。
- 多栏 PDF 沿用 M1 已有多栏提示；M5 不引入版面模型，只做置信度与降级说明。
- 置信度只影响展示与警告，不阻断检索/引用；表格仍按原文回答。

## 4. Promptfoo 与指标

### 4.1 配置

- `tests/eval/promptfoo/rag.yaml`：8 个用例，覆盖章节定位、表格单元格、空结果、跨文档对比、图检索直接/多跳、扫描表格置信度、旧文档无结构。
- `provider.mjs`：零网络 mock provider，按 `caseId` 返回固定 golden 输出，保证 CI 稳定；`cases.json` 维护 golden 文案。
- 断言既校验文本，也以 `metric` 分组：`citation_traceability`、`empty_result_recognition`、`comparison_artifact`、`relation_traceability`、`table_confidence`、`degradation_explained`（Ragas 风格指标命名的轻量落地，不引入 Python/Ragas 依赖）。
- 根脚本 `pnpm eval:rag`；CI 在 `pnpm check` 后执行，`PROMPTFOO_DISABLE_TELEMETRY=1`。

### 4.2 基线与定位

- 本轮基线：8/8 通过（100%）。
- mock provider 用于锁定评测口径与 CI 稳定性；真实模型回答质量仍由单测、集成与后续扩展用例保障。
- Promptfoo 作为 devDependency；不进入运行时依赖，不影响桌面安装包体积。

## 5. 兼容与偏差

- 未新增迁移：`knowledge_relations` 在 v043 已建；本次只加仓储、编译写入与读取链路。
- 图检索走编译优先 RAG 路径（对话自动注入）；`knowledge_search` 工具仍以向量/FTS 分片为主，未增加独立关系工具。
- 关系事实只在查询命中实体时出现；普通问题不会引入图上下文。
- 表格置信度为启发式分数，不是版面识别概率；OCR 表格统一保守降分。
- Promptfoo 使用 mock provider，不是真实模型调用；这是 CI 稳定性取舍，已在 M0 约定允许。
- Ragas 仅借用指标命名与断言分组，未引入 Python/Ragas 包。
