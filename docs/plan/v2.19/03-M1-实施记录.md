### 2.1 解析口径

- PDF 页内按 TextItem 的 y 坐标合并行，字号变化切行；x 间距超过 `max(12pt, 1.5×字号)` 切列。
- 标题：字号高于正文中位数 1.15 倍且长度 ≤80；PDF 额外支持 `第X章`、`一、`、`1.1` 等编号；最多 4 层章节路径。
- 表格：连续 ≥2 行、每行 ≥2 列；首行作表头；表注（`表 N` / `Table N`）挂在 `DocumentTable.caption`；多栏页面（≥4 行且固定 2 列）明确告警。
- Markdown/Office：管道表格与制表符行按列拆分；Markdown 分隔行不计入数据行；列表合并为一个 list 块；图注行记为 figure 块。
- 表格块正文统一渲染 Markdown 表格；`charStart/charEnd` 指向最终规范化文本中的该块区间，与 `chunkText` 同口径。
- 文本组装：块之间 `\n\n`；新文档以结构块文本为准，旧文档不重写、继续使用原分片文本。

## 3. 数据库与兼容

`v043-document-structure` 只执行 `ADD COLUMN` / `CREATE TABLE IF NOT EXISTS`：

- `document_chunks`：`section_path TEXT NOT NULL DEFAULT '[]'`、`block_kind`、`table_no`、`table_row_start`、`table_row_end`；
- `document_blocks`：契约 11 列 + `idx_blocks_document(document_id, ordinal)`；
- `knowledge_relations`：P2 图检索预留表 + 3 个索引。

兼容验证：

- v42 库升级后 `document_chunks` 行数不变，旧行 `section_path='[]'`、`block_kind/table_no=NULL`；
- `document_blocks` 为空，不阻塞旧文档检索；重传/重建索引时整批替换；
- 迁移遇到手工构造的局部测试库（缺 `document_chunks`/`documents`）时跳过相关段，不报错；
- 备份恢复后旧分片保持空结构，结构块不随备份导入（可从原文档重建）。

## 5. 已知限制

1. PDF 表格为坐标启发式，不承诺复杂跨页表/合并单元格；多栏与错列只给 warning，不阻断入库。
2. 扫描件表格识别依赖 OCR 文本中的制表符/管道符，OCR 文本无分隔时会降级为段落。
3. DOCX 标题依赖 mammoth 对 Word 标题样式的映射；无样式的文档按段落处理并给“未检测到标题”告警。
4. 图片/图表尚未提取图像与摘要，M4 视觉模型能力接入。
5. `table_row_start/end` 暂为 NULL，M2 表格分块时写入；Citation 扩展字段同步在 M2 落地。
6. 旧文档不自动重解析；M2 提供手动重建入口。
