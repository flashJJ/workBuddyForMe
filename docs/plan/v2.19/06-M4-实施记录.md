## 2. 查看器结构

`features/document-viewer` 按能力拆分：

| 文件 | 职责 |
|---|---|
| `document-viewer-dialog.tsx` | 读取结构、警告、章节选择、原文块、页徽标与页脚操作插槽 |
| `chapter-tree.tsx` | 路径前缀建树、折叠/展开、选中与滚动定位 |
| `table-panel.tsx` | 表头/行号/单元格渲染、Excel 地址解析、目标行/单元格高亮 |
| `figure-panel.tsx` | 图注列表、视觉模型按需解读、摘要/错误/免责声明 |

- `knowledge/document-list.tsx` 通过公开入口 `@/features/document-viewer` 打开查看器，并提供「重建结构」页脚操作。
- `chat/message/citations-list.tsx` 对本地引用（无 `sourceUrl`）把文档名改为按钮，点击打开同一查看器；外部网页引用保持原文链接。
- 旧 `knowledge/document-structure-dialog.tsx` 删除，避免两套结构面板分叉。

## 3. 引用定位口径

- 章节：`sectionPath` 精确匹配树节点；选中后「原文」面板只展示该章节路径下的结构块。
- 表格：按 `tableNo` 定位表卡；`tableRow` 为数据行（从 1）直接高亮；`tableCell` 为 Excel 地址，按表头偏移换算数据行与列。
- 无单元格但行可确定时只高亮行；字段缺省时查看器仍展示完整结构，不报错。
- 表格行号/单元格地址均与 M3 的 `tableCell` 生成口径一致；查看器顶部显示「已定位到引用」与章节/表/行/单元格文本。
- 所有结构内容按纯文本渲染；表格内容不当作 HTML，URL 与外链不自动激活。

## 4. 图表/图片理解

### 4.1 API

`POST /api/documents/:id/figure-summary`：

```json
{ "blockId": "b3" }
```

响应：

```json
{
  "documentId": "d1",
  "blockId": "b3",
  "caption": "图 1 季度营收趋势",
  "pageNo": 2,
  "model": "qwen2.5-vl",
  "summary": "图表显示营收逐季上升，Q4 达到峰值。"
}
```

- `blockId` 为结构视图块 id（`b3` 对应 DB ordinal 2）；非图注块、非法 id 分别返回可读错误。
- 未配置视觉模型：422「未配置视觉模型：请在设置中选择支持图片理解（vision）的模型后再试」。
- 非 PDF / 无原始文件 / 图注缺页码：分别返回明确 422，不尝试渲染或猜测。
- 页面渲染缩放 2、单页像素上限 1,200,000；模型调用超时 60s，随请求中止信号取消。

### 4.2 交互

- 结构 API 返回 `visionAvailable`；未配置时图注列表仍可见，内联提示不可解读，解读按钮禁用。
- 已配置时每个图注提供「理解图表」按钮；摘要展示模型名与「由视觉模型生成，可能存在误差」免责声明。
- 解读按需触发，不写入数据库、不进入检索上下文，重复点击会重新调用模型（成本由用户主动触发）。
- 当前只对「保留原始文件的 PDF 页面」提供图像理解；DOCX/PPTX/TXT/Markdown 仅展示图注文字，避免假装能看图。

## 5. 兼容与偏差

- 图注来自 M1 解析器（PDF 文本行/表格标题等启发式），不是独立图片抽取；M4 不做版面/图像对象检测。
- 视觉摘要不落库：旧文档无结构、无原始文件时不能用视觉理解；与 M2/M3 口径一致，需重新上传或手动重建。
- 引用定位只对本地文档打开查看器；外部网页引用保持原链接，不强行拉取结构。
- 查看器按需拉取结构；打开时刷新一次，引用切换复用同一查询缓存。
- 无新增迁移、无新增长驻服务；Promptfoo 仍在 M5 统一接入。
- 对比产物（M3）与查看器不互斥：对比页展示结构差异，查看器负责单文档定位。
