# v2.16 M0 契约冻结：可导航

> 状态：✅ 已冻结（2026-11-01，评审记录见 [02-M0-评审记录](02-M0-评审记录.md)）
> 范围：目录分类、公开入口、跨域依赖、页面组合查询、结构门禁、循环依赖、命名与行为冻结（M1-M5 回归）。
> 原则：**只改结构，不改行为**；零迁移；每个里程碑都保持单测 / 构建 / e2e 不降级。

## 0. 冻结决策摘要

| # | 决策 | 取舍 |
|---|---|---|
| D1 | 目录按「域 → 子能力 → 文件」；P0 目录直接 `.ts/.tsx` ≤12，子目录同样 ≤12 | 先解决最大 12 个目录；不追求全仓一刀切 |
| D2 | 多文件 feature 必须有 `index.ts` 公开入口；单文件 feature 可豁免登记 | 单文件加 barrel 只增加噪音 |
| D3 | 公开入口只做 `export` / `export type` 纯转发，不写逻辑、不产生副作用 | 防止入口变成隐形服务层 |
| D4 | 外部按能力引用公开入口；内部直接引用文件；禁止从自己目录的 barrel 反向导入 | 防循环，保持依赖方向可读 |
| D5 | web feature 之间按允许矩阵依赖；矩阵外引用改走公开入口或上移共享层 | 合理依赖保留，不为零引用复制代码 |
| D6 | 页面数据先测量后优化：facade + 可见区触发查询；只读聚合端点仅在门槛满足时启用 | 不盲目合并接口，避免缓存与 payload 反噬 |
| D7 | M4 不改页面内容与交互语义，只改变「何时发请求」；保留 DOM、锚点与面板结构 | 避免懒挂载破坏设置页锚点与 e2e |
| D8 | 结构脚本以基线快照为准：已有超标登记，新增超标 error；达标后移除基线 | 先冻结现状，再逐步下降，不阻塞 M1 |
| D9 | 循环依赖基线 9 个 SCC；禁止新增；P0 域内的环在 M5 清零，剩余逐条登记 | 类型环 / barrel 环先分类，不误伤 |
| D10 | 统一职责后缀；停止新增 `kernel / utils / helpers` 这类无法判断职责的文件名 | 旧文件不强制改名，新文件遵守 |
| D11 | **行为冻结**：不改 UI 内容、API 契约、错误码、数据库结构；零迁移 | M4 的加载时机属唯一例外 |
| D12 | 每个移动批次只做 `git mv` + import 改写；发现业务问题记 backlog，不顺手修 | 保证 review 可核对、可回滚 |

### 1.2 豁免

- `packages/database/src/migrations`：append-only 历史，不分区、不重排；
- 自动生成清单（如语音模型文件清单）；
- i18n 词条字典与 shared 常量：P1 候补，不阻塞本版；
- 单文件 feature：不强制 `index.ts`，在结构脚本豁免表登记。

## 2. 公开入口

- 入口文件：`apps/web/src/features/<feature>/index.ts`、`apps/web/src/lib/hooks/<domain>/index.ts`、包域 `index.ts`。
- 入口内容：只允许 `export { ... } from './x'` 与 `export type { ... } from './x'`；禁止函数调用、常量计算、注册副作用。
- 外部引用：`@/features/settings`、`@/lib/hooks/chat`；禁止 `@/features/settings/foo`。
- 内部引用：同一域内直接 `./foo` / `../foo`；禁止 `import { x } from '.'` 或 `from '..'` 反向走自身 barrel。
- 客户端 / 服务端：`lib/server` 不进入客户端 feature barrel；客户端入口不得间接拉入 `better-sqlite3`、Node 内置模块或 route handler。
- 根 barrel 超过 300 行时，按子域拆二级 barrel，根入口只转发二级 barrel；`packages/shared/src/schemas/index.ts` 的白名单在 M1 复核后保留或缩窄。

## 3. 跨域依赖矩阵

允许的 web feature 依赖（只允许通过目标 feature 的公开入口）：

| 来源 | 允许目标 | 理由 |
|---|---|---|
| `settings` | `events`、`voice`、`memory`、`character-cards`、`tuning`、`help-center`、`reminders` | 设置页是组合页，聚合各域面板 |
| `chat` | `events`、`onboarding`、`voice`、`memory`、`avatar`、`pet`、`plans` | 会话运行时需要触发、语音、形象与计划能力 |
| `avatar` | `events` | 表情与剧情事件联动 |
| `pet` | `avatar`、`voice`、`interaction` | 桌宠复用形象、语音与互动信号 |
| `stage` | `avatar` | 舞台渲染形象 |
| `interaction` | `avatar` | 互动信号驱动表情 |
| `onboarding` | `voice` | 首启语音引导 |
| `flow-execution` | `flow-editor` | 运行态复用画布节点与边展示 |

矩阵外引用一律整改。已知需要整改的偶然耦合：

| 引用 | 处理 |
|---|---|
| `capabilities → settings/subagent-panel` | 把面板移到 capabilities 或抽到共享组件 |
| `tuning → assistants` | 复用助手表单需走 assistants 公开入口或上移 |
| `settings → shortcuts` / `settings → onboarding` | 若仅为宿主触发，改走 `lib/` 公共能力 |
| `chat → voice` 的 9 条相对引用 | 改走 `@/features/voice` 公开入口 |

> 允许矩阵与例外清单在 M3 冻结到 `docs/architecture.md`；不在矩阵内的新增依赖直接 lint 失败。

## 4. 页面组合查询（M4）

### 4.1 基线

- 设置页首屏：29 次 API GET、22 个 distinct 路径、峰值并发 15、响应体约 44 KB。

### 4.2 实施顺序

1. **页面级 facade hook**：组合该页面的查询与失效策略，页面只依赖 facade；内部仍可并行多个 query。
2. **可见区触发查询**：保留面板 DOM 与锚点结构，用可见性控制 query `enabled`；不可见分组不请求，滚到 / 锚点跳转时再请求。M4 只改「何时请求」，不改面板内容。
3. **只读聚合端点**：仅当 facade + 可见区触发后，首屏仍有 ≥4 个独立资源且 distinct GET 未达目标时启用。

### 4.3 聚合端点准入（若启用）

| 项 | 要求 |
|---|---|
| 方法 | 仅 GET |
| 范围 | 页面首屏只读最小字段；不聚合 mutation |
| 复用 | 服务端复用既有 service / repo，不复制 SQL |
| 契约 | 响应 schema 放 `packages/shared`；不改变既有端点 |
| 失效 | 明确 mutation → 聚合 key / 明细 key 的失效矩阵 |
| 预算 | payload ≤ 原请求总和 +10%；p95 不劣于基线；首屏 distinct GET 降 ≥50% |
| 回退 | 聚合失败不得拖垮页面；允许按分区降级到明细端点 |

## 5. 结构门禁与命名

- `scripts/check-structure.mjs`：目录直接文件数、公开入口存在性、豁免清单；读取 `scripts/.structure-baseline.json`，新增超标 error，存量超标 warning。
- ESLint：禁止跨 feature 深引用；禁止客户端 feature 引用 `lib/server`；保留现有包方向与 internal 规则。
- 循环：M5 增加检查，禁止新增 SCC；P0 域内的 9 个基线环逐条处理或登记。
- 命名：`*-service.ts`、`*-repo.ts`、`*-schema.ts`、`use-*.ts`、`*-panel.tsx`、`*-dialog.tsx`、`*-types.ts`、`*-helpers.ts`（helpers 仅限同域私有）。
- 文档：`docs/architecture.md` 必须包含目录地图、依赖矩阵、入口规则、新增文件决策树、豁免清单。

## 8. 验收口径

1. P0 目录直接文件 ≤12；≥20 文件目录从 24 降到 ≤10。
2. 多文件 feature 全部有公开入口；跨 feature 深引用 0（例外 ≤10 且登记）。
3. 设置页 distinct GET 降 ≥50%，或聚合端点准入被明确否决；First Load JS 增长 ≤5%。
4. 结构 / 边界 / 循环检查进入 `pnpm check`，新增违例阻断。
5. `docs/architecture.md` 可回答新增文件落点与引用规则。
6. 单测 2879 / Web e2e 139 / 桌面 10/11 不降级；零迁移。
7. 版本 2.16.0 发布并置 Latest。
