## 3. 验收偏差

| # | 事项 | 说明 |
|---|---|---|
| 1 | ≥20 文件目录 24 → 12，未达到 ≤10 | 目标要求再做 2 个目录分区。剩余 12 个中 11 个为 P1 / 豁免 / desktop 主进程，仅 `core/ingestion` 未在 P1 清单中；为避免在发布里程碑扩大重构范围，本版按 P1 非阻塞口径收口，`ingestion` 与另外 1 个 P1 目录计入后续版本 |
| 2 | 跨 feature 深引用由脚本而非 ESLint 拦截 | ESLint zone 无法表达「只允许目录 index」；结构脚本解析真实模块，能力等价且零误报（M5 已记录） |
| 3 | feature 根入口不导出能力全集 | 首轮 `export *` 造成包体回退；根入口只导出页面级组件，跨域改走子域入口（M3 / M5 已记录） |
| 4 | 依赖矩阵比 M0 初版扩大 | 登记 16 组实际存在的合理依赖与 `capabilities → settings/subagent` 例外；矩阵外新增仍需登记 |

## 8. 已知边界（随发行说明）

- 功能行为、UI 文案、API 契约与错误码零变更；本版只改目录位置、引用入口与首屏请求时机。
- M4 只让设置页分组在首次进入视口时取数；滚出视口不回收查询，锚点与面板 DOM 不变。
- P1 目录（backup / knowledge / tools / emotion / voice / stage / constants / i18n / desktop 主进程 / `lib/server`）与 `core/ingestion` 未分区，结构门禁按存量冻结。
- 循环依赖只做了「无新增 + 逐域登记」，存量 8 个 SCC 未清零。
- 只读聚合端点未启用；设置页剩余请求按页面基础区与全局壳层保留。
