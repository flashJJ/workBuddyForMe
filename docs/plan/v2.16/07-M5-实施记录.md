## 2. 结构门禁

`scripts/check-structure.mjs` 三类检查：

| 检查 | 规则 | 基线 |
|---|---|---|
| 目录预算 | 直接 `.ts/.tsx` ≤12；存量超标 warning，新增/增长 error | `.structure-baseline.json`：25 个存量目录 + 2 个豁免 |
| 公开入口 | 多文件 feature 必须有 `index.ts`；缺失且未登记即 error | 无存量缺失 |
| 引用边界 | 跨 feature 只能引用入口；`lib/hooks` 只能引用域 entry；feature 不得引用 `lib/server`；禁止自身 barrel 反向导入 | 深引用例外 0（上限 10） |

- 支持 `--self-test`（跨域深引用 + 自身 barrel 反向导入）。
- 已接入 `pnpm check`（`pnpm check:structure`）。

## 3. 循环依赖门禁

## 4. ESLint 客户端边界

`apps/web/.eslintrc.json` 新增 zone：

```json
{ "target": "./src/features", "from": "./src/lib/server" }
```

- 语义：`target` 是受限文件的所在目录（发起方），`from` 是禁止引用的来源；别名与相对引用都会命中（已用临时探针验证后删除）。
- 跨 feature 深引用由结构脚本负责：`import/no-restricted-paths` 无法表达「只允许目录 index」，脚本按真实模块解析（别名 / 相对 / 目录 index），零误报。
