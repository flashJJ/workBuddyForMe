## 6. 关键口径

1. **根 barrel 只导出公开面**：内部 helpers、测试 harness 不进入公开 barrel。`chat-orchestrator` 的 compaction / hitl helpers 与 `run-service.helpers` 保留在子域内，避免 `drain` 等内部符号污染根导出。
2. **测试跟随**：大部分测试随实现进入子域；chat 的 orchestrator / context 测试集中到 `__tests__/`，快照目录一并移动。
3. **独立入口同步**：`stage-client` 的 package exports、tsup entry 与构建产物全部指向新路径。
4. **包导出不变**：`@wbfm/core/agents`、`/services`、`/chat`、`/flow`、`/stage-client` 仍可用，消费者零改动。
5. **未改行为**：只移动文件与调整 import；无函数签名、schema、API 变更。

## 7. 契约偏差与说明

| # | 事项 | 说明 |
|---|---|---|
| 1 | 根 barrel 不再 `export *` 全部源文件 | 避免 `drain` 等内部符号冲突，并保持原公开面；子域 barrel 仍可按能力导航 |
| 2 | chat 测试集中到 `__tests__/` | orchestrator / context 文件过多，测试集中后源码目录可读；其余子域测试仍随实现 |
| 3 | `flow/compiler` 无 `compiler-agent.ts` 源文件 | `compiler-agent.test.ts` 测试的是 compiler；barrel 只导 `compiler` |
| 4 | 时区相关测试修正 | `schedules-agent.test.ts` 的 `atDate` 原写死当天，午后运行会因「时间已过」失败；改为固定未来日期，断言不变 |
| 5 | `vi.mock` 路径修正 | `first-token-probe.test.ts` 的 mock 路径随 provider-adapter 移动，改为 `../provider/provider-adapter` |
