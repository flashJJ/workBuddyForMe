# 验收清单（失败路径与边界场景）

> 目的：常规 E2E 覆盖「成功主干」，本清单补「取消 / 超时 / 重启 / 环境变化 / 协议边界」。
> 每条都对应一次真实缺陷（见 [Bug 记录表](./bug-registry.md)），作为同类问题的回归门禁。
> 使用：每版封版前至少跑 A + F；改动对应模块时加跑 B–E 的相关行。

## A. 成功主干（冒烟，10 分钟）

| # | 场景 | 操作 | 期望 |
|---|---|---|---|
| A1 | 首次对话 | 全新数据根 → 配置供应商/模型 → 发一句话 | 正常流式返回并落库 |
| A2 | 知识库 | 上传文档 → 索引完成 → RAG 提问 | 引用带实体与段落坐标 |
| A3 | 语音 | 下载 ASR/TTS 模型 → 按住说话 / 免手 | 识别与朗读正常，停止后可再次发起 |
| A4 | 桌宠 + 舞台 | 开桌宠 → 开舞台 → 关舞台 | 互斥正确，桌宠按原模型恢复 |
| A5 | 工作流 | 手动运行 → 查看运行报告 | 终态 `succeeded`，报告可打开 |

## B. 失败与取消（每版必测）

| # | 场景 | 操作 | 期望 | 关联 |
|---|---|---|---|---|
| B1 | 停止生成 | 流式回答中点停止 | 立即停止、消息标记 stopped、可再次发送；无残留音频播放 | B-09/B-12 |
| B2 | 上游断流 | mock 上游吐一帧后挂起，等待 120s | 空闲看门狗中止并提示超时，不再永久转圈 | B-07 |
| B3 | 取消下载 | 语音模型下载中取消 → 重启应用 | 卡片回到「未下载」，可重新开始；不会停在「下载中」 | B-21 |
| B4 | 取消分支/外部代理 | 连续启动多个分支与外部代理后取消 | 全部收敛为 cancelled，不占用并发名额与预留 token | B-23/B-24 |
| B5 | 工具超时 | 工具调试台跑一个超时工具 | 返回失败结果，后续对话仍可继续 | — |
| B6 | 审批拒绝 | HITL 弹窗拒绝 | 工具不执行、消息标记 cancelled、无副作用 | — |

## C. 生命周期与进程（每版必测）

| # | 场景 | 操作 | 期望 | 关联 |
|---|---|---|---|---|
| C1 | 退出应用 | 桌宠/舞台/下载/运行中任务存在时退出 | 所有子进程退出，端口释放，无孤儿 `node`/`next` | B-08/B-01/B-29 |
| C2 | 启动失败 | 模拟托管服务健康检查超时 | 弹启动失败原因，退出后无残留服务进程 | B-08 |
| C3 | 修改 MCP 配置 | 运行中改 command/args，连续两次 | 旧进程被回收，新连接状态为 connected，工具数正确 | B-28 |
| C4 | 禁用 MCP / 外部代理 | 运行中关闭开关 | 在途运行取消，子进程整树退出（Windows 用 taskkill /T） | B-22 |
| C5 | 删除模型/供应商 | 删除当前默认模型 | 设置中的默认绑定自动清空，新对话不报「模型不存在」 | B-20 |
| C6 | 删除知识库/文档 | 删除从未成功嵌入的文档、再删整个库 | 不报 `no such table`；删除后关键词检索不再命中旧内容 | B-15/B-16 |
| C7 | 事件引擎异常隔离 | 模拟演出释放或用量记账失败后继续触发剧本 | 演出正常收尾，后续事件仍可准入，不出现永久 busy | B-36 |

## D. 环境变化（封版前抽测）

| # | 场景 | 操作 | 期望 | 关联 |
|---|---|---|---|---|
| D1 | 拔扩展屏 | 主窗/舞台移到副屏 → 退出 → 拔屏 → 重启 | 窗口回落主屏居中，不会「启动了但看不到窗口」 | B-17/B-18 |
| D2 | 改缩放/分辨率 | 125% ↔ 100% 切换 | 桌宠位置仍在屏内；主窗尺寸不小于最小值 | — |
| D3 | 局域网/离线 | 断网后发消息、抓网页、检查更新 | 明确报错且可重试；不卡死在等待态 | — |
| D4 | 权限拒绝 | 拒绝麦克风/通知权限 | 提示可操作，不产生未处理异常 | B-10 |
| D5 | 系统睡眠/唤醒 | 休眠 > 10 分钟唤醒 | 定时任务不重复补演；语音/流式状态可恢复 | — |

## E. 协议与数据边界（改动对应模块时测）

| # | 场景 | 操作 | 期望 | 关联 |
|---|---|---|---|---|
| E1 | MCP 特殊工具名 | 接入工具名含 `.`/`/` 的 MCP 服务器（stdio 与 HTTP 各一次） | 工具可见且调用成功（调用时还原原始名） | B-26/B-32 |
| E2 | MCP 异常分页 | 服务器重复返回同一 cursor | 列表在有限请求内结束，不无限翻页 | B-27/B-32 |
| E3 | GBK 网页 | 抓取 GBK/GB2312 中文页面 | 正文不乱码，摘要可读 | B-11 |
| E4 | 超长工具结果 | 连续抓取多个长页面 | 旧结果被折叠，最新结果完整，不触发上游 400 | — |
| E5 | 流式工具调用 | 模型并行发起多个工具调用 | 参数分片拼接完整、结果按序回灌、tool_call_id 配对 | — |
| E6 | 备份恢复 | 导出 → 改数据 → 恢复 | 恢复后默认模型/助手/知识库引用一致，无悬空 id | — |
| E7 | MCP 权限声明 | 接入声明 `readOnlyHint` 与未声明 annotations 的服务器，分别在 `confirm_each`/`plan_only` 下调用 | 只读工具直接执行；写/未声明工具触发审批；`plan_only` 拒绝写操作 | B-31 |
| E8 | 恶意备份 | 导入含 `attachments/../x` 条目或超大单条目的归档 | 恢复被拒绝并给出原因，数据根外无新文件，进程内存不被撑爆 | B-34 |
| E9 | 切换嵌入模型 | 用不同维度的嵌入模型替换默认模型，再提问与写记忆 | 对话不报错：知识库降级为关键词结果；记忆召回降级关键词；新增/编辑记忆正常落库 | B-35 |

## F. CI / 自动化（每版必测）

| # | 检查 | 期望 |
|---|---|---|
| F1 | 每个长步骤有 `timeout-minutes` | 单步异常不会拖死整条流水线 |
| F2 | 验收/评测结束 | 进程立即退出，日志先出现结论再退出，无端口残留 |
| F3 | E2E 失败产物 | `playwright-artifacts` 含 trace/screenshot/error-context |
| F4 | 串行 spec 重试 | 重试从组头开始且状态复位，不依赖上一次残留 |
| F5 | 视觉巡检 | 非阻断观察期内失败可下载 `visual-diff` 对比 |
